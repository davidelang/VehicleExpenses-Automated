# <a id="vehicle-expenses-automated--user-manual"></a>ವಾಹನ ವೆಚ್ಚಗಳು ಸ್ವಯಂಚಾಲಿತ — ಬಳಕೆದಾರರ ಕೈಪಿಡಿ

> **ಮೂಲವನ್ನು ಸಂಪಾದಿಸಿ (ಮಾರ್ಕ್‌ಡೌನ್).** ಬ್ರೌಸರ್‌ಗಳು ಮತ್ತು ಇನ್-ಆಪ್ ರೀಡರ್ **ರೆಂಡರ್ ಮಾಡಿದ HTML** ಅನ್ನು ತೆರೆಯುತ್ತದೆ:
> - ವೆಬ್: [`docs/user-manual/index.html`](index.html) (`./scripts/render-user-manual.sh` ನೊಂದಿಗೆ ಮರುಸೃಷ್ಟಿ)
> - ಅಪ್ಲಿಕೇಶನ್: ಸಹಾಯ / ಬಗ್ಗೆ → ಪೂರ್ಣ ಕೈಪಿಡಿ (ಬಂಡಲ್ ಮಾಡಿದ HTML + ಸ್ಕ್ರೀನ್‌ಶಾಟ್‌ಗಳು)
>
> ಕಚ್ಚಾ `.md` URL ಗಳಲ್ಲಿ ಅಂತಿಮ ಬಳಕೆದಾರರನ್ನು ಸೂಚಿಸಬೇಡಿ - ಬ್ರೌಸರ್‌ಗಳು ಸರಳ ಪಠ್ಯವನ್ನು ಮಾತ್ರ ತೋರಿಸುತ್ತವೆ.

**ನಿಮ್ಮ** ಕ್ಲೌಡ್ ಖಾತೆಗಳ ಅಡಿಯಲ್ಲಿ ಐಚ್ಛಿಕ ಬಹು-ಸಾಧನ ಸಿಂಕ್ ಮತ್ತು ಬ್ಯಾಕಪ್‌ನೊಂದಿಗೆ ಇಂಧನ ತುಂಬುವಿಕೆಗಳು ಮತ್ತು ವಾಹನ ವೆಚ್ಚಗಳಿಗಾಗಿ ಕ್ಯಾಮೆರಾ-ಮೊದಲ ಟ್ರ್ಯಾಕಿಂಗ್.

ಇದು **ಪೂರ್ಣ ಕೈಪಿಡಿ** (ಸ್ಕ್ರೀನ್‌ಶಾಟ್‌ಗಳು + ಪ್ರತಿ ಹಂತ). ಫೋನ್‌ನಲ್ಲಿ, **ಮೆನು → ಸಹಾಯ** ಚಿಕ್ಕದಾದ ಪ್ರಾರಂಭಿಕ ಮಾರ್ಗದರ್ಶಿಯಾಗಿದೆ.

**ಇಲ್ಲಿ ಒಳಗೊಂಡಿಲ್ಲ:** ಹಳೆಯ ಚಿತ್ರಗಳು, ಜೋಡಣೆ ಪ್ರಯೋಗ ಮತ್ತು ಪಂಪ್ ಪ್ರಯೋಗ (ಡೆವಲಪರ್ / ಸುಧಾರಿತ ಉಪಕರಣಗಳು) ಆಮದು ಮಾಡಿ.

## <a id="open-the-menu"></a>ಮೆನು ತೆರೆಯಿರಿ

1. ಮೇಲಿನ ಎಡಭಾಗದಲ್ಲಿ **☰** ಟ್ಯಾಪ್ ಮಾಡಿ.
2. ಪುಟವನ್ನು ಆರಿಸಿ.

![ನ್ಯಾವಿಗೇಷನ್ ಡ್ರಾಯರ್](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/01-drawer.jpg)

**ಮುಖ್ಯ ಡ್ರಾಯರ್:** ಭರ್ತಿ · ಪ್ರಯಾಣವನ್ನು ಪ್ರಾರಂಭಿಸಿ · ವಾಹನಗಳನ್ನು ನಿರ್ವಹಿಸಿ · ಹೊಸ ವೆಚ್ಚ · **ವರದಿಗಳು** · ಸೆಟ್ಟಿಂಗ್‌ಗಳು · ಸಿಂಕ್ ಮಾಡಲಾಗುತ್ತಿದೆ · ಸಹಾಯ · ಕುರಿತು.

**ಪ್ರಯೋಗ ಡ್ರಾಯರ್** (ಸೆಟ್ಟಿಂಗ್‌ಗಳು → ಪ್ರಯೋಗ ಪರದೆಗಳನ್ನು ತೋರಿಸಿ): ಜೋಡಣೆ ಪ್ರಯೋಗ · ಪಂಪ್ ಪ್ರಯೋಗ · **ಹಳೆಯ ಚಿತ್ರಗಳನ್ನು ಆಮದು ಮಾಡಿ**.

**ವರದಿಗಳ ಹಬ್ ಮೂಲಕ (ಮುಖ್ಯ ಡ್ರಾಯರ್ ಅಲ್ಲ):** ವೆಚ್ಚಗಳ ಪಟ್ಟಿ · ಇತಿಹಾಸವನ್ನು ಭರ್ತಿ ಮಾಡಿ.

## <a id="first-time-setup-manage-vehicles"></a>ಮೊದಲ ಬಾರಿಯ ಸೆಟಪ್: ವಾಹನಗಳನ್ನು ನಿರ್ವಹಿಸಿ

OCR ಮತ್ತು **ಸ್ವಯಂಚಾಲಿತ ವಾಹನ ಹೊಂದಾಣಿಕೆ** ನೀವು ಪ್ರತಿ ವಾಹನವನ್ನು **ಉಲ್ಲೇಖ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಫೋಟೋ** ಜೊತೆಗೆ ನೋಂದಾಯಿಸಿದ ನಂತರ, **ಡಿಸ್ಕವರಿ** ರನ್ ಮಾಡಿ, ಪ್ಯಾಡಲ್ ಸೀಡ್‌ನಿಂದ ಓಡೋಮೀಟರ್ ಕ್ರಾಪ್ ಅನ್ನು ಹೊಂದಿಸಿ ಮತ್ತು ಆ ಡ್ಯಾಶ್‌ಗಾಗಿ ಲ್ಯಾಂಡ್‌ಮಾರ್ಕ್‌ಗಳನ್ನು ಉಳಿಸಿದ ನಂತರ ಉತ್ತಮವಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ.

### <a id="open-manage-vehicles"></a>ಓಪನ್ ಮ್ಯಾನೇಜ್ ವೆಹಿಕಲ್ಸ್

ಮೆನು → **ವಾಹನಗಳನ್ನು ನಿರ್ವಹಿಸಿ**. ವಾಹನವನ್ನು ಆಯ್ಕೆಮಾಡಿ (ಅಥವಾ **ಹೊಸ ವಾಹನವನ್ನು ಸೇರಿಸಿ**).

![ಉಲ್ಲೇಖ ಡ್ಯಾಶ್, ಬೆಳೆಗಳು ಮತ್ತು ಅನ್ವೇಷಣೆಯೊಂದಿಗೆ ವಾಹನಗಳನ್ನು ನಿರ್ವಹಿಸಿ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a> ವಾಹನವನ್ನು ಸೇರಿಸಿ ಅಥವಾ ಸಂಪಾದಿಸಿ

1. **ವಾಹನ** ಡ್ರಾಪ್‌ಡೌನ್ ತೆರೆಯಿರಿ → ವಾಹನವನ್ನು ಆರಿಸಿ ಅಥವಾ **ಹೊಸ ವಾಹನವನ್ನು ಸೇರಿಸಿ**.
2. ಸ್ಪಷ್ಟವಾದ **ಉಲ್ಲೇಖದ ಡ್ಯಾಶ್ ಫೋಟೋ** ಅನ್ನು ಸೆರೆಹಿಡಿಯಿರಿ ಅಥವಾ ಆರಿಸಿಕೊಳ್ಳಿ **ಫೋಟೋ ತೆಗೆಯಿರಿ** ಅಥವಾ **ಗ್ಯಾಲರಿ** ಬಳಸಿ.
3. ** ರನ್ ಡಿಸ್ಕವರಿ** ಟ್ಯಾಪ್ ಮಾಡಿ — ಪ್ಯಾಡಲ್ ಪತ್ತೆ ಹಚ್ಚುವಿಕೆ ಫೋಟೋದಲ್ಲಿ ಹಳದಿ **ಬೀಜಗಳನ್ನು** ಇರಿಸುತ್ತದೆ (ಹೆಗ್ಗುರುತುಗಳು ಮೊದಲಿನಂತೆಯೇ `"ML Kit"` JSON ಅನ್ನು ಬಳಸುತ್ತವೆ).
4. **ಆಯ್ಕೆ ಓಡೋ** ಅನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿ, ಅಂಕಿಗಳ ಮೇಲೆ ಬೀಜವನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿ, ಹ್ಯಾಂಡಲ್‌ಗಳನ್ನು ಹೊಂದಿಸಿ, ನಂತರ **ಉಳಿಸಿ**.
5. **ಎಡಿಟ್ ಓಡೋ** ಈಗಾಗಲೇ ಇರುವ ಬಾಕ್ಸ್ ಅನ್ನು ಸರಿಹೊಂದಿಸುತ್ತದೆ. ** ತೆರವುಗೊಳಿಸಿ ಓಡೋ** ಅದನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ, ಮತ್ತು ಬಟನ್ ನಂತರ **ಓಡೊ ಆಯ್ಕೆಮಾಡಿ** ಎಂದು ಓದುತ್ತದೆ.
6. **ಹೆಗ್ಗುರುತುಗಳನ್ನು ತೋರಿಸು** ಜೊತೆಗೆ ಪರಿಶೀಲಿಸಿ. ತಪ್ಪಾಗಿ ಓದುವುದನ್ನು ಸರಿಪಡಿಸಲು **ಓಸಿಆರ್ ಸಂಪಾದಿಸಿ** ಬಳಸಿ ಅಥವಾ ತಪ್ಪಿಸಿಕೊಂಡ ಪಠ್ಯವನ್ನು ** ಸೇರಿಸಿ** ಬಳಸಿ.
7. **ವಾಹನದ ಹೆಸರು** (ಅಗತ್ಯವಿದೆ), ಜೊತೆಗೆ ನೀವು ಬಯಸಿದಂತೆ ಮಾಡಿ/ಮಾದರಿ/ವರ್ಷ/ಪ್ಲೇಟ್ ಅನ್ನು ಭರ್ತಿ ಮಾಡಿ.
8. **ವಾಹನವನ್ನು ರಚಿಸಿ** ಅಥವಾ **ಬದಲಾವಣೆಗಳನ್ನು ಉಳಿಸಿ** ಟ್ಯಾಪ್ ಮಾಡಿ (ಹೊಸ ವಾಹನಕ್ಕೆ ಹೆಸರು + ಉಲ್ಲೇಖದ ಫೋಟೋ ಅಗತ್ಯವಿದೆ).

### <a id="landmarks-fix-what-discovery-missed"></a>ಹೆಗ್ಗುರುತುಗಳು: ಡಿಸ್ಕವರಿ ತಪ್ಪಿಸಿಕೊಂಡದ್ದನ್ನು ಸರಿಪಡಿಸಿ

**ಹೆಗ್ಗುರುತುಗಳನ್ನು ತೋರಿಸಿ** ನಂತರ, ಪಟ್ಟಿಯನ್ನು ಸ್ಕ್ರಾಲ್ ಮಾಡಿ ಮತ್ತು ಮೌಲ್ಯಗಳನ್ನು ಸರಿಪಡಿಸಿ. ಎಂಜಿನ್‌ಗಳು ಕೆಲವೊಮ್ಮೆ ಸಣ್ಣ ಅಂಕೆಗಳನ್ನು ಕಳೆದುಕೊಳ್ಳುತ್ತವೆ (ಉದಾಹರಣೆಗೆ ಕ್ಲಸ್ಟರ್‌ನ ಕೆಳಗಿನ ಬಲಭಾಗದಲ್ಲಿ ಗಡಿಯಾರ **60**). ಅವುಗಳನ್ನು ಸೇರಿಸಲು ಅಥವಾ ಸರಿಪಡಿಸಲು **ಎಡಿಟ್ OCR** ​​ಅನ್ನು ಬಳಸಿ ಇದರಿಂದ ವಾಹನದ ಗುರುತು ವಿಶ್ವಾಸಾರ್ಹವಾಗಿರುತ್ತದೆ.

![ಲ್ಯಾಂಡ್‌ಮಾರ್ಕ್‌ಗಳ ಸಂವಾದ - OCR ಅನ್ನು ಪರಿಶೀಲಿಸಿ ಮತ್ತು ಸಂಪಾದಿಸಿ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a>Typing without a perfect photo

ನೀವು ಇನ್ನೂ ವಾಹನವನ್ನು ಆಯ್ಕೆ ಮಾಡುವ ಮೂಲಕ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಬಳಸಬಹುದು ಮತ್ತು **ಟೈಪಿಂಗ್** ಓಡೋಮೀಟರ್, ವಾಲ್ಯೂಮ್ ಮತ್ತು ಫಿಲ್‌ನಲ್ಲಿ ವೆಚ್ಚ - OCR ಪ್ರತಿ ಕ್ಷೇತ್ರಕ್ಕೂ ಐಚ್ಛಿಕವಾಗಿರುತ್ತದೆ. ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ಶೂಟ್ ಮಾಡದಿರಲು ನೀವು ಬಯಸಿದಾಗ ರೆಫರೆನ್ಸ್ ಡ್ಯಾಶ್ ಫೋಟೋಗಾಗಿ ಗ್ಯಾಲರಿ ಆಮದು ಕೆಲಸ ಮಾಡುತ್ತದೆ.

**ಸಲಹೆ:** ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಸಿಂಕ್ ನಂತರ, ವಾಹನದ ವ್ಯಾಖ್ಯಾನಗಳು (ಬೆಳೆಗಳು, ಹೆಗ್ಗುರುತುಗಳು) ಸ್ಥಳೀಯ ಡೇಟಾಬೇಸ್‌ನಲ್ಲಿ ಲೈವ್ ಆಗುತ್ತವೆ - ಅವುಗಳನ್ನು ಬಳಸಲು ನೀವು ತುಂಬಲು ವಾಹನಗಳನ್ನು ನಿರ್ವಹಿಸಿ ಮರು-ತೆರೆಯುವ ಅಗತ್ಯವಿಲ್ಲ.

## <a id="backups-and-multi-device-sync"></a>Backups ಮತ್ತು ಬಹು-ಸಾಧನ ಸಿಂಕ್

ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ನಿರ್ಮಿಸಲಾಗಿದೆ ಆದ್ದರಿಂದ **ಹಲವಾರು ಫೋನ್‌ಗಳು ಅಥವಾ ಟ್ಯಾಬ್ಲೆಟ್‌ಗಳು ಒಂದೇ ಫ್ಲೀಟ್ ಡೇಟಾವನ್ನು ಹಂಚಿಕೊಳ್ಳಬಹುದು**, ಆದ್ದರಿಂದ ನೀವು ** ನಿಮ್ಮ ಡೇಟಾ ಮತ್ತು ಫೋಟೋಗಳ ನಕಲನ್ನು ಸಾಧನದಿಂದ ಹೊರಗಿಡಬಹುದು**. ಇದನ್ನು **ನೀವು** **ನಿಮ್ಮ** ಖಾತೆಗಳು ಅಥವಾ **ನಿಮ್ಮ** ಸ್ವಯಂ-ಹೋಸ್ಟ್ ಮಾಡಿದ ಸರ್ವರ್‌ಗಳ ಅಡಿಯಲ್ಲಿ ಕಾನ್ಫಿಗರ್ ಮಾಡಿದ ಗಮ್ಯಸ್ಥಾನಗಳೊಂದಿಗೆ ಮಾಡಲಾಗುತ್ತದೆ - ಇತರ ಜನರು ನೋಡಬಹುದಾದ ಕಂಪನಿ-ಚಾಲಿತ "ವಾಹನ ವೆಚ್ಚಗಳ ಕ್ಲೌಡ್" ಅಲ್ಲ.

### <a id="what-runs-where"></a>ಯಾವುದು ಎಲ್ಲಿ ಓಡುತ್ತದೆ

| ರೀತಿಯ | ಇದು ಏನು ಸಂಗ್ರಹಿಸುತ್ತದೆ | ವಿಶಿಷ್ಟ ಬಳಕೆ |
|------|---------------|------------|
| **ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ / ಕೋಷ್ಟಕ ಸಿಂಕ್** | ವಾಹನಗಳು, ಇಂಧನ ತುಂಬುವಿಕೆಗಳು, ವೆಚ್ಚಗಳು (ಸಾಲುಗಳು ಮತ್ತು ಟ್ಯಾಬ್‌ಗಳು) | ಬಹು-ಸಾಧನ ವಿಲೀನ + ರಚನಾತ್ಮಕ ಬ್ಯಾಕಪ್ |
| **ಫೋಟೋ ಬ್ಯಾಕಪ್** | ಬೈನರಿ ಚಿತ್ರಗಳು (ಡ್ಯಾಶ್/ಪಂಪ್/ರಶೀದಿ/ಉಲ್ಲೇಖ ಫೋಟೋಗಳು) | ಫೋಟೋ ಬ್ಯಾಕಪ್ + ಕಾಣೆಯಾದ ಫೈಲ್‌ಗಳನ್ನು ಮರುಸ್ಥಾಪಿಸಿ |

ನೀವು ಪ್ರತಿ ಪ್ರಕಾರದ **ಬಹು ಗಮ್ಯಸ್ಥಾನಗಳನ್ನು** ಕಾನ್ಫಿಗರ್ ಮಾಡಬಹುದು (ಪ್ರತಿ ಪ್ರಕಾರಕ್ಕೆ ಸಾಫ್ಟ್ ಕ್ಯಾಪ್). ಹಸ್ತಚಾಲಿತ **ಈಗ ಸಿಂಕ್ ಮಾಡಿ** ಮತ್ತು **ಹಿನ್ನೆಲೆ** ಕೆಲಸಗಾರರು ಸಕ್ರಿಯಗೊಳಿಸಿದವುಗಳನ್ನು ರನ್ ಮಾಡುತ್ತಾರೆ.

### <a id="offline-first"></a>Offline ಮೊದಲು

- **ಯಾವುದೇ ನೆಟ್‌ವರ್ಕ್ ಅಗತ್ಯವಿಲ್ಲ** ಭರ್ತಿ, ವೆಚ್ಚ ಅಥವಾ ರಸೀದಿಯನ್ನು ಸೇರಿಸಲು. ಎಲ್ಲವನ್ನೂ ಉಳಿಸಲಾಗಿದೆ **ಸ್ಥಳೀಯವಾಗಿ ಮೊದಲು**.
- ನೆಟ್‌ವರ್ಕ್ ಲಭ್ಯವಿದ್ದಾಗ, ಸಿಂಕ್ ಮತ್ತು ಫೋಟೋ ಬ್ಯಾಕಪ್ **ಹಿನ್ನೆಲೆ ಕಾರ್ಯಗಳು** (ನೀವು ಹೊಂದಿಸಿರುವ ವೇಳಾಪಟ್ಟಿಯಲ್ಲಿ ಮತ್ತು ನೀವು **ಸಿಂಕ್ ಈಗ** ಟ್ಯಾಪ್ ಮಾಡಿದಾಗ). ವೈಫಲ್ಯಗಳು ಸೆಟ್ಟಿಂಗ್‌ಗಳ ಸಾಲುಗಳ ಅಡಿಯಲ್ಲಿ ಕೆಂಪು ಪಠ್ಯ ಮತ್ತು ಅಪ್ಲಿಕೇಶನ್ ಶೀರ್ಷಿಕೆ ಪಟ್ಟಿಯಲ್ಲಿ **!** ಎಂದು ತೋರಿಸುತ್ತವೆ.

### <a id="your-accounts-only"></a>ನಿಮ್ಮ ಖಾತೆಗಳು ಮಾತ್ರ

ಸೈನ್-ಇನ್ ಮತ್ತು ಟೋಕನ್‌ಗಳು ನೀವು ಆಯ್ಕೆ ಮಾಡುವ ಪೂರೈಕೆದಾರರಿಗೆ ಸಾಧನದಲ್ಲಿ ಉಳಿಯುತ್ತವೆ (Google, Microsoft, S3 ಕೀಗಳು, ಸ್ವಯಂ-ಹೋಸ್ಟ್ ಮಾಡಿದ URL ಗಳು, ಇತ್ಯಾದಿ). ಗಮ್ಯಸ್ಥಾನಗಳು ಬಳಕೆದಾರರ ಸಂಪೂರ್ಣ ನಿಯಂತ್ರಣದಲ್ಲಿದೆ** — ನಿಮ್ಮ Google ಖಾತೆ, ನಿಮ್ಮ OneDrive, ನಿಮ್ಮ MinIO ಬಕೆಟ್, ನಿಮ್ಮ EtherCalc ಹೋಸ್ಟ್, ಇತ್ಯಾದಿ. ಹಂಚಿಕೊಂಡ ಬ್ಯಾಕೆಂಡ್ ಮೂಲಕ ಇತರ ವಾಹನ ವೆಚ್ಚಗಳ ಬಳಕೆದಾರರೊಂದಿಗೆ ಏನನ್ನೂ ಹಂಚಿಕೊಳ್ಳಲಾಗುವುದಿಲ್ಲ.

### <a id="supported-targets--data-spreadsheet--tabular"></a>ಬೆಂಬಲಿತ ಗುರಿಗಳು — ಡೇಟಾ (ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ / ಕೋಷ್ಟಕ)

**ಮೆನು → ಸಿಂಕ್ ಮಾಡುವಿಕೆ → ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಸಿಂಕ್** ಅಡಿಯಲ್ಲಿ ಕಾನ್ಫಿಗರ್ ಮಾಡಲಾಗಿದೆ (ಸೆಟ್ಟಿಂಗ್‌ಗಳ ಸಾರಾಂಶ ಸಾಲುಗಳಿಂದಲೂ ಸಹ ತಲುಪಬಹುದು). ಪ್ರಥಮ ದರ್ಜೆ ಪಿಕ್ಕರ್ ಆಯ್ಕೆಗಳು:

| ಗುರಿ | ಟಿಪ್ಪಣಿಗಳು |
|---------|---------|
| **ಗೂಗಲ್ ಶೀಟ್‌ಗಳು** | ಸಾಮಾನ್ಯ ಡೀಫಾಲ್ಟ್; ವಾಹನಗಳು, ವೆಚ್ಚಗಳು ಮತ್ತು ಪ್ರತಿ ವಾಹನ ಇಂಧನಕ್ಕಾಗಿ ಟ್ಯಾಬ್‌ಗಳು |
| **ಎಕ್ಸೆಲ್** | ಗ್ರಾಫ್ / ಒನ್‌ಡ್ರೈವ್-ಶೈಲಿಯ ಬೈಂಡಿಂಗ್ ಮೂಲಕ ಮೈಕ್ರೋಸಾಫ್ಟ್ ವರ್ಕ್‌ಬುಕ್ |
| **EtherCalc** | ಸ್ವಯಂ ಹೋಸ್ಟ್ ಮಾಡಿದ ಸಹಯೋಗದ ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಕೊಠಡಿಗಳು |
| **ಇತರ →** ಕಾರ್ಯಗತಗೊಳಿಸಿದ ಬ್ಯಾಕೆಂಡ್‌ಗಳು | **Baserow**, **NocoDB**, **Airtable**, **PocketBase**, **Supabase**, **Firebase**, **Zoho Sheet** |

ಮುಂದೂಡಲಾಗಿದೆ / ಇನ್ನೂ ತಲೆರಹಿತವಾಗಿಲ್ಲ (ಇತರ ಅಡಿಯಲ್ಲಿ ಪಟ್ಟಿ ಮಾಡಲಾಗಿದೆ ಆದರೆ ಸಂಪೂರ್ಣವಾಗಿ ಕಾರ್ಯಗತಗೊಳಿಸಲಾಗಿಲ್ಲ): ಕೇವಲ ಕಚೇರಿ, ಸಹಯೋಗ. ಇದನ್ನೂ ನೋಡಿ [ಸ್ವಯಂ-ಹೋಸ್ಟ್ ಇಂಡೆಕ್ಸ್](reference/self-host/INDEX.md).

CSV **ರಫ್ತು/ಆಮದು** (ಅದೇ ಟ್ಯಾಬ್ ಲೇಔಟ್‌ನ ZIP) ಲೈವ್ ಸಿಂಕ್‌ನಿಂದ ಸ್ವತಂತ್ರವಾಗಿ ಪೋರ್ಟಬಲ್ ಬ್ಯಾಕಪ್‌ನಂತೆ ಸೆಟ್ಟಿಂಗ್‌ಗಳಿಂದ ಲಭ್ಯವಿದೆ.

### <a id="supported-targets--photos-image-backup"></a>ಬೆಂಬಲಿತ ಗುರಿಗಳು — ಫೋಟೋಗಳು (ಇಮೇಜ್ ಬ್ಯಾಕಪ್)

**ಮೆನು → ಸಿಂಕ್ ಮಾಡುವಿಕೆ → ಫೋಟೋ ಬ್ಯಾಕಪ್** ಅಡಿಯಲ್ಲಿ ಕಾನ್ಫಿಗರ್ ಮಾಡಲಾಗಿದೆ (ಸೆಟ್ಟಿಂಗ್‌ಗಳ ಸಾರಾಂಶ ಸಾಲುಗಳಿಂದ ಕೂಡ):

| ಗುರಿ | ಟಿಪ್ಪಣಿಗಳು |
|---------|---------|
| **Google ಡ್ರೈವ್** | ನೀವು ಆಯ್ಕೆ ಮಾಡುವ ಫೋಲ್ಡರ್ (ಬ್ರೌಸ್ ಅಥವಾ ಪೇಸ್ಟ್ URL) |
| **OneDrive** | Microsoft ಖಾತೆ + ಮಾರ್ಗ ಪೂರ್ವಪ್ರತ್ಯಯ |
| **S3** | AWS, Wasabi, Cloudflare R2, MinIO, ಮತ್ತು ಇತರ S3-ಹೊಂದಾಣಿಕೆಯ ಅಂತಿಮ ಬಿಂದುಗಳು |
| **ಇತರ** | rclone-ಬೆಂಬಲಿತ ಸಂಗ್ರಹಣೆ (ಉದಾ. WebDAV, SFTP, ಮತ್ತು ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿನ ಪಿಕರ್‌ನಲ್ಲಿ ಲಭ್ಯವಿರುವ ಇತರ ಕ್ಯುರೇಟೆಡ್ ರಿಮೋಟ್‌ಗಳು) |

ಸ್ವಯಂ-ಹೋಸ್ಟ್ ಮಾಡಿದ ಫೋಟೋ ಮತ್ತು ಕೋಷ್ಟಕ ಗುರಿಗಳಿಗಾಗಿ ಚೀಟ್‌ಶೀಟ್‌ಗಳನ್ನು ಸೆಟಪ್ ಮಾಡಿ: [ಸ್ವಯಂ-ಹೋಸ್ಟ್ ಇಂಡೆಕ್ಸ್](reference/self-host/INDEX.md).

### <a id="multi-device-behavior-short"></a>ಮಲ್ಟಿ-ಡಿವೈಸ್ ನಡವಳಿಕೆ (ಸಣ್ಣ)

- **ಸಿಂಕ್ ಐಡಿ** ಮೂಲಕ **ಕೊನೆಯ-ಬರೆ-ಗೆಲುವು** **ನವೀಕರಿಸಿದ** ಟೈಮ್‌ಸ್ಟ್ಯಾಂಪ್‌ಗಳಲ್ಲಿ ಸಾಲುಗಳು ವಿಲೀನಗೊಳ್ಳುತ್ತವೆ.
- ಅಳಿಸುವಿಕೆಗಳು ಮೃದುವಾಗಿರುತ್ತವೆ; ಮತ್ತೊಂದು ಸಾಧನದಲ್ಲಿ ಹೊಸ ಸಂಪಾದನೆಯು ಸಾಲನ್ನು ಮರುಸ್ಥಾಪಿಸಬಹುದು.
- ಎರಡು ಸಾಧನಗಳಲ್ಲಿ **ಅದೇ ಫಿಲ್ ಅನ್ನು ಎರಡು ಬಾರಿ** ನಮೂದಿಸುವುದು **ಎರಡು ಸಾಲುಗಳನ್ನು ರಚಿಸುತ್ತದೆ** — ನೀವು ಗಮನಿಸಿದಾಗ ಹೆಚ್ಚುವರಿ ಅಳಿಸಿ.
- ಹೆಚ್ಚಿನ ವಿವರ: [ಸಿಂಕ್ ನಡವಳಿಕೆ ಟಿಪ್ಪಣಿಗಳು](#sync-behavior-notes) ಮತ್ತು [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md).

### <a id="example-add-google-sheets-data"></a>ಉದಾಹರಣೆ: Google ಶೀಟ್‌ಗಳನ್ನು ಸೇರಿಸಿ (ಡೇಟಾ)

1. **ಮೆನು → ಸಿಂಕ್ ಮಾಡುವಿಕೆ → ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಸಿಂಕ್** (ಅಥವಾ ಸೆಟ್ಟಿಂಗ್‌ಗಳು → ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಸಿಂಕ್).

![ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಸಿಂಕ್ ಪಟ್ಟಿ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/08-spreadsheet-sync.jpg)

2. **ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಗಮ್ಯಸ್ಥಾನವನ್ನು ಸೇರಿಸಿ** ಟ್ಯಾಪ್ ಮಾಡಿ.

![ಪ್ರೊವೈಡರ್ ಪಿಕರ್](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/09-spreadsheet-provider-picker.jpg)

3. **Google ಶೀಟ್‌ಗಳನ್ನು** ಆಯ್ಕೆಮಾಡಿ.

![Google ಶೀಟ್‌ಗಳ ಫಾರ್ಮ್](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/10-spreadsheet-google-form.jpg)

4. **Google ನೊಂದಿಗೆ ಸೈನ್ ಇನ್ ಮಾಡಿ** ಒಮ್ಮೆ — ಆ ಸೈನ್-ಇನ್ ನಿಮಗೆ ಬ್ರೌಸ್ ಮಾಡಲು ಸಹ ಅನುಮತಿಸುತ್ತದೆ. ಪ್ರದರ್ಶನ ಹೆಸರು → **ಶೀಟ್ URL** (ಇನ್ನೂ ಮಾನ್ಯ) ಅಂಟಿಸಿ ಅಥವಾ **🔍** ಬ್ರೌಸ್ ಮಾಡಿ. **ಎಲ್ಲಾ ಮತ್ತು ಹಂಚಿಕೊಂಡಿರುವ** ನಲ್ಲಿ ಬ್ರೌಸ್ ತೆರೆಯುತ್ತದೆ ಆದ್ದರಿಂದ ನೀವು ಹೊಂದಿರುವ ಅಥವಾ ನಿಮ್ಮೊಂದಿಗೆ ಹಂಚಿಕೊಂಡಿರುವ ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಅನ್ನು ನೀವು ಆಯ್ಕೆ ಮಾಡಬಹುದು. ನಂತರ ಆಯ್ಕೆಗಳನ್ನು ನಿಗದಿಪಡಿಸಿ → ಸಕ್ರಿಯಗೊಳಿಸಿ → ಉಳಿಸಿ.
5. ಟ್ಯಾಬ್‌ಗಳನ್ನು ರಚಿಸಲು/ಅಪ್‌ಡೇಟ್ ಮಾಡಲು **ಈಗ ಸಿಂಕ್ ಮಾಡಿ** ಒಮ್ಮೆ: `Vehicles`, `Expenses`, `Fuel - {vehicle name}`.

### <a id="example-add-google-drive-photos"></a>ಉದಾಹರಣೆ: Google ಡ್ರೈವ್ ಸೇರಿಸಿ (ಫೋಟೋಗಳು)

1. **ಮೆನು → ಸಿಂಕ್ ಮಾಡುವಿಕೆ → ಫೋಟೋ ಬ್ಯಾಕಪ್** (ಅಥವಾ ಸೆಟ್ಟಿಂಗ್‌ಗಳು → ಫೋಟೋ ಬ್ಯಾಕಪ್).

![ಫೋಟೋ ಬ್ಯಾಕಪ್ ಪಟ್ಟಿ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/11-photo-backup.jpg)

2. **ಫೋಟೋ ಗಮ್ಯಸ್ಥಾನವನ್ನು ಸೇರಿಸಿ** ಟ್ಯಾಪ್ ಮಾಡಿ.

![ಫೋಟೋ ಪೂರೈಕೆದಾರ ಪಿಕರ್](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/12-photo-provider-picker.jpg)

3. **Google ಡ್ರೈವ್** ಆಯ್ಕೆಮಾಡಿ.

![Google ಡ್ರೈವ್ ಫಾರ್ಮ್](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/13-photo-google-form.jpg)

4. **Google (ಡ್ರೈವ್) ನೊಂದಿಗೆ ಸೈನ್ ಇನ್ ಮಾಡಿ** → ಐಚ್ಛಿಕ ಫೋಲ್ಡರ್ URL/ಬ್ರೌಸ್ → ಸಕ್ರಿಯಗೊಳಿಸಿ → ಉಳಿಸಿ → **ಈಗ ಸಿಂಕ್ ಮಾಡಿ**.

ಫೋಟೋಗಳಿಗಾಗಿ **ಈಗ ಸಿಂಕ್ ಮ್ಯಾನುಯಲ್** ಸಂಪೂರ್ಣ ಪ್ರಕ್ರಿಯೆ; ಬ್ಯಾಕ್‌ಗ್ರೌಂಡ್ ಬ್ಯಾಕಪ್ ಸಾಮಾನ್ಯವಾಗಿ ಸಮಯಾನುಸಾರ **ಮಾತ್ರ ಮೌಲ್ಯಕ್ಕಿಂತಲೂ** ಅಪ್‌ಲೋಡ್‌ಗಳನ್ನು ಪ್ರಕ್ರಿಯಿಸುತ್ತದೆ.

### <a id="sync-behavior-notes"></a> ನಡವಳಿಕೆ ಟಿಪ್ಪಣಿಗಳನ್ನು ಸಿಂಕ್ ಮಾಡಿ

- ಅಪ್ಲಿಕೇಶನ್ ಅಪ್‌ಗ್ರೇಡ್ ನಂತರ ನೀವು ಸಂಕ್ಷಿಪ್ತವಾಗಿ **“ಅಪ್‌ಗ್ರೇಡ್ ಮಾಡಿದ ನಂತರ ಡೇಟಾಬೇಸ್ ಅನ್ನು ನವೀಕರಿಸಲಾಗುತ್ತಿದೆ…”** (ಸ್ಥಳೀಯ ಸಿಂಕ್-ಐಡಿ ಬ್ಯಾಕ್‌ಫಿಲ್) ಅನ್ನು ನೋಡಬಹುದು.
- ಸಿಂಕ್‌ಗೆ ಅಡ್ಡಿಯುಂಟಾದರೆ, ಮುಂದಿನ **ಯಶಸ್ವಿ** ಸಿಂಕ್ ರಿಮೋಟ್ ಟ್ಯಾಬ್‌ಗಳನ್ನು ಮರು ವಿಲೀನಗೊಳಿಸುತ್ತದೆ ಮತ್ತು ರಿಪೇರಿ ಮಾಡುತ್ತದೆ.
- ವೈಫಲ್ಯಗಳು: ಅಪ್ಲಿಕೇಶನ್ ಬಾರ್‌ನಲ್ಲಿ ಸಿಂಕ್ ಮಾಡುವ ಕಾರ್ಡ್‌ಗಳಲ್ಲಿ ಕೆಂಪು ಸಾರಾಂಶ + **!**.

## <a id="fill-up-fuel"></a>Fill (ಇಂಧನ)

ನೀವು ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ತೆರೆದಾಗ ಇದು **ಹೋಮ್ ಸ್ಕ್ರೀನ್** ಆಗಿದೆ.

### <a id="vehicle-selection-usually-automatic"></a>ವಾಹನ ಆಯ್ಕೆ (ಸಾಮಾನ್ಯವಾಗಿ ಸ್ವಯಂಚಾಲಿತ)

ನೀವು **ಅಲ್ಲ** ಮೊದಲು ವಾಹನವನ್ನು ಆರಿಸಬೇಕಾಗುತ್ತದೆ. ವಾಹನಗಳು ನಿರ್ವಹಣಾ ವಾಹನಗಳಲ್ಲಿ **ಹೆಗ್ಗುರುತುಗಳನ್ನು** ಹೊಂದಿಸಿದಾಗ, ನೀವು ದೂರಮಾಪಕವನ್ನು ಸೆರೆಹಿಡಿದ ನಂತರ ಡ್ಯಾಶ್ ಚಿತ್ರದಿಂದ **ಯಾವ ವಾಹನವನ್ನು** ಅನ್ನು ಭರ್ತಿ ಮಾಡಿ. ಅಗತ್ಯವಿದ್ದರೆ ಅತಿಕ್ರಮಿಸಲು ನೀವು ಇನ್ನೂ **ವಾಹನ** ಡ್ರಾಪ್‌ಡೌನ್ ಅನ್ನು ತೆರೆಯಬಹುದು.

### <a id="aim-at-the-odometer"></a> ದೂರಮಾಪಕವನ್ನು ಗುರಿಮಾಡಿ

ಓಡೋಮೀಟರ್ ಮೋಡ್‌ನಲ್ಲಿ ಇರಿ ಮತ್ತು ಕ್ಲಸ್ಟರ್ ಅನ್ನು ಫ್ರೇಮ್ ಮಾಡಿ. ಸೂಚನೆ: * ದೂರಮಾಪಕವನ್ನು ಗುರಿಯಾಗಿಸಿ. ಸೆರೆಹಿಡಿಯಲು ಶಟರ್ ಅನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿ.*

![ಭರ್ತಿ — ಓಡೋಮೀಟರ್‌ನಲ್ಲಿ ಲೈವ್ ಕ್ಯಾಮೆರಾ (ಪೂರ್ವವೀಕ್ಷಣೆಯಲ್ಲಿ ಉದಾಹರಣೆ ಡ್ಯಾಶ್ ಚಿತ್ರ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a> ಓಡೋಮೀಟರ್ ಶಟರ್ ನಂತರ

OCR **Odo** ಅನ್ನು ತುಂಬುತ್ತದೆ ಮತ್ತು ಹೆಗ್ಗುರುತುಗಳಿಂದ ವಾಹನವನ್ನು ಹೊಂದಿಸಲು ಪ್ರಯತ್ನಿಸುತ್ತದೆ (ಅಗತ್ಯವಿದ್ದಲ್ಲಿ ಎರಡನ್ನೂ ಪರಿಶೀಲಿಸಿ). ಮರು-ಶೂಟ್ ಮಾಡಲು ಮುಖ್ಯ ಬಟನ್ **ಮರುಪ್ರಯತ್ನಿಸಿ** ಆಗುತ್ತದೆ. ಸೂಚನೆಯು ಓದುವಿಕೆಯನ್ನು ಸಾರಾಂಶಗೊಳಿಸುತ್ತದೆ.

![ಭರ್ತಿ — ಓಡೋಮೀಟರ್ OCR ಫಲಿತಾಂಶ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a>ಪಂಪ್ ಮೋಡ್ (ವೆಚ್ಚ ಮತ್ತು ಪರಿಮಾಣ)

1. ಪಂಪ್ ಮೋಡ್‌ಗೆ ಬದಲಾಯಿಸಲು **↕** ಟ್ಯಾಪ್ ಮಾಡಿ: *ಪಂಪ್ ಡಿಸ್‌ಪ್ಲೇ (ವೆಚ್ಚ/ವಾಲ್ಯೂಮ್) ನಲ್ಲಿ ಗುರಿ ಮಾಡಿ. ಟ್ಯಾಪ್ ಶಟರ್.*
2. ಪಂಪ್ ಮೊತ್ತವನ್ನು ಸೆರೆಹಿಡಿಯಿರಿ. ವೆಚ್ಚ ಮತ್ತು ಪರಿಮಾಣ ಕ್ಷೇತ್ರಗಳು ಭರ್ತಿ; ಅವುಗಳನ್ನು ಬದಲಾಯಿಸಿದರೆ **↔** ಬಳಸಿ.
3. ಕರೆನ್ಸಿ ಟ್ಯಾಪ್ ಮಾಡಿ ಅಥವಾ **G/L** ಅಗತ್ಯವಿದ್ದರೆ, ನಂತರ **ಉಳಿಸಿ** (ಡಿಸ್ಕ್). ಖಾಲಿ ಜಾಗಗಳು **ಭಾಗಶಃ ಭರ್ತಿ** (ಇನ್ನೂ ಅನುಮತಿಸಲಾಗಿದೆ).

![ಭರ್ತಿ — ಪಂಪ್ ಪೂರ್ವವೀಕ್ಷಣೆ / ಮೊತ್ತಗಳು (ಪೂರ್ವವೀಕ್ಷಣೆಯಲ್ಲಿ ಉದಾಹರಣೆ ಪಂಪ್ ಚಿತ್ರ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

ನೀವು ಮುಂದಿನ ಸ್ಟಾಪ್‌ಗಾಗಿ ಫಿಲ್‌ನಲ್ಲಿಯೇ ಇರುತ್ತೀರಿ (ಉಳಿಸಿದ ನಂತರ ಕ್ಷೇತ್ರಗಳು ತೆರವುಗೊಳಿಸುತ್ತವೆ). ಸಂಪೂರ್ಣವಾಗಿ ಕೆಲಸ **ಆಫ್‌ಲೈನ್**; ಕಾನ್ಫಿಗರ್ ಮಾಡಿದಾಗ ಸಿಂಕ್ ನಂತರ ಹಿನ್ನೆಲೆಯಲ್ಲಿ ರನ್ ಆಗುತ್ತದೆ.

### <a id="manual-entry-no-camera--bad-ocr"></a>ಹಸ್ತಚಾಲಿತ ನಮೂದು (ಯಾವುದೇ ಕ್ಯಾಮರಾ / ಕೆಟ್ಟ OCR ಇಲ್ಲ)

1. **ಓಡೋ**, **ವೆಚ್ಚ**, ಅಥವಾ **ವಾಲ್ಯೂಮ್** ಟ್ಯಾಪ್ ಮಾಡಿ ಮತ್ತು ಮೌಲ್ಯಗಳನ್ನು ಟೈಪ್ ಮಾಡಿ (ಪೋಟ್ರೇಟ್ ಸಿಸ್ಟಮ್ ಕೀಬೋರ್ಡ್ ಅನ್ನು ಬಳಸುತ್ತದೆ; ಲ್ಯಾಂಡ್‌ಸ್ಕೇಪ್ ಆನ್-ಸ್ಕ್ರೀನ್ ಕೀಪ್ಯಾಡ್ ಅನ್ನು ಬಳಸುತ್ತದೆ).
2. ಸ್ವಯಂ ಪತ್ತೆ ಚಾಲನೆ ಮಾಡದಿದ್ದರೆ **ವಾಹನ** ಆಯ್ಕೆಮಾಡಿ ಅಥವಾ ದೃಢೀಕರಿಸಿ.
3. ಮೇಲಿನಂತೆ ಉಳಿಸಿ.

### <a id="modes-and-borders"></a>ಮೋಡ್‌ಗಳು ಮತ್ತು ಗಡಿಗಳು

- **ಗ್ರೀನ್ ಬಾರ್ಡರ್** ವಾಹನ+ಓಡೋ → ಕ್ಯಾಪ್ಚರ್/ಎಡಿಟಿಂಗ್ ಓಡೋಮೀಟರ್ ಸುತ್ತಲೂ.
- **ಹಸಿರು ಅಂಚು** ವೆಚ್ಚ+ವಾಲ್ಯೂಮ್ → ಪಂಪ್ ಮೋಡ್ ಸುತ್ತಲೂ.
- ವಾಹನವನ್ನು ಆಯ್ಕೆಮಾಡುವವರೆಗೆ **ಉಳಿಸು** ನಿಷ್ಕ್ರಿಯವಾಗಿರುತ್ತದೆ ಮತ್ತು ಕನಿಷ್ಠ ಒಂದು ಓಡೋ/ವೆಚ್ಚ/ವಾಲ್ಯೂಮ್‌ನಲ್ಲಿ ಡೇಟಾ ಇರುತ್ತದೆ ಮತ್ತು OCR ಇನ್ನೂ ಚಾಲನೆಯಲ್ಲಿಲ್ಲ.

ಆನ್-ಸ್ಕ್ರೀನ್ ತುದಿ (ಸೂಚನೆ ಸಾಲಿನ ಕೆಳಗೆ): *ಶಟರ್ = ಕ್ಯಾಪ್ಚರ್ · ಡಿಸ್ಕ್ = ಸೇವ್ · ↕ = ಓಡೋ/ಪಂಪ್ ಮೋಡ್ · ↔ = ಸ್ವಾಪ್ ವೆಚ್ಚ/ಸಂಪುಟ.*

## <a id="expenses"></a>ವೆಚ್ಚಗಳು

### <a id="new-expense"></a>ಹೊಸ ವೆಚ್ಚ

ಮೆನು → **ಹೊಸ ವೆಚ್ಚ**.

![ಹೊಸ ವೆಚ್ಚದ ರೂಪ ಮತ್ತು ಕ್ಯಾಮರಾ ನಿಯಂತ್ರಣಗಳು (ಖಾಲಿಯಾಗಿರುವಾಗ ಕ್ಯಾಮರಾ ಬ್ಯಾಂಡ್‌ನಲ್ಲಿ ಡ್ಯಾಶ್ ಚಿತ್ರ ಉದಾಹರಣೆ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r6-new-expense.jpg)

1. **ಉಳಿಸು** (ಡಿಸ್ಕ್), ** ಶಟರ್** (ರಶೀದಿ ಫೋಟೋ), ಅಥವಾ **ಗ್ಯಾಲರಿ** (ಚಿತ್ರವನ್ನು ಆರಿಸಿ).
2. **ದಿನಾಂಕ**, **ವಾಹನ**, **ಮಾರಾಟಗಾರ**, **ವಿವರಣೆ**, **ಮೊತ್ತ** (ಕರೆನ್ಸಿ ಚಿಹ್ನೆ ಟ್ಯಾಪ್ ಮಾಡಬಹುದಾದ), **ವರ್ಗ**, ಐಚ್ಛಿಕ **ಓಡೋಮೀಟರ್** ಅನ್ನು ಭರ್ತಿ ಮಾಡಿ.
3. ಬಹು-ಪುಟ ರಶೀದಿಗಳು: UI ಪೇಜಿಂಗ್ ಅನ್ನು ನೀಡಿದರೆ ಹೆಚ್ಚುವರಿ ಪುಟಗಳನ್ನು ಸೆರೆಹಿಡಿಯಿರಿ (ಪುಟ 0 ಪ್ರಾಥಮಿಕ ರಶೀದಿಯಾಗಿದೆ).
4. **ಉಳಿಸಿ** ಸಂಗ್ರಹಿಸಲು (ಸ್ಥಳೀಯ ಮೊದಲು; ಫೋಟೋ ಬ್ಯಾಕಪ್ ಮತ್ತು ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಸಿಂಕ್ ಕಾನ್ಫಿಗರ್ ಮಾಡಿದಾಗ ಹಿನ್ನೆಲೆಯಲ್ಲಿ ಸಂಭವಿಸುತ್ತದೆ).

### <a id="expense-list"></a>ವೆಚ್ಚದ ಪಟ್ಟಿ

ಮೆನು → **ವರದಿಗಳು** → **ವೆಚ್ಚಗಳ ಪಟ್ಟಿ** — ಹಿಂದಿನ ಇಂಧನವಲ್ಲದ ವೆಚ್ಚಗಳನ್ನು ಬ್ರೌಸ್ ಮಾಡಿ; ಸಂಪಾದಿಸಲು ಐಟಂ ತೆರೆಯಿರಿ.

![ವೆಚ್ಚದ ಪಟ್ಟಿ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/05-expense-list.jpg)

### <a id="edit-expense"></a>ವೆಚ್ಚವನ್ನು ಸಂಪಾದಿಸಿ

ಪಟ್ಟಿಯಿಂದ ಸಾಲನ್ನು ತೆರೆಯಿರಿ. ಸರಿಯಾದ ಮಾರಾಟಗಾರ, ಮೊತ್ತ, ವರ್ಗ, ವಾಹನ ಮತ್ತು ವಿವರಣೆ. ರಶೀದಿಯು ಫೋಟೋ ಬ್ಯಾಕಪ್‌ನಲ್ಲಿದ್ದರೆ (ಓದಲು ಸಾಧ್ಯವಾಗದ ಸ್ಥಳೀಯ ಫೈಲ್ ಇಲ್ಲ), ತೋರಿಸಿದಾಗ **ಆರ್ಕೈವ್‌ನಿಂದ ಚಿತ್ರವನ್ನು ಪಡೆದುಕೊಳ್ಳಿ** ಬಳಸಿ (ಕಾನ್ಫಿಗರ್ ಮಾಡಿದ ಫೋಟೋ ಗಮ್ಯಸ್ಥಾನಗಳಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ).

![ವೆಚ್ಚ ಸಂಪಾದಿಸಿ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/expense-edit.jpg)

## <a id="start-trip"></a>ಟ್ರಿಪ್ ಪ್ರಾರಂಭಿಸಿ

ಮೆನು → **ಟ್ರಿಪ್ ಪ್ರಾರಂಭಿಸಿ** (ಡ್ರಾಯರ್ ಅನ್ನು ಭರ್ತಿ ಮಾಡಿದ ನಂತರ). ದೂರಮಾಪಕವನ್ನು ಸೆರೆಹಿಡಿಯಿರಿ ಅಥವಾ ನಮೂದಿಸಿ, ಟ್ರಿಪ್ ಪ್ರಕಾರವನ್ನು ಆಯ್ಕೆಮಾಡಿ, **ಡಿಸ್ಕ್** ಐಕಾನ್‌ನೊಂದಿಗೆ ಉಳಿಸಿ. **ನಿಲ್ಲಿಸು** ಈಗ ಹಿಡಿದಿರುವ GPS ಸ್ಥಳದಲ್ಲಿ ವೈಯಕ್ತಿಕಕ್ಕೆ ಶಾರ್ಟ್‌ಕಟ್ ಆಗಿದೆ. ನಿಯಂತ್ರಣ ಜ್ಞಾಪನೆಗಳಿಗಾಗಿ **ⓘ** ಬಳಸಿ.

![ಪ್ರವಾಸ ಪ್ರಾರಂಭಿಸಿ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/start-trip.jpg)

ಟ್ರಿಪ್ ಸ್ಟಾರ್ಟ್‌ಗಳನ್ನು ಇಂಧನ ಸಾಲುಗಳಾಗಿ **ಟ್ರಿಪ್ ಪ್ರಕಾರ** (ಸಾಮಾನ್ಯ ಫಿಲ್‌ಗಳಲ್ಲ) ನೊಂದಿಗೆ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ. ಅವು **ವರದಿಗಳು → ಟ್ರಿಪ್ ಮೈಲ್** ಅಡಿಯಲ್ಲಿ ಕಂಡುಬರುತ್ತವೆ, ಇಂಧನ ಇತಿಹಾಸದ ಅಡಿಯಲ್ಲಿ ಅಲ್ಲ.

## <a id="reports"></a>ವರದಿಗಳು

ಮೆನು → **ವರದಿಗಳು** ಉತ್ಪನ್ನ ಕೇಂದ್ರವನ್ನು ತೆರೆಯುತ್ತದೆ (ಸಾರ್ವಕಾಲಿಕ ಸಾರಾಂಶ + ಕ್ಯಾಟಲಾಗ್ ಕಾರ್ಡ್‌ಗಳು). ಇದು ಏಕೈಕ ಉತ್ಪನ್ನ ವರದಿಗಳ ಮೇಲ್ಮೈಯಾಗಿದೆ - ಯಾವುದೇ ಪ್ರತ್ಯೇಕ "ವರದಿಗಳು ಮತ್ತು ಚಾರ್ಟ್‌ಗಳು" ಡ್ರಾಯರ್ ಐಟಂ ಇಲ್ಲ.

![ವರದಿಗಳ ಕೇಂದ್ರ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/06-reports.jpg)

ವಾಹನ ಮೋಡ್‌ಗಾಗಿ ಕಾರ್ಡ್ ತೆರೆಯಿರಿ (**ಎಲ್ಲಾ / ಪ್ರತಿಯೊಂದೂ / ಸಿಂಗಲ್**), ಅವಧಿ ಫಿಲ್ಟರ್‌ಗಳು, ಚಾರ್ಟ್‌ಗಳು ಮತ್ತು ಹಂಚಿಕೆ (**TEXT / CSV / PDF**). ವರದಿ ಮಕ್ಕಳ ಮೇಲಿನ ಟಾಪ್ ಬಾರ್: **☰ + ←** (ಮತ್ತು **ⓘ** ನೋಂದಾಯಿಸಿದಾಗ).

### <a id="time-based-reports"></a>ಸಮಯ ಆಧಾರಿತ ವರದಿಗಳು

ಮುಖ್ಯ ಚಾರ್ಟ್ ಕಾರ್ಡ್. ಐಚ್ಛಿಕ ಮೆಟ್ರಿಕ್ಸ್ (mpg, G/mi ನಂತಹ ವಾಲ್ಯೂಮ್/ದೂರ, $/G ಯಂತಹ ಯೂನಿಟ್ ಬೆಲೆ, ವೆಚ್ಚ/ದೂರ, ಮಾಸಿಕ $, ಟ್ರಿಪ್ ಮೈಲುಗಳು, ಟ್ರಿಪ್ % ಪ್ರಕಾರ) **ಸ್ಮೂತ್** ಬಿನ್‌ಗಳು ಮತ್ತು **ಸ್ವತಂತ್ರ Y ಮಾಪಕಗಳು** (ಆರ್ಥಿಕ ಎಡ; ಬಲಭಾಗದಲ್ಲಿ ಹಣ ಮತ್ತು ಟ್ರಿಪ್ ಕುಟುಂಬಗಳು).

![ಸಮಯ ಆಧಾರಿತ ವರದಿಗಳು](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports.jpg)

![ಸಮಯ ಆಧಾರಿತ ವರದಿಗಳು — ಸ್ಕ್ರಾಲ್ ಮಾಡಿದ ಮೆಟ್ರಿಕ್‌ಗಳು](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports-scrolled.jpg)

ಆರ್ಥಿಕ ಗಣಿತದ ವಿವರಗಳು: [REPORTS_METRICS.md](reference/REPORTS_METRICS.md).

### <a id="fill-history-vs-fuel-history"></a>Fill history vs ಇಂಧನ ಇತಿಹಾಸ

- **ವರದಿಗಳು → ಇತಿಹಾಸವನ್ನು ಭರ್ತಿ ಮಾಡಿ** — ವರದಿ ಫಿಲ್ಟರ್‌ಗಳಿಗಾಗಿ ಕಾಲಾನುಕ್ರಮದ ಭರ್ತಿಗಳು (** ತುಂಬುತ್ತದೆ ಮಾತ್ರ**; ಯಾವುದೇ ಟ್ರಿಪ್ ಪ್ರಾರಂಭವಾಗುವುದಿಲ್ಲ).

![ಇತಿಹಾಸ ವರದಿಯನ್ನು ಭರ್ತಿ ಮಾಡಿ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fill-history.jpg)

- **ಇಂಧನ ಇತಿಹಾಸ** (ನಿಮ್ಮ ಬಿಲ್ಡ್‌ನ ನ್ಯಾವಿಗೇಷನ್‌ನಲ್ಲಿ ಇದ್ದರೆ) — ಪ್ರತಿ-ವಾಹನ ಭರ್ತಿ ದಾಸ್ತಾನು ಕೂಡ ತುಂಬುತ್ತದೆ; ಸಂಪಾದಿಸಲು ಸಾಲನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿ.

### <a id="trip-miles"></a>ಟ್ರಿಪ್ ಮೈಲುಗಳು

**ವರದಿಗಳು → ಟ್ರಿಪ್ ಮೈಲುಗಳು** — ಮೈಲಿ ಪ್ರಕಾರ, ಚಾರ್ಟ್‌ಗಳು ಮತ್ತು ಕಾಲಾನುಕ್ರಮದ **ಟ್ರಿಪ್ ಪ್ರಾರಂಭ / ವಿಭಾಗದ ಪಟ್ಟಿ**. ಆ ಸಾಲಿಗಾಗಿ ** ತುಂಬುವಿಕೆಯನ್ನು ಸಂಪಾದಿಸಿ** ತೆರೆಯಲು ನಿಜವಾದ ಪ್ರಾರಂಭವನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿ.

![ಟ್ರಿಪ್ ಮೈಲುಗಳು](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a> ತುಂಬುವಿಕೆಯನ್ನು ಸಂಪಾದಿಸಿ

ಫಿಲ್ ಇತಿಹಾಸ, ಇಂಧನ ಇತಿಹಾಸ, ಅಥವಾ ಟ್ರಿಪ್ ಮೈಲುಗಳಿಂದ, ಫಿಲ್ ಅನ್ನು ತೆರೆಯಿರಿ. ಲೇಔಟ್: ವಾಹನ ಮತ್ತು ದೂರಮಾಪಕ, **ವೆಚ್ಚದ ಮೊದಲು ಕರೆನ್ಸಿ**, ಪರಿಮಾಣ, ಟಿಪ್ಪಣಿಗಳು. ಸಾಲು ಟ್ರಿಪ್ ಪ್ರಾರಂಭವಾದಾಗ ಮಾತ್ರ ಟ್ರಿಪ್ ಪ್ರಕಾರವು ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ. ಸ್ಥಳವು ಸಾರಾಂಶದ ಜೊತೆಗೆ **ಸ್ಥಳದ ವಿವರಗಳನ್ನು** ಹೊಂದಿದೆ. ಕ್ಲೌಡ್ ಗುರುತಿನೊಂದಿಗೆ ಸ್ಥಳೀಯ ಫೋಟೋ ಕಾಣೆಯಾಗಿದೆ: **ಆರ್ಕೈವ್‌ನಿಂದ ಚಿತ್ರವನ್ನು ಪಡೆದುಕೊಳ್ಳಿ**.

![ಭರ್ತಿಯನ್ನು ಸಂಪಾದಿಸಿ — ಸ್ಥಳೀಯ ಫೋಟೋ ಕಾಣೆಯಾದಾಗ ಆರ್ಕೈವ್‌ನಿಂದ ಪಡೆದುಕೊಳ್ಳಿ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

ಇತರೆ ಕ್ಯಾಟಲಾಗ್ ಕಾರ್ಡ್‌ಗಳು ವರ್ಗದ ಮೂಲಕ ವೆಚ್ಚಗಳು, ವಾಹನ ಸಾರಾಂಶ ಮತ್ತು ವೆಚ್ಚಗಳ ಪಟ್ಟಿಯನ್ನು ಒಳಗೊಂಡಿರುತ್ತದೆ.

ಹಣ ಹೊಂದಿಸಿದಾಗ ಪ್ರತಿ ಸಾಲಿನ ಕರೆನ್ಸಿಯನ್ನು ಬಳಸುತ್ತದೆ. ಮಿಶ್ರ-ಕರೆನ್ಸಿ ಮೊತ್ತವು **ಪ್ರತಿ-ಕರೆನ್ಸಿಯ ಉಪಮೊತ್ತಗಳನ್ನು ತೋರಿಸುತ್ತದೆ** (ಯಾವುದೇ ಮೂಕ FX ಪರಿವರ್ತನೆ ಇಲ್ಲ).

## <a id="syncing"></a>Syncing

ಮೆನು → **ಸಿಂಕ್ ಮಾಡುವಿಕೆ** ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಮತ್ತು ಫೋಟೋ ಗಮ್ಯಸ್ಥಾನಗಳಿಗೆ ಕೇಂದ್ರವಾಗಿದೆ (ಸೆಟ್ಟಿಂಗ್‌ಗಳ ಅಡಿಯಲ್ಲಿ ಮಾತ್ರ ಸಮಾಧಿ ಮಾಡಲಾಗಿಲ್ಲ).

![ಸಿಂಕ್ ಮಾಡುವ ಹಬ್](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- ಚಿಕ್ಕ ಸ್ಥಿತಿಯೊಂದಿಗೆ **ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಸಿಂಕ್** ಮತ್ತು **ಫೋಟೋ ಬ್ಯಾಕಪ್** ಗಾಗಿ ಕಾರ್ಡ್‌ಗಳು, ಆ ಪ್ರಕಾರಕ್ಕಾಗಿ **ಸಿಂಕ್** ಮತ್ತು **›** ಗಮ್ಯಸ್ಥಾನ ಪಟ್ಟಿಗೆ.
- **ಪರೀಕ್ಷಾ ಸಂಪರ್ಕ** ಗಾಗಿ ಗಮ್ಯಸ್ಥಾನವನ್ನು ತೆರೆಯಿರಿ ಮತ್ತು **ಈಗಲೇ ಸಿಂಕ್ ಮಾಡಿ (ಈ ಗಮ್ಯಸ್ಥಾನ)** / ಎಲ್ಲವನ್ನೂ ಕಾನ್ಫಿಗರ್ ಮಾಡಲಾಗಿದೆ.
- ವೈಫಲ್ಯ **ವಿವರಗಳು** ಮತ್ತು ಇಲ್ಲಿ ಶೀರ್ಷಿಕೆ ಪಟ್ಟಿಯ ಭೂಮಿಯಲ್ಲಿ ಕೆಂಪು **!**.
- ಹಂತ-ಹಂತದ Google ಶೀಟ್‌ಗಳು ಮತ್ತು ಡ್ರೈವ್ ಸೆಟಪ್: [ಬ್ಯಾಕಪ್‌ಗಳು ಮತ್ತು ಬಹು-ಸಾಧನ ಸಿಂಕ್](#backups-and-multi-device-sync).

## <a id="settings-local-preferences"></a>ಸೆಟ್ಟಿಂಗ್‌ಗಳು (ಸ್ಥಳೀಯ ಆದ್ಯತೆಗಳು)

ಮೆನು → **ಸೆಟ್ಟಿಂಗ್‌ಗಳು**.

![ಸೆಟ್ಟಿಂಗ್‌ಗಳು](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07-settings.jpg)

![ಇನ್ನಷ್ಟು ಸೆಟ್ಟಿಂಗ್‌ಗಳು (ಸ್ಕ್ರೋಲ್ ಮಾಡಲಾಗಿದೆ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07b-settings-more.jpg)

ಗಮ್ಯಸ್ಥಾನಗಳಿಗಾಗಿ, **ಮೆನು → ಸಿಂಕ್ ಮಾಡುವಿಕೆ** ಆದ್ಯತೆ ನೀಡಿ. ಅದೇ ಪಟ್ಟಿಗಳನ್ನು ತೆರೆಯುವ ಸಾರಾಂಶ ಸಾಲುಗಳನ್ನು ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಇನ್ನೂ ತೋರಿಸಬಹುದು.

### <a id="local-preferences-common"></a>ಸ್ಥಳೀಯ ಆದ್ಯತೆಗಳು (ಸಾಮಾನ್ಯ)

- **ಇಂಧನ ರಸೀದಿ ಫೋಟೋಗಳನ್ನು ಉಳಿಸಿ** / **ವೆಚ್ಚದ ಫೋಟೋಗಳನ್ನು ಸ್ಥಳೀಯವಾಗಿ ಉಳಿಸಿ** — ಸಾಧನದಲ್ಲಿ ಚಿತ್ರಗಳನ್ನು ಇರಿಸಿ (ಫೋಟೋಗಳ ಅನುಮತಿಯನ್ನು ಕೋರಬಹುದು).
- **ಶಟರ್ ಸೌಂಡ್ ಪ್ಲೇ ಮಾಡಿ**
- **ಕರೆನ್ಸಿ** / **ವಾಲ್ಯೂಮ್ ಯೂನಿಟ್** — ಅಪ್ಲಿಕೇಶನ್ ಡೀಫಾಲ್ಟ್‌ಗಳು (ಸಿಸ್ಟಮ್ ಅಥವಾ ಸ್ಪಷ್ಟ). ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಇಂಧನ ಡೇಟಾದೊಂದಿಗೆ ವಾಲ್ಯೂಮ್ ಯುನಿಟ್ ಅನ್ನು ಬದಲಾಯಿಸುವುದು ಪರಿವರ್ತಿತ ಸಂವಾದವನ್ನು ನೀಡಬಹುದು.
- **ಡಾರ್ಕ್ ಮೋಡ್**
- **ಸೆಟಪ್ ಟಿಪ್ಸ್** — ಮೊದಲ ಚಾಲನೆಯಲ್ಲಿರುವ ವಾಹನ / ಸಿಂಕ್ ಟ್ಯುಟೋರಿಯಲ್‌ಗಳನ್ನು ಮರು-ತೆರೆಯಿರಿ.
- **ಡೀಬಗ್ ಫಿಲ್** / **ಪ್ರಯೋಗ ಪರದೆಗಳನ್ನು ತೋರಿಸು (dev)** — ಮುಂದುವರಿದ; ದೈನಂದಿನ ಬಳಕೆಗಾಗಿ ಬಿಡಿ. ಪ್ರಯೋಗ ಪರದೆಗಳನ್ನು ಇಲ್ಲಿ ದಾಖಲಿಸಲಾಗಿಲ್ಲ.

CSV **ರಫ್ತು/ಆಮದು** (ವಾಹನಗಳು / ವೆಚ್ಚಗಳು / ಇಂಧನ ಟ್ಯಾಬ್‌ಗಳ ZIP) ಪ್ರಸ್ತುತ ನಿರ್ಮಾಣದಿಂದ ನೀಡಿದಾಗ ಸೆಟ್ಟಿಂಗ್‌ಗಳಿಂದ ಲಭ್ಯವಿದೆ.
