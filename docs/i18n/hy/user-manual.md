## <a id="first-time-setup-manage-vehicles"></a>Առաջին անգամ տեղադրում՝ կառավարել տրանսպորտային միջոցները

OCR-ը և **մեքենայի ավտոմատ համընկնումը** լավագույնս աշխատում են այն բանից հետո, երբ յուրաքանչյուր մեքենա գրանցեք **տեղեկատու վահանակի լուսանկարով**, գործարկեք **Discovery**, սահմանեք վազաչափի կտրվածքը թիակի սերմից և պահպանեք ուղենիշները այդ գծիկի համար:

### <a id="open-manage-vehicles"></a>Բաց Կառավարեք տրանսպորտային միջոցներ

Մենյու → **Կառավարել տրանսպորտային միջոցները**: Ընտրեք մեքենա (կամ **Ավելացրեք նոր մեքենա**):

![Կառավարեք տրանսպորտային միջոցները հղման գծիկով, մշակաբույսերով և հայտնաբերմամբ] (https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a>Ավելացրեք կամ խմբագրեք մեքենա

1. Բացեք **Vehicle** բացվող ցանկը → ընտրեք մեքենա կամ **Ավելացրեք նոր մեքենա**:
2. Լուսանկարեք կամ ընտրեք հստակ **հղման գծիկի լուսանկար** (գործիքների ամբողջական խումբ, լավ լուսավորված, հեռախոսը մոտավորապես քառակուսի վրա): Օգտագործեք **Լուսանկարել** կամ **Պատկերասրահ**:
3. Հպեք **Գործարկել Discovery** — թիավարման հայտնաբերումը լուսանկարի վրա դնում է դեղին **սերմեր** (ուղղանիշներն օգտագործում են նույն `"ML Kit"` JSON-ը, ինչ նախկինում):
4. Կտտացրեք **Ընտրեք Odo**, հպեք սերմը թվանշանների վրա, կարգավորեք բռնակները, այնուհետև **Save**:
5. **Խմբագրել Odo**-ը կարգավորում է մի տուփ, որն արդեն այնտեղ է: **Clear Odo**-ը հեռացնում է այն, և կոճակը կարդում է **Select Odo**:
6. Վերանայեք **Ցույց տալ տեսարժան վայրերը**-ով: Օգտագործեք **Խմբագրել OCR** ​​սխալ ընթերցումները շտկելու կամ **ավելացնել** բաց թողնված տեքստը:
7. Լրացրեք **Տրանսպորտային միջոցի անվանումը** (պարտադիր է), գումարած մակնիշը/մոդելը/տարին/համարը, ինչպես ցանկանում եք:
8. Հպեք **Ստեղծել մեքենա** կամ **Պահպանել փոփոխությունները** (պահանջվում է անուն + տեղեկանքի լուսանկար նոր մեքենայի համար):

![Ավելացնել մեքենայի ձևի նոր դաշտեր](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/03b-manage-vehicles-new.jpg)

### <a id="landmarks-fix-what-discovery-missed"></a>Հենանիշներ. ուղղեք այն, ինչ բաց թողեց Discovery-ը

**Ցուցադրել ուղենիշները** հետո, ոլորեք ցանկը և ուղղեք արժեքները: Շարժիչները երբեմն բաց են թողնում փոքր թվանշանները (օրինակ՝ կլաստերի ներքևի աջ կողմում գտնվող ժամացույցը **60**): Օգտագործեք **Խմբագրել OCR** ​​դրանք ավելացնելու կամ ուղղելու համար, որպեսզի մեքենայի ինքնությունը հուսալի մնա:

![Ուղենիշների երկխոսություն — վերանայել և խմբագրել OCR](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a> Տպում առանց կատարյալ լուսանկարի

Դուք դեռ կարող եք օգտագործել հավելվածը՝ ընտրելով մեքենա և **մուտքագրելով** վազաչափը, ծավալը և արժեքը Fill-ում. OCR-ն ընտրովի է յուրաքանչյուր դաշտի համար: Պատկերասրահի ներմուծումն աշխատում է հղման գծիկի լուսանկարի համար, երբ նախընտրում եք չնկարահանել հավելվածից:

**Խորհուրդ.** Աղյուսակների համաժամացումից հետո տրանսպորտային միջոցների սահմանումները (մշակաբույսեր, ուղենիշներ) ապրում են տեղական տվյալների բազայում. դրանք օգտագործելու համար ձեզ հարկավոր չէ նորից բացել Manage Vehicles for Fill-ը:

---

## <a id="backups-and-multi-device-sync"></a>Պահուստավորում և բազմապարատ համաժամացում

Հավելվածը ստեղծվել է այնպես, որ **մի քանի հեռախոսներ կամ պլանշետներ կարողանան կիսել նույն նավատորմի տվյալները**, և այնպես որ դուք կարող եք պահել **ձեր տվյալների և լուսանկարների պատճենը սարքից**: Դա արվում է այն ուղղություններով, որոնք **դուք** կազմաձևում եք **ձեր** հաշիվների կամ **ձեր** ինքնակառավարվող սերվերների տակ, այլ ոչ թե ընկերության կողմից ղեկավարվող «Տրանսպորտային ծախսերի ամպ», որը կարող են տեսնել այլ մարդիկ:

### <a id="what-runs-where"></a>Ինչն է վազում

| Բարի | Ինչ է այն պահպանում | Տիպիկ օգտագործման |
|------|----------------|-------------|
| **Աղյուսակ / աղյուսակային համաժամացում ** | Տրանսպորտային միջոցներ, վառելիքի լցոնումներ, ծախսեր (տողեր և ներդիրներ) | Բազմ սարքերի միաձուլում + կառուցվածքային կրկնօրինակում |
| **Լուսանկարի կրկնօրինակում** | Երկուական պատկերներ (գծիկ/պոմպ/ստացում/տեղեկատու լուսանկարներ) | Լուսանկարների կրկնօրինակում + վերականգնել բացակայող ֆայլերը |

Դուք կարող եք կարգավորել **մի քանի ուղղություններ** յուրաքանչյուր տեսակի (փափուկ գլխարկ յուրաքանչյուր տեսակի համար): Ձեռնարկ **Համաժամեցրեք հիմա** և **ֆոնային** աշխատողները գործարկում են միացվածները:

### <a id="offline-first"></a>Առաջինը անցանց

- **Ցանց չի պահանջվում** լրացում, ծախս կամ անդորրագիր ավելացնելու համար: Ամեն ինչ պահպանված է **առաջին տեղում**:
- Երբ ցանցը հասանելի է, համաժամեցումը և լուսանկարների պահուստավորումը գործարկվում են որպես **ֆոնային առաջադրանքներ** (ձեր կողմից սահմանված ժամանակացույցով և երբ հպում եք **Համաժամեցրեք հիմա**): Անհաջողությունները ցուցադրվում են որպես կարմիր տեքստ Կարգավորումների տողերի տակ և **!** հավելվածի վերնագրի տողում:

### <a id="your-accounts-only"></a>Միայն ձեր հաշիվները

Մուտքը և նշանները մնում են սարքում ձեր ընտրած մատակարարների համար (Google, Microsoft, S3 ստեղներ, ինքնուրույն տեղադրվող URL-ներ և այլն): Ուղղությունները գտնվում են օգտատիրոջ **լիարժեք հսկողության ներքո**՝ ձեր Google հաշիվը, ձեր OneDrive-ը, ձեր MinIO դույլը, ձեր EtherCalc հոսթը և այլն: Ոչինչ չի տարածվում այլ Vehicle Expenses-ի օգտատերերի հետ ընդհանուր հետին պլանի միջոցով:

### <a id="supported-targets--data-spreadsheet--tabular"></a>Աջակցվող թիրախներ — տվյալներ (աղյուսակ/աղյուսակ)

Կազմաձևված է **Մենյու → Համաժամացում → Աղյուսակի համաժամացում** (նաև հասանելի է Կարգավորումների ամփոփ տողերից): Առաջին կարգի ընտրիչի ընտրանքներ.

| Թիրախային | Ծանոթագրություններ |
|--------|--------|
| **Google Աղյուսակներ** | Ընդհանուր լռելյայն; ներդիրներ տրանսպորտային միջոցների, ծախսերի և յուրաքանչյուր մեքենայի վառելիքի համար |
| **Excel** | Microsoft-ի աշխատանքային գրքույկ Graph / OneDrive-ի ոճով պարտադիր |
| **EtherCalc** | Ինքնահոսթինգ համատեղ աղյուսակային սենյակներ |
| **Այլ →** իրականացված հետին պլաններ | **Baserow**, **NocoDB**, **Airtable**, **PocketBase**, **Supabase**, **Firebase**, **Zoho Sheet** |

Հետաձգված / դեռևս անգլուխ չէ (թվարկված է Այլ, բայց ամբողջությամբ չի իրականացվել). OnlyOffice, Collabora: Տես նաև [self-host index](reference/self-host/INDEX.md):

CSV **արտահանում/ներմուծում** (նույն ներդիրի դասավորության ZIP) հասանելի է Կարգավորումներից՝ որպես շարժական պահուստավորում՝ անկախ ուղիղ համաժամացումից:

### <a id="supported-targets--photos-image-backup"></a>Աջակցվող թիրախներ — լուսանկարներ (պատկերի կրկնօրինակում)

Կազմաձևված է **Մենյու → Համաժամացում → Լուսանկարների կրկնօրինակում** (նաև Կարգավորումների ամփոփ տողերից).

| Թիրախային | Ծանոթագրություններ |
|--------|--------|
| **Google Drive** | Ձեր ընտրած թղթապանակը (թերթիր կամ տեղադրիր URL) |
| **OneDrive** | Microsoft հաշիվ + ուղու նախածանց |
| **S3** | AWS, Wasabi, Cloudflare R2, MinIO և այլ S3-ին համատեղելի վերջնակետեր |

Կարգավորեք խաբեաթերթեր ինքնատեղակայված լուսանկարների և աղյուսակային թիրախների համար՝ [self-host index](reference/self-host/INDEX.md):

### <a id="multi-device-behavior-short"></a>Բազմասարքի վարք (կարճ)

- Տողերը միաձուլվում են **Sync ID**-ի միջոցով **վերջին գրելու շահումներով** **Թարմացված** ժամադրոշմների վրա:
- Ջնջումները փափուկ են; մեկ այլ սարքի ավելի նոր խմբագրումը կարող է վերականգնել տողը:
- Երկու սարքերում **նույն լցոնումը երկու անգամ** մուտքագրելը ստեղծում է **երկու տող** — ջնջել ավելորդը, երբ նկատել եք:
- Ավելի մանրամասն՝ [Համաժամեցնել վարքագծի նշումները](#sync-behavior-notes) և [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md):

### <a id="sync-behavior-notes"></a>Համաժամացնել վարքագծի նշումները

- Հավելվածի թարմացումից հետո դուք կարող եք համառոտ տեսնել **«Թարմացվում է տվյալների բազան թարմացումից հետո…»** (տեղական համաժամացման id լրացում):
- Եթե համաժամացումը ընդհատվում է, հաջորդ **հաջող** համաժամացումը նորից միաձուլվում է և վերանորոգում հեռավոր ներդիրները:
- Սխալներ. կարմիր ամփոփում Syncing քարտերի վրա + **!** հավելվածի բարում:

### <a id="vehicle-selection-usually-automatic"></a>Մեքենաների ընտրություն (սովորաբար ավտոմատ)

- **Վառելիքի պատմություն** (եթե առկա է ձեր կառուցվածքի նավիգացիայի մեջ) — յուրաքանչյուր մեքենայի լիցքավորման գույքագրում, որը նույնպես լրացվում է միայն. հպեք մի շարք՝ խմբագրելու համար:

### <a id="trip-miles"></a>Ուղևորություն մղոն

**Հաշվետվություններ → Ուղևորության մղոններ** — մղոններ ըստ տեսակի, գծապատկերների և ժամանակագրական **ուղևորության մեկնարկի/հատվածի ցանկ**: Հպեք իրական սկիզբ՝ բացելու **Խմբագրել լրացնել** այդ տողի համար:

![Ուղեւորություն մղոն](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a>Խմբագրել լրացնելը

Լրացման պատմությունից, Վառելիքի պատմությունից կամ Ուղևորության մղոններից բացեք լցոնումը: Դասավորությունը՝ տրանսպորտային միջոց և վազաչափ, **արժույթը մինչև ինքնարժեքը**, ծավալը, նշումները: Ուղևորության տեսակը հայտնվում է միայն այն դեպքում, երբ շարքը մեկնարկային է: Տեղադրությունն ունի ամփոփում, գումարած **Տեղադրության մանրամասներ**: Բացակայում է ամպային ինքնությամբ տեղական լուսանկար. **Ներբերեք պատկերը արխիվից**:

![Խմբագրել լրացումը — Վերցրեք արխիվից, երբ բացակայում է տեղական լուսանկարը](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

Կատալոգի այլ քարտերը ներառում են ծախսեր ըստ կատեգորիայի, մեքենայի ամփոփագրի և ծախսերի ցանկի:

Փողը օգտագործում է յուրաքանչյուր տողի արժույթը, երբ սահմանված է: Խառը արժույթի հանրագումարները ցույց են տալիս **մեկ արժույթի ենթագումարները** (առանց արտարժույթի անաղմուկ փոխարկում):

## <a id="syncing"></a>Համաժամացում

Մենյու → **Syncing**-ը աղյուսակների և լուսանկարների ուղղությունների կենտրոնն է (ոչ միայն թաղված է Կարգավորումների տակ):

![Համաժամացման հանգույց](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- Քարտեր **Աղյուսակների համաժամացման** և **Լուսանկարների պահուստավորման** կարճ կարգավիճակով, **Համաժամացնել** այդ տեսակի համար և **›** նպատակակետի ցանկում:
- Բացեք նպատակակետ **Փորձարկման կապ** և **Համաժամեցրեք հիմա (այս նպատակակետը)** / բոլորը կազմաձևված են:
- ձախողում **Մանրամասները** և վերնագրի տողի կարմիր **!**-ը հայտնվում են այստեղ:
- Google Sheets-ի և Drive-ի քայլ առ քայլ կարգավորում՝ [Պահուստավորումներ և մի քանի սարքերի համաժամացում] (#backups-and-multi-device-sync):

## <a id="settings-local-preferences"></a>Կարգավորումներ (տեղական նախապատվություններ)

Մենյու → **Կարգավորումներ**:

![Կարգավորումներ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07-settings.jpg)

![Լրացուցիչ կարգավորումներ (ոլորված)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07b-settings-more.jpg)

Ուղղությունների համար նախընտրեք **Մենյու → Համաժամացում**: Կարգավորումները դեռ կարող են ցույց տալ ամփոփ տողեր, որոնք բացում են նույն ցուցակները:

### <a id="local-preferences-common"></a>Տեղական նախապատվություններ (ընդհանուր)

- **Պահպանել վառելիքի ստացման լուսանկարները** / **Պահպանել ծախսերի լուսանկարները տեղում** — պահել պատկերները սարքում (կարող է պահանջել Լուսանկարների թույլտվություն):
- **Նվագարկել կափարիչի ձայնը**
- **Արժույթ** / **Ծավալի միավոր** — հավելվածի լռելյայն (համակարգային կամ բացահայտ): Վառելիքի առկա տվյալների հետ ծավալի միավորը փոխելը կարող է փոխակերպման երկխոսություն առաջարկել:
- **Մութ ռեժիմ **
- **Կարգավորման խորհուրդներ** — նորից բացեք առաջին գործարկվող մեքենայի / համաժամացման ձեռնարկները:
- **Վրիպազերծման լրացում** / **Ցուցադրել փորձի էկրանները (dev)** — առաջադեմ; թողնել ամենօրյա օգտագործման համար: Փորձի էկրաններն այստեղ փաստաթղթավորված չեն:

CSV **արտահանում/ներմուծում** (Տրանսպորտային միջոցների/Ծախսերի/Վառելիքի ներդիրների ZIP) հասանելի է Կարգավորումներից, երբ առաջարկվում է ընթացիկ կառուցվածքի կողմից:
