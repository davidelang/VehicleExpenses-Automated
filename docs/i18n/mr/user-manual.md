# <a id="vehicle-expenses-automated--user-manual"></a> वाहन खर्च स्वयंचलित — वापरकर्ता मॅन्युअल

> **स्रोत संपादित करा (मार्कडाउन).** ब्राउझर आणि ॲपमधील वाचक **रेंडर केलेला HTML** उघडतात:
> - वेब: [`docs/user-manual/index.html`](index.html) (`./scripts/render-user-manual.sh` सह पुन्हा निर्माण करा)
> - ॲप: मदत / बद्दल → संपूर्ण मॅन्युअल (बंडल केलेले HTML + स्क्रीनशॉट)
>
> अंतिम वापरकर्त्यांना कच्च्या `.md` URL वर निर्देशित करू नका — ब्राउझर फक्त साधा मजकूर दाखवतात.

**तुमच्या** क्लाउड खाती अंतर्गत पर्यायी मल्टी-डिव्हाइस सिंक आणि बॅकअपसह इंधन भरणे आणि वाहन खर्चासाठी कॅमेरा-प्रथम ट्रॅकिंग.

हे **संपूर्ण मॅन्युअल** आहे (स्क्रीनशॉट + प्रत्येक चरण). फोनवर, **मेनू → मदत** हा एक लहान प्रारंभ-सुरुवात मार्गदर्शक आहे.

**येथे कव्हर केलेले नाही:** जुनी चित्रे, संरेखन प्रयोग आणि पंप प्रयोग (विकासक / प्रगत साधने) आयात करा.

## <a id="what-you-need"></a> तुम्हाला काय हवे आहे

- सर्वोत्तम OCR साठी: तुमच्या **डॅशबोर्ड ओडोमीटर** आणि **पंप टोटल** चे स्पष्ट दृश्य (किंवा हाताने संख्या टाइप करा).

## <a id="first-time-setup-manage-vehicles"></a>प्रथम-वेळ सेटअप: वाहने व्यवस्थापित करा

OCR आणि **स्वयंचलित वाहन जुळणी** तुम्ही प्रत्येक वाहनाची **संदर्भ डॅशबोर्ड फोटो** सह नोंदणी केल्यानंतर, **डिस्कव्हरी** चालवल्यानंतर, पॅडल सीडमधून ओडोमीटर क्रॉप सेट केल्यानंतर आणि त्या डॅशसाठी महत्त्वाच्या खुणा सेव्ह केल्यानंतर उत्तम काम करतात.

### <a id="open-manage-vehicles"></a>वाहने व्यवस्थापित करा

मेनू → **वाहने व्यवस्थापित करा**. वाहन निवडा (किंवा **नवीन वाहन जोडा**).

![संदर्भ डॅश, पीक आणि शोध असलेली वाहने व्यवस्थापित करा](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a> वाहन जोडा किंवा संपादित करा

1. **वाहन** ड्रॉपडाउन उघडा → वाहन निवडा किंवा **नवीन वाहन जोडा**.
2. स्पष्ट **संदर्भ डॅश फोटो** कॅप्चर करा किंवा निवडा (संपूर्ण इन्स्ट्रुमेंट क्लस्टर, चांगला प्रकाश असलेला, फोन अंदाजे स्क्वेअर-ऑन). **फोटो घ्या** किंवा **गॅलरी** वापरा.
3. **डिस्कव्हरी चालवा** वर टॅप करा — पॅडल डिटेक्शन फोटोवर पिवळे **बिया** ठेवते (लँडमार्क पूर्वीप्रमाणेच `"ML Kit"` JSON वापरतात).
4. **ओडो निवडा** वर टॅप करा, अंकांवर बियांवर टॅप करा, हँडल समायोजित करा, नंतर **सेव्ह करा**.
5. **एडिट ओडो** आधीपासून असलेला बॉक्स समायोजित करते. **Clear Odo** ते काढून टाकते, आणि बटण नंतर **Odo निवडा** वाचते.
6. **लँडमार्क दर्शवा** सह पुनरावलोकन करा. चुकीचे वाचन निश्चित करण्यासाठी **ओसीआर संपादित करा** वापरा किंवा चुकलेला मजकूर **जोडा**.
7. **वाहनाचे नाव** भरा (आवश्यक), तसेच तुमच्या आवडीनुसार/मॉडेल/वर्ष/प्लेट तयार करा.
8. **वाहन तयार करा** किंवा **बदल जतन करा** वर टॅप करा (नवीन वाहनासाठी नाव + संदर्भ फोटो आवश्यक आहे).

![नवीन वाहन फॉर्म फील्ड जोडा](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/03b-manage-vehicles-new.jpg)

### <a id="landmarks-fix-what-discovery-missed"></a>लँडमार्क्स: डिस्कवरीने काय चुकवले ते दुरुस्त करा

**लँडमार्क दाखवा** नंतर, सूची स्क्रोल करा आणि मूल्ये योग्य करा. इंजिन कधीकधी लहान अंक चुकतात (उदाहरणार्थ क्लस्टरच्या तळाशी उजवीकडे घड्याळ **60**). ते जोडण्यासाठी किंवा दुरुस्त करण्यासाठी **ओसीआर संपादित करा** वापरा जेणेकरून वाहन ओळख विश्वसनीय राहते.

![लँडमार्क डायलॉग — पुनरावलोकन करा आणि OCR संपादित करा](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a> परिपूर्ण फोटोशिवाय टायपिंग

तुम्ही वाहन निवडून आणि **टाइपिंग** ओडोमीटर, व्हॉल्यूम आणि फिलवरील खर्च करूनही ॲप वापरू शकता — OCR प्रत्येक फील्डसाठी पर्यायी आहे. तुम्ही ॲप-मधील शूट न करण्यास प्राधान्य देता तेव्हा संदर्भ डॅश फोटोसाठी गॅलरी आयात कार्य करते.

**टीप:** स्प्रेडशीट सिंक केल्यानंतर, वाहन व्याख्या (पीक, खुणा) स्थानिक डेटाबेसमध्ये राहतात — तुम्हाला ते वापरण्यासाठी भरण्यासाठी वाहने व्यवस्थापित करा पुन्हा उघडण्याची गरज नाही.

## <a id="backups-and-multi-device-sync"></a>बॅकअप आणि मल्टी-डिव्हाइस सिंक

ॲप तयार केले आहे जेणेकरून **अनेक फोन किंवा टॅब्लेट समान फ्लीट डेटा शेअर करू शकतील** आणि त्यामुळे तुम्ही **तुमच्या डेटाची आणि फोटोंची प्रत डिव्हाइसबाहेर ठेवू शकता**. हे **तुमची** खाती किंवा **तुमच्या** सेल्फ-होस्टेड सर्व्हरच्या अंतर्गत **आपण** कॉन्फिगर केलेल्या गंतव्यस्थानांसह केले जाते — इतर लोक पाहू शकतील असे कंपनी-रन "वाहन खर्च क्लाउड" नाही.

### <a id="what-runs-where"></a>काय चालतं कुठे

| दयाळू | ते काय साठवते | ठराविक वापर |
|------|------------------------------|
| **स्प्रेडशीट / सारणी समक्रमण** | वाहने, इंधन भरणे, खर्च (पंक्ती आणि टॅब) | मल्टी-डिव्हाइस मर्ज + संरचित बॅकअप |
| **फोटो बॅकअप** | बायनरी प्रतिमा (डॅश/पंप/पावती/संदर्भ फोटो) | फोटो बॅकअप + गहाळ फायली पुनर्संचयित करा |

तुम्ही प्रत्येक प्रकारची **एकाधिक गंतव्ये** कॉन्फिगर करू शकता (प्रति प्रकार सॉफ्ट कॅप). मॅन्युअल **आता समक्रमित करा** आणि **पार्श्वभूमी** कामगार सक्षम केलेले चालवतात.

### <a id="offline-first"></a>प्रथम ऑफलाइन

- भराव, खर्च किंवा पावती जोडण्यासाठी **कोणत्याही नेटवर्कची आवश्यकता नाही**. सर्व काही **स्थानिकरित्या प्रथम** जतन केले आहे.
- नेटवर्क उपलब्ध असताना, सिंक आणि फोटो बॅकअप **पार्श्वभूमी कार्ये** म्हणून चालतात (तुम्ही सेट केलेल्या शेड्यूलवर आणि तुम्ही **आता सिंक करा** वर टॅप करता तेव्हा). अयशस्वी सेटिंग्ज पंक्ती अंतर्गत लाल मजकूर आणि ॲप शीर्षक बारमध्ये **!** म्हणून दर्शवतात.

### <a id="your-accounts-only"></a> फक्त तुमची खाती

साइन-इन आणि टोकन तुम्ही निवडलेल्या प्रदात्यांसाठी डिव्हाइसवर राहतात (Google, Microsoft, S3 की, स्व-होस्ट केलेले URL आणि असेच). गंतव्ये **वापरकर्त्याच्या पूर्ण नियंत्रणाखाली** असतात — तुमचे Google खाते, तुमची OneDrive, तुमची MinIO बकेट, तुमचे EtherCalc होस्ट इ. शेअर केलेल्या बॅकएंडद्वारे इतर वाहन खर्च वापरकर्त्यांसोबत काहीही शेअर केले जात नाही.

### <a id="supported-targets--data-spreadsheet--tabular"></a>समर्थित लक्ष्य — डेटा (स्प्रेडशीट / सारणी)

**मेनू → सिंकिंग → स्प्रेडशीट सिंक** अंतर्गत कॉन्फिगर केलेले (सेटिंग्ज सारांश पंक्तींमधून देखील पोहोचता येते). प्रथम श्रेणी निवडक पर्याय:

| लक्ष्य | नोट्स |
|---------|---------|
| **Google Sheets** | सामान्य डीफॉल्ट; वाहनांसाठी टॅब, खर्च आणि प्रति-वाहन इंधन |
| **एक्सेल** | ग्राफ / OneDrive-शैली बंधनाद्वारे Microsoft कार्यपुस्तिका |
| **इथरकॅल्क** | स्वयं-होस्टेड सहयोगी स्प्रेडशीट रूम |
| **इतर →** लागू केलेले बॅकएंड | **बेसरो**, **नोकोडीबी**, **एअरटेबल**, **पॉकेटबेस**, **सुपाबेस**, **फायरबेस**, **झोहो शीट** |

स्थगित / अद्याप हेडलेस नाही (इतर अंतर्गत सूचीबद्ध परंतु पूर्णपणे लागू केलेले नाही): OnlyOffice, Collabora. [सेल्फ-होस्ट इंडेक्स](reference/self-host/INDEX.md) देखील पहा.

CSV **निर्यात/आयात** (त्याच टॅब लेआउटची झिप) थेट सिंकपासून स्वतंत्र, पोर्टेबल बॅकअप म्हणून सेटिंग्जमधून उपलब्ध आहे.

### <a id="supported-targets--photos-image-backup"></a>समर्थित लक्ष्य — फोटो (इमेज बॅकअप)

**मेनू → सिंकिंग → फोटो बॅकअप** अंतर्गत कॉन्फिगर केलेले (सेटिंग्ज सारांश पंक्तींमधून देखील):

| लक्ष्य | नोट्स |
|---------|---------|
| **Google ड्राइव्ह** | तुम्ही निवडलेले फोल्डर (URL ब्राउझ करा किंवा पेस्ट करा) |
| **OneDrive** | Microsoft खाते + पथ उपसर्ग |
| **S3** | AWS, Wasabi, Cloudflare R2, MinIO, आणि इतर S3-सुसंगत एंडपॉइंट्स |
| **इतर** | rclone-बॅक्ड स्टोरेज (उदा. WebDAV, SFTP, आणि ॲप-मधील पिकरमध्ये उपलब्ध इतर क्युरेटेड रिमोट) |

स्व-होस्ट केलेले फोटो आणि टॅब्युलर लक्ष्यांसाठी चीटशीट सेट करा: [सेल्फ-होस्ट इंडेक्स](reference/self-host/INDEX.md).

### <a id="multi-device-behavior-short"></a>मल्टी-डिव्हाइस वर्तन (लहान)

- **अपडेट केलेल्या** टाइमस्टॅम्पवर **अंतिम-लेखन-विजय** सह **सिंक आयडी** द्वारे पंक्ती एकत्र केल्या जातात.
- डिलीट मऊ असतात; दुसऱ्या डिव्हाइसवरील नवीन संपादन पंक्ती पुनर्संचयित करू शकते.
- दोन डिव्हाइसेसवर **समान भरण दोनदा** प्रविष्ट केल्याने **दोन पंक्ती** तयार होतात — तुमच्या लक्षात आल्यावर अतिरिक्त हटवा.
- अधिक तपशील: [वर्तन टिपा समक्रमित करा](#sync-behavior-notes) आणि [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md).

### <a id="example-add-google-sheets-data"></a>उदाहरण: Google Sheets (डेटा) जोडा

1. **मेनू → सिंकिंग → स्प्रेडशीट सिंक** (किंवा सेटिंग्ज → स्प्रेडशीट सिंक).

![स्प्रेडशीट सिंक सूची](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/08-spreadsheet-sync.jpg)

2. **स्प्रेडशीट गंतव्यस्थान जोडा** वर टॅप करा.

![प्रोव्हायडर पिकर](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/09-spreadsheet-provider-picker.jpg)

3. **Google Sheets** निवडा.

![Google शीट फॉर्म](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/10-spreadsheet-google-form.jpg)

4. **Google सह साइन इन करा** एकदा — ते साइन-इन तुम्हाला ब्राउझ देखील करू देते. डिस्प्ले नाव → **शीट URL** पेस्ट करा (अद्याप वैध) किंवा **🔍** ब्राउझ करा. ब्राउझ **सर्व आणि सामायिक** वर उघडेल जेणेकरुन तुम्ही तुमच्या मालकीची किंवा तुमच्यासोबत शेअर केलेली विद्यमान स्प्रेडशीट निवडू शकता. नंतर शेड्यूल पर्याय → सक्षम → सेव्ह करा.
5. टॅब तयार/अपडेट करण्यासाठी **आता सिंक करा** एकदा: `Vehicles`, `Expenses`, `Fuel - {vehicle name}`.

### <a id="example-add-google-drive-photos"></a>उदाहरण: Google ड्राइव्ह जोडा (फोटो)

1. **मेनू → सिंक करणे → फोटो बॅकअप** (किंवा सेटिंग्ज → फोटो बॅकअप).

![फोटो बॅकअप सूची](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/11-photo-backup.jpg)

2. **फोटो गंतव्यस्थान जोडा** वर टॅप करा.

![फोटो प्रदाता पिकर](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/12-photo-provider-picker.jpg)

3. **Google Drive** निवडा.

![Google ड्राइव्ह फॉर्म](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/13-photo-google-form.jpg)

4. **Google (ड्राइव्ह) सह साइन इन करा** → पर्यायी फोल्डर URL/ब्राउझ करा → सक्षम करा → सेव्ह करा → **आता सिंक करा**.

फोटोंसाठी मॅन्युअल **आता सिंक करा** हा पूर्ण प्रक्रिया आहे; पार्श्वभूमी बॅकअप साधारणपणे फक्त **थांबवलेले** अपलोड वेळापत्रकानुसार प्रक्रिया करतो.

### <a id="sync-behavior-notes"></a> सिंक वर्तन नोट्स

- ॲप अपग्रेड केल्यानंतर तुम्हाला थोडक्यात **"अपग्रेड केल्यानंतर डेटाबेस अपडेट करणे..."** (स्थानिक सिंक-आयडी बॅकफिल) दिसेल.
- सिंकमध्ये व्यत्यय आल्यास, पुढील **यशस्वी** सिंक रिमोट टॅब पुन्हा विलीन आणि दुरुस्त करते.
- अयशस्वी: ॲप बारमध्ये सिंक कार्ड + **!** वर लाल सारांश.

## <a id="fill-up-fuel"></a>फिल (इंधन)

तुम्ही ॲप उघडता तेव्हा ही **होम स्क्रीन** असते.

### <a id="vehicle-selection-usually-automatic"></a>वाहन निवड (सामान्यतः स्वयंचलित)

तुम्हाला प्रथम वाहन उचलण्याची **आवश्यकता नाही**. जेव्हा वाहनांमध्ये **लँडमार्क** सेट केले जातात तेव्हा वाहने व्यवस्थापित करा, तुम्ही ओडोमीटर कॅप्चर केल्यानंतर डॅश इमेजमधून **कोणते वाहन ऑटो-डिटेक्ट करा** भरा. आवश्यक असल्यास ओव्हरराइड करण्यासाठी तुम्ही **वाहन** ड्रॉपडाउन उघडू शकता.

### <a id="aim-at-the-odometer"></a> ओडोमीटरकडे लक्ष्य करा

ओडोमीटर मोडमध्ये रहा आणि क्लस्टर फ्रेम करा. सूचना: *ओडोमीटरवर लक्ष्य ठेवा. कॅप्चर करण्यासाठी शटरवर टॅप करा.*

![भरा — ओडोमीटरवर थेट कॅमेरा (पूर्वावलोकनमध्ये डॅश प्रतिमा)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a>ओडोमीटर शटर नंतर

OCR **Odo** भरते आणि खूणांवरून वाहन जुळवण्याचा प्रयत्न करते (आवश्यक असल्यास दोन्हीचे पुनरावलोकन करा). मुख्य बटण पुन्हा शूट करण्यासाठी **पुन्हा प्रयत्न करा** होईल. सूचना वाचनाचा सारांश देते.

![भरा — ओडोमीटर OCR निकाल](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a>पंप मोड (किंमत आणि व्हॉल्यूम)

1. पंप मोडवर स्विच करण्यासाठी **↕** टॅप करा: *पंप डिस्प्लेवर लक्ष्य ठेवा (किंमत/व्हॉल्यूम). शटरवर टॅप करा.*
2. पंप बेरीज कॅप्चर करा. खर्च आणि व्हॉल्यूम फील्ड भरतात; **↔** स्वॅप केले असल्यास वापरा.
3. आवश्यक असल्यास चलन किंवा **G/L** वर टॅप करा, नंतर **सेव्ह करा** (डिस्क). रिकाम्या फील्डमुळे **आंशिक भराव** होतो (अद्याप परवानगी आहे).

![भरा — पंप पूर्वावलोकन / बेरीज (पूर्वावलोकनमध्ये पंप प्रतिमा उदाहरण)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

तुम्ही पुढील स्टॉपसाठी Fill वर रहा (सेव्ह केल्यानंतर फील्ड साफ करा). पूर्णपणे **ऑफलाइन** कार्य करा; कॉन्फिगर केल्यावर सिंक नंतर बॅकग्राउंडमध्ये चालते.

### <a id="manual-entry-no-camera--bad-ocr"></a>मॅन्युअल एंट्री (कॅमेरा नाही / खराब OCR)

1. **ओडो**, **किंमत**, किंवा **व्हॉल्यूम** वर टॅप करा आणि मूल्ये टाइप करा (पोर्ट्रेट सिस्टम कीबोर्ड वापरते; लँडस्केप ऑन-स्क्रीन कीपॅड वापरते).
2. ऑटो-डिटेक्ट चालत नसल्यास **वाहन** निवडा किंवा पुष्टी करा.
3. वरीलप्रमाणे सेव्ह करा.

### <a id="modes-and-borders"></a>मोड आणि सीमा

- वाहनाभोवती **हिरवी सीमा**+ओडो → कॅप्चरिंग/एडिटिंग ओडोमीटर.
- **हिरवी बॉर्डर** किंमत + व्हॉल्यूम → पंप मोडच्या आसपास.
- वाहन निवडेपर्यंत **सेव्ह** अक्षम राहते आणि ओडो/किंमत/व्हॉल्यूमपैकी किमान एक डेटा आहे आणि OCR अजूनही चालू नाही.

ऑन-स्क्रीन टीप (सूचना ओळीच्या खाली): *शटर = कॅप्चर · डिस्क = सेव्ह · ↕ = ओडो/पंप मोड · ↔ = स्वॅप किंमत/व्हॉल्यूम.*

## <a id="expenses"></a>खर्च

### <a id="new-expense"></a>नवीन खर्च

मेनू → **नवीन खर्च**.

![नवीन खर्चाचा फॉर्म आणि कॅमेरा नियंत्रणे (रिकामे असताना कॅमेरा बँडमधील डॅश इमेजचे उदाहरण)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r6-new-expense.jpg)

3. एकाधिक-पृष्ठ पावत्या: UI पेजिंग ऑफर करत असल्यास अतिरिक्त पृष्ठे कॅप्चर करा (पृष्ठ 0 ही प्राथमिक पावती आहे).

सूचीमधून एक पंक्ती उघडा. योग्य विक्रेता, रक्कम, श्रेणी, वाहन आणि वर्णन. पावती फक्त फोटो बॅकअपमध्ये असल्यास (वाचण्यायोग्य स्थानिक फाइल नाही), दाखवल्यावर **आर्काइव्हमधून प्रतिमा आणा** वापरा (कॉन्फिगर केलेल्या फोटो गंतव्यांवर कार्य करते).

## <a id="reports"></a> अहवाल

मेनू → **अहवाल** उत्पादन हब उघडतो (सर्वकालीन सारांश + कॅटलॉग कार्ड). हे एकमेव उत्पादन अहवाल पृष्ठभाग आहे — कोणताही वेगळा “अहवाल आणि चार्ट” ड्रॉवर आयटम नाही.

![रिपोर्ट हब](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/06-reports.jpg)

वाहन मोड (**सर्व / प्रत्येक / सिंगल**), कालावधी फिल्टर, चार्ट आणि शेअर (**TEXT / CSV / PDF**) साठी कार्ड उघडा. मुलांचा अहवाल देण्यासाठी शीर्ष पट्टी: **☰ + ←** (आणि **ⓘ** नोंदणीकृत असताना).

### <a id="time-based-reports"></a>वेळेवर आधारित अहवाल

मुख्य चार्ट कार्ड. पर्यायी मेट्रिक्स (mpg, व्हॉल्यूम/अंतर जसे की G/mi, युनिट किंमत जसे की $/G, खर्च/अंतर, मासिक $, ट्रिप मैल, ट्रिप % प्रकारानुसार) **गुळगुळीत** डब्बे आणि **स्वतंत्र Y स्केल** (डावीकडे अर्थव्यवस्था; पैसे आणि ट्रिप कुटुंबे उजवीकडे).

![वेळेवर आधारित अहवाल](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports.jpg)

![वेळेवर आधारित अहवाल — स्क्रोल केलेले मेट्रिक्स](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports-scrolled.jpg)

अर्थव्यवस्थेच्या गणिताचे तपशील: [REPORTS_METRICS.md](reference/REPORTS_METRICS.md).

### <a id="fill-history-vs-fuel-history"></a>फिल इतिहास वि इंधन इतिहास

- **अहवाल → इतिहास भरा** — अहवाल फिल्टरसाठी कालक्रमानुसार भरणे (**फक्त भरणे**; कोणतीही सहल सुरू होत नाही).

![इतिहास अहवाल भरा](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fill-history.jpg)

- **इंधन इतिहास** (जर तुमच्या बिल्डच्या नेव्हिगेशनमध्ये असेल तर) — प्रति-वाहन फिल इन्व्हेंटरी, फक्त भरते; संपादित करण्यासाठी एका पंक्तीवर टॅप करा.

### <a id="trip-miles"></a> ट्रिप मैल

**अहवाल → ट्रिप मैल** — प्रकारानुसार मैल, चार्ट आणि कालक्रमानुसार **ट्रिप स्टार्ट/सेगमेंट सूची**. त्या पंक्तीसाठी **एडिट फिल** उघडण्यासाठी प्रत्यक्ष सुरुवात टॅप करा.

![ट्रिप मैल](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a> संपादन भरा

फिल हिस्ट्री, फ्युएल हिस्ट्री किंवा ट्रिप मैल मधून, फिल उघडा. लेआउट: वाहन आणि ओडोमीटर, **किमतीपूर्वी चलन**, खंड, नोट्स. जेव्हा पंक्ती ट्रिप स्टार्ट असते तेव्हाच ट्रिप प्रकार दिसून येतो. स्थानाचा सारांश आणि **स्थान तपशील** आहे. क्लाउड आयडेंटिटीसह गहाळ स्थानिक फोटो: **आर्काइव्हमधून प्रतिमा मिळवा**.

![भरण संपादित करा — स्थानिक फोटो गहाळ असताना संग्रहणातून आणा](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

इतर कॅटलॉग कार्ड्समध्ये श्रेणीनुसार खर्च, वाहनाचा सारांश आणि खर्चाची यादी समाविष्ट आहे.

सेट केल्यावर मनी प्रत्येक पंक्तीचे चलन वापरते. मिश्रित चलन बेरीज **प्रति-चलन उप बेरजे** दर्शवतात (कोणतेही शांत FX रूपांतरण नाही).

## <a id="syncing"></a> सिंक करत आहे

मेनू → **सिंक करणे** हे स्प्रेडशीट आणि फोटो डेस्टिनेशनसाठी केंद्र आहे (केवळ सेटिंग्ज अंतर्गतच नाही).

![सिंकिंग हब](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- लहान स्थितीसह **स्प्रेडशीट समक्रमण** आणि **फोटो बॅकअप** साठी कार्ड, त्या प्रकारासाठी **सिंक** आणि गंतव्य सूचीमध्ये **›**.
- **चाचणी कनेक्शन** आणि **आता समक्रमित करा (हे गंतव्यस्थान)** / सर्व कॉन्फिगर केलेले गंतव्यस्थान उघडा.
- अयशस्वी **तपशील** आणि लाल **!** येथे शीर्षक पट्टीमध्ये आहे.
- चरण-दर-चरण Google पत्रक आणि ड्राइव्ह सेटअप: [बॅकअप आणि मल्टी-डिव्हाइस सिंक](#backups-and-multi-device-sync).

## <a id="settings-local-preferences"></a> सेटिंग्ज (स्थानिक प्राधान्ये)

मेनू → **सेटिंग्ज**.

![सेटिंग्ज](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07-settings.jpg)

![अधिक सेटिंग्ज (स्क्रोल केलेले)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07b-settings-more.jpg)

गंतव्यस्थानांसाठी, **मेनू → सिंक करणे** ला प्राधान्य द्या. सेटिंग्ज अजूनही सारांश पंक्ती दर्शवू शकतात ज्या समान सूची उघडतात.

### <a id="local-preferences-common"></a>स्थानिक प्राधान्ये (सामान्य)

- **इंधन पावतीचे फोटो वाचवा** / **खर्चाचे फोटो स्थानिक पातळीवर जतन करा** — इमेज डिव्हाइसवर ठेवा (फोटो परवानगीची विनंती करू शकतात).
- **शटर साउंड प्ले करा**
- **चलन** / **व्हॉल्यूम युनिट** — ॲप डीफॉल्ट (सिस्टम किंवा स्पष्ट). विद्यमान इंधन डेटासह व्हॉल्यूम युनिट बदलल्याने कन्व्हर्ट डायलॉग मिळू शकतो.
- **गडद मोड**
- **सेटअप टिपा** — प्रथम चालणारे वाहन / सिंक ट्यूटोरियल पुन्हा उघडा.
- **डीबग फिल** / **प्रयोग स्क्रीन दाखवा (dev)** — प्रगत; रोजच्या वापरासाठी सोडा. प्रयोग स्क्रीन येथे दस्तऐवजीकरण केलेले नाहीत.

CSV **निर्यात/आयात** (वाहनांची झिप / खर्च / इंधन टॅब) सध्याच्या बिल्डद्वारे ऑफर केल्यावर सेटिंग्जमधून उपलब्ध आहे.
