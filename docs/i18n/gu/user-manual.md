# <a id="vehicle-expenses-automated--user-manual"></a> વાહન ખર્ચ ઓટોમેટેડ — વપરાશકર્તા માર્ગદર્શિકા

> **સ્રોત સંપાદિત કરો (માર્કડાઉન).** બ્રાઉઝર્સ અને ઇન-એપ રીડર **રેન્ડર કરેલ HTML** ખોલે છે:
> - વેબ: [`docs/user-manual/index.html`](index.html) (`./scripts/render-user-manual.sh` વડે ફરીથી બનાવો)
> - એપ્લિકેશન: મદદ / વિશે → સંપૂર્ણ માર્ગદર્શિકા (બંડલ કરેલ HTML + સ્ક્રીનશોટ)
>
> અંતિમ વપરાશકર્તાઓને કાચા `.md` URL પર નિર્દેશ કરશો નહીં — બ્રાઉઝર ફક્ત સાદો ટેક્સ્ટ બતાવે છે.

**તમારા** ક્લાઉડ એકાઉન્ટ્સ હેઠળ વૈકલ્પિક મલ્ટિ-ડિવાઈસ સમન્વયન અને બેકઅપ સાથે, બળતણ ભરવા અને વાહન ખર્ચ માટે કેમેરા-પ્રથમ ટ્રેકિંગ.

આ **સંપૂર્ણ માર્ગદર્શિકા** છે (સ્ક્રીનશોટ + દરેક પગલું). ફોન પર, **મેનૂ → મદદ** એ ટૂંકી શરૂઆત માટે માર્ગદર્શિકા છે.

**અહીં આવરી લેવામાં આવતું નથી:** જૂના ચિત્રો, સંરેખણ પ્રયોગ અને પંપ પ્રયોગ (વિકાસકર્તા / અદ્યતન સાધનો) આયાત કરો.

## <a id="what-you-need"></a>તમને જે જોઈએ છે

- Android ફોન અથવા ટેબ્લેટ.
- શ્રેષ્ઠ OCR માટે: તમારા **ડૅશબોર્ડ ઓડોમીટર** અને **પંપ ટોટલ**નું સ્પષ્ટ દૃશ્ય (અથવા હાથથી નંબરો લખો).
- વૈકલ્પિક: સ્પ્રેડશીટ ડેટા અને/અથવા ફોટો બેકઅપ માટે **તમે નિયંત્રિત કરો છો તેવા એકાઉન્ટ્સ (જુઓ [બેકઅપ્સ અને મલ્ટિ-ડિવાઈસ સિંક](#backups-and-multi-device-sync)).

## <a id="first-time-setup-manage-vehicles"></a>પ્રથમ વખત સેટઅપ: વાહનોનું સંચાલન કરો

OCR અને **ઓટોમેટિક વ્હીકલ મેચીંગ** તમે દરેક વાહનને **સંદર્ભ ડેશબોર્ડ ફોટો** સાથે રજીસ્ટર કરો, **ડિસ્કવરી** ચલાવો, પેડલ સીડમાંથી ઓડોમીટર ક્રોપ સેટ કરો અને તે ડેશ માટે સીમાચિહ્નો સાચવો તે પછી શ્રેષ્ઠ કાર્ય કરે છે.

### <a id="open-manage-vehicles"></a>ઓપન મેનેજ વાહનો

મેનુ → **વાહનોનું સંચાલન કરો**. વાહન પસંદ કરો (અથવા **નવું વાહન ઉમેરો**).

![સંદર્ભ ડૅશ, પાક અને શોધ સાથે વાહનોનું સંચાલન કરો](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a> વાહન ઉમેરો અથવા સંપાદિત કરો

1. **વાહન** ડ્રોપડાઉન ખોલો → વાહન પસંદ કરો અથવા **નવું વાહન ઉમેરો**.
2. સ્પષ્ટ **સંદર્ભ ડૅશ ફોટો** કૅપ્ચર કરો અથવા પસંદ કરો (સંપૂર્ણ ઇન્સ્ટ્રુમેન્ટ ક્લસ્ટર, સારી રીતે પ્રકાશિત, ફોન લગભગ ચોરસ-ઑન). **ફોટો લો** અથવા **ગેલેરી**નો ઉપયોગ કરો.
3. **ડિસ્કવરી ચલાવો** પર ટૅપ કરો — પેડલ ડિટેક્શન ફોટો પર પીળા **બીજ** મૂકે છે (લેન્ડમાર્ક્સ પહેલાની જેમ જ `"ML Kit"` JSON નો ઉપયોગ કરે છે).
4. **ઓડો પસંદ કરો** પર ટૅપ કરો, અંકો પર બીજને ટેપ કરો, હેન્ડલ્સને સમાયોજિત કરો, પછી **સાચવો**.
5. **ઓડો સંપાદિત કરો** પહેલાથી જ છે તે બોક્સને સમાયોજિત કરે છે. **ઓડો સાફ કરો** તેને દૂર કરે છે, અને બટન પછી **ઓડો પસંદ કરો** વાંચે છે.
6. **સીમાચિહ્નો બતાવો** સાથે સમીક્ષા કરો. ગેરરીડને ઠીક કરવા માટે **ઓસીઆર સંપાદિત કરો** નો ઉપયોગ કરો અથવા ચૂકી ગયેલ ટેક્સ્ટ **ઉમેરો** કરો.
7. **વાહનનું નામ** (જરૂરી) ભરો, ઉપરાંત તમને ગમે તે પ્રમાણે/મોડલ/વર્ષ/પ્લેટ બનાવો.
8. **વાહન બનાવો** અથવા **ફેરફારો સાચવો** પર ટૅપ કરો (નવા વાહન માટે નામ + સંદર્ભ ફોટો જરૂરી છે).

![નવા વાહન ફોર્મ ફીલ્ડ્સ ઉમેરો](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/03b-manage-vehicles-new.jpg)

### <a id="landmarks-fix-what-discovery-missed"></a>લેન્ડમાર્ક્સ: ડિસ્કવરી શું ચૂકી ગઈ છે તેને ઠીક કરો

**લેન્ડમાર્ક્સ બતાવો** પછી, સૂચિને સ્ક્રોલ કરો અને યોગ્ય મૂલ્યો. એન્જિન ક્યારેક નાના અંકો ચૂકી જાય છે (ઉદાહરણ તરીકે ક્લસ્ટરની નીચે જમણી બાજુએ ઘડિયાળ **60**). તેમને ઉમેરવા અથવા સુધારવા માટે **OCR સંપાદિત કરો** નો ઉપયોગ કરો જેથી વાહનની ઓળખ વિશ્વસનીય રહે.

![લેન્ડમાર્ક્સ સંવાદ — સમીક્ષા કરો અને OCR સંપાદિત કરો](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a> સંપૂર્ણ ફોટો વગર ટાઈપ કરો

તમે હજુ પણ વાહન પસંદ કરીને અને **ટાઈપ કરીને** ઓડોમીટર, વોલ્યુમ અને ફીલ પર ખર્ચ કરીને એપ્લિકેશનનો ઉપયોગ કરી શકો છો — OCR દરેક ક્ષેત્ર માટે વૈકલ્પિક છે. જ્યારે તમે ઇન-એપ શૂટ કરવાનું પસંદ ન કરો ત્યારે ગેલેરી આયાત રેફરન્સ ડેશ ફોટો માટે કામ કરે છે.

**ટિપ:** સ્પ્રેડશીટ સમન્વયન પછી, વાહનની વ્યાખ્યાઓ (પાક, સીમાચિહ્નો) સ્થાનિક ડેટાબેઝમાં રહે છે — તમારે તેનો ઉપયોગ કરવા માટે ભરણ માટે મેનેજ વાહનોને ફરીથી ખોલવાની જરૂર નથી.

## <a id="backups-and-multi-device-sync"></a>બેકઅપ અને મલ્ટિ-ડિવાઈસ સિંક

એપ્લિકેશન એટલા માટે બનાવવામાં આવી છે કે **કેટલાક ફોન અથવા ટેબ્લેટ સમાન ફ્લીટ ડેટાને શેર કરી શકે**, અને તેથી તમે **તમારા ડેટા અને ફોટાની એક નકલ ઉપકરણની બહાર રાખી શકો**. તે **તમારા** એકાઉન્ટ્સ અથવા **તમારા** સ્વ-હોસ્ટેડ સર્વર્સ હેઠળ **તમે** કન્ફિગર કરો છો — જે અન્ય લોકો જોઈ શકે તે કંપની દ્વારા સંચાલિત "વ્હીકલ એક્સપેન્સ ક્લાઉડ" સાથે નહીં.

### <a id="what-runs-where"></a> ક્યાં ચાલે છે

| પ્રકારની | તે શું સંગ્રહ કરે છે | લાક્ષણિક ઉપયોગ |
|------|------------------------------|
| **સ્પ્રેડશીટ / ટેબ્યુલર સમન્વયન** | વાહનો, ઇંધણ ભરવું, ખર્ચ (રો અને ટેબ) | મલ્ટિ-ડિવાઈસ મર્જ + સ્ટ્રક્ચર્ડ બેકઅપ |
| **ફોટો બેકઅપ** | દ્વિસંગી છબીઓ (ડૅશ/પંપ/રસીદ/સંદર્ભ ફોટા) | ફોટો બેકઅપ + ગુમ થયેલ ફાઇલોને પુનઃસ્થાપિત કરો |

તમે દરેક પ્રકારના **બહુવિધ ગંતવ્યો** ગોઠવી શકો છો (પ્રકાર પ્રતિ સોફ્ટ કેપ). મેન્યુઅલ **હમણાં સમન્વય કરો** અને **બેકગ્રાઉન્ડ** કાર્યકર્તાઓ સક્ષમ કરેલને ચલાવે છે.

### <a id="offline-first"></a>ઓફલાઈન પહેલા

- ફીલ-અપ, ખર્ચ અથવા રસીદ ઉમેરવા માટે **કોઈ નેટવર્કની જરૂર નથી**. દરેક વસ્તુ **સ્થાનિક રીતે પહેલા** સાચવવામાં આવે છે.
- જ્યારે નેટવર્ક ઉપલબ્ધ હોય, ત્યારે સમન્વયન અને ફોટો બેકઅપ **બેકગ્રાઉન્ડ કાર્યો** તરીકે ચાલે છે (તમે સેટ કરેલ શેડ્યૂલ પર, અને જ્યારે તમે **હમણાં સમન્વય કરો** પર ટેપ કરો છો). નિષ્ફળતાઓ સેટિંગ્સ પંક્તિઓ હેઠળ લાલ ટેક્સ્ટ અને એપ્લિકેશન શીર્ષક બારમાં **!** તરીકે દર્શાવે છે.

### <a id="your-accounts-only"></a>ફક્ત તમારા એકાઉન્ટ્સ

સાઇન-ઇન અને ટોકન્સ તમે પસંદ કરો છો તે પ્રદાતાઓ માટે ઉપકરણ પર રહે છે (Google, Microsoft, S3 કી, સ્વ-હોસ્ટેડ URL, અને તેથી વધુ). ડેસ્ટિનેશન **વપરાશકર્તાના સંપૂર્ણ નિયંત્રણ** હેઠળ છે — તમારું Google એકાઉન્ટ, તમારું OneDrive, તમારું MinIO બકેટ, તમારું EtherCalc હોસ્ટ, વગેરે. શેર કરેલ બેકએન્ડ દ્વારા અન્ય વાહન ખર્ચ વપરાશકર્તાઓ સાથે કંઈપણ શેર કરવામાં આવતું નથી.

### <a id="supported-targets--data-spreadsheet--tabular"></a>આધારિત લક્ષ્યો — ડેટા (સ્પ્રેડશીટ / ટેબ્યુલર)

**મેનુ → સમન્વયન → સ્પ્રેડશીટ સમન્વયન** હેઠળ ગોઠવેલ (સેટિંગ્સ સારાંશ પંક્તિઓથી પણ પહોંચી શકાય છે). પ્રથમ-વર્ગ પીકર વિકલ્પો:

| લક્ષ્ય | નોંધો |
|---------|---------|
| **Google શીટ્સ** | સામાન્ય મૂળભૂત; વાહનો, ખર્ચ અને વાહન દીઠ ઇંધણ માટે ટેબ |
| **એક્સેલ** | માઈક્રોસોફ્ટ વર્કબુક ગ્રાફ / વનડ્રાઈવ-સ્ટાઈલ બાઈન્ડીંગ દ્વારા |
| **ઇથરકેલ્ક** | સ્વ-હોસ્ટેડ સહયોગી સ્પ્રેડશીટ રૂમ |
| **અન્ય →** અમલમાં મૂકાયેલ બેકએન્ડ | **બેઝરો**, **નોકોડીબી**, **એરટેબલ**, **પોકેટબેઝ**, **સુપાબેઝ**, **ફાયરબેઝ**, **ઝોહો શીટ** |

વિલંબિત / હજુ સુધી હેડલેસ નથી (અન્ય હેઠળ સૂચિબદ્ધ પરંતુ સંપૂર્ણ રીતે અમલમાં નથી): OnlyOffice, Collabora. [સ્વ-યજમાન અનુક્રમણિકા](reference/self-host/INDEX.md) પણ જુઓ.

CSV **નિકાસ/આયાત** (સમાન ટેબ લેઆઉટની ZIP) પોર્ટેબલ બેકઅપ તરીકે સેટિંગ્સમાંથી ઉપલબ્ધ છે, લાઇવ સિંકથી સ્વતંત્ર.

### <a id="supported-targets--photos-image-backup"></a>આધારિત લક્ષ્યો — ફોટા (ઇમેજ બેકઅપ)

**મેનુ → સમન્વયન → ફોટો બેકઅપ** હેઠળ ગોઠવેલ (સેટિંગ્સ સારાંશ પંક્તિઓમાંથી પણ):

| લક્ષ્ય | નોંધો |
|---------|---------|
| **Google ડ્રાઇવ** | તમે પસંદ કરો છો તે ફોલ્ડર (બ્રાઉઝ અથવા પેસ્ટ URL) |
| **OneDrive** | Microsoft એકાઉન્ટ + પાથ ઉપસર્ગ |
| **S3** | AWS, Wasabi, Cloudflare R2, MinIO, અને અન્ય S3-સુસંગત અંતિમ બિંદુઓ |
| **અન્ય** | rclone-બેક્ડ સ્ટોરેજ (દા.ત. WebDAV, SFTP અને અન્ય ક્યુરેટેડ રિમોટ્સ ઇન-એપ પીકરમાં ઉપલબ્ધ) |

સ્વ-હોસ્ટેડ ફોટો અને ટેબ્યુલર લક્ષ્યો માટે ચીટશીટ્સ સેટ કરો: [સેલ્ફ-હોસ્ટ ઇન્ડેક્સ](reference/self-host/INDEX.md).

### <a id="multi-device-behavior-short"></a>મલ્ટિ-ડિવાઈસ વર્તન (ટૂંકું)

- **અપડેટ કરેલ** ટાઇમસ્ટેમ્પ પર **છેલ્લે-લખવા-જીત** સાથે **સિંક ID** દ્વારા પંક્તિઓ મર્જ થાય છે.
- ડિલીટ નરમ હોય છે; બીજા ઉપકરણ પર નવું સંપાદન પંક્તિ પુનઃસ્થાપિત કરી શકે છે.
- બે ઉપકરણો પર **એક જ ભરણને બે વાર દાખલ કરવાથી **બે પંક્તિઓ** બને છે — જ્યારે તમે ધ્યાન આપો ત્યારે વધારાને કાઢી નાખો.
- વધુ વિગત: [વર્તણૂક નોંધો સમન્વયિત કરો](#sync-behavior-notes) અને [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md).

### <a id="example-add-google-sheets-data"></a>ઉદાહરણ: Google શીટ્સ ઉમેરો (ડેટા)

1. **મેનૂ → સમન્વયન → સ્પ્રેડશીટ સમન્વયન ** (અથવા સેટિંગ્સ → સ્પ્રેડશીટ સમન્વયન).

![સ્પ્રેડશીટ સમન્વયન સૂચિ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/08-spreadsheet-sync.jpg)

2. **સ્પ્રેડશીટ ગંતવ્ય ઉમેરો** પર ટૅપ કરો.

![પ્રોવાઇડર પીકર](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/09-spreadsheet-provider-picker.jpg)

3. **Google શીટ્સ** પસંદ કરો.

![Google શીટ્સ ફોર્મ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/10-spreadsheet-google-form.jpg)

4. **Google સાથે સાઇન ઇન કરો** એકવાર — તે સાઇન-ઇન તમને બ્રાઉઝ પણ કરવા દે છે. ડિસ્પ્લે નામ → **શીટ URL** પેસ્ટ કરો (હજુ પણ માન્ય) અથવા **🔍** બ્રાઉઝ કરો. બ્રાઉઝ **બધા અને શેર કરેલ** પર ખુલે છે જેથી તમે તમારી માલિકીની અથવા તમારી સાથે શેર કરેલ હોય તેવી અસ્તિત્વમાંની સ્પ્રેડશીટ પસંદ કરી શકો. પછી શેડ્યૂલ વિકલ્પો → સક્ષમ → સાચવો.
5. ટૅબ્સ બનાવવા/અપડેટ કરવા માટે **હવે સમન્વયિત કરો: `Vehicles`, `Expenses`, `Fuel - {vehicle name}`.

### <a id="example-add-google-drive-photos"></a>ઉદાહરણ: Google ડ્રાઇવ ઉમેરો (ફોટા)

1. **મેનૂ → સમન્વયન → ફોટો બેકઅપ** (અથવા સેટિંગ્સ → ફોટો બેકઅપ).

![ફોટો બેકઅપ સૂચિ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/11-photo-backup.jpg)

2. **ફોટો ડેસ્ટિનેશન ઉમેરો** પર ટૅપ કરો.

![ફોટો પ્રદાતા પીકર](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/12-photo-provider-picker.jpg)

3. **Google ડ્રાઇવ** પસંદ કરો.

![Google ડ્રાઇવ ફોર્મ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/13-photo-google-form.jpg)

4. **Google (ડ્રાઇવ) સાથે સાઇન ઇન કરો** → વૈકલ્પિક ફોલ્ડર URL/બ્રાઉઝ કરો → સક્ષમ કરો → સાચવો → **હવે સમન્વય કરો**.

ફોટાઓ માટેનું મેન્યુઅલ **હવે સિંક કરો** સંપૂર્ણ પાસ છે; બેકગ્રાઉન્ડ બેકઅપ સામાન્ય રીતે **માત્ર વિલંબિત** અપલોડને શેડ્યૂલ પર પ્રોસેસ કરે છે.

### <a id="sync-behavior-notes"></a> વર્તન નોંધો સમન્વયિત કરો

- એપ અપગ્રેડ કર્યા પછી તમે સંક્ષિપ્તમાં **"અપગ્રેડ કર્યા પછી ડેટાબેઝ અપડેટ કરી રહ્યા છીએ..."** (સ્થાનિક સિંક-આઈડી બેકફિલ) જોઈ શકો છો.
- જો સમન્વયનમાં વિક્ષેપ આવે છે, તો પછીનું **સફળ** સમન્વયન રીમોટ ટેબ્સને ફરીથી મર્જ કરે છે અને સમારકામ કરે છે.
- નિષ્ફળતાઓ: ઍપ બારમાં સિંકિંગ કાર્ડ્સ + **!** પર લાલ સારાંશ.

## <a id="fill-up-fuel"></a>ફિલ (ઈંધણ)

જ્યારે તમે એપ્લિકેશન ખોલો છો ત્યારે આ **હોમ સ્ક્રીન** છે.

### <a id="vehicle-selection-usually-automatic"></a>વાહન પસંદગી (સામાન્ય રીતે સ્વચાલિત)

તમારે પહેલા વાહન પસંદ કરવાની **જરૂર નથી**. જ્યારે વાહનોમાં **લેન્ડમાર્ક્સ** મેનેજ વેહિકલ્સમાં સેટઅપ હોય, ત્યારે તમે ઓડોમીટર કેપ્ચર કર્યા પછી ડૅશ ઈમેજમાંથી **કયા વાહનને સ્વતઃ શોધે છે** ભરો. જો જરૂરી હોય તો ઓવરરાઇડ કરવા માટે તમે હજુ પણ **વાહન** ડ્રોપડાઉન ખોલી શકો છો.

### <a id="aim-at-the-odometer"></a>ઓડોમીટર પર લક્ષ્ય રાખો

ઓડોમીટર મોડમાં રહો અને ક્લસ્ટરને ફ્રેમ કરો. સૂચના: *ઓડોમીટર પર લક્ષ્ય રાખો. કેપ્ચર કરવા માટે શટરને ટેપ કરો.*

![ભરો — ઓડોમીટર પર લાઇવ કૅમેરો (પૂર્વાવલોકનમાં ઉદાહરણ ડૅશ છબી)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a>ઓડોમીટર શટર પછી

OCR **Odo** ભરે છે અને સીમાચિહ્નોથી વાહનને મેચ કરવાનો પ્રયાસ કરે છે (જો જરૂરી હોય તો બંનેની સમીક્ષા કરો). મુખ્ય બટન ફરીથી શૂટ કરવા માટે **ફરી પ્રયાસ** બની જાય છે. સૂચના વાંચનનો સારાંશ આપે છે.

![ભરો — ઓડોમીટર OCR પરિણામ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a>પમ્પ મોડ (કિંમત અને વોલ્યુમ)

1. પંપ મોડ પર સ્વિચ કરવા માટે **↕** ટેપ કરો: *પંપ ડિસ્પ્લે (કિંમત/વોલ્યુમ) પર લક્ષ્ય રાખો. શટરને ટેપ કરો.*
2. પંપના ટોટલને કેપ્ચર કરો. કિંમત અને વોલ્યુમ ક્ષેત્રો ભરો; જો તેઓ અદલાબદલી હોય તો **↔** નો ઉપયોગ કરો.
3. જો જરૂરી હોય તો ચલણ અથવા **G/L** પર ટૅપ કરો, પછી **સેવ** (ડિસ્ક). ખાલી ફીલ્ડ **આંશિક ભરણ** બનાવે છે (હજુ પણ મંજૂરી છે).

![ભરો — પંપ પૂર્વાવલોકન / કુલ (પૂર્વાવલોકનમાં પંપ છબીનું ઉદાહરણ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

તમે આગલા સ્ટોપ માટે ફિલ પર રહો (સેવ કર્યા પછી ફીલ્ડ્સ સાફ કરો). સંપૂર્ણપણે **ઓફલાઇન** કામ કરો; જ્યારે રૂપરેખાંકિત કરવામાં આવે ત્યારે સમન્વયન પૃષ્ઠભૂમિમાં પાછળથી ચાલે છે.

### <a id="manual-entry-no-camera--bad-ocr"></a>મેન્યુઅલ એન્ટ્રી (કોઈ કેમેરા નથી / ખરાબ OCR)

1. **ઓડો**, **કિંમત** અથવા **વોલ્યુમ** પર ટૅપ કરો અને મૂલ્યો ટાઈપ કરો (પોટ્રેટ સિસ્ટમ કીબોર્ડનો ઉપયોગ કરે છે; લેન્ડસ્કેપ ઑન-સ્ક્રીન કીપેડનો ઉપયોગ કરે છે).
2. **વાહન** પસંદ કરો અથવા કન્ફર્મ કરો જો ઑટો-ડિટેક્ટ ન ચાલે.
3. ઉપર મુજબ સાચવો.

### <a id="modes-and-borders"></a>મોડ્સ અને બોર્ડર્સ

- વાહનની આસપાસ **લીલી સરહદ**+ઓડો → કેપ્ચરિંગ/એડિટિંગ ઓડોમીટર.
- **લીલી સરહદ** કિંમત+વોલ્યુમ → પંપ મોડની આસપાસ.
- **સાચવો** ત્યાં સુધી અક્ષમ રહે છે જ્યાં સુધી વાહન પસંદ ન થાય અને ઓડો/કિંમત/વોલ્યુમમાંથી ઓછામાં ઓછો એક ડેટા હોય અને OCR હજી ચાલુ ન હોય.

ઓન-સ્ક્રીન ટીપ (સૂચના લાઇનની નીચે): *શટર = કેપ્ચર · ડિસ્ક = સેવ · ↕ = ઓડો/પંપ મોડ · ↔ = સ્વેપ ખર્ચ/વોલ્યુમ.*

## <a id="expenses"></a>ખર્ચ

### <a id="new-expense"></a>નવો ખર્ચ

મેનુ → **નવો ખર્ચ**.

![નવું ખર્ચ ફોર્મ અને કૅમેરા નિયંત્રણો (ખાલી હોય ત્યારે કૅમેરા બેન્ડમાં ઉદાહરણ ડૅશ છબી)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r6-new-expense.jpg)

1. **સેવ** (ડિસ્ક), **શટર** (રસીદનો ફોટો), અથવા **ગેલેરી** (છબી પસંદ કરો).
2. **તારીખ**, **વાહન**, **વિક્રેતા**, **વર્ણન**, **રકમ** (ચલણ પ્રતીક ટેપ કરી શકાય તેવું), **કેટેગરી**, વૈકલ્પિક **ઓડોમીટર** ભરો.
3. મલ્ટી-પેજની રસીદ: જો UI પેજિંગ ઓફર કરે તો વધારાના પૃષ્ઠો કેપ્ચર કરો (પૃષ્ઠ 0 એ પ્રાથમિક રસીદ છે).
4. સ્ટોર કરવા માટે **સાચવો** (સ્થાનિક પહેલા; જ્યારે ગોઠવેલ હોય ત્યારે ફોટો બેકઅપ અને સ્પ્રેડશીટ સિંક બેકગ્રાઉન્ડમાં થાય છે).

### <a id="expense-list"></a>ખર્ચ યાદી

મેનુ → **અહેવાલ** → **ખર્ચોની યાદી** — ભૂતકાળના બિન-ઈંધણ ખર્ચને બ્રાઉઝ કરો; ફેરફાર કરવા માટે આઇટમ ખોલો.

![ખર્ચ યાદી](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/05-expense-list.jpg)

### <a id="edit-expense"></a> સંપાદિત ખર્ચ

યાદીમાંથી એક પંક્તિ ખોલો. યોગ્ય વિક્રેતા, રકમ, શ્રેણી, વાહન અને વર્ણન. જો રસીદ માત્ર ફોટો બેકઅપમાં છે (કોઈ વાંચી શકાય તેવી સ્થાનિક ફાઇલ નથી), જ્યારે બતાવવામાં આવે ત્યારે **આર્કાઇવમાંથી છબી મેળવો** નો ઉપયોગ કરો (રૂપરેખાંકિત ફોટો ગંતવ્યોમાં કાર્ય કરે છે).

![ખર્ચ સંપાદિત કરો](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/expense-edit.jpg)

## <a id="start-trip"></a> ટ્રિપ શરૂ કરો

મેનુ → **પ્રારંભ ટ્રીપ** (ડ્રોઅર ભર્યા પછી). ઓડોમીટર કેપ્ચર કરો અથવા દાખલ કરો, ટ્રિપનો પ્રકાર પસંદ કરો, **ડિસ્ક** આઇકન સાથે સાચવો. **સ્ટોપ** એ હવે યોજાયેલ GPS સ્થાન પર વ્યક્તિગત માટેનો શોર્ટકટ છે. નિયંત્રણ રીમાઇન્ડર્સ માટે **ⓘ** નો ઉપયોગ કરો.

![સફર શરૂ કરો](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/start-trip.jpg)

ટ્રિપની શરૂઆત **ટ્રીપ પ્રકાર** સાથે બળતણ પંક્તિઓ તરીકે સંગ્રહિત થાય છે (સામાન્ય ભરણ નહીં). તેઓ **રિપોર્ટ્સ → ટ્રિપ માઈલ** હેઠળ દેખાય છે, ફ્યુઅલ હિસ્ટ્રી હેઠળ નહીં.

## <a id="reports"></a> અહેવાલો

મેનૂ → **રિપોર્ટ્સ** પ્રોડક્ટ હબ ખોલે છે (ઑલ-ટાઇમ સારાંશ + કૅટેલોગ કાર્ડ્સ). આ એકમાત્ર પ્રોડક્ટ રિપોર્ટ સપાટી છે — ત્યાં કોઈ અલગ “રિપોર્ટ્સ અને ચાર્ટ્સ” ડ્રોઅર આઇટમ નથી.

![રિપોર્ટ હબ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/06-reports.jpg)

વાહન મોડ (**બધા / દરેક / સિંગલ**), પીરિયડ ફિલ્ટર્સ, ચાર્ટ અને શેર (**TEXT / CSV / PDF**) માટે કાર્ડ ખોલો. રિપોર્ટ ચિલ્ડ્રન પર ટોચની પટ્ટી: **☰ + ←** (અને **ⓘ** જ્યારે નોંધાયેલ હોય).

### <a id="time-based-reports"></a>સમય આધારિત અહેવાલો

મુખ્ય ચાર્ટ કાર્ડ. વૈકલ્પિક મેટ્રિક્સ (mpg, વોલ્યુમ/અંતર જેમ કે G/mi, એકમની કિંમત જેમ કે $/G, કિંમત/અંતર, માસિક $, ટ્રિપ માઇલ, ટ્રિપ % પ્રકાર દ્વારા) **સુગમ** ડબ્બા અને **સ્વતંત્ર Y સ્કેલ** સાથે (ડાબે અર્થતંત્ર; પૈસા અને જમણી બાજુએ ટ્રિપ પરિવારો).

![સમય આધારિત અહેવાલો](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports.jpg)

![સમય આધારિત અહેવાલો — સ્ક્રોલ કરેલ મેટ્રિક્સ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports-scrolled.jpg)

અર્થતંત્ર ગણિતની વિગતો: [REPORTS_METRICS.md](reference/REPORTS_METRICS.md).

### <a id="fill-history-vs-fuel-history"></a>ફિલ ઈતિહાસ વિરુદ્ધ ઈંધણ ઈતિહાસ

- **રિપોર્ટ → ઇતિહાસ ભરો** — રિપોર્ટ ફિલ્ટર્સ માટે કાલક્રમિક ભરણો (**ફક્ત ભરે છે**; કોઈ ટ્રિપ શરૂ થતી નથી).

![ઈતિહાસ રિપોર્ટ ભરો](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fill-history.jpg)

- **ઇંધણનો ઇતિહાસ** (જો તમારા બિલ્ડના નેવિગેશનમાં હાજર હોય તો) — પ્રતિ-વાહન ભરણ ઇન્વેન્ટરી, પણ માત્ર ભરે છે; સંપાદિત કરવા માટે પંક્તિને ટેપ કરો.

### <a id="trip-miles"></a> ટ્રીપ માઈલ

**અહેવાલ → ટ્રીપ માઈલ** — પ્રકાર, ચાર્ટ અને કાલક્રમિક **ટ્રીપ સ્ટાર્ટ/સેગમેન્ટ લિસ્ટ** દ્વારા માઈલ. તે પંક્તિ માટે **સંપાદિત ભરણ** ખોલવા માટે વાસ્તવિક શરૂઆત પર ટૅપ કરો.

![ટ્રીપ માઈલ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a>સંપાદિત કરો

ફિલ હિસ્ટ્રી, ફ્યુઅલ હિસ્ટ્રી અથવા ટ્રિપ માઇલમાંથી, ફિલ ખોલો. લેઆઉટ: વાહન અને ઓડોમીટર, **કિંમત પહેલાંનું ચલણ**, વોલ્યુમ, નોંધો. ટ્રિપનો પ્રકાર ત્યારે જ દેખાય છે જ્યારે પંક્તિ ટ્રિપની શરૂઆત હોય. સ્થાનનો સારાંશ વત્તા **સ્થાનની વિગતો** છે. મેઘ ઓળખ સાથેનો સ્થાનિક ફોટો ખૂટે છે: **આર્કાઇવમાંથી છબી મેળવો**.

![ભરણ સંપાદિત કરો — સ્થાનિક ફોટો ખૂટે ત્યારે આર્કાઇવમાંથી મેળવો](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

અન્ય કેટલોગ કાર્ડ્સમાં કેટેગરી, વાહન સારાંશ અને ખર્ચની સૂચિ દ્વારા ખર્ચનો સમાવેશ થાય છે.

જ્યારે સેટ હોય ત્યારે દરેક પંક્તિના ચલણનો ઉપયોગ કરે છે. મિશ્ર-ચલણનો કુલ **પ્રતિ-ચલણ પેટા-ટોટલ** (કોઈ સાયલન્ટ FX રૂપાંતરણ) દર્શાવે છે.

## <a id="syncing"></a> સમન્વયન

મેનુ → **સિંકીંગ** એ સ્પ્રેડશીટ અને ફોટો ડેસ્ટિનેશન માટેનું હબ છે (માત્ર સેટિંગ્સ હેઠળ જ નહીં).

![સિંકિંગ હબ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- ટૂંકી સ્થિતિ સાથે **સ્પ્રેડશીટ સમન્વયન** અને **ફોટો બેકઅપ** માટે કાર્ડ, તે પ્રકારના માટે **સમન્વયન** અને **›** ગંતવ્ય સૂચિમાં.
- **ટેસ્ટ કનેક્શન** માટે ગંતવ્ય ખોલો અને **હમણાં સિંક કરો (આ ગંતવ્ય)** / બધું ગોઠવેલું છે.
- નિષ્ફળતા **વિગતો** અને લાલ **!** અહીં ટાઈટલ બારમાં છે.
- સ્ટેપ-બાય-સ્ટેપ Google શીટ્સ અને ડ્રાઇવ સેટઅપ: [બેકઅપ્સ અને મલ્ટિ-ડિવાઈસ સિંક](#backups-and-multi-device-sync).

## <a id="settings-local-preferences"></a>સેટિંગ્સ (સ્થાનિક પસંદગીઓ)

મેનુ → **સેટિંગ**.

![સેટિંગ્સ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07-settings.jpg)

![વધુ સેટિંગ્સ (સ્ક્રોલ કરેલ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07b-settings-more.jpg)

ગંતવ્ય સ્થાનો માટે, **મેનુ → સમન્વયન** પસંદ કરો. સેટિંગ્સ હજી પણ સારાંશ પંક્તિઓ બતાવી શકે છે જે સમાન સૂચિઓ ખોલે છે.

### <a id="local-preferences-common"></a>સ્થાનિક પસંદગીઓ (સામાન્ય)

- **બળતણ રસીદના ફોટા સાચવો** / **ખર્ચના ફોટા સ્થાનિક રીતે સાચવો** — ઉપકરણ પર છબીઓ રાખો (ફોટો પરવાનગીની વિનંતી કરી શકે છે).
- **શટર સાઉન્ડ વગાડો**
- **ચલણ** / **વોલ્યુમ યુનિટ** — એપ્લિકેશન ડિફોલ્ટ્સ (સિસ્ટમ અથવા સ્પષ્ટ). હાલના ઈંધણ ડેટા સાથે વોલ્યુમ યુનિટ બદલવાથી કન્વર્ટ ડાયલોગ ઓફર થઈ શકે છે.
- **ડાર્ક મોડ**
- **સેટઅપ ટિપ્સ** — ફર્સ્ટ-રન વ્હીકલ / સિંક ટ્યુટોરિયલ્સ ફરીથી ખોલો.
- **ડીબગ ફિલ** / **પ્રયોગ સ્ક્રીન બતાવો (દેવ)** — અદ્યતન; દૈનિક ઉપયોગ માટે છોડી દો. પ્રયોગ સ્ક્રીનો અહીં દસ્તાવેજીકૃત નથી.

CSV **નિકાસ/આયાત** (વાહનો / ખર્ચ / બળતણ ટેબની ZIP) વર્તમાન બિલ્ડ દ્વારા ઓફર કરવામાં આવે ત્યારે સેટિંગ્સમાંથી ઉપલબ્ધ છે.
