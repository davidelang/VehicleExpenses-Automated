# <a id="vehicle-expenses-automated--user-manual"></a>Унаа чыгашалары автоматташтырылган — Колдонуучунун колдонмосу

> **Бакты түзөтүү (Markdown).** Серепчилер жана колдонмодогу окурман **көрсөтүлгөн HTML** ачат:
> - Веб: [`docs/user-manual/index.html`](index.html) (`./scripts/render-user-manual.sh` менен калыбына келтирүү)
> - Колдонмо: Жардам / Жөнүндө → толук колдонмо (кошумча HTML + скриншоттор)
>
> Акыркы колдонуучуларды чийки `.md` URL даректерине көрсөтпөңүз — браузерлер жалпак текстти гана көрсөтөт.

Камеранын биринчи жолу күйүүчү майга жана унаага кеткен чыгымдарга көз салуу, кошумча бир нече түзмөктү синхрондоштуруу жана **сиздин** булут эсебиңиздин камдык көчүрмөсү.

Бул **толук колдонмо** (скриншоттор + ар бир кадам). Телефондо **Меню → Жардам** баштоо үчүн кыскараак колдонмо болуп саналат.

**Бул жерде камтылган эмес:** Эски сүрөттөрдү, тегиздөө экспериментин жана насостук экспериментти импорттоо (иштеп чыгуучу / өркүндөтүлгөн куралдар).

## <a id="first-time-setup-manage-vehicles"></a>Биринчи жолу орнотуу: Унааларды башкаруу

OCR жана **автоматтык унаа дал келүүсү** ар бир унааны **маалымдама тактасынын сүрөтү** менен каттап, **Discovery** иштетип, калактан алынган одометрдин түшүмүн орноткондон кийин жана ошол сызык үчүн жерлерди сактагандан кийин жакшы иштейт.

### <a id="open-manage-vehicles"></a>Унааларды башкарууну ачыңыз

Меню → **Унааларды башкаруу**. Унааны тандаңыз (же **Жаңы унаа кошуу**).

![Маалымдама сызыкчалары, түшүмдөрү жана ачылыштары бар унааларды башкарыңыз](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a>Унааны кошуу же түзөтүү

1. **Унаа** ачылуучу тизмесин ачыңыз → унаа тандаңыз же **Жаңы Унаа кошуу**.
2. Таза **маалымдама сызыкча сүрөтүн** тартыңыз же тандаңыз (толук аспаптар кластери, жакшы жарыктанган, телефон болжол менен төрт бурчтуу). **Сүрөткө тартуу** же **Галерея** колдонуңуз.
3. **Run Discovery** баскычын таптаңыз — калак менен аныктоо сүрөткө сары **уруктарды** коёт (ориентирлер мурункудай эле `"ML Kit"` JSON колдонот).
4. **Select Odo** дегенди таптап, сандардагы уруктарды таптап, туткаларды тууралап, андан соң **Сактоо** баскычын басыңыз.
5. **Одо түзөтүү** мурунтан эле бар кутучаны тууралайт. **Clear Odo** аны жок кылат, анан баскыч **Select Odo** деп окуйт.
6. **Ориенталдык белгилерди көрсөтүү** менен карап чыгуу. Туура эмес окууларды оңдоо үчүн **OCRди түзөтүү** колдонуңуз же өтүп кеткен текстти **кошуңуз**.
7. **Унаанын аталышын** (талап кылынат), плюс маркасын/моделин/жылын/номерди каалагандай толтуруңуз.
8. **Унааны түзүү** же **Өзгөртүүлөрдү сактоо** баскычын таптаңыз (жаңы унаанын аталышы + маалымдама сүрөтү талап кылынат).

![Жаңы унаа формасынын талааларын кошуу](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/03b-manage-vehicles-new.jpg)

### <a id="landmarks-fix-what-discovery-missed"></a>Ориентификация: Discovery өткөрүп жиберген нерселерди оңдоо

**Ориенталдык белгилерди көрсөтүү** дегенден кийин, тизмени жылдырып, маанилерди тууралаңыз. Кыймылдаткычтар кээде кичинекей сандарды өткөрүп жиберишет (мисалы, кластердин төмөнкү оң жагындагы саат **60**). Унаанын аныктыгы ишенимдүү болушу үчүн, аларды кошуу же оңдоо үчүн **OCRди түзөтүү** колдонуңуз.

![Ориенттиктер диалогу — OCRди карап чыгуу жана түзөтүү](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a>Мыкты сүрөтсүз терүү

Сиз дагы эле унааны тандап, **терүү** одометрди, көлөмдү жана толтуруудагы бааны колдонуу менен колдоно аласыз — OCR ар бир талаа үчүн милдеттүү эмес. Галереяны импорттоо колдонмодо тартпоону кааласаңыз, шилтеме сызыкча сүрөтү үчүн иштейт.

**Кеңеш:** Электрондук жадыбалды синхрондоштуруудан кийин, унаа аныктамалары (эгиндер, жерлер) жергиликтүү маалымат базасында жашайт — аларды колдонуу үчүн Унааларды толтуруу үчүн башкарууну кайра ачуунун кереги жок.

## <a id="backups-and-multi-device-sync"></a>Камдык көчүрмөлөр жана көп түзмөк синхрондоштуруу

Колдонмо **бир нече телефондор же планшеттер бир эле флот дайындарын бөлүшө алышы үчүн** жана сиз **дайындарыңыздын жана сүрөттөрүңүздүн көчүрмөсүн түзмөктөн** сактай тургандай кылып курулган. Бул башка адамдар көрө ала турган компания тарабынан башкарылган "Унаа чыгашалары булуту" эмес, **сиз** каттоо эсебиңиздин же **сиздин** өзүңүздүн** серверлериңиздин астында конфигурациялаган багыттар менен жасалат.

### <a id="what-runs-where"></a>Эмне кайда чуркайт

| Kind | Эмне сактайт | Типтүү колдонуу |
|------|----------------|-------------|
| **Электрондук жадыбал/таблицалык синхрондоштуруу** | Унаалар, күйүүчү майлар, чыгашалар (катарлар жана таблицалар) | Көп түзмөктөрдү бириктирүү + структураланган камдык |
| **Сүрөттүн камдык көчүрмөсү** | Бинардык сүрөттөр (сызыкча/насос/дүмүрчөк/маалымдама сүрөттөр) | Сүрөттүн камдык көчүрмөсү + жок файлдарды калыбына келтирүү |

Ар бир түрдөгү **бир нече багыттарды** конфигурациялай аласыз (ар бир түргө жумшак капкак). Кол менен **Азыр синхрондоштуруу** жана **фондук** жумушчулар иштетилгендерди иштетет.

### <a id="offline-first"></a>Адегенде оффлайн

- Толтурууну, чыгашаны же дүмүрчөктү кошуу үчүн **Тармак талап кылынбайт**. Баары сакталат **жергиликтүү биринчи**.
- Тармак жеткиликтүү болгондо, синхрондоштуруу жана фотонун камдык көчүрмөсү **фондук тапшырмалар** (сиз койгон график боюнча жана **Азыр синхрондоштуруу** дегенди таптаганда) иштейт. Каталар Орнотуулар саптарынын астында кызыл текст жана колдонмонун аталыш тилкесинде **!** катары көрсөтүлөт.

### <a id="your-accounts-only"></a>Сиздин аккаунттарыңыз гана

Кирүү жана токендер сиз тандаган провайдерлердин түзмөгүндө кала берет (Google, Microsoft, S3 ачкычтары, өз алдынча жайгаштырылган URL'дер ж.б.у.с.). Бара турган жерлер **колдонуучунун толук көзөмөлүндө** — Google каттоо эсебиңиз, OneDrive, MiniIO чакаңыз, EtherCalc хостуңуз ж.б. Бөлүшүлгөн сервер аркылуу башка Vehicle Expenses колдонуучулары менен эч нерсе бөлүшүлбөйт.

### <a id="supported-targets--data-spreadsheet--tabular"></a>Колдоого алынган максаттар — берилиштер (электрондук жадыбал/таблица)

**Меню → Шайкештештирүү → Электрондук жадыбалды синхрондоштуруу** астында конфигурацияланган (Жөндөөлөрдүн жыйынды саптарынан да жеткиликтүү). Биринчи класстагы тандоо параметрлери:

| Максат | Эскертүүлөр |
|--------|--------|
| **Google Барактары** | Жалпы демейки; Транспорттук каражаттар, чыгашалар жана ар бир унаага күйүүчү май |
| **Excel** | График аркылуу Microsoft жумушчу китеби / OneDrive стилиндеги байланыш |
| **EtherCalc** | Өз алдынча жайгаштырылган биргелешкен электрондук жадыбал бөлмөлөрү |
| **Башка →** ишке ашырылган backends | **Baserow**, **NocoDB**, **Airtable**, **PocketBase**, **Supabase**, **Firebase**, **Zoho Sheet** |

Кийинкиге калтырылган / али башсыз эмес (Башкалардын астында тизмеленген, бирок толук ишке ашырылган эмес): OnlyOffice, Collabora. Ошондой эле караңыз [өз алдынча хосттун индекси](reference/self-host/INDEX.md).

CSV **экспорт/импорт** (ошол эле өтмөктүн форматындагы ZIP) Жөндөөлөрдөн жандуу синхрондоштуруудан көз карандысыз көчмө камдык көчүрмө катары жеткиликтүү.

### <a id="supported-targets--photos-image-backup"></a>Колдоого алынган максаттар — сүрөттөр (сүрөттөрдүн камдык көчүрмөсү)

**Меню → Шайкештештирүү → Сүрөттүн камдык көчүрмөсү** астында конфигурацияланган (ошондой эле Жөндөөлөрдүн корутунду саптарынан):

| Максат | Эскертүүлөр |
|--------|--------|
| **Google Drive** | Сиз тандаган папка (URL карап чыгуу же чаптоо) |
| **OneDrive** | Microsoft каттоо эсеби + жол префикси |
| **S3** | AWS, Wasabi, Cloudflare R2, MiniIO жана башка S3 шайкеш акыркы чекиттери |
| **Башка** | rclone тарабынан колдоого алынган сактагыч (мис., WebDAV, SFTP жана колдонмодогу тандагычта жеткиликтүү башка тандалып алынган пульттар) |

Өз алдынча жайгаштырылган сүрөттөр жана таблица максаттары үчүн жалган жадыбалдарды орнотуу: [өзүн-өзү хосттун индекси](reference/self-host/INDEX.md).

### <a id="multi-device-behavior-short"></a>Көптөгөн түзмөк аракети (кыска)

- Саптар **Жаңыртылган** убакыт белгилериндеги **акыркы жазуудагы утуштар** менен **Sync ID** менен бириктирилет.
- жок кылуу жумшак; башка түзмөктөгү жаңы түзөтүү сапты калыбына келтириши мүмкүн.

## <a id="fill-up-fuel"></a>Толтуруу (күйүүчү май)

Бул колдонмону ачканыңызда **башкы экран**.

### <a id="vehicle-selection-usually-automatic"></a>Унааны тандоо (көбүнчө автоматтык)

Сизге адегенде унааны тандоонун кереги жок. Унааларды башкарууда **ориентирлер** орнотулганда, сиз одометрди тартып алгандан кийин **кайсы унааны** автоматтык түрдө аныктай турган сызыкчаны толтуруңуз. Керек болсо жокко чыгаруу үчүн **Унаа** ачылуучу ылдый жагын дагы ачсаңыз болот.

### <a id="aim-at-the-odometer"></a>Одометрди максат кылыңыз

Одометр режиминде калып, кластерди алкак кылыңыз. Көрсөтмө: *Одометрге багыт алыңыз. Тартуу үчүн жапкычты таптаңыз.*

![Толтуруу — одометрдеги жандуу камера (алдын ала көрүүдөгү сызыкчанын үлгүсү)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a>Одометр жапкычынан кийин

OCR **Odo**ну толтуруп, унааны көрүнүктүү жерлерге дал келтирүүгө аракет кылат (зарыл болсо, экөөнү тең карап көрүңүз). Негизги баскыч кайра атуу үчүн **Кайра аракет кылуу** болуп калат. Көрсөтмө окууну жыйынтыктайт.

![Толтуруу — одометрдин OCR натыйжасы](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a>Насос режими (баасы жана көлөмү)

1. Насос режимине өтүү үчүн **↕** таптап коюңуз: *Насостун дисплейин (баасы/көлөмү) көздөңүз. Жапкычты таптаңыз.*
2. Насостун жыйынтыгын тартыңыз. Нарк жана көлөм талаалары толтурулат; алар алмаштырылса **↔** колдонуңуз.
3. Керек болсо валютаны же **G/L**, андан кийин **Сактоо** (диск) баскычын басыңыз. Бош талаалар **жарым-жартылай толтурууну** түзөт (дагы эле уруксат берилген).

![Толтуруу — насосту алдын ала көрүү / жыйынтыктар (алдын ала көрүүдөгү насостун үлгүсү)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

Кийинки аялдамага толтуруу боюнча каласыз (сакталгандан кийин талаалар тазаланат). Толук **оффлайн** иштеңиз; синхрондоштуруу конфигурацияланганда кийинчерээк фондо иштейт.

### <a id="manual-entry-no-camera--bad-ocr"></a>Кол менен киргизүү (камера жок / начар OCR)

1. **Odo**, **нарк** же **том** дегенди таптап, маанилерди териңиз (портрет системалык баскычтопту, пейзажда экрандагы баскычтопту колдонот).
2. Автоматтык аныктоо иштебей калса, **Унааны** тандаңыз же ырастаңыз.
3. Жогорудагыдай сактаңыз.

### <a id="modes-and-borders"></a>Ржимдер жана чектер

- **Жашыл чек ара** унаа+одонун тегерегинде → одометрди тартуу/түзөтүү.
- Наркы+көлөм → насос режиминин тегерегинде **Жашыл чек ара**.
- **Сактоо** унаа тандалганга чейин жана одо/баа/томдун жок дегенде биринде дайындар болмоюнча, ал эми OCR дагы эле иштебейт.

Экрандагы кеңеш (нускоо сызыгынын астында): *Жапкыч = тартуу · Диск = сактоо · ↕ = одо/насос режими · ↔ = алмаштыруу наркы/көлөмү.*

Негизги диаграмма картасы. Кошумча көрсөткүчтөр (мпг, G/ми сыяктуу көлөм/аралык, $/G сыяктуу бирдик баасы, нарк/аралык, айлык $, жол милясы, түрү боюнча % саякат) **Тиликтүү** урналар жана **көз карандысыз Y таразалары** (экономика солдо; акча жана саякат үй-бүлөлөрү оң жакта).

**Отчеттор → Сапардын милялары** — түрү, диаграммалары жана хронологиялык **саякаттын башталышы / сегмент тизмеси** боюнча миль. Ошол сап үчүн **Төлөмдү түзөтүү** ачуу үчүн чыныгы баштоону таптаңыз.

![Саякат миля](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a>Толтурууну түзөтүү

Толтуруунун тарыхынан, Күйүүчү майдын тарыхынан же Сапар милясынан толтурууну ачыңыз. Макет: унаа жана одометр, **баадан мурунку валюта**, көлөм, ноталар. Сапардын түрү сап сапардын башталышы болгондо гана көрүнөт. Жайгашкан жердин корутундусу жана **Жайгашкан жердин маалыматы** бар. ![Толтурууну түзөтүү — Жергиликтүү сүрөт жок болгондо архивден алуу](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

Башка каталог карталары категориялар боюнча чыгымдарды, транспорт каражаттарынын корутундусун жана чыгашалардын тизмесин камтыйт.

Акча коюлганда ар бир саптын валютасын колдонот. Аралаш валютадагы суммалар **бир валютанын ортосундагы суммаларды** көрсөтөт (үнсүз FX конвертациясы жок).

Көздөгөн жерлер үчүн **Меню → Шайкештештирүү** тандаңыз. Орнотуулар дагы эле ошол эле тизмелерди ачкан жыйынды саптарды көрсөтө бериши мүмкүн.

### <a id="local-preferences-common"></a>Жергиликтүү тандоолор (жалпы)

- **Күйүүчү майдын дүмүрчөктөрүнүн сүрөттөрүн үнөмдөө** / **Чыгым сүрөттөрүн жергиликтүү үнөмдөө** — сүрөттөрдү түзмөктө сактаңыз (Сүрөттөрдөн уруксат суралышы мүмкүн).
- **Жапкычтын үнүн ойнотуу**
- **Валюта** / **Көлөм бирдиги** — колдонмонун демейки параметрлери (тутум же ачык). Учурдагы күйүүчү май маалыматтары менен көлөм бирдигин өзгөртүү конвертациялоо диалогун сунуш кылышы мүмкүн.
- **Кара режим**
- **Орнотуу кеңештери** — биринчи иштетилген унаа / синхрондоштуруу үйрөткүчтөрүн кайра ачыңыз.
- **Debug Fill** / **Эксперимент экрандарын көрсөтүү (дев)** — өркүндөтүлгөн; күнүмдүк колдонуу үчүн таштап. Эксперимент экрандары бул жерде документтештирилбейт.

CSV **экспорт/импорт** (Унаалардын ZIP почтасы / Чыгымдар / Күйүүчү май өтмөктөрү) учурдагы түзүм сунуштаганда Жөндөөлөрдөн жеткиликтүү.
