## <a id="icons-at-a-glance"></a>Εικονίδια με μια ματιά

Εμφανίζονται στις κύριες οθόνες. Η γνώση τους σώζει πολύ το κυνήγι.

| Πού | Εικονίδιο / έλεγχος | Τι κάνει |
|-------|----------------|--------------|
| Κορυφαία μπάρα | **☰ Μενού** (χάμπουργκερ) | Ανοίγει το συρτάρι πλοήγησης |
| Κορυφαία μπάρα | **ⓘ** (βοήθεια σελίδας) | Σύντομη βοήθεια για την **τρέχουσα** σελίδα (δίπλα στο μενού όταν είναι διαθέσιμη) |
| Κορυφαία μπάρα | **`?N`** (κίτρινο) | Ερωτήσεις ελέγχου εισαγωγής σε εκκρεμότητα — ανοίγει Έλεγχος εισαγωγής |
| Κορυφαία μπάρα | ***!** (κόκκινο) | Ένα υπολογιστικό φύλλο ή ένας προορισμός φωτογραφίας απέτυχε πρόσφατα — ανοίξτε το **Συγχρονισμός** για να διορθώσετε |
| Κορυφαία μπάρα | **☰ + ←** | Η αναφορά παιδιών και η λίστα Εξόδων εμφανίζουν το **μενού και πίσω** μαζί. Ο κόμβος αναφορών είναι μόνο μενού |
| Ρυθμίσεις / επεξεργασία καυσίμου | **←** | Πίσω (υπολογιστικό φύλλο ρυθμίσεων/φωτογραφία και η επεξεργασία καυσίμου παραμένουν επικεντρωμένα) |
| Γέμισμα | **Λευκός κύκλος** (παντζούρι) | Λήψη χιλιομετρητή ή ένδειξης αντλίας για OCR |
| Γέμισμα | **Δίσκος / Αποθήκευση** | Αποθηκεύστε το γέμισμα (χρειάζεται ένα όχημα και τουλάχιστον ένα από odo / όγκο / κόστος) |
| Γέμισμα | **↕ βέλη** (διακόπτης λειτουργίας) | Εναλλαγή λειτουργίας **οδόμετρου** έναντι λειτουργίας **αντλίας (κόστος/όγκος)**. Το πράσινο περίγραμμα επισημαίνει την ομάδα ενεργών πεδίων |
| Γέμισμα | **↔ βέλη** (μεταξύ κόστους και όγκου) | Ανταλλάξτε το κόστος και τον όγκο εάν το OCR τα βάλει σε λάθος πεδία |
| Γέμισμα | **Ζουμ 1x / …** | Αναλογίες ζουμ κάμερας όταν ο φακός τις υποστηρίζει |
| Γέμισμα (μετά τη σύλληψη) | **Ανανέωση** στο κύριο κουμπί | Απορρίψτε την προεπισκόπηση και επιστρέψτε στη ζωντανή κάμερα |
| Συμπλήρωση (κατά την επεξεργασία) | **X** στο κύριο κουμπί | Ακύρωση λήψης σε εξέλιξη/OCR |
| Δαπάνες | **Αποθήκευση** | Εξοικονομήστε τα έξοδα |
| Δαπάνες | **Κύκλος κλείστρου** | Λήψη φωτογραφίας απόδειξης |
| Δαπάνες | **Γκαλερί** | Επιλέξτε μια εικόνα απόδειξης από τη βιβλιοθήκη |
| Δαπάνες | **Επανάληψη** | Διαγράψτε τη φωτογραφία της τρέχουσας απόδειξης και τραβήξτε ξανά |
| Έξοδα / Διαχείριση Οχημάτων | **+ / −** FABs | Μεγέθυνση της προεπισκόπησης φωτογραφίας |
| Διάλογος ορόσημα | **Επεξεργασία OCR** ​​| Διορθώστε ή προσθέστε κείμενο ορόσημο που έχασαν οι μηχανές |
| Υπολογιστικό φύλλο / Φόρμες φωτογραφιών | **🔍 Αναζήτηση ** | Περιηγηθείτε στο Google Drive για ένα φύλλο ή φάκελο (μετά την είσοδο) |

Τα σύμβολα νομισμάτων στα πεδία κόστους και **G/L** στα πεδία όγκου μπορούν να πατηθούν: ανοίξτε ένα μικρό μενού για να αλλάξετε νόμισμα ή γαλόνια έναντι λίτρων για αυτήν την καταχώρηση.

## <a id="first-time-setup-manage-vehicles"></a>Ρύθμιση για πρώτη φορά: Διαχείριση οχημάτων

OCR and **automatic vehicle matching** work best after you register each vehicle with a **reference dashboard photo**, run **Discovery**, set the odometer crop from a paddle seed, and save landmarks for that dash.

### <a id="open-manage-vehicles"></a>Open Manage Vehicles

Μενού → **Διαχείριση οχημάτων**. Επιλέξτε ένα όχημα (ή **Προσθήκη νέου οχήματος**).

![Διαχείριση οχημάτων με παύλα αναφοράς, καλλιέργειες και ανακάλυψη](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a>Προσθέστε ή επεξεργαστείτε ένα όχημα

1. Ανοίξτε το αναπτυσσόμενο μενού **Όχημα** → επιλέξτε ένα όχημα ή **Προσθήκη νέου οχήματος**.
2. Τραβήξτε ή επιλέξτε μια καθαρή **φωτογραφία παύλα αναφοράς** (πλήρες ταμπλό οργάνων, καλά φωτισμένο, τηλέφωνο σχεδόν τετράγωνο). Χρησιμοποιήστε το **Take Photo** ή το **Gallery**.
3. Πατήστε **Εκτέλεση Discovery** — η ανίχνευση κουπιών τοποθετεί κίτρινους **σπόρους** στη φωτογραφία (τα ορόσημα χρησιμοποιούν το ίδιο `"ML Kit"` JSON όπως πριν).
4. Πατήστε **Επιλέξτε Odo**, αγγίξτε τον σπόρο στα ψηφία, προσαρμόστε τις λαβές και μετά **Αποθήκευση**.
5. Η **Επεξεργασία Odo** προσαρμόζει ένα πλαίσιο που υπάρχει ήδη. Το **Clear Odo** το αφαιρεί και το κουμπί διαβάζει στη συνέχεια **Select Odo**.
6. Κριτική με **Εμφάνιση ορόσημων**. Χρησιμοποιήστε την **Επεξεργασία OCR** ​​για να διορθώσετε τις εσφαλμένες αναγνώσεις ή **να προσθέσετε** κείμενο που χάσατε.
7. Συμπληρώστε **Όνομα οχήματος** (απαιτείται), συν μάρκα/μοντέλο/έτος/πινακίδα όπως θέλετε.
8. Πατήστε **Δημιουργία οχήματος** ή **Αποθήκευση αλλαγών** (απαιτείται όνομα + φωτογραφία αναφοράς για νέο όχημα).

![Προσθήκη πεδίων φόρμας νέου οχήματος](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/03b-manage-vehicles-new.jpg)

### <a id="landmarks-fix-what-discovery-missed"></a>Ορόσημα: διορθώστε τι έχασε το Discovery

Μετά την **Εμφάνιση ορόσημων**, κάντε κύλιση στη λίστα και διορθώστε τις τιμές. Οι κινητήρες μερικές φορές χάνουν μικρά ψηφία (για παράδειγμα ένα ρολόι **60** κάτω δεξιά στο σύμπλεγμα). Χρησιμοποιήστε το **Επεξεργασία OCR** ​​για να τα προσθέσετε ή να τα διορθώσετε, ώστε η ταυτότητα του οχήματος να παραμένει αξιόπιστη.

![Διάλογος Landmarks — έλεγχος και επεξεργασία OCR](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a>Πληκτρολόγηση χωρίς τέλεια φωτογραφία

Μπορείτε ακόμα να χρησιμοποιήσετε την εφαρμογή επιλέγοντας ένα όχημα και **πληκτρολογώντας** χιλιομετρητή, ένταση και κόστος στο Fill — Το OCR είναι προαιρετικό για κάθε πεδίο. Η εισαγωγή συλλογής λειτουργεί για τη φωτογραφία αναφοράς παύλας όταν προτιμάτε να μην κάνετε λήψη εντός εφαρμογής.

**Συμβουλή:** Μετά τον συγχρονισμό υπολογιστικών φύλλων, οι ορισμοί των οχημάτων (καλλιέργειες, ορόσημα) βρίσκονται στην τοπική βάση δεδομένων — δεν χρειάζεται να ανοίξετε ξανά το Manage Vehicles for Fill για να τους χρησιμοποιήσετε.

## <a id="backups-and-multi-device-sync"></a>Δημιουργία αντιγράφων ασφαλείας και συγχρονισμός πολλών συσκευών

Η εφαρμογή έχει κατασκευαστεί έτσι ώστε **πολλά τηλέφωνα ή tablet να μπορούν να μοιράζονται τα ίδια δεδομένα στόλου** και έτσι να μπορείτε να κρατάτε ένα **αντίγραφο των δεδομένων και των φωτογραφιών σας εκτός συσκευής**. Αυτό γίνεται με προορισμούς **που** διαμορφώνετε κάτω από τους **τους** λογαριασμούς σας ή **τους** διακομιστές σας που φιλοξενούνται μόνοι σας — όχι ένα "σύννεφο δαπανών οχήματος" που διαχειρίζεται η εταιρεία και το οποίο μπορούν να δουν άλλα άτομα.

### <a id="what-runs-where"></a>Τι τρέχει πού

| Είδος | Τι αποθηκεύει | Τυπική χρήση |
|------|----------------|-------------|
| **Υπολογιστικό φύλλο / συγχρονισμός πίνακα** | Οχήματα, γεμίσματα καυσίμων, έξοδα (σειρές και καρτέλες) | Συγχώνευση πολλών συσκευών + δομημένο αντίγραφο ασφαλείας |
| **Δημιουργία αντιγράφων ασφαλείας φωτογραφιών** | Δυαδικές εικόνες (παύλα/αντλία/απόδειξη/φωτογραφίες αναφοράς) | Δημιουργία αντιγράφων ασφαλείας φωτογραφιών + επαναφορά αρχείων που λείπουν |

Μπορείτε να διαμορφώσετε **πολλαπλούς προορισμούς** κάθε είδους (soft cap ανά τύπο). Χειροκίνητα **Συγχρονισμός τώρα** και **παρασκήνιο** οι εργαζόμενοι εκτελούν τα ενεργοποιημένα.

### <a id="offline-first"></a>Πρώτα εκτός σύνδεσης

- **Δεν απαιτείται δίκτυο** για την προσθήκη συμπλήρωσης, δαπάνης ή απόδειξης. Όλα αποθηκεύονται **πρώτα τοπικά**.
- Όταν το δίκτυο είναι διαθέσιμο, ο συγχρονισμός και η δημιουργία αντιγράφων ασφαλείας φωτογραφιών εκτελούνται ως **εργασίες στο παρασκήνιο** (σε ένα χρονοδιάγραμμα που έχετε ορίσει και όταν πατάτε **Συγχρονισμός τώρα**). Οι αποτυχίες εμφανίζονται ως κόκκινο κείμενο κάτω από τις σειρές Ρυθμίσεις και ένα **!** στη γραμμή τίτλου της εφαρμογής.

### <a id="your-accounts-only"></a>Μόνο οι λογαριασμοί σας

Η είσοδος και τα διακριτικά παραμένουν στη συσκευή για τους παρόχους που επιλέγετε (Google, Microsoft, κλειδιά S3, αυτο-φιλοξενούμενες διευθύνσεις URL κ.λπ.). Οι προορισμοί βρίσκονται υπό **τον πλήρη έλεγχο του χρήστη** — ο Λογαριασμός σας Google, το OneDrive, ο κάδος MinIO, ο κεντρικός υπολογιστής EtherCalc κ.λπ. Τίποτα δεν κοινοποιείται με άλλους χρήστες του Vehicle Expenses μέσω ενός κοινόχρηστου backend.

### <a id="supported-targets--data-spreadsheet--tabular"></a>Υποστηριζόμενοι στόχοι — δεδομένα (υπολογιστικό φύλλο / πίνακας)

Διαμορφώθηκε στο **Μενού → Συγχρονισμός → Συγχρονισμός υπολογιστικού φύλλου** (επίσης προσβάσιμο από τις σειρές σύνοψης Ρυθμίσεις). Επιλογές επιλογής πρώτης κατηγορίας:

| Στόχος | Σημειώσεις |
|--------|--------|
| **Φύλλα Google** | Κοινή προεπιλογή. καρτέλες για Οχήματα, Έξοδα και καύσιμα ανά όχημα |
| **Excel** | Βιβλίο εργασίας της Microsoft μέσω Γράφημα / Σύνδεση σε στυλ OneDrive |
| **EtherCalc** | Αίθουσες λογιστικών φύλλων συνεργασίας που φιλοξενούνται μόνοι σας |
| **Άλλα →** υλοποιημένα backend | **Baserow**, **NocoDB**, **Airtable**, **PocketBase**, **Supabase**, **Firebase**, **Zoho Sheet** |

Αναβλήθηκε / δεν είναι ακόμα χωρίς κεφάλι (αναφέρεται στην ενότητα Άλλο αλλά δεν έχει εφαρμοστεί πλήρως): OnlyOffice, Collabora. Δείτε επίσης [ευρετήριο self-host](reference/self-host/INDEX.md).

CSV **export/import** (ZIP of the same tab layout) is available from Settings as a portable backup, independent of live sync.

### <a id="supported-targets--photos-image-backup"></a>Υποστηριζόμενοι στόχοι — φωτογραφίες (αντίγραφο ασφαλείας εικόνας)

Διαμορφώθηκε στο **Μενού → Συγχρονισμός → Δημιουργία αντιγράφων ασφαλείας φωτογραφιών** (επίσης από τις σειρές σύνοψης Ρυθμίσεις):

| Στόχος | Σημειώσεις |
|--------|--------|
| **Google Drive** | Φάκελος που επιλέγετε (περιήγηση ή επικόλληση διεύθυνσης URL) |
| **OneDrive** | Λογαριασμός Microsoft + πρόθεμα διαδρομής |
| **S3** | AWS, Wasabi, Cloudflare R2, MinIO και άλλα τελικά σημεία συμβατά με το S3 |
| **Άλλα** | Αποθηκευτικός χώρος με υποστήριξη rclone (π.χ. WebDAV, SFTP και άλλα επιλεγμένα τηλεχειριστήρια διαθέσιμα στο εργαλείο επιλογής εντός εφαρμογής) |

Ρύθμιση cheatsheets για αυτο-φιλοξενούμενους στόχους φωτογραφιών και πινάκων: [ευρετήριο self-host](reference/self-host/INDEX.md).

### <a id="multi-device-behavior-short"></a>Συμπεριφορά πολλών συσκευών (σύντομη)

- Οι σειρές συγχωνεύονται με **Sync ID** με **last-write-wins** σε **Updated** timestamps.
- Οι διαγραφές είναι απαλές. μια νεότερη τροποποίηση σε άλλη συσκευή μπορεί να επαναφέρει μια σειρά.
- Η εισαγωγή του **ίδιου γεμίσματος δύο φορές** σε δύο συσκευές δημιουργεί **δύο σειρές** — διαγράψτε το επιπλέον όταν το παρατηρήσετε.
- Περισσότερες λεπτομέρειες: [Συγχρονισμός σημειώσεων συμπεριφοράς](#sync-behavior-notes) και [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md).

![Λίστα συγχρονισμού υπολογιστικών φύλλων](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/08-spreadsheet-sync.jpg)

2. Πατήστε **Προσθήκη προορισμού υπολογιστικού φύλλου**.

![Επιλογέας παρόχου](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/09-spreadsheet-provider-picker.jpg)

3. Επιλέξτε **Φύλλα Google**.

![Φόρμα Φύλλων Google](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/10-spreadsheet-google-form.jpg)

4. **Συνδεθείτε με το Google** μία φορά — αυτή η σύνδεση σάς επιτρέπει επίσης να περιηγηθείτε. Εμφανιζόμενο όνομα → επικολλήστε μια **Διεύθυνση URL φύλλου** (ακόμα ισχύει) ή **🔍** περιηγηθείτε. Το Browse ανοίγει στο **Όλα & κοινόχρηστα** ώστε να μπορείτε να επιλέξετε ένα υπάρχον υπολογιστικό φύλλο που σας ανήκει ή που είναι κοινόχρηστο μαζί σας. Στη συνέχεια, προγραμματίστε επιλογές → ενεργοποίηση → αποθήκευση.
5. **Συγχρονισμός τώρα** μία φορά για δημιουργία/ενημέρωση καρτελών: `Vehicles`, `Expenses`, `Fuel - {vehicle name}`.

### <a id="example-add-google-drive-photos"></a>Παράδειγμα: προσθήκη Google Drive (φωτογραφίες)

1. **Μενού → Συγχρονισμός → Δημιουργία αντιγράφων ασφαλείας φωτογραφιών** (ή Ρυθμίσεις → Δημιουργία αντιγράφων ασφαλείας φωτογραφιών).

![Λίστα αντιγράφων ασφαλείας φωτογραφιών](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/11-photo-backup.jpg)

2. Πατήστε **Προσθήκη προορισμού φωτογραφίας**.

![Επιλογέας παρόχου φωτογραφιών](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/12-photo-provider-picker.jpg)

3. Επιλέξτε **Google Drive**.

![Φόρμα Google Drive](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/13-photo-google-form.jpg)

4. **Συνδεθείτε με το Google (Drive)** → URL προαιρετικού φακέλου/περιήγηση → ενεργοποίηση → αποθήκευση → **Συγχρονισμός τώρα**.

Εγχειρίδιο **Ο συγχρονισμός τώρα** για φωτογραφίες είναι ένα πλήρες πάσο. Η δημιουργία αντιγράφων ασφαλείας στο παρασκήνιο επεξεργάζεται συνήθως μεταφορτώσεις **μόνο σε εκκρεμότητα** βάσει χρονοδιαγράμματος.

### <a id="sync-behavior-notes"></a>Συγχρονισμός σημειώσεων συμπεριφοράς

- Μετά την αναβάθμιση της εφαρμογής, ενδέχεται να δείτε για λίγο **"Ενημέρωση βάσης δεδομένων μετά την αναβάθμιση..."** (τοπική συμπλήρωση αναγνωριστικού συγχρονισμού).
- Εάν ένας συγχρονισμός διακοπεί, ο επόμενος **επιτυχής** συγχρονισμός συγχωνεύεται ξανά και επιδιορθώνει τις απομακρυσμένες καρτέλες.
- Αποτυχίες: κόκκινη σύνοψη στις κάρτες Συγχρονισμός + **!** στη γραμμή εφαρμογών.

## <a id="fill-up-fuel"></a>Γέμισμα (καύσιμο)

Αυτή είναι η **αρχική οθόνη** όταν ανοίγετε την εφαρμογή.

### <a id="vehicle-selection-usually-automatic"></a>Επιλογή οχήματος (συνήθως αυτόματη)

**Δεν** χρειάζεται να επιλέξετε πρώτα το όχημα. Όταν τα οχήματα έχουν **ορόσημα** ρυθμισμένα στο Manage Vehicles, το Fill **εντοπίζει αυτόματα ποιο όχημα** από την εικόνα ταμπλό αφού καταγράψετε το χιλιομετρητή. Μπορείτε ακόμα να ανοίξετε το αναπτυσσόμενο μενού **Όχημα** για παράκαμψη, εάν χρειάζεται.

### <a id="aim-at-the-odometer"></a>Στόχευσε το χιλιομετρητή

Μείνετε σε λειτουργία χιλιομετρητή και πλαισιώστε το σύμπλεγμα. Οδηγία: *Στόχευση στο χιλιομετρητή. Πατήστε το κλείστρο για λήψη.*

![Γέμισμα — ζωντανή κάμερα στο χιλιομετρητή (παράδειγμα εικόνας παύλα σε προεπισκόπηση)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a>Μετά το κλείστρο του χιλιομετρητή

OCR γεμίζει το **Odo** και προσπαθεί να ταιριάξει το όχημα από ορόσημα (ελέγξτε και τα δύο εάν χρειάζεται). Το κύριο κουμπί γίνεται **Επανάληψη** για επανάληψη λήψης. Η οδηγία συνοψίζει την ανάγνωση.

![Γέμισμα — αποτέλεσμα OCR χιλιομετρητή](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a>Λειτουργία αντλίας (κόστος και όγκος)

1. Πατήστε **↕** για εναλλαγή στη λειτουργία αντλίας: *Στόχευση στην οθόνη αντλίας (κόστος/όγκος). Πατήστε κλείστρο.*
2. Καταγράψτε τα σύνολα της αντλίας. Συμπληρώνονται τα πεδία κόστους και όγκου. χρησιμοποιήστε **↔** εάν ανταλλάσσονται.
3. Πατήστε νόμισμα ή **G/L** εάν χρειάζεται και μετά **Αποθήκευση** (δίσκος). Τα κενά πεδία κάνουν **μερική συμπλήρωση** (ακόμα επιτρέπεται).

![Γέμισμα — προεπισκόπηση αντλίας / σύνολα (παράδειγμα εικόνας αντλίας σε προεπισκόπηση)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

Παραμένετε στο Fill για την επόμενη στάση (τα πεδία διαγράφονται μετά την αποθήκευση). Εργαστείτε πλήρως **εκτός σύνδεσης**. ο συγχρονισμός εκτελείται αργότερα στο παρασκήνιο όταν ρυθμιστεί.

### <a id="manual-entry-no-camera--bad-ocr"></a>Χειροκίνητη καταχώρηση (χωρίς κάμερα / κακή OCR)

1. Πατήστε **Odo**, **cost** ή **volume** και πληκτρολογήστε τιμές (το πορτραίτο χρησιμοποιεί το πληκτρολόγιο συστήματος, το οριζόντιο πληκτρολόγιο στην οθόνη).
2. Επιλέξτε ή επιβεβαιώστε το **Όχημα** εάν δεν εκτελέστηκε η αυτόματη ανίχνευση.
3. Αποθηκεύστε όπως παραπάνω.

### <a id="modes-and-borders"></a>Λειτουργίες και περιγράμματα

- **Πράσινο περίγραμμα** γύρω από το όχημα+odo → λήψη/επεξεργασία χιλιομετρητή.
- **Πράσινο περίγραμμα** γύρω από το κόστος+όγκος → λειτουργία αντλίας.
- Η **Αποθήκευση** παραμένει απενεργοποιημένη έως ότου επιλεγεί ένα όχημα και τουλάχιστον ένα από τα odo/cost/volume έχει δεδομένα και το OCR δεν λειτουργεί ακόμα.

Συμβουλή επί της οθόνης (κάτω από τη γραμμή οδηγιών): *Κλείστρο = λήψη · Δίσκος = αποθήκευση · ↕ = λειτουργία odo/άντλησης · ↔ = εναλλαγή κόστους/όγκου.*

## <a id="expenses"></a>Έξοδα

### <a id="new-expense"></a>Νέο έξοδο

Μενού → **Νέο έξοδο**.

![Νέα φόρμα εξόδων και στοιχεία ελέγχου κάμερας (παράδειγμα εικόνας παύλας στη ζώνη κάμερας όταν είναι κενή)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r6-new-expense.jpg)

1. **Αποθήκευση** (δίσκος), **κλείστρο** (φωτογραφία απόδειξης) ή **γκαλερί** (επιλογή εικόνας).
2. Συμπληρώστε **Ημερομηνία**, **Όχημα**, **Πωλητής**, **Περιγραφή**, **Ποσό** (το σύμβολο νομίσματος μπορεί να πατηθεί), **Κατηγορία**, προαιρετικό **Χιλιόμετρο**.
3. Αποδείξεις πολλών σελίδων: καταγράψτε επιπλέον σελίδες εάν το περιβάλλον χρήστη προσφέρει σελιδοποίηση (η σελίδα 0 είναι η κύρια απόδειξη).
4. **Αποθήκευση** για αποθήκευση (τοπικά πρώτα. Η δημιουργία αντιγράφων ασφαλείας φωτογραφιών και ο συγχρονισμός υπολογιστικού φύλλου γίνονται στο παρασκήνιο όταν διαμορφώνονται).

### <a id="expense-list"></a>Λίστα εξόδων

Μενού → **Αναφορές** → **Λίστα εξόδων** — περιηγηθείτε σε προηγούμενα έξοδα μη καυσίμων. ανοίξτε ένα στοιχείο για επεξεργασία.

![Λίστα εξόδων](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/05-expense-list.jpg)

### <a id="edit-expense"></a>Επεξεργασία εξόδων

Ανοίξτε μια σειρά από τη λίστα. Σωστός προμηθευτής, ποσό, κατηγορία, όχημα και περιγραφή. Εάν η απόδειξη είναι μόνο σε αντίγραφο ασφαλείας φωτογραφιών (δεν υπάρχει αναγνώσιμο τοπικό αρχείο), χρησιμοποιήστε τη **Λήψη εικόνας από το αρχείο** όταν εμφανίζεται (λειτουργεί σε διαμορφωμένους προορισμούς φωτογραφιών).

![Επεξεργασία εξόδων](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/expense-edit.jpg)

## <a id="reports"></a>Αναφορές

Μενού → **Αναφορές** ανοίγει το κέντρο προϊόντος (σύνοψη όλων των εποχών + κάρτες καταλόγου). Αυτή είναι η μόνη επιφάνεια αναφορών προϊόντων — δεν υπάρχει ξεχωριστό στοιχείο συρταριού "Αναφορές και γραφήματα".

![Κόμβος αναφορών](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/06-reports.jpg)

Ανοίξτε μια κάρτα για τη λειτουργία οχήματος (**Όλα / Κάθε / Μονό**), φίλτρα περιόδου, γραφήματα και κοινή χρήση (**TEXT / CSV / PDF**). Επάνω γραμμή στα παιδιά αναφοράς: **☰ + ←** (και **ⓘ** όταν είναι εγγεγραμμένοι).

### <a id="time-based-reports"></a>Αναφορές βάσει χρόνου

Η κύρια κάρτα γραφήματος. Προαιρετικές μετρήσεις (mpg, όγκος/απόσταση όπως G/mi, τιμή μονάδας όπως $/G, κόστος/απόσταση, μηνιαία $, μίλια ταξιδιού, % διαδρομής ανά τύπο) με **Smooth** δοχεία και **ανεξάρτητες κλίμακες Y** (οικονομία αριστερά, χρήματα και οικογένειες ταξιδιών στα δεξιά).

![Αναφορές βάσει χρόνου](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports.jpg)

![Αναφορές βάσει χρόνου — μετρήσεις με κύλιση](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports-scrolled.jpg)

Λεπτομέρειες μαθηματικών οικονομίας: [REPORTS_METRICS.md](reference/REPORTS_METRICS.md).

### <a id="fill-history-vs-fuel-history"></a>Ιστορικό πλήρωσης έναντι Ιστορικού καυσίμου

- **Αναφορές → Ιστορικό πλήρωσης** — χρονολογικά συμπληρώματα για τα φίλτρα αναφοράς (**γεμίζει μόνο**, δεν ξεκινά κανένα ταξίδι).

![Συμπλήρωση αναφοράς ιστορικού](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fill-history.jpg)

- **Ιστορικό καυσίμου** (εάν υπάρχει στην πλοήγηση της κατασκευής σας) — το απόθεμα πλήρωσης ανά όχημα, επίσης γεμίζει μόνο. πατήστε μια σειρά για επεξεργασία.

### <a id="trip-miles"></a>Μίλια ταξιδιού

**Αναφορές → Μίλια ταξιδιού** — μίλια ανά τύπο, γραφήματα και μια χρονολογική **Λίστα έναρξης/τμήματος ταξιδιού**. Πατήστε μια πραγματική αρχή για να ανοίξετε την **Επεξεργασία γεμίσματος** για αυτήν τη σειρά.

![Trip miles](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a>Επεξεργασία συμπλήρωσης

Από το ιστορικό πλήρωσης, το Ιστορικό καυσίμου ή τα μίλια ταξιδιού, ανοίξτε ένα γέμισμα. Διάταξη: όχημα και χιλιομετρητής, **νόμισμα πριν από το κόστος**, όγκος, σημειώσεις. Ο τύπος ταξιδιού εμφανίζεται μόνο όταν η σειρά είναι έναρξη ταξιδιού. Η τοποθεσία έχει μια σύνοψη συν **Λεπτομέρειες τοποθεσίας**. Λείπει τοπική φωτογραφία με ταυτότητα cloud: **Λήψη εικόνας από το αρχείο**.

![Επεξεργασία συμπλήρωσης — Λήψη από το αρχείο όταν λείπει η τοπική φωτογραφία](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

Άλλες κάρτες καταλόγου περιλαμβάνουν έξοδα ανά κατηγορία, περίληψη οχήματος και λίστα εξόδων.

Το Money χρησιμοποιεί το νόμισμα κάθε σειράς όταν ορίζεται. Τα σύνολα μικτών νομισμάτων εμφανίζουν **υποσύνολα ανά νόμισμα** (χωρίς σιωπηρή μετατροπή FX).

## <a id="syncing"></a>Συγχρονισμός

- Ανοίξτε έναν προορισμό για **Δοκιμή σύνδεσης** και **Συγχρονισμός τώρα (αυτός ο προορισμός)** / όλα έχουν διαμορφωθεί.

## <a id="settings-local-preferences"></a>Ρυθμίσεις (τοπικές προτιμήσεις)

Μενού → **Ρυθμίσεις**.

![Ρυθμίσεις](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07-settings.jpg)

![Περισσότερες ρυθμίσεις (με κύλιση)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07b-settings-more.jpg)

Για προορισμούς, προτιμήστε **Μενού → Συγχρονισμός**. Οι ρυθμίσεις ενδέχεται να εξακολουθούν να εμφανίζουν σειρές σύνοψης που ανοίγουν τις ίδιες λίστες.

### <a id="local-preferences-common"></a>Τοπικές προτιμήσεις (κοινές)

- **Αποθήκευση φωτογραφιών απόδειξης καυσίμου** / **Αποθήκευση φωτογραφιών δαπανών τοπικά** — διατηρήστε τις εικόνες στη συσκευή (μπορεί να ζητήσετε άδεια φωτογραφιών).
- **Αναπαραγωγή ήχου κλείστρου**
- **Νόμισμα** / **Μονάδα έντασης** — προεπιλογές εφαρμογής (σύστημα ή ρητά). Η αλλαγή της μονάδας όγκου με τα υπάρχοντα δεδομένα καυσίμου μπορεί να προσφέρει ένα παράθυρο διαλόγου μετατροπής.
- **Σκοτεινή λειτουργία**
- **Συμβουλές ρύθμισης** — ανοίξτε ξανά τα εκπαιδευτικά προγράμματα πρώτης κυκλοφορίας οχήματος/συγχρονισμού.
- **Γέμισμα εντοπισμού σφαλμάτων** / **Εμφάνιση οθονών πειράματος (dev)** — προηγμένες. αφήστε το για καθημερινή χρήση. Οι οθόνες πειράματος δεν τεκμηριώνονται εδώ.

CSV **εξαγωγή/εισαγωγή** (ZIP καρτέλες οχημάτων / εξόδων / καυσίμων) είναι διαθέσιμο από τις Ρυθμίσεις όταν προσφέρεται από την τρέχουσα έκδοση.
