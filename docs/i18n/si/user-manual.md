**මෙහි ආවරණය නොවේ:** පැරණි පින්තූර, පෙළගැස්වීමේ අත්හදා බැලීම සහ පොම්ප අත්හදා බැලීම (සංවර්ධක / උසස් මෙවලම්) ආයාත කරන්න.

## <a id="first-time-setup-manage-vehicles"></a>පළමු-වර පිහිටුවීම: වාහන කළමනාකරණය

OCR සහ **ස්වයංක්‍රීය වාහන ගැලපීම** ඔබ සෑම වාහනයක්ම **යොමු උපකරණ පුවරුවේ ඡායාරූපයක්** සමඟ ලියාපදිංචි කිරීමෙන් පසුව, **Discovery** ධාවනය කර, පැඩල් බීජයකින් odometer බෝගය සකසා, එම ඉර සඳහා බිම් සලකුණු සුරැකීමෙන් පසුව වඩාත් හොඳින් ක්‍රියා කරයි.

### <a id="open-manage-vehicles"></a>Vivicle Manage Vehicles

මෙනුව → **වාහන කළමනාකරණය**. වාහනයක් තෝරන්න (හෝ **නව වාහනයක් එකතු කරන්න**).

![යොමු ඉර, භෝග, සහ සොයාගැනීම් සහිත වාහන කළමනාකරණය කරන්න](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a>වාහනයක් එක් කරන්න හෝ සංස්කරණය කරන්න

1. **වාහන** පතන විවෘත කරන්න → වාහනයක් තෝරන්න හෝ **නව වාහනයක් එක් කරන්න**.
2. පැහැදිලි **යොමු ඩෑෂ් ඡායාරූපයක්** ග්‍රහණය කර ගන්න හෝ තෝරන්න **ඡායාරූප ගන්න** හෝ **ගැලරිය** භාවිතා කරන්න.
3. **Discovery ධාවනය කරන්න** තට්ටු කරන්න — paddle අනාවරණය ඡායාරූපයේ කහ **බීජ** ස්ථානගත කරයි (බිම් සලකුණු පෙර පරිදිම `"ML Kit"` JSON භාවිතා කරයි).
4. **ඔඩෝ තෝරන්න** තට්ටු කරන්න, ඉලක්කම් මත ඇති බීජය තට්ටු කරන්න, හැන්ඩ්ල් සීරුමාරු කරන්න, ඉන්පසු **සුරකින්න**.
5. **Edit Odo** දැනටමත් ඇති පෙට්ටියක් සකසයි. **Clear Odo** එය ඉවත් කරයි, සහ බොත්තම පසුව කියවයි **Odo තෝරන්න**.
6. ** බිම් සලකුණු පෙන්වන්න** සමඟ සමාලෝචනය කරන්න. වැරදි කියවීම් නිවැරදි කිරීමට **සංස්කරණය OCR** ​​භාවිතා කරන්න හෝ මඟ හැරුණු පෙළ ** එකතු කරන්න.
7. **වාහනයේ නම** (අවශ්‍ය), ඊට අමතරව ඔබ කැමති පරිදි සාදන්න/ආකෘතිය/වසර/තහඩුව පුරවන්න.
8. තට්ටු කරන්න **වාහන සාදන්න** හෝ **වෙනස්කම් සුරකින්න** (නව වාහනයක් සඳහා නම + යොමු ඡායාරූපයක් අවශ්‍ය වේ).

### <a id="landmarks-fix-what-discovery-missed"></a>Landmarks: Discovery මග හැරුණු දේ නිවැරදි කරන්න

** බිම් සලකුණු පෙන්වන්න** පසු, ලැයිස්තුව අනුචලනය කර අගයන් නිවැරදි කරන්න. එන්ජිමට සමහර විට කුඩා ඉලක්කම් මග හැරේ (උදාහරණයක් ලෙස පොකුරේ පහළ දකුණේ ඔරලෝසුව **60**). වාහන අනන්‍යතාවය විශ්වාසනීයව පවතින පරිදි ඒවා එක් කිරීමට හෝ නිවැරදි කිරීමට **Edit OCR** ​​භාවිතා කරන්න.

### <a id="typing-without-a-perfect-photo"></a> පරිපූර්ණ ඡායාරූපයක් නොමැතිව ටයිප් කිරීම

ඔබට වාහනයක් තේරීමෙන් සහ **ටයිප් කිරීමෙන්** ඕඩෝමීටරය, පරිමාව සහ පිරවුමේ පිරිවැය - OCR සෑම ක්ෂේත්‍රයක් සඳහාම වෛකල්පිත වේ. ඔබ යෙදුම තුළ රූගත නොකිරීමට කැමති විට ගැලරි ආයාත යොමු ඩෑෂ් ඡායාරූපය සඳහා ක්‍රියා කරයි.

**ඉඟිය:** පැතුරුම්පත් සමමුහුර්ත කිරීමෙන් පසු, වාහන නිර්වචන (බෝග, බිම් සලකුණු) දේශීය දත්ත ගබඩාවේ සජීවී වේ — ඔබට ඒවා භාවිතා කිරීමට පිරවීම සඳහා වාහන කළමනාකරණය නැවත විවෘත කිරීමට අවශ්‍ය නොවේ.

## <a id="backups-and-multi-device-sync"></a>Backups සහ multi-device sync

යෙදුම ගොඩනඟා ඇත්තේ **දුරකථන කිහිපයකට හෝ ටැබ්ලට් පරිගණක කිහිපයකට එකම සමූහයේ දත්ත** බෙදා ගැනීමට හැකි වන පරිදි, ඔබට **ඔබගේ දත්ත සහ ඡායාරූපවල පිටපතක් උපාංගයෙන් බැහැරව තබාගත හැක**. එය සිදු කරනු ලබන්නේ ගමනාන්ත **ඔබේ** ගිණුම් යටතේ වින්‍යාස කර ඇති **ඔබේ** ගිණුම් හෝ **ඔබේ** ස්වයං-සත්කාරක සේවාදායක - වෙනත් පුද්ගලයින්ට දැකිය හැකි සමාගමක් විසින් පවත්වාගෙන යනු ලබන “වාහන වියදම් වලාකුළක්” නොවේ.

ඔබට එක් එක් වර්ගයේ ** බහු ගමනාන්ත** වින්‍යාසගත කළ හැක (වර්ගයකට මෘදු කැප්). අතින් **දැන් සමමුහුර්ත කරන්න** සහ **පසුබිම්** කම්කරුවන් සබල කළ ඒවා ධාවනය කරයි.

### <a id="offline-first"></a>Offline පළමුව

- පිරවීමක්, වියදමක් හෝ රිසිට්පතක් එක් කිරීමට **ජාලයක් අවශ්‍ය නොවේ. සියල්ල සුරැකේ **දේශීයව පළමුව**.
- ජාලය පවතින විට, සමමුහුර්ත කිරීම සහ ඡායාරූප උපස්ථය **පසුබිම් කාර්යයන්** ලෙස ධාවනය කරන්න (ඔබ සකසා ඇති කාලසටහනකට අනුව, සහ ඔබ **සමමුහුර්ත කරන්න** තට්ටු කළ විට). අසාර්ථකත්වයන් සැකසීම් පේළි යටතේ රතු පාඨ ලෙස සහ යෙදුම් මාතෘකා තීරුවේ **!** ලෙස පෙන්වයි.

### <a id="multi-device-behavior-short"></a>Multi-device හැසිරීම (කෙටි)

- පේළි ඒකාබද්ධ කිරීම **සමමුහුර්ත හැඳුනුම්පත** සමඟ **අවසන් ලිවීම්-ජයග්‍රහණ** **යාවත්කාලීන කළ** වේලා මුද්‍රා මත.
- මකාදැමීම් මෘදුයි; වෙනත් උපාංගයක නව සංස්කරණයක් මඟින් පේළියක් ප්‍රතිසාධනය කළ හැක.

1. **මෙනුව → සමමුහුර්ත කිරීම → ඡායාරූප උපස්ථ** (හෝ සැකසීම් → ඡායාරූප උපස්ථ).

2. **ඡායාරූප ගමනාන්තය එක් කරන්න** තට්ටු කරන්න.

4. **Google (Drive) සමඟින් පුරනය වන්න** → විකල්ප ෆෝල්ඩරය URL/browse → enable → save → **Sync now**.

අතින් **දැන් සම්බන්ධ කරන්න** හැමෝම පින්තූර සඳහා පූර්ණ පසුගිය ක්‍රියාවලියක් වන අතර, පසුබැසි ගබඩා කිරීම සාමාන්‍යයෙන් කාලසටහනක් අනුව **රැඳී සිටින** උඩුගත කිරීම් ක්‍රියාත්මක කරයි.

### <a id="sync-behavior-notes"></a>චර්යා සටහන් සමමුහුර්ත කරන්න

- යෙදුම් උත්ශ්‍රේණිගත කිරීමෙන් පසු ඔබට කෙටියෙන් **“උත්ශ්‍රේණිගත කිරීමෙන් පසු දත්ත සමුදාය යාවත්කාලීන කිරීම...”** (දේශීය සමමුහුර්ත-id backfill) දැකිය හැක.
- සමමුහුර්ත කිරීමකට බාධාවක් සිදුවුවහොත්, මීළඟ **සාර්ථක** සමමුහුර්ත කිරීම නැවත ඒකාබද්ධ කර දුරස්ථ ටැබ් අලුත්වැඩියා කරයි.
- අසාර්ථකත්වය: යෙදුම් තීරුවේ සමමුහුර්ත කාඩ්පත් + **!** පිළිබඳ රතු සාරාංශය.

## <a id="fill-up-fuel"></a>Fill (ඉන්ධන)

ඔබ යෙදුම විවෘත කරන විට මෙය **මුල් තිරය** වේ.

### <a id="vehicle-selection-usually-automatic"></a>වාහන තේරීම (සාමාන්‍යයෙන් ස්වයංක්‍රීය)

ඔබට **නෑ** පළමුව වාහනය තෝරා ගැනීමට අවශ්‍ය වේ. වාහන කළමනාකරණය තුළ වාහන ** බිම් සලකුණු** පිහිටුවා ඇති විට, ඔබ ඕඩෝමීටරය ග්‍රහණය කර ගත් පසු ඩෑෂ් රූපයෙන් ** කුමන වාහනයදැයි ස්වයංක්‍රීයව හඳුනා ගනී. ඔබට තවමත් අවශ්‍ය නම් අභිබවා යාමට **වාහන** පතන විවෘත කළ හැක.

### <a id="aim-at-the-odometer"></a>ඕඩෝමීටරය ඉලක්ක කරන්න

odometer මාදිලියේ රැඳී පොකුර රාමු කරන්න. උපදෙස්: *ඕඩෝමීටරය ඉලක්ක කරන්න. අල්ලා ගැනීමට ෂටරය තට්ටු කරන්න.*

![පුරවන්න — odometer මත සජීවී කැමරාව (පෙරදසුනෙහි උදාහරණ ඩෑෂ් රූපය)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a>odometer ෂටරයට පසුව

OCR **Odo** පුරවා, බිම් සලකුණු වලින් වාහනය ගැලපීමට උත්සාහ කරයි (අවශ්‍ය නම් දෙකම සමාලෝචනය කරන්න). ප්‍රධාන බොත්තම නැවත රූගත කිරීමට **නැවත උත්සාහ කරන්න** බවට පත් වේ. උපදෙස් කියවීම සාරාංශ කරයි.

![පුරවන්න — odometer OCR ප්‍රතිඵලය](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a>Pump mode (පිරිවැය සහ පරිමාව)

1. පොම්ප ප්‍රකාරයට මාරු වීමට **↕** තට්ටු කරන්න: *පොම්ප සංදර්ශකය ඉලක්ක කරන්න (පිරිවැය/පරිමාව). ටැප් ෂටරය.*
2. පොම්ප එකතුව අල්ලා ගන්න. පිරිවැය සහ පරිමාව ක්ෂේත්ර පිරවීම; ඒවා මාරු කර ඇත්නම් **↔** භාවිතා කරන්න.
3. අවශ්‍ය නම් මුදල් හෝ **G/L** තට්ටු කරන්න, ඉන්පසු **සුරකින්න** (තැටිය). හිස් ක්ෂේත්‍ර **අර්ධ පිරවීමක්** සිදු කරයි (තවමත් අවසර දී ඇත).

![පුරවන්න — පොම්ප පෙරදසුන / එකතුව (පෙරදසුනෙහි උදාහරණ පොම්ප රූපය)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

ඔබ ඊළඟ නැවතුම සඳහා පුරවන්න (සුරකීමෙන් පසු ක්ෂේත්‍ර පැහැදිලි). සම්පුර්ණයෙන්ම වැඩ කරන්න **නොබැඳි**; වින්‍යාස කළ විට සමමුහුර්තකරණය පසුව පසුබිමේ ක්‍රියාත්මක වේ.

### <a id="manual-entry-no-camera--bad-ocr"></a>Manual entry (කැමරාවක් නැත / නරක OCR)

1. **Odo**, **cost**, හෝ ** Volume** තට්ටු කර අගයන් ටයිප් කරන්න (ආලේඛ්‍ය චිත්‍රය පද්ධති යතුරුපුවරුව භාවිතා කරයි; භූ දර්ශනය තිරයේ යතුරු පෑඩයක් භාවිතා කරයි).
2. ස්වයංක්‍රීය හඳුනාගැනීම ක්‍රියාත්මක නොවූයේ නම් **වාහන** තෝරන්න හෝ තහවුරු කරන්න.
3. ඉහත ආකාරයට සුරකින්න.

### <a id="modes-and-borders"></a>Modes සහ borders

- **හරිත මායිම** වාහනය+ඕඩෝ → අල්ලා ගැනීම/සංස්කරණය ඕඩෝමීටරය වටා.
- **හරිත මායිම** පිරිවැය+පරිමාව → පොම්ප මාදිලිය වටා.
- වාහනයක් තෝරා ගන්නා තෙක් **සුරකින්න** අක්‍රියව පවතින අතර අඩුම තරමින් odo/cost/volume එකක දත්ත ඇති අතර OCR තවමත් ක්‍රියාත්මක නොවේ.

තිරයේ ඉඟිය (උපදෙස් රේඛාවට පහළින්): *Shutter = ග්‍රහණ · Disk = save · ↕ = odo/pomp mode · ↔ = swap පිරිවැය/පරිමාව.*

## <a id="expenses"></a>වියදම්

### <a id="new-expense"></a>නව වියදම

මෙනුව → **නව වියදම්**.

![නව වියදම් පෝරමය සහ කැමරා පාලන (උදාහරණ කැමරා බෑන්ඩ් හි ඇති ඉරි රූපය හිස් වූ විට)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r6-new-expense.jpg)

1. ** සුරකින්න** (තැටිය), ** ෂටර්** (රිසිට්පත් ඡායාරූපය), හෝ ** ගැලරිය** (පින්තූරය තෝරන්න).
2. **දිනය**, **වාහන**, **වෙළෙන්දා**, **විස්තරය**, **මුදල්** (මුදල් සංකේතය තට්ටු කළ හැකි), **ප්‍රවර්ගය**, විකල්ප **Odometer** පුරවන්න.
3. බහු-පිටු රිසිට්පත්: UI විසින් පිටුකරණය ලබා දෙන්නේ නම් අමතර පිටු ග්‍රහණය කරන්න (පිටුව 0 ප්‍රාථමික ලදුපතයි).
4. ගබඩා කිරීමට **සුරකින්න** (දේශීය පළමුව; ඡායාරූප උපස්ථ සහ පැතුරුම්පත් සමමුහුර්තකරණය වින්‍යාස කළ විට පසුබිමේ සිදු වේ).

## <a id="start-trip"></a>සංචාරය අරඹන්න

## <a id="reports"></a>Reports

මෙනුව → **වාර්තා** නිෂ්පාදන කේන්ද්‍රය විවෘත කරයි (සියලු කාලීන සාරාංශය + නාමාවලි කාඩ්පත්). එකම නිෂ්පාදන වාර්තා මතුපිට මෙයයි - වෙනම "වාර්තා සහ ප්‍රස්ථාර" ලාච්චු අයිතමයක් නොමැත.

### <a id="trip-miles"></a>Trip miles

**වාර්තා → සංචාර සැතපුම්** — වර්ගය අනුව සැතපුම්, ප්‍රස්ථාර, සහ කාලානුක්‍රමික **සංචාර ආරම්භය / ඛණ්ඩ ලැයිස්තුව**. එම පේළිය සඳහා **සංස්කරණ පිරවීම** විවෘත කිරීමට සැබෑ ආරම්භයක් තට්ටු කරන්න.

### <a id="edit-fill"></a>Fill සංස්කරණය කරන්න

පිරවුම් ඉතිහාසය, ඉන්ධන ඉතිහාසය හෝ සංචාර සැතපුම් වලින් පිරවුමක් විවෘත කරන්න. පිරිසැලසුම: වාහනය සහ ඕඩෝමීටරය, ** පිරිවැයට පෙර මුදල්**, පරිමාව, සටහන්. සංචාර වර්ගය දිස්වන්නේ පේළිය චාරිකා ආරම්භයක් වූ විට පමණි. ස්ථානයට සාරාංශයක් සහ **ස්ථාන විස්තර** ඇත. වලාකුළු අනන්‍යතාවය සහිත දේශීය ඡායාරූපය අස්ථානගත වී ඇත: **සංරක්ෂිතයෙන් රූපය ලබා ගන්න**.

![සංස්කරණය පිරවීම - දේශීය ඡායාරූපය නැති වූ විට සංරක්ෂිතයෙන් ලබා ගන්න](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

අනෙකුත් නාමාවලි කාඩ්පත් වර්ග අනුව වියදම්, වාහන සාරාංශය සහ වියදම් ලැයිස්තුව ඇතුළත් වේ.

මුදල් සැකසූ විට එක් එක් පේළියේ මුදල් භාවිත කරයි. මිශ්‍ර-මුදල් එකතුව **එක් මුදල් උප එකතුව** පෙන්වයි (නිහඬ FX පරිවර්තනයක් නැත).

## <a id="syncing"></a>Syncing

Menu → **Syncing** යනු පැතුරුම්පත් සහ ඡායාරූප ගමනාන්ත සඳහා කේන්ද්‍රස්ථානයයි (සැකසීම් යටතේ පමණක් වළලනු නොලැබේ).

![සමමුහුර්ත මධ්‍යස්ථානය](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- කෙටි තත්ත්‍වයක් සහිත **පැතුරුම්පත් සමමුහුර්ත කිරීම** සහ **ඡායාරූප උපස්ථ** සඳහා කාඩ්පත්, **සමමුහුර්ත කරන්න**, සහ ගමනාන්ත ලැයිස්තුවට **›**.
- **පරීක්ෂණ සම්බන්ධතාවය** සඳහා ගමනාන්තයක් විවෘත කරන්න සහ **දැන් සමමුහුර්ත කරන්න (මෙම ගමනාන්තය)** / සියල්ල වින්‍යාස කර ඇත.
- අසාර්ථක **විස්තර** සහ මෙහි හිමිකම් තීරුවේ ඉඩමේ රතු **!**.
- පියවරෙන් පියවර Google Sheets සහ Drive පිහිටුවීම: [උපස්ථ සහ බහු උපාංග සමමුහුර්ත කිරීම](#backups-and-multi-device-sync).

## <a id="settings-local-preferences"></a>Settings (දේශීය මනාප)

මෙනුව → **සැකසීම්**.

![සැකසීම්](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07-settings.jpg)

![තවත් සැකසුම් (අනුචලනය කරන ලද)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07b-settings-more.jpg)

ගමනාන්ත සඳහා, **මෙනුව → සමමුහුර්ත කිරීම** කැමති. සැකසීම් තවමත් එකම ලැයිස්තු විවෘත කරන සාරාංශ පේළි පෙන්විය හැක.

### <a id="local-preferences-common"></a>දේශීය මනාප (පොදු)

- **ඉන්ධන ලදුපත් ඡායාරූප සුරකින්න** / **වියදම් ඡායාරූප දේශීයව සුරකින්න** — පින්තූර උපාංගයේ තබා ගන්න (ඡායාරූප අවසරය ඉල්ලා සිටිය හැක).
- **Shutter Sound වාදනය කරන්න**
- **මුදල්** / **පරිමා ඒකකය** — යෙදුම් පෙරනිමි (පද්ධතිය හෝ පැහැදිලි). පවතින ඉන්ධන දත්ත සමඟ පරිමා ඒකකය වෙනස් කිරීම පරිවර්තන සංවාදයක් ලබා දිය හැක.
- **අඳුරු මාදිලිය**
- **Setup tips** — පළමු ධාවන වාහන / සමමුහුර්ත නිබන්ධන නැවත විවෘත කරන්න.
- **Debug Fill** / **පරීක්ෂණ තිර පෙන්වන්න (dev)** — උසස්; දෛනික භාවිතය සඳහා නිවාඩු. අත්හදා බැලීම් තිර මෙහි ලේඛනගත කර නොමැත.

CSV **අපනයන/ආනයනය** (වාහන / වියදම් / ඉන්ධන ටැබ් ZIP) වත්මන් ගොඩනැගීමෙන් පිරිනමන විට සැකසීම් වෙතින් ලබා ගත හැක.
