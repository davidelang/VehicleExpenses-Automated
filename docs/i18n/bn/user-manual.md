# <a id="vehicle-expenses-automated--user-manual"></a> যানবাহন খরচ স্বয়ংক্রিয় — ব্যবহারকারী ম্যানুয়াল

> **উৎস সম্পাদনা করুন (মার্কডাউন)।** ব্রাউজার এবং ইন-অ্যাপ রিডার **রেন্ডার করা HTML** খুলবে:
> - ওয়েব: [`docs/user-manual/index.html`](index.html) (`./scripts/render-user-manual.sh` দিয়ে পুনরায় তৈরি করুন)
> - অ্যাপ: সহায়তা / সম্বন্ধে → সম্পূর্ণ ম্যানুয়াল (বান্ডিল HTML + স্ক্রিনশট)
>
> কাঁচা `.md` ইউআরএল-এ শেষ ব্যবহারকারীদের নির্দেশ করবেন না — ব্রাউজার শুধুমাত্র প্লেইন টেক্সট দেখায়।

**আপনার** ক্লাউড অ্যাকাউন্টের অধীনে ঐচ্ছিক মাল্টি-ডিভাইস সিঙ্ক এবং ব্যাকআপ সহ জ্বালানী ফিল-আপ এবং গাড়ির খরচের জন্য ক্যামেরা-প্রথম ট্র্যাকিং।

এটি **সম্পূর্ণ ম্যানুয়াল** (স্ক্রিনশট + প্রতিটি ধাপ)। ফোনে, **মেনু → সহায়তা** হল একটি সংক্ষিপ্ত শুরুর নির্দেশিকা।

**এখানে কভার করা নেই:** পুরানো ছবি, প্রান্তিককরণ পরীক্ষা, এবং পাম্প পরীক্ষা (বিকাশকারী / উন্নত সরঞ্জাম) আমদানি করুন।

## <a id="what-you-need"></a> আপনার যা প্রয়োজন

- Android ফোন বা ট্যাবলেট।
- সেরা OCR-এর জন্য: আপনার **ড্যাশবোর্ড ওডোমিটার** এবং **পাম্প টোটাল** এর একটি পরিষ্কার দৃশ্য (বা হাত দিয়ে সংখ্যা টাইপ করুন)।
- ঐচ্ছিক: স্প্রেডশীট ডেটা এবং/অথবা ফটো ব্যাকআপের জন্য অ্যাকাউন্টগুলি **আপনি নিয়ন্ত্রণ করেন** (দেখুন [ব্যাকআপ এবং মাল্টি-ডিভাইস সিঙ্ক](#backups-and-multi-device-sync))।

![নেভিগেশন ড্রয়ার](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/01-drawer.jpg)

## <a id="first-time-setup-manage-vehicles"></a>প্রথমবার সেটআপ: যানবাহন পরিচালনা করুন

OCR এবং **স্বয়ংক্রিয় যানবাহন ম্যাচিং** আপনি একটি **রেফারেন্স ড্যাশবোর্ড ফটো** দিয়ে প্রতিটি গাড়ি নিবন্ধন করার পরে, **আবিষ্কার** চালান, একটি প্যাডেল বীজ থেকে ওডোমিটার ক্রপ সেট করার পরে এবং সেই ড্যাশের জন্য ল্যান্ডমার্ক সংরক্ষণ করার পরে সবচেয়ে ভাল কাজ করে৷

### <a id="open-manage-vehicles"></a> যানবাহন পরিচালনা করুন

মেনু → **যানবাহন পরিচালনা করুন**। একটি যান চয়ন করুন (বা **নতুন যান যোগ করুন**)।

![রেফারেন্স ড্যাশ, ফসল এবং আবিষ্কার সহ যানবাহন পরিচালনা করুন](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a>একটি গাড়ি যোগ করুন বা সম্পাদনা করুন

1. **যানবাহন** ড্রপডাউন খুলুন → একটি যান বাছাই করুন বা **নতুন যান যোগ করুন**।
2. ক্যাপচার করুন বা একটি পরিষ্কার **রেফারেন্স ড্যাশ ফটো** বাছাই করুন (সম্পূর্ণ ইন্সট্রুমেন্ট ক্লাস্টার, ভাল আলো, ফোন মোটামুটি স্কোয়ার-অন)। **ফটো তুলুন** বা **গ্যালারি** ব্যবহার করুন।
3. **Run Discovery** এ আলতো চাপুন — প্যাডেল সনাক্তকরণ ফটোতে হলুদ **বীজ** রাখে (ল্যান্ডমার্কগুলি আগের মতো একই `"ML Kit"` JSON ব্যবহার করে)।
4. **Odo নির্বাচন করুন** আলতো চাপুন, অঙ্কগুলিতে বীজে আলতো চাপুন, হ্যান্ডলগুলি সামঞ্জস্য করুন, তারপর **সংরক্ষণ করুন**।
5. **ওডো সম্পাদনা করুন** একটি বাক্সকে সামঞ্জস্য করে যা আগে থেকেই আছে। **ক্লিয়ার ওডো** এটিকে সরিয়ে দেয় এবং বোতামটি পরে **ওডো নির্বাচন করুন** পড়ে।
6. **ল্যান্ডমার্ক দেখান** দিয়ে পর্যালোচনা করুন। ভুল পড়া ঠিক করতে **ওসিআর সম্পাদনা করুন** ব্যবহার করুন বা মিস করা পাঠ্য **যোগ করুন**।
7. **গাড়ির নাম** পূরণ করুন (প্রয়োজনীয়), প্লাস আপনার পছন্দ মতো তৈরি করুন/মডেল/বছর/প্লেট।
8. **যানবাহন তৈরি করুন** বা **পরিবর্তনগুলি সংরক্ষণ করুন** (নতুন গাড়ির জন্য নাম + রেফারেন্স ফটো প্রয়োজন) আলতো চাপুন।

![নতুন যানবাহনের ফর্ম ক্ষেত্র যোগ করুন](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/03b-manage-vehicles-new.jpg)

### <a id="landmarks-fix-what-discovery-missed"></a>ল্যান্ডমার্ক: ডিসকভারি যা মিস করেছে তা ঠিক করুন

**ল্যান্ডমার্ক দেখান** এর পরে, তালিকাটি স্ক্রোল করুন এবং মানগুলি সঠিক করুন। ইঞ্জিন কখনও কখনও ছোট অঙ্কগুলি মিস করে (উদাহরণস্বরূপ ক্লাস্টারের নীচে ডানদিকে একটি ঘড়ি **60**)। এগুলি যোগ করতে বা ঠিক করতে **সম্পাদনা OCR** ​​ব্যবহার করুন যাতে গাড়ির পরিচয় নির্ভরযোগ্য থাকে৷

![ল্যান্ডমার্ক ডায়ালগ — পর্যালোচনা করুন এবং OCR সম্পাদনা করুন](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a> একটি নিখুঁত ছবি ছাড়া টাইপিং

আপনি এখনও একটি গাড়ি নির্বাচন করে অ্যাপটি ব্যবহার করতে পারেন এবং **টাইপ** ওডোমিটার, ভলিউম, এবং ফিল-এ খরচ — OCR প্রতিটি ক্ষেত্রের জন্য ঐচ্ছিক। গ্যালারি আমদানি রেফারেন্স ড্যাশ ছবির জন্য কাজ করে যখন আপনি অ্যাপ-মধ্যস্থ শুট করতে পছন্দ করেন না।

**টিপ:** স্প্রেডশীট সিঙ্ক করার পরে, গাড়ির সংজ্ঞাগুলি (ফসল, ল্যান্ডমার্ক) স্থানীয় ডাটাবেসে থাকে — সেগুলি ব্যবহার করার জন্য আপনাকে ভরাট করার জন্য যানবাহনগুলিকে পুনরায় খোলার দরকার নেই৷

## <a id="backups-and-multi-device-sync"></a>ব্যাকআপ এবং মাল্টি-ডিভাইস সিঙ্ক

অ্যাপটি এমনভাবে তৈরি করা হয়েছে যাতে **বেশ কয়েকটি ফোন বা ট্যাবলেট একই ফ্লিট ডেটা ভাগ করতে পারে**, এবং তাই আপনি **আপনার ডেটা এবং ফটোগুলির একটি অনুলিপি ডিভাইসের বাইরে রাখতে পারেন**। এটি গন্তব্যগুলির সাথে করা হয় **আপনি** **আপনার** অ্যাকাউন্ট বা **আপনার** স্ব-হোস্ট করা সার্ভারের অধীনে কনফিগার করেন — কোনো কোম্পানি-চালিত "ভেহিক্যাল এক্সপেনস ক্লাউড" নয় যা অন্য লোকেরা দেখতে পারে।

### <a id="what-runs-where"></a>কি চলে কোথায়

| সদয় | এটা কি সঞ্চয় করে | সাধারণ ব্যবহার |
|------|----------------|-------------|
| **স্প্রেডশীট/টেবুলার সিঙ্ক** | যানবাহন, জ্বালানি ভর্তি, খরচ (সারি এবং ট্যাব) | মাল্টি-ডিভাইস মার্জ + স্ট্রাকচার্ড ব্যাকআপ |
| **ফটো ব্যাকআপ** | বাইনারি ছবি (ড্যাশ/পাম্প/রসিদ/রেফারেন্স ফটো) | ফটো ব্যাকআপ + অনুপস্থিত ফাইল পুনরুদ্ধার |

আপনি প্রতিটি ধরণের **একাধিক গন্তব্য** কনফিগার করতে পারেন (প্রতি প্রকার নরম ক্যাপ)। ম্যানুয়াল **এখনই সিঙ্ক করুন** এবং **ব্যাকগ্রাউন্ড** কর্মীরা সক্রিয়গুলি চালান।

### <a id="offline-first"></a>অফলাইন প্রথমে

- একটি ফিল-আপ, খরচ বা রসিদ যোগ করতে **কোন নেটওয়ার্কের প্রয়োজন নেই। সবকিছু **স্থানীয়ভাবে প্রথমে** সংরক্ষিত হয়।
- নেটওয়ার্ক উপলব্ধ হলে, সিঙ্ক এবং ফটো ব্যাকআপ **ব্যাকগ্রাউন্ড টাস্ক** হিসাবে চলে (আপনার সেট করা একটি সময়সূচীতে, এবং যখন আপনি **এখনই সিঙ্ক করুন** আলতো চাপুন)। ব্যর্থতাগুলি সেটিংস সারির নীচে লাল টেক্সট এবং অ্যাপ শিরোনাম বারে একটি **!** হিসাবে দেখায়৷

### <a id="your-accounts-only"></a> শুধুমাত্র আপনার অ্যাকাউন্ট

সাইন-ইন এবং টোকেন আপনার চয়ন করা প্রদানকারীদের জন্য ডিভাইসে থাকে (Google, Microsoft, S3 কী, স্ব-হোস্ট করা URL, এবং আরও অনেক কিছু)। গন্তব্যগুলি **ব্যবহারকারীর সম্পূর্ণ নিয়ন্ত্রণের অধীনে** — আপনার Google অ্যাকাউন্ট, আপনার OneDrive, আপনার MinIO বালতি, আপনার EtherCalc হোস্ট, ইত্যাদি। শেয়ার্ড ব্যাকএন্ডের মাধ্যমে অন্য যানবাহন খরচ ব্যবহারকারীদের সাথে কিছুই ভাগ করা হয় না।

### <a id="supported-targets--data-spreadsheet--tabular"></a>সমর্থিত লক্ষ্য — ডেটা (স্প্রেডশীট/টেবুলার)

**মেনু → সিঙ্কিং → স্প্রেডশীট সিঙ্ক** এর অধীনে কনফিগার করা হয়েছে (সেটিংস সারাংশ সারি থেকেও পৌঁছানো যায়)। প্রথম-শ্রেণীর চয়নকারী বিকল্প:

| লক্ষ্য | নোট |
|---------|---------|
| **গুগল শীট** | সাধারণ ডিফল্ট; যানবাহন, খরচ, এবং প্রতি যানবাহনের জ্বালানীর জন্য ট্যাব |
| **এক্সেল** | গ্রাফ / ওয়ানড্রাইভ-স্টাইল বাইন্ডিংয়ের মাধ্যমে মাইক্রোসফ্ট ওয়ার্কবুক |
| **ইথারক্যালক** | স্ব-হোস্টেড সহযোগী স্প্রেডশীট রুম |
| **অন্যান্য →** বাস্তবায়িত ব্যাকএন্ড | **বেসরো**, **নোকোডিবি**, **এয়ারটেবল**, **পকেটবেস**, **সুপাবেস**, **ফায়ারবেস**, **জোহো শিট** |

বিলম্বিত / এখনও মাথাবিহীন নয় (অন্যান্যের অধীনে তালিকাভুক্ত কিন্তু সম্পূর্ণরূপে বাস্তবায়িত নয়): OnlyOffice, Collabora. এছাড়াও [স্ব-হোস্ট সূচক](reference/self-host/INDEX.md) দেখুন।

CSV **এক্সপোর্ট/আমদানি** (একই ট্যাব লেআউটের জিপ) সেটিংস থেকে পোর্টেবল ব্যাকআপ হিসেবে পাওয়া যায়, লাইভ সিঙ্ক থেকে স্বাধীন।

### <a id="supported-targets--photos-image-backup"></a>সমর্থিত লক্ষ্য — ফটো (ছবির ব্যাকআপ)

**মেনু → সিঙ্কিং → ফটো ব্যাকআপ** এর অধীনে কনফিগার করা হয়েছে (সেটিংস সারাংশ সারি থেকেও):

| লক্ষ্য | নোট |
|---------|---------|
| **গুগল ড্রাইভ** | আপনি যে ফোল্ডারটি বেছে নিয়েছেন (ব্রউজ বা পেস্ট URL) |
| **ওয়ানড্রাইভ** | মাইক্রোসফট অ্যাকাউন্ট + পাথ উপসর্গ |
| **S3** | AWS, Wasabi, Cloudflare R2, MinIO, এবং অন্যান্য S3-সামঞ্জস্যপূর্ণ শেষ পয়েন্ট |
| **অন্যান্য** | rclone-ব্যাকড স্টোরেজ (যেমন WebDAV, SFTP, এবং অন্যান্য কিউরেটেড রিমোট ইন-অ্যাপ পিকারে উপলব্ধ) |

স্ব-হোস্ট করা ফটো এবং ট্যাবুলার লক্ষ্যগুলির জন্য চিটশিট সেটআপ করুন: [সেলফ-হোস্ট ইনডেক্স](reference/self-host/INDEX.md)।

### <a id="multi-device-behavior-short"></a>মাল্টি-ডিভাইস আচরণ (সংক্ষিপ্ত)

- **আপডেট করা** টাইমস্ট্যাম্পগুলিতে **শেষ-লেখা-জিত** সহ **সিঙ্ক আইডি** দ্বারা সারিগুলি একত্রিত হয়।
- মুছে ফেলা নরম; অন্য ডিভাইসে একটি নতুন সম্পাদনা একটি সারি পুনরুদ্ধার করতে পারে।
- দুটি ডিভাইসে **একই ফিল দুইবার** প্রবেশ করালে **দুটি সারি** তৈরি হয় — আপনি যখন লক্ষ্য করবেন তখন অতিরিক্ত মুছে ফেলুন।
- আরও বিশদ: [সিঙ্ক আচরণ নোট](#sync-behavior-notes) এবং [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md)।

### <a id="example-add-google-sheets-data"></a> উদাহরণ: Google পত্রক যোগ করুন (ডেটা)

1. **মেনু → সিঙ্কিং → স্প্রেডশীট সিঙ্ক** (বা সেটিংস → স্প্রেডশীট সিঙ্ক)।

![স্প্রেডশীট সিঙ্ক তালিকা](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/08-spreadsheet-sync.jpg)

2. **স্প্রেডশীট গন্তব্য যোগ করুন** আলতো চাপুন।

![প্রোভাইডার পিকার](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/09-spreadsheet-provider-picker.jpg)

3. **গুগল শীট** বেছে নিন।

![গুগল শিট ফর্ম](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/10-spreadsheet-google-form.jpg)

4. **Google দিয়ে সাইন ইন করুন** একবার — সেই সাইন-ইন আপনাকে ব্রাউজ করতেও দেয়। প্রদর্শনের নাম → একটি **শীট URL** পেস্ট করুন (এখনও বৈধ) অথবা **🔍** ব্রাউজ করুন। ব্রাউজ **সব এবং ভাগ করা** এ খোলে যাতে আপনি একটি বিদ্যমান স্প্রেডশীট বাছাই করতে পারেন যা আপনার মালিকানাধীন বা আপনার সাথে ভাগ করা হয়েছে৷ তারপর সময়সূচী বিকল্প → সক্ষম → সংরক্ষণ করুন.
5. **এখনই সিঙ্ক করুন** একবার ট্যাব তৈরি/আপডেট করতে: `Vehicles`, `Expenses`, `Fuel - {vehicle name}`।

1. **মেনু → সিঙ্কিং → ফটো ব্যাকআপ** (বা সেটিংস → ফটো ব্যাকআপ)।

![ফটো ব্যাকআপ তালিকা](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/11-photo-backup.jpg)

2. **ফটো গন্তব্য যোগ করুন** আলতো চাপুন।

![ফটো প্রদানকারী পিকার](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/12-photo-provider-picker.jpg)

3. **Google ড্রাইভ** চয়ন করুন।

![গুগল ড্রাইভ ফর্ম](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/13-photo-google-form.jpg)

4. **Google (ড্রাইভ) দিয়ে সাইন ইন করুন** → ঐচ্ছিক ফোল্ডার URL/ব্রাউজ করুন → সক্ষম করুন → সংরক্ষণ করুন → **এখনই সিঙ্ক করুন**।

ম্যানুয়াল **এখনই সিঙ্ক করুন** ফটোগুলির জন্য একটি সম্পূর্ণ পাস; ব্যাকগ্রাউন্ড ব্যাকআপ সাধারণত **শুধুমাত্র** আপলোডগুলি একটি সময়সূচীতে প্রক্রিয়া করে।

### <a id="sync-behavior-notes"></a> সিঙ্ক আচরণ নোট

- অ্যাপ আপগ্রেড করার পরে আপনি সংক্ষেপে দেখতে পাবেন **"আপগ্রেডের পরে ডেটাবেস আপডেট হচ্ছে..."** (স্থানীয় সিঙ্ক-আইডি ব্যাকফিল)।
- যদি একটি সিঙ্ক বাধাপ্রাপ্ত হয়, পরবর্তী **সফল** সিঙ্ক রিমোট ট্যাবগুলিকে পুনরায় মার্জ করে এবং মেরামত করে।
- ব্যর্থতা: অ্যাপ বারে সিঙ্কিং কার্ড + **!**-এ লাল সারাংশ।

## <a id="fill-up-fuel"></a>ফিল (জ্বালানি)

আপনি অ্যাপটি খুললে এটিই **হোম স্ক্রিন**।

### <a id="vehicle-selection-usually-automatic"></a> যানবাহন নির্বাচন (সাধারণত স্বয়ংক্রিয়)

আপনাকে প্রথমে যানবাহন বাছাই করার প্রয়োজন নেই। যানবাহনগুলির পরিচালনায় **ল্যান্ডমার্ক** সেট আপ করা থাকলে, আপনি ওডোমিটার ক্যাপচার করার পরে ড্যাশ চিত্র থেকে **কোন যানবাহনটি স্বয়ংক্রিয়ভাবে সনাক্ত করে** পূরণ করুন৷ প্রয়োজনে ওভাররাইড করার জন্য আপনি এখনও **গাড়ি** ড্রপডাউন খুলতে পারেন।

### <a id="aim-at-the-odometer"></a> ওডোমিটারের দিকে লক্ষ্য করুন

ওডোমিটার মোডে থাকুন এবং ক্লাস্টার ফ্রেম করুন। নির্দেশনা: *ওডোমিটারে লক্ষ্য করুন। ক্যাপচার করতে শাটারে আলতো চাপুন।*

![পূর্ণ করুন — ওডোমিটারে লাইভ ক্যামেরা (প্রিভিউতে ড্যাশ চিত্রের উদাহরণ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a>ওডোমিটার শাটার পরে

OCR **Odo** পূরণ করে এবং ল্যান্ডমার্ক থেকে গাড়ির সাথে মিল করার চেষ্টা করে (প্রয়োজন হলে উভয়ের পর্যালোচনা করুন)। মূল বোতামটি পুনরায় শ্যুট করার জন্য **পুনরায় চেষ্টা করুন** হয়ে যায়। নির্দেশ পাঠের সংক্ষিপ্ত বিবরণ.

![ফিল — ওডোমিটার ওসিআর ফলাফল](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a>পাম্প মোড (খরচ এবং ভলিউম)

1. পাম্প মোডে স্যুইচ করতে **↕** আলতো চাপুন: *পাম্প ডিসপ্লেতে লক্ষ্য করুন (খরচ/ভলিউম)। শাটারে ট্যাপ করুন।*
2. পাম্পের মোট সংখ্যা ক্যাপচার করুন। খরচ এবং ভলিউম ক্ষেত্র পূরণ; **↔** ব্যবহার করুন যদি সেগুলি অদলবদল করা হয়।
3. প্রয়োজনে মুদ্রা বা **G/L** ট্যাপ করুন, তারপর **সংরক্ষণ করুন** (ডিস্ক)। খালি ক্ষেত্রগুলি একটি **আংশিক পূরণ** করে (এখনও অনুমোদিত)।

![পূর্ণ করুন — পাম্প প্রিভিউ / মোট (প্রিভিউতে পাম্পের ছবি উদাহরণ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

আপনি পরবর্তী স্টপের জন্য Fill এ থাকুন (সংরক্ষণের পরে ক্ষেত্রগুলি পরিষ্কার করুন)। সম্পূর্ণরূপে **অফলাইনে** কাজ করুন; কনফিগার করা হলে সিঙ্ক পরে ব্যাকগ্রাউন্ডে চলে।

### <a id="manual-entry-no-camera--bad-ocr"></a>ম্যানুয়াল এন্ট্রি (কোন ক্যামেরা নেই / খারাপ OCR)

1. **ওডো**, **কস্ট**, বা **ভলিউম** ট্যাপ করুন এবং মান টাইপ করুন (প্রতিকৃতি সিস্টেম কীবোর্ড ব্যবহার করে; ল্যান্ডস্কেপ একটি অন-স্ক্রীন কীপ্যাড ব্যবহার করে)।
2. স্বয়ংক্রিয় সনাক্তকরণ চালু না হলে **যানবাহন** চয়ন করুন বা নিশ্চিত করুন।
3. উপরের মত সংরক্ষণ করুন।

### <a id="modes-and-borders"></a>মোড এবং সীমানা

- গাড়ির চারপাশে **সবুজ সীমানা**+ওডো → ক্যাপচারিং/এডিটিং ওডোমিটার।
- **সবুজ বর্ডার** খরচ+ভলিউম → পাম্প মোডের চারপাশে।
- **সংরক্ষণ** অক্ষম থাকে যতক্ষণ না একটি গাড়ি নির্বাচন করা হয় এবং অন্তত একটি ওডো/কস্ট/ভলিউমের ডেটা থাকে এবং OCR এখনও চালু না হয়।

অন-স্ক্রীন টিপ (নির্দেশ লাইনের নীচে): *শাটার = ক্যাপচার · ডিস্ক = সংরক্ষণ · ↕ = ওডো/পাম্প মোড · ↔ = অদলবদল খরচ/ভলিউম।*

## <a id="expenses"></a> খরচ

### <a id="new-expense"></a>নতুন খরচ

মেনু → **নতুন খরচ**।

![নতুন খরচের ফর্ম এবং ক্যামেরা নিয়ন্ত্রণ (ক্যামেরা ব্যান্ডে ড্যাশ ছবি খালি থাকলে উদাহরণ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r6-new-expense.jpg)

1. **সংরক্ষণ করুন** (ডিস্ক), **শাটার** (রসিদের ছবি), অথবা **গ্যালারি** (ছবি বাছুন)।
2. **তারিখ**, **যানবাহন**, **বিক্রেতা**, **বিবরণ**, **অ্যামাউন্ট** (মুদ্রার প্রতীক ট্যাপযোগ্য), **বিভাগ**, ঐচ্ছিক **ওডোমিটার** পূরণ করুন।
3. বহু-পৃষ্ঠার রসিদ: অতিরিক্ত পৃষ্ঠাগুলি ক্যাপচার করুন যদি UI পেজিং অফার করে (পৃষ্ঠা 0 প্রাথমিক রসিদ)।
4. **সংরক্ষণ করুন** সংরক্ষণ করুন (স্থানীয় প্রথমে; কনফিগার করা হলে পটভূমিতে ফটো ব্যাকআপ এবং স্প্রেডশীট সিঙ্ক হয়)।

### <a id="expense-list"></a> ব্যয় তালিকা

মেনু → **প্রতিবেদন** → **ব্যয়ের তালিকা** — অতীতের অ-জ্বালানি খরচ ব্রাউজ করুন; সম্পাদনা করতে একটি আইটেম খুলুন।

![ব্যয়ের তালিকা](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/05-expense-list.jpg)

### <a id="edit-expense"></a> সম্পাদনা ব্যয়

তালিকা থেকে একটি সারি খুলুন। সঠিক বিক্রেতা, পরিমাণ, বিভাগ, যানবাহন এবং বিবরণ। যদি রসিদটি শুধুমাত্র ফটো ব্যাকআপে থাকে (কোন পঠনযোগ্য স্থানীয় ফাইল নেই), দেখানো হলে **আর্কাইভ থেকে ছবি আনুন** ব্যবহার করুন (কনফিগার করা ফটো গন্তব্য জুড়ে কাজ করে)।

![সম্পাদনা ব্যয়](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/expense-edit.jpg)

## <a id="start-trip"></a> ট্রিপ শুরু করুন

মেনু → **যাত্রা শুরু করুন** (ড্রয়ার পূরণ করার পরে)। ওডোমিটার ক্যাপচার করুন বা এন্টার করুন, ট্রিপ টাইপ বেছে নিন, **ডিস্ক** আইকন দিয়ে সেভ করুন। **স্টপ** হল ব্যক্তিগত জন্য একটি শর্টকাট এখন অনুষ্ঠিত GPS অবস্থানে। কন্ট্রোল রিমাইন্ডারের জন্য **ⓘ** ব্যবহার করুন।

![ভ্রমণ শুরু করুন](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/start-trip.jpg)

ট্রিপ স্টার্ট **ট্রিপ টাইপ** সহ জ্বালানী সারি হিসাবে সংরক্ষণ করা হয় (সাধারণ ফিল নয়)। এগুলি **রিপোর্ট → ট্রিপ মাইলস** এর অধীনে প্রদর্শিত হয়, জ্বালানী ইতিহাসের অধীনে নয়।

## <a id="reports"></a> প্রতিবেদন

মেনু → **রিপোর্ট** প্রোডাক্ট হাব খোলে (সর্বকালীন সারাংশ + ক্যাটালগ কার্ড)। এটিই একমাত্র পণ্যের প্রতিবেদনের সারফেস — কোন আলাদা "রিপোর্ট এবং চার্ট" ড্রয়ার আইটেম নেই।

![রিপোর্ট হাব](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/06-reports.jpg)

গাড়ির মোড (**সমস্ত / প্রতিটি / একক**), পিরিয়ড ফিল্টার, চার্ট এবং শেয়ার (**TEXT / CSV / PDF**) এর জন্য একটি কার্ড খুলুন। রিপোর্ট শিশুদের শীর্ষ বার: **☰ + ←** (এবং **ⓘ** নিবন্ধিত হলে)।

### <a id="time-based-reports"></a>সময় ভিত্তিক প্রতিবেদন

প্রধান চার্ট কার্ড। ঐচ্ছিক মেট্রিক্স (mpg, ভলিউম/দূরত্ব যেমন G/mi, ইউনিট মূল্য যেমন $/G, খরচ/দূরত্ব, মাসিক $, ট্রিপ মাইল, প্রকার অনুসারে ট্রিপ) **মসৃণ** বিন এবং **স্বাধীন Y স্কেল** সহ (বামে অর্থনীতি; অর্থ এবং ডানদিকে ট্রিপ পরিবার)।

![সময় ভিত্তিক প্রতিবেদন](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports.jpg)

![সময় ভিত্তিক প্রতিবেদন — স্ক্রোল করা মেট্রিক্স](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports-scrolled.jpg)

অর্থনীতির গণিতের বিবরণ: [REPORTS_METRICS.md](reference/REPORTS_METRICS.md)।

### <a id="fill-history-vs-fuel-history"></a>ফিল ইতিহাস বনাম জ্বালানির ইতিহাস

- **রিপোর্ট → ফিল হিস্ট্রি** — রিপোর্ট ফিল্টারগুলির জন্য কালানুক্রমিক ফিল (**শুধুমাত্র ফিল**; কোন ট্রিপ শুরু হয় না)।

![ইতিহাসের প্রতিবেদন পূরণ করুন](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fill-history.jpg)

- **জ্বালানির ইতিহাস** (যদি আপনার বিল্ডের নেভিগেশনে উপস্থিত থাকে) — প্রতি যানবাহন ফিল ইনভেন্টরি, এছাড়াও শুধুমাত্র পূরণ করে; সম্পাদনা করতে একটি সারিতে আলতো চাপুন।

### <a id="trip-miles"></a>ট্রিপ মাইল

**রিপোর্ট → ট্রিপ মাইলস** — ধরন, চার্ট এবং একটি কালানুক্রমিক **ট্রিপ শুরু/সেগমেন্ট তালিকা** অনুসারে মাইল। সেই সারির জন্য **সম্পাদনা পূরণ** খুলতে একটি আসল শুরুতে ট্যাপ করুন।

![ট্রিপ মাইলস](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a>সম্পাদনা পূরণ করুন

ফিল হিস্ট্রি, ফুয়েল হিস্ট্রি, বা ট্রিপ মাইলস থেকে একটি ফিল খুলুন। লেআউট: যানবাহন এবং ওডোমিটার, **মূল্যের আগে মুদ্রা**, ভলিউম, নোট। সারিটি ট্রিপ শুরু হলেই ট্রিপের ধরন দেখা যায়। অবস্থানের একটি সারাংশ এবং **অবস্থানের বিবরণ** রয়েছে। ক্লাউড পরিচয় সহ স্থানীয় ফটো অনুপস্থিত: **আর্কাইভ থেকে ছবি আনুন**।

![সম্পাদনা পূরণ করুন — স্থানীয় ফটো অনুপস্থিত হলে সংরক্ষণাগার থেকে আনুন](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

অন্যান্য ক্যাটালগ কার্ডের মধ্যে রয়েছে বিভাগ অনুযায়ী খরচ, গাড়ির সারাংশ এবং খরচের তালিকা।

টাকা সেট করার সময় প্রতিটি সারির মুদ্রা ব্যবহার করে। মিশ্র-মুদ্রার মোট **প্রতি-মুদ্রার সাবটোটাল** দেখায় (কোন নীরব FX রূপান্তর নেই)।

## <a id="syncing"></a> সিঙ্ক করা হচ্ছে

মেনু → **সিঙ্কিং** হল স্প্রেডশীট এবং ছবির গন্তব্যের হাব (কেবল সেটিংসের অধীনে নয়)।

![সিঙ্কিং হাব](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- সংক্ষিপ্ত স্থিতি সহ **স্প্রেডশীট সিঙ্ক** এবং **ফটো ব্যাকআপ** এর জন্য কার্ড, এই ধরণের জন্য **সিঙ্ক** এবং গন্তব্য তালিকায় **›**।
- **টেস্ট কানেকশন** এবং **এখনই সিঙ্ক করুন (এই গন্তব্য)** / সমস্ত কনফিগার করার জন্য একটি গন্তব্য খুলুন।
- ব্যর্থতা **বিশদ বিবরণ** এবং লাল **!** এখানে টাইটেল বারে ল্যান্ড করুন।
- ধাপে ধাপে Google পত্রক এবং ড্রাইভ সেটআপ: [ব্যাকআপ এবং মাল্টি-ডিভাইস সিঙ্ক](#backups-and-multi-device-sync)।

## <a id="settings-local-preferences"></a>সেটিংস (স্থানীয় পছন্দ)

মেনু → **সেটিংস**।

![সেটিংস](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07-settings.jpg)

![আরো সেটিংস (স্ক্রোল করা)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07b-settings-more.jpg)

গন্তব্যের জন্য, **মেনু → সিঙ্ক** পছন্দ করুন। সেটিংস এখনও সারাংশের সারিগুলি দেখাতে পারে যা একই তালিকাগুলি খোলে৷

### <a id="local-preferences-common"></a>স্থানীয় পছন্দ (সাধারণ)

- **জ্বালানি রসিদ ফটো সংরক্ষণ করুন** / **ব্যয় ফটো স্থানীয়ভাবে সংরক্ষণ করুন** — ডিভাইসে ছবি রাখুন (ফটোর অনুমতির অনুরোধ করতে পারে)।
- **শাটার সাউন্ড চালান**
- **মুদ্রা** / **ভলিউম ইউনিট** — অ্যাপ ডিফল্ট (সিস্টেম বা স্পষ্ট)। বিদ্যমান জ্বালানী ডেটা সহ ভলিউম ইউনিট পরিবর্তন করা একটি রূপান্তর ডায়ালগ অফার করতে পারে।
- **ডার্ক মোড**
- **সেটআপ টিপস** — প্রথম-চালিত যানবাহন / সিঙ্ক টিউটোরিয়ালগুলি পুনরায় খুলুন।
- **ডিবাগ ফিল** / **পরীক্ষামূলক স্ক্রিনগুলি দেখান (dev)** — উন্নত; দৈনন্দিন ব্যবহারের জন্য ছেড়ে দিন। পরীক্ষার পর্দা এখানে নথিভুক্ত করা হয় না.

CSV **রপ্তানি/আমদানি** (যানবাহন / খরচ / জ্বালানী ট্যাবের জিপ) বর্তমান বিল্ড দ্বারা অফার করা হলে সেটিংস থেকে পাওয়া যায়।
