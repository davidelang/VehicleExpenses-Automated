# <a id="vehicle-expenses-automated--user-manual"></a>வாகனச் செலவுகள் தானியங்கி — பயனர் கையேடு

> **மூலத்தைத் திருத்து (மார்க் டவுன்).** உலாவிகள் மற்றும் ஆப்ஸ் ரீடர் மூலம் **ரெண்டர் செய்யப்பட்ட HTML**ஐத் திறக்கவும்:
> - இணையம்: [`docs/user-manual/index.html`](index.html) (`./scripts/render-user-manual.sh` உடன் மீண்டும் உருவாக்கவும்)
> - ஆப்: உதவி / பற்றி → முழு கையேடு (தொகுக்கப்பட்ட HTML + திரைக்காட்சிகள்)
>
> இறுதிப் பயனர்களை மூல `.md` URLகளில் சுட்டிக்காட்ட வேண்டாம் - உலாவிகள் எளிய உரையை மட்டுமே காட்டுகின்றன.

**உங்கள்** கிளவுட் கணக்குகளின் கீழ் விருப்பமான பல சாதன ஒத்திசைவு மற்றும் காப்புப்பிரதியுடன் எரிபொருள் நிரப்புதல்கள் மற்றும் வாகனச் செலவுகளுக்கான கேமரா-முதல் கண்காணிப்பு.

இது **முழு கையேடு** (ஸ்கிரீன்ஷாட்கள் + ஒவ்வொரு அடியிலும்). தொலைபேசியில், **மெனு → உதவி** என்பது ஒரு குறுகிய தொடக்க வழிகாட்டியாகும்.

**இங்கே குறிப்பிடப்படவில்லை:** பழைய படங்கள், சீரமைப்பு பரிசோதனை மற்றும் பம்ப் பரிசோதனை (டெவலப்பர் / மேம்பட்ட கருவிகள்) ஆகியவற்றை இறக்குமதி செய்யவும்.

## <a id="what-you-need"></a>உங்களுக்கு என்ன தேவை

- Android தொலைபேசி அல்லது டேப்லெட்.
- சிறந்த OCRக்கு: உங்கள் **டாஷ்போர்டு ஓடோமீட்டர்** மற்றும் **பம்ப் மொத்தம்** (அல்லது எண்களை கையால் தட்டச்சு செய்யவும்) பற்றிய தெளிவான பார்வை.
- விருப்பமானது: விரிதாள் தரவு மற்றும்/அல்லது புகைப்பட காப்புப்பிரதிக்கான **நீங்கள் கட்டுப்படுத்தும்** கணக்குகள் (பார்க்க [காப்புப்பிரதிகள் மற்றும் பல சாதன ஒத்திசைவு](#backups-and-multi-device-sync)).

## <a id="first-time-setup-manage-vehicles"></a>முதல் முறை அமைவு: வாகனங்களை நிர்வகி

OCR மற்றும் **தானியங்கி வாகனப் பொருத்தம்** நீங்கள் ஒவ்வொரு வாகனத்தையும் **குறிப்பு டாஷ்போர்டு புகைப்படத்துடன்** பதிவுசெய்து, **டிஸ்கவரி**யை இயக்கி, துடுப்பு விதையிலிருந்து ஓடோமீட்டர் க்ராப்பை அமைத்து, அந்த கோடுக்கான அடையாளங்களைச் சேமித்த பிறகு சிறப்பாகச் செயல்படும்.

### <a id="open-manage-vehicles"></a>திறந்த நிர்வகி வாகனங்கள்

மெனு → **வாகனங்களை நிர்வகி**. வாகனத்தைத் தேர்ந்தெடுக்கவும் (அல்லது **புதிய வாகனத்தைச் சேர்**).

![குறிப்புக் கோடு, பயிர்கள் மற்றும் கண்டுபிடிப்புடன் வாகனங்களை நிர்வகிக்கவும்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a>வாகனத்தைச் சேர்க்கவும் அல்லது திருத்தவும்

1. **வாகனம்** கீழ்தோன்றும் → வாகனத்தைத் தேர்ந்தெடுக்கவும் அல்லது **புதிய வாகனத்தைச் சேர்**.
2. தெளிவான **குறிப்புக் கோடு புகைப்படத்தைப் பிடிக்கவும் அல்லது எடுக்கவும் **படம் எடு** அல்லது **கேலரி** பயன்படுத்தவும்.
3. **கண்டறிதலை இயக்கு** என்பதைத் தட்டவும் — துடுப்பு கண்டறிதல் புகைப்படத்தில் மஞ்சள் **விதைகளை** இடுகிறது.
4. **ஓடோ தேர்ந்தெடு** என்பதைத் தட்டவும், இலக்கங்களில் விதையைத் தட்டி, கைப்பிடிகளைச் சரிசெய்து, பிறகு **சேமி**.
5. **Edit Odo** ஏற்கனவே உள்ள பெட்டியை சரிசெய்கிறது. **கிளியர் ஓடோ** அதை நீக்கி, பொத்தான் **ஓடோவை தேர்ந்தெடு** என்று வாசிக்கிறது.
6. **Show Landmarks** உடன் மதிப்பாய்வு செய்யவும். தவறான வாசிப்புகளை சரிசெய்ய **OCR ஐ திருத்து** பயன்படுத்தவும் அல்லது தவறவிட்ட உரையை **சேர்**.
7. **வாகனத்தின் பெயர்** (தேவை), மேலும் நீங்கள் விரும்பியபடி உருவாக்கவும்/மாடல்/ஆண்டு/தட்டு.
8. **வாகனத்தை உருவாக்கு** அல்லது **மாற்றங்களைச் சேமி** என்பதைத் தட்டவும் (புதிய வாகனத்திற்கு பெயர் + குறிப்பு புகைப்படம் தேவை).

### <a id="landmarks-fix-what-discovery-missed"></a>Landmarks: டிஸ்கவரி தவறவிட்டதை சரிசெய்யவும்

**லேண்ட்மார்க்குகளைக் காண்பி**க்குப் பிறகு, பட்டியலை உருட்டி, மதிப்புகளைச் சரி செய்யவும். எஞ்சின்கள் சில நேரங்களில் சிறிய இலக்கங்களைத் தவறவிடுகின்றன (உதாரணமாக கிளஸ்டரின் கீழ் வலதுபுறத்தில் ஒரு கடிகாரம் **60**). அவற்றைச் சேர்க்க அல்லது சரிசெய்ய **OCR ஐத் திருத்து** பயன்படுத்தவும், இதனால் வாகன அடையாளம் நம்பகமானதாக இருக்கும்.

![லேண்ட்மார்க்ஸ் உரையாடல் — OCR மதிப்பாய்வு செய்து திருத்தவும்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a>சரியான புகைப்படம் இல்லாமல் தட்டச்சு செய்தல்

வாகனத்தைத் தேர்ந்தெடுத்து, **டைப்பிங்** ஓடோமீட்டர், வால்யூம் மற்றும் ஃபில்ல் செலவு - OCR ஒவ்வொரு துறைக்கும் விருப்பமானது. பயன்பாட்டில் படமெடுக்க வேண்டாம் என நீங்கள் விரும்பினால், குறிப்பு கோடு புகைப்படத்திற்கு கேலரி இறக்குமதி வேலை செய்கிறது.

**உதவிக்குறிப்பு:** விரிதாள் ஒத்திசைவுக்குப் பிறகு, வாகன வரையறைகள் (பயிர்கள், அடையாளங்கள்) உள்ளூர் தரவுத்தளத்தில் இருக்கும் — அவற்றைப் பயன்படுத்த, நிரப்புவதற்கு வாகனங்களை நிர்வகிப்பதை நீங்கள் மீண்டும் திறக்க வேண்டியதில்லை.

## <a id="backups-and-multi-device-sync"></a>காப்புப்பிரதிகள் மற்றும் பல சாதன ஒத்திசைவு

பயன்பாடு கட்டமைக்கப்பட்டுள்ளது, எனவே **பல ஃபோன்கள் அல்லது டேப்லெட்டுகள் ஒரே ஃப்ளீட் தரவைப் பகிர முடியும்**, எனவே உங்கள் தரவு மற்றும் புகைப்படங்களின் நகலை சாதனத்திலிருந்து ** வைத்திருக்கலாம். இது **நீங்கள்** **உங்கள்** கணக்குகள் அல்லது **உங்கள்** சுய-ஹோஸ்ட் செய்யப்பட்ட சேவையகங்களின் கீழ் உள்ளமைக்கப்பட்ட இலக்குகளுடன் செய்யப்படுகிறது — மற்றவர்கள் பார்க்கக்கூடிய நிறுவனத்தால் நடத்தப்படும் “வாகனச் செலவுகள் கிளவுட்” அல்ல.

### <a id="what-runs-where"></a>எது எங்கே இயங்குகிறது

| வகையான | அது என்ன சேமிக்கிறது | வழக்கமான பயன்பாடு |
|------|---------------|------------|
| **விரிதாள் / அட்டவணை ஒத்திசைவு** | வாகனங்கள், எரிபொருள் நிரப்புதல், செலவுகள் (வரிசைகள் மற்றும் தாவல்கள்) | பல சாதன இணைப்பு + கட்டமைக்கப்பட்ட காப்புப்பிரதி |
| **புகைப்பட காப்புப்பிரதி** | பைனரி படங்கள் (கோடு/பம்ப்/ரசீது/குறிப்பு புகைப்படங்கள்) | புகைப்பட காப்புப்பிரதி + காணாமல் போன கோப்புகளை மீட்டமை |

நீங்கள் ஒவ்வொரு வகையிலும் **பல இடங்களை** உள்ளமைக்கலாம் (ஒரு வகைக்கு மென்மையான தொப்பி). கைமுறையாக **இப்போது ஒத்திசைக்கவும்** மற்றும் **பின்னணி** பணியாளர்கள் இயக்கப்பட்டவற்றை இயக்குகிறார்கள்.

### <a id="offline-first"></a>Offline முதலில்

- நிரப்புதல், செலவு அல்லது ரசீதைச் சேர்க்க **நெட்வொர்க் தேவையில்லை**. எல்லாம் சேமிக்கப்பட்டது **உள்ளூரில் முதலில்**.
- நெட்வொர்க் கிடைக்கும்போது, ​​ஒத்திசைவு மற்றும் புகைப்பட காப்புப்பிரதி **பின்னணிப் பணிகளாக** இயங்கும் (நீங்கள் அமைத்த அட்டவணையில், **இப்போது ஒத்திசை** என்பதைத் தட்டினால்). செயலிழப்புகள் அமைப்புகள் வரிசைகளின் கீழ் சிவப்பு உரையாகவும், பயன்பாட்டின் தலைப்புப் பட்டியில் **!** ஆகவும் காட்டப்படும்.

### <a id="your-accounts-only"></a>உங்கள் கணக்குகள் மட்டும்

உள்நுழைவு மற்றும் டோக்கன்கள் நீங்கள் தேர்வு செய்யும் வழங்குநர்களுக்கான சாதனத்தில் இருக்கும் (Google, Microsoft, S3 விசைகள், சுய-ஹோஸ்ட் செய்யப்பட்ட URLகள் மற்றும் பல). இலக்குகள் **பயனரின் முழுக் கட்டுப்பாட்டில் உள்ளது** — உங்கள் Google கணக்கு, உங்கள் OneDrive, உங்கள் MinIO பக்கெட், உங்கள் EtherCalc ஹோஸ்ட் போன்றவை. பகிரப்பட்ட பின்தளத்தின் மூலம் மற்ற வாகனச் செலவுகள் பயனர்களுடன் எதுவும் பகிரப்படாது.

### <a id="multi-device-behavior-short"></a>பல சாதன நடத்தை (குறுகிய)

- வரிசைகள் **ஒத்திசைவு ஐடி** மூலம் **புதுப்பிக்கப்பட்ட** நேர முத்திரைகளில் **கடைசியாக எழுதப்பட்ட வெற்றி** மூலம் ஒன்றிணைக்கப்படும்.
- நீக்குதல்கள் மென்மையானவை; மற்றொரு சாதனத்தில் ஒரு புதிய திருத்தம் ஒரு வரிசையை மீட்டெடுக்க முடியும்.
- இரண்டு சாதனங்களில் **ஒரே நிரப்புதலை இருமுறை** உள்ளிடுவது **இரண்டு வரிசைகளை** உருவாக்குகிறது - நீங்கள் கவனிக்கும்போது கூடுதல் நீக்கவும்.
- மேலும் விவரம்: [ஒத்திசைவு நடத்தை குறிப்புகள்](#sync-behavior-notes) மற்றும் [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md).

### <a id="example-add-google-drive-photos"></a>உதாரணம்: Google இயக்ககத்தைச் சேர் (புகைப்படங்கள்)

![புகைப்பட வழங்குநர் தேர்வாளர்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/12-photo-provider-picker.jpg)

### <a id="sync-behavior-notes"></a> நடத்தை குறிப்புகளை ஒத்திசைக்கவும்

- பயன்பாட்டை மேம்படுத்திய பிறகு, **“மேம்படுத்திய பிறகு தரவுத்தளத்தைப் புதுப்பிக்கிறது…”** (உள்ளூர் ஒத்திசைவு-ஐடி பேக்ஃபில்) என்பதை நீங்கள் சுருக்கமாகப் பார்க்கலாம்.
- ஒத்திசைவு குறுக்கிடப்பட்டால், அடுத்த **வெற்றிகரமான** ஒத்திசைவு ரிமோட் டேப்களை மீண்டும் ஒன்றிணைத்து சரிசெய்கிறது.
- தோல்விகள்: ஆப்ஸ் பட்டியில் கார்டுகளை ஒத்திசைப்பதில் சிவப்பு சுருக்கம் + **!**.

## <a id="fill-up-fuel"></a>நிரப்பு (எரிபொருள்)

நீங்கள் பயன்பாட்டைத் திறக்கும்போது இது **முகப்புத் திரை**.

### <a id="vehicle-selection-usually-automatic"></a>வாகனத் தேர்வு (பொதுவாக தானியங்கி)

நீங்கள் **இல்லை** முதலில் வாகனத்தை எடுக்க வேண்டும். வாகனங்களை நிர்வகித்தல் என்பதில் வாகனங்கள் **மைன் அடையாளங்கள்** அமைக்கப்பட்டால், ஓடோமீட்டரைப் பிடித்த பிறகு, கோடு படத்திலிருந்து ** எந்த வாகனத்தை தானாகக் கண்டறியும்** என்பதை நிரப்பவும். தேவைப்பட்டால் மேலெழுத, நீங்கள் இன்னும் **வாகனம்** கீழ்தோன்றலைத் திறக்கலாம்.

### <a id="aim-at-the-odometer"></a>ஓடோமீட்டரை நோக்கவும்

ஓடோமீட்டர் பயன்முறையில் இருங்கள் மற்றும் கிளஸ்டரை வடிவமைக்கவும். வழிமுறை: *ஓடோமீட்டரை நோக்கவும். படமெடுக்க ஷட்டரைத் தட்டவும்.*

![பூர்த்தி — ஓடோமீட்டரில் நேரடி கேமராக்கள் (முன்னோட்டத்தில் விளக்கப்படமான டாஷ் படம்)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a>ஓடோமீட்டர் ஷட்டருக்குப் பிறகு

OCR **Odo** ஐ நிரப்புகிறது மற்றும் வாகனத்தை அடையாளங்களிலிருந்து பொருத்த முயற்சிக்கிறது (தேவைப்பட்டால் இரண்டையும் மதிப்பாய்வு செய்யவும்). மீண்டும் படமெடுக்க பிரதான பொத்தான் **மீண்டும் முயற்சி** ஆகிவிடும். அறிவுறுத்தல் வாசிப்பை சுருக்கமாகக் கூறுகிறது.

![நிரப்பு — ஓடோமீட்டர் OCR முடிவு](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a>பம்ப் பயன்முறை (செலவு மற்றும் அளவு)

1. பம்ப் பயன்முறைக்கு மாற **↕** என்பதைத் தட்டவும்: *பம்ப் டிஸ்ப்ளேவை நோக்கமாகக் கொள்ளவும் (செலவு/தொகுதி). தட்டவும்.*
2. பம்ப் மொத்தத்தை கைப்பற்றவும். செலவு மற்றும் தொகுதி புலங்கள் நிரப்பப்படுகின்றன; அவை மாற்றப்பட்டால் **↔** ஐப் பயன்படுத்தவும்.
3. நாணயம் அல்லது **G/L** தேவைப்பட்டால், **சேமி** (வட்டு) என்பதைத் தட்டவும். வெற்றுப் புலங்கள் **பகுதி நிரப்புதலை** (இன்னும் அனுமதிக்கப்படுகின்றன).

![நிரப்பு — பம்ப் முன்னோட்டம் / மொத்தங்கள் (முன்னோட்டத்தில் எடுத்துக்காட்டு பம்ப் படம்)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

அடுத்த நிறுத்தத்திற்கு நீங்கள் நிரப்பி இருக்கிறீர்கள் (சேமித்த பிறகு புலங்கள் அழிக்கப்படும்). முழுமையாக வேலை **ஆஃப்லைனில்**; உள்ளமைக்கப்படும் போது பின்னனியில் ஒத்திசைவு இயங்கும்.

### <a id="manual-entry-no-camera--bad-ocr"></a>கைமுறை நுழைவு (கேமரா இல்லை / மோசமான OCR)

1. **Odo**, **cost**, அல்லது **volume** என்பதைத் தட்டவும் மற்றும் மதிப்புகளைத் தட்டச்சு செய்யவும் (உருவப்படம் கணினி விசைப்பலகையைப் பயன்படுத்துகிறது; நிலப்பரப்பு ஆன்-ஸ்கிரீன் கீபேடைப் பயன்படுத்துகிறது).
2. தானாக கண்டறிதல் இயங்கவில்லை எனில் **வாகனத்தை** தேர்வு செய்யவும் அல்லது உறுதிப்படுத்தவும்.
3. மேலே உள்ளவாறு சேமிக்கவும்.

### <a id="modes-and-borders"></a>முறைகள் மற்றும் எல்லைகள்

- வாகனத்தைச் சுற்றி **பச்சை கரை**+ஓடோ → கேப்சரிங்/எடிட்டிங் ஓடோமீட்டர்.
- **பச்சை கரை** செலவு+தொகுதி → பம்ப் பயன்முறையைச் சுற்றி.
- வாகனம் தேர்ந்தெடுக்கப்படும் வரை **சேமி** முடக்கப்பட்டிருக்கும் மற்றும் குறைந்தபட்சம் ஒடோ/செலவு/தொகுதியில் ஏதேனும் தரவு இருக்கும், மேலும் OCR இன்னும் இயங்கவில்லை.

ஆன்-ஸ்கிரீன் டிப் (அறிவுறுத்தல் வரிக்கு கீழே): *ஷட்டர் = கேப்சர் · டிஸ்க் = சேவ் · ↕ = ஓடோ/பம்ப் பயன்முறை · ↔ = இடமாற்று செலவு/தொகுதி.*

## <a id="reports"></a>அறிக்கைகள்

மெனு → **அறிக்கைகள்** தயாரிப்பு மையத்தைத் திறக்கும் (எல்லா நேர சுருக்கம் + பட்டியல் அட்டைகள்). இது மட்டுமே தயாரிப்பு அறிக்கைகளின் மேற்பரப்பு - தனி "அறிக்கைகள் & விளக்கப்படங்கள்" டிராயர் உருப்படி இல்லை.

![அறிக்கைகள் மையம்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/06-reports.jpg)

வாகனப் பயன்முறைக்கான கார்டைத் திறக்கவும் (**அனைத்தும் / ஒவ்வொன்றும் / ஒற்றை**), கால வடிப்பான்கள், விளக்கப்படங்கள் மற்றும் பகிர்வு (**TEXT / CSV / PDF**). குழந்தைகள் அறிக்கையின் மேல் பட்டி: **☰ + ←** (மற்றும் **ⓘ** பதிவு செய்யும் போது).

### <a id="time-based-reports"></a>நேர அடிப்படையிலான அறிக்கைகள்

முக்கிய விளக்கப்பட அட்டை. விருப்ப அளவீடுகள் (எம்பிஜி, ஜி/மை போன்ற தொகுதி/தொலைவு, $/ஜி போன்ற யூனிட் விலை, செலவு/தொலைவு, மாத $, பயண மைல்கள், வகையின்படி பயணம் %) **மென்மையான** தொட்டிகள் மற்றும் **சுதந்திரமான Y அளவுகள்** (பொருளாதாரம் இடது; வலதுபுறம் பணம் மற்றும் பயணக் குடும்பங்கள்).

![நேர அடிப்படையிலான அறிக்கைகள்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports.jpg)

![நேர அடிப்படையிலான அறிக்கைகள் — உருட்டப்பட்ட அளவீடுகள்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports-scrolled.jpg)

பொருளாதாரக் கணிதத்தின் விவரங்கள்: [REPORTS_METRICS.md](reference/REPORTS_METRICS.md).

### <a id="fill-history-vs-fuel-history"></a>Fill history vs Fuel History

- **அறிக்கைகள் → வரலாற்றை நிரப்பு** — அறிக்கை வடிப்பான்களுக்கான காலவரிசை நிரப்புதல்கள் (** நிரப்புகிறது மட்டும்**; பயணம் தொடங்கவில்லை).

![வரலாற்று அறிக்கையை நிரப்பவும்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fill-history.jpg)

- **எரிபொருள் வரலாறு** (உங்கள் கட்டமைப்பின் வழிசெலுத்தலில் இருந்தால்) — ஒரு வாகனத்திற்கான நிரப்பு சரக்கு, மேலும் நிரப்பப்படும்; திருத்த ஒரு வரிசையைத் தட்டவும்.

### <a id="trip-miles"></a>டிரிப் மைல்கள்

**அறிக்கைகள் → பயண மைல்கள்** — வகை, விளக்கப்படங்கள் மற்றும் காலவரிசைப்படி மைல்கள் **பயண தொடக்கம் / பிரிவு பட்டியல்**. அந்த வரிசையில் **திருத்து நிரப்பு** திறக்க உண்மையான தொடக்கத்தைத் தட்டவும்.

![டிரிப் மைல்கள்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a>திருத்து நிரப்பவும்

நிரப்பு வரலாறு, எரிபொருள் வரலாறு அல்லது பயண மைல்கள் ஆகியவற்றிலிருந்து நிரப்புதலைத் திறக்கவும். தளவமைப்பு: வாகனம் மற்றும் ஓடோமீட்டர், **செலவுக்கு முன் நாணயம்**, தொகுதி, குறிப்புகள். வரிசை பயணம் தொடங்கும் போது மட்டுமே பயண வகை தோன்றும். இருப்பிடத்தில் சுருக்கம் மற்றும் **இருப்பிட விவரங்கள்** உள்ளது. கிளவுட் அடையாளத்துடன் உள்ளூர் புகைப்படம் இல்லை: **காப்பகத்தில் இருந்து படத்தைப் பெறவும்**.

![நிரப்பைத் திருத்து - உள்ளூர் புகைப்படம் இல்லாதபோது காப்பகத்திலிருந்து பெறவும்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

பிற பட்டியல் அட்டைகளில் வகை வாரியான செலவுகள், வாகனச் சுருக்கம் மற்றும் செலவுகள் பட்டியல் ஆகியவை அடங்கும்.

பணம் ஒவ்வொரு வரிசையின் நாணயத்தையும் அமைக்கும் போது பயன்படுத்துகிறது. கலப்பு-நாணய மொத்தங்கள் **ஒவ்வொரு நாணயத்தின் துணைத்தொகைகளையும்** காட்டுகின்றன (அமைதியான FX மாற்றம் இல்லை).

## <a id="syncing"></a>Syncing

Menu → **Syncing** என்பது விரிதாள் மற்றும் புகைப்பட இடங்களுக்கான மையமாகும் (அமைப்புகளின் கீழ் மட்டும் புதைக்கப்படவில்லை).

![ஒத்திசைவு மையம்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- குறுகிய நிலையுடன் **விரிதாள் ஒத்திசைவு** மற்றும் **புகைப்பட காப்புப்பிரதி**க்கான கார்டுகள், அந்த வகையான **ஒத்திசைவு** மற்றும் **›** இலக்கு பட்டியலில்.
- **சோதனை இணைப்பு**க்கான இலக்கைத் திறக்கவும் மற்றும் **இப்போது ஒத்திசைக்கவும் (இந்த இலக்கு)** / அனைத்தும் கட்டமைக்கப்பட்டுள்ளன.
- தோல்வி **விவரங்கள்** மற்றும் இங்கே தலைப்பு பட்டியில் உள்ள சிவப்பு **!**.
- படி-படி-படி Google தாள்கள் மற்றும் இயக்கக அமைவு: [காப்புப்பிரதிகள் மற்றும் பல சாதன ஒத்திசைவு](#backups-and-multi-device-sync).

## <a id="settings-local-preferences"></a>அமைப்புகள் (உள்ளூர் விருப்பத்தேர்வுகள்)

மெனு → **அமைப்புகள்**.

![அமைப்புகள்](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07-settings.jpg)

![மேலும் அமைப்புகள் (ஸ்க்ரோல் செய்யப்பட்டவை)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07b-settings-more.jpg)

சேருமிடங்களுக்கு, **மெனு → ஒத்திசைத்தல்** என்பதைத் தேர்ந்தெடுக்கவும். அமைப்புகள் இன்னும் அதே பட்டியல்களைத் திறக்கும் சுருக்க வரிசைகளைக் காட்டலாம்.

### <a id="local-preferences-common"></a>உள்ளூர் விருப்பத்தேர்வுகள் (பொது)

- **எரிபொருள் ரசீது புகைப்படங்களை சேமிக்கவும்** / **செலவு புகைப்படங்களை உள்நாட்டில் சேமிக்கவும்** — படங்களை சாதனத்தில் வைத்திருக்கலாம் (புகைப்பட அனுமதி கோரலாம்).
- **ப்ளே ஷட்டர் சவுண்ட்**
- **நாணயம்** / **வால்யூம் யூனிட்** — ஆப்ஸ் இயல்புநிலைகள் (கணினி அல்லது வெளிப்படையானது). தற்போதுள்ள எரிபொருள் தரவுடன் தொகுதி அலகு மாற்றுவது மாற்றும் உரையாடலை வழங்கலாம்.
- **இருண்ட பயன்முறை**
- **அமைவு உதவிக்குறிப்புகள்** — முதலில் இயங்கும் வாகனம் / ஒத்திசைவு பயிற்சிகளை மீண்டும் திறக்கவும்.
- **பிழைத்திருத்த நிரப்பு** / **சோதனை திரைகளைக் காட்டு (dev)** — மேம்பட்டது; தினசரி பயன்பாட்டிற்கு விடுங்கள். பரிசோதனைத் திரைகள் இங்கு ஆவணப்படுத்தப்படவில்லை.

CSV **ஏற்றுமதி/இறக்குமதி** (வாகனங்கள் / செலவுகள் / எரிபொருள் தாவல்களின் ஜிப்) தற்போதைய உருவாக்கம் வழங்கும் போது அமைப்புகளில் இருந்து கிடைக்கும்.
