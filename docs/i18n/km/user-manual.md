## <a id="first-time-setup-manage-vehicles"></a> ការរៀបចំលើកដំបូង៖ គ្រប់គ្រងយានយន្ត

OCR និង **ការផ្គូផ្គងរថយន្តស្វ័យប្រវត្តិ** ដំណើរការបានល្អបំផុតបន្ទាប់ពីអ្នកចុះឈ្មោះយានយន្តនីមួយៗជាមួយនឹង ** រូបថតផ្ទាំងគ្រប់គ្រងឯកសារយោង ** ដំណើរការ ** Discovery ** កំណត់ដំណាំ odometer ពីគ្រាប់ពូជ paddle និងរក្សាទុកទីតាំងសម្គាល់សម្រាប់សញ្ញានោះ។

![គ្រប់គ្រងយានជំនិះដែលមានសញ្ញាយោង ដំណាំ និងការរកឃើញ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a> បន្ថែម ឬកែសម្រួលយានយន្ត

1. បើកកម្មវិធីទម្លាក់ចុះ **យានជំនិះ** → ជ្រើសរើសយានជំនិះ ឬ **បន្ថែមយានជំនិះថ្មី**។
2. ថត​ឬ​ជ្រើសរើស ** រូបថត​សញ្ញា​យោង** ច្បាស់​លាស់ (ចង្កោម​ឧបករណ៍​ពេញ ពន្លឺ​ល្អ ទូរសព្ទ​ប្រហែល​ជា​ការ​បើក)។ ប្រើ ** ថតរូប ** ឬ ** វិចិត្រសាល ** ។
3. ចុច **Run Discovery** — ការរកឃើញ paddle ដាក់ពណ៌លឿង **seeds** នៅលើរូបថត (សញ្ញាសម្គាល់ប្រើ `"ML Kit"` JSON ដូចពីមុន)។
4. ប៉ះ **ជ្រើសរើស Odo** ចុចលើគ្រាប់ពូជនៅលើខ្ទង់ កែតម្រូវចំណុចទាញ បន្ទាប់មក **Save**។
5. **Edit Odo** កែតម្រូវប្រអប់ដែលមានរួចហើយ។ **Clear Odo** យកវាចេញ ហើយបន្ទាប់មកប៊ូតុងអាន **ជ្រើសរើស Odo**។
6. ពិនិត្យឡើងវិញជាមួយ **បង្ហាញទីតាំង**។ ប្រើ **កែសម្រួល OCR** ​​ដើម្បីជួសជុលការអានខុស ឬ **បន្ថែម** អត្ថបទដែលត្រូវបានខកខាន។
7. បំពេញ **ឈ្មោះរថយន្ត** (ទាមទារ) បូកផ្សំ/ម៉ូដែល/ឆ្នាំ/ចានតាមចិត្ត។
8. ប៉ះ **បង្កើតយានជំនិះ** ឬ **រក្សាទុកការផ្លាស់ប្តូរ** (ទាមទារឈ្មោះ + រូបថតយោងសម្រាប់យានជំនិះថ្មី)។

## <a id="backups-and-multi-device-sync"></a> ការបម្រុងទុក និងសមកាលកម្មឧបករណ៍ច្រើន

កម្មវិធីនេះត្រូវបានបង្កើតឡើងដូច្នេះ **ទូរសព្ទ ឬថេប្លេតជាច្រើនអាចចែករំលែកទិន្នន័យកងនាវាដូចគ្នា** ហើយដូច្នេះអ្នកអាចរក្សា **ច្បាប់ចម្លងទិន្នន័យ និងរូបថតរបស់អ្នកចេញពីឧបករណ៍**។ វាត្រូវបានធ្វើជាមួយនឹងទិសដៅ ** អ្នក ** កំណត់រចនាសម្ព័ន្ធនៅក្រោម ** គណនី ** របស់អ្នក ឬ ** ម៉ាស៊ីនមេដែលបង្ហោះដោយខ្លួនឯង ** របស់អ្នក - មិនមែនជា "ពពកការចំណាយលើយានយន្ត" ដែលដំណើរការដោយក្រុមហ៊ុនដែលអ្នកផ្សេងទៀតអាចមើលឃើញនោះទេ។

- ជួរដេកបញ្ចូលគ្នាដោយ **លេខសម្គាល់សមកាលកម្ម** ជាមួយនឹង **ការសរសេរចុងក្រោយ** នៅលើត្រាពេលវេលា **បានធ្វើបច្ចុប្បន្នភាព**។
- ការលុបគឺទន់; ការកែសម្រួលថ្មីជាងនេះនៅលើឧបករណ៍ផ្សេងទៀតអាចស្ដារជួរដេកមួយ។
- ការបញ្ចូល **ការបំពេញដូចគ្នាពីរដង** នៅលើឧបករណ៍ពីរបង្កើត **ជួរពីរ** — លុបការបន្ថែមនៅពេលអ្នកកត់សម្គាល់។
- ព័ត៌មានលម្អិតបន្ថែម៖ [ធ្វើសមកាលកម្មកំណត់ចំណាំឥរិយាបថ](#sync-behavior-notes) និង [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md)។

### <a id="sync-behavior-notes"></a> កំណត់ចំណាំឥរិយាបថសមកាលកម្ម

- ប្រសិនបើការធ្វើសមកាលកម្មត្រូវបានរំខាន ការធ្វើសមកាលកម្មបន្ទាប់ **ជោគជ័យ** នឹងបញ្ចូលចូលគ្នាឡើងវិញ និងជួសជុលផ្ទាំងពីចម្ងាយ។
- បរាជ័យ៖ សេចក្តីសង្ខេបពណ៌ក្រហមនៅលើការធ្វើសមកាលកម្មកាត + **!** នៅក្នុងរបារកម្មវិធី។

## <a id="fill-up-fuel"></a> Fill (ប្រេងឥន្ធនៈ)

នេះគឺជា **អេក្រង់ដើម** នៅពេលអ្នកបើកកម្មវិធី។

### <a id="vehicle-selection-usually-automatic"></a> ការជ្រើសរើសយានយន្ត (ជាធម្មតាដោយស្វ័យប្រវត្តិ)

អ្នកមិន **មិន ** ត្រូវការជ្រើសរើសយានយន្តជាមុន។ នៅពេលដែលយានជំនិះមាន **កន្លែងសម្គាល់** ដែលបង្កើតឡើងក្នុងការគ្រប់គ្រងយានជំនិះ សូមបំពេញ ** រកមើលដោយស្វ័យប្រវត្តិនូវយានជំនិះមួយណា ** ពីរូបភាពសញ្ញាបន្ទាប់ពីអ្នកចាប់យកឧបករណ៍វាស់ចម្ងាយ។ អ្នកនៅតែអាចបើកបញ្ជីទម្លាក់ចុះ **រថយន្ត** ដើម្បីបដិសេធប្រសិនបើចាំបាច់។

### <a id="aim-at-the-odometer"></a> តម្រង់ទៅ odometer

ស្ថិតនៅក្នុងរបៀប odometer ហើយដាក់ស៊ុមចង្កោម។ សេចក្តីណែនាំ៖ * តម្រង់ទៅ odometer ។ ចុចបិទដើម្បីថត។*

![Fill — កាមេរ៉ាបន្តផ្ទាល់នៅលើ odometer (ឧទាហរណ៍រូបភាព dash នៅក្នុងការមើលជាមុន)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a> បន្ទាប់ពីឧបករណ៍វាស់ចម្ងាយ

OCR បំពេញ **Odo** ហើយព្យាយាមផ្គូផ្គងរថយន្តពីកន្លែងសម្គាល់ (ពិនិត្យមើលទាំងពីរប្រសិនបើចាំបាច់)។ ប៊ូតុងមេនឹងក្លាយជា **ព្យាយាមម្តងទៀត** ដើម្បីថតម្តងទៀត។ ការណែនាំសង្ខេបការអាន។

![Fill — odometer OCR results](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a> របៀបបូម (តម្លៃ និងបរិមាណ)

1. ប៉ះ **↕** ដើម្បីប្តូរទៅរបៀបបូម៖ * តម្រង់ទៅលើការបង្ហាញស្នប់ (តម្លៃ/បរិមាណ)។ ចុចបិទ។*
2. ចាប់យកចំនួនបូម។ វាលតម្លៃនិងបរិមាណបំពេញ; ប្រើ **↔** ប្រសិនបើពួកគេត្រូវបានប្តូរ។
3. ប៉ះរូបិយប័ណ្ណ ឬ **G/L** ប្រសិនបើចាំបាច់ បន្ទាប់មក **Save** (disk)។ វាលទទេបង្កើត **ការបំពេញដោយផ្នែក** (នៅតែអនុញ្ញាត)។

![Fill — ការ​មើល​ជាមុន​នៃ​ការ​បូម / សរុប (ឧទាហរណ៍​រូបភាព​បូម​ក្នុង​ការ​មើល​ជា​មុន)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

អ្នក​បន្ត​នៅ​លើ Fill សម្រាប់​ការ​ឈប់​បន្ទាប់ (វាល​ច្បាស់​លាស់​បន្ទាប់​ពី Save)។ ធ្វើការពេញលេញ ** ក្រៅបណ្តាញ **; សមកាលកម្មដំណើរការនៅពេលក្រោយក្នុងផ្ទៃខាងក្រោយនៅពេលកំណត់រចនាសម្ព័ន្ធ។

### <a id="manual-entry-no-camera--bad-ocr"></a> ការបញ្ចូលដោយដៃ (គ្មានកាមេរ៉ា / OCR អាក្រក់)

1. ប៉ះ **Odo**, **cost**, ឬ **volume** ហើយវាយតម្លៃ (បញ្ឈរប្រើក្តារចុចប្រព័ន្ធ ទេសភាពប្រើក្តារចុចលើអេក្រង់)។
2. ជ្រើសរើស ឬបញ្ជាក់ **រថយន្ត** ប្រសិនបើការរកឃើញដោយស្វ័យប្រវត្តិមិនដំណើរការ។
3. រក្សាទុកដូចខាងលើ។

### <a id="modes-and-borders"></a> របៀប និងស៊ុម

- **ព្រំដែនបៃតង** ជុំវិញរថយន្ត + អូដូ → ចាប់យក/កែសម្រួល odometer ។
- **ស៊ុមបៃតង** ជុំវិញតម្លៃ + បរិមាណ → របៀបបូម។
- **Save** បិទរហូតទាល់តែរថយន្តមួយត្រូវបានជ្រើសរើស ហើយយ៉ាងហោចណាស់មួយនៃ odo/cost/volume មានទិន្នន័យ ហើយ OCR មិនដំណើរការនៅឡើយ។

ព័ត៌មានជំនួយនៅលើអេក្រង់ (ខាងក្រោមបន្ទាត់ការណែនាំ): *Shutter = capture · Disk = save · ↕ = odo/pump mode · ↔ = swap cost/volume.*

4. **រក្សាទុក** ដើម្បីរក្សាទុក (មូលដ្ឋានដំបូង ការបម្រុងទុករូបថត និងការធ្វើសមកាលកម្មសៀវភៅបញ្ជីកើតឡើងនៅផ្ទៃខាងក្រោយនៅពេលកំណត់រចនាសម្ព័ន្ធ)។

- **រូបិយប័ណ្ណ** / **ឯកតាបរិមាណ** — លំនាំដើមកម្មវិធី (ប្រព័ន្ធ ឬច្បាស់លាស់)។ ការផ្លាស់ប្តូរឯកតាបរិមាណជាមួយនឹងទិន្នន័យប្រេងឥន្ធនៈដែលមានស្រាប់អាចផ្តល់នូវប្រអប់បំប្លែង។
- **របៀបងងឹត**
- **ការណែនាំអំពីការដំឡើង** — បើកការបង្រៀនអំពីយានជំនិះដំបូង/ការធ្វើសមកាលកម្មឡើងវិញ។
- **បំបាត់កំហុស** / **បង្ហាញអេក្រង់ពិសោធន៍ (dev)** — កម្រិតខ្ពស់; ទុកចោលសម្រាប់ការប្រើប្រាស់ប្រចាំថ្ងៃ។ អេក្រង់សាកល្បងមិនត្រូវបានចងក្រងជាឯកសារនៅទីនេះទេ។

CSV **ការនាំចេញ/នាំចូល** (ZIP នៃយានជំនិះ / ការចំណាយ / ផ្ទាំងឥន្ធនៈ) អាចរកបានពីការកំណត់ នៅពេលផ្តល់ជូនដោយការស្ថាបនាបច្ចុប្បន្ន។
