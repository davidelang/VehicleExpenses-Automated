# <a id="vehicle-expenses-automated--user-manual"></a>വാഹന ചെലവുകൾ ഓട്ടോമേറ്റഡ് — ഉപയോക്തൃ മാനുവൽ

> ** ഉറവിടം എഡിറ്റ് ചെയ്യുക (മാർക്ക്ഡൗൺ).** ബ്രൗസറുകളും ഇൻ-ആപ്പ് റീഡറും **റെൻഡർ ചെയ്‌ത HTML** തുറക്കുക:
> - വെബ്: [`docs/user-manual/index.html`](index.html) (`./scripts/render-user-manual.sh` ഉപയോഗിച്ച് പുനഃസൃഷ്ടിക്കുക)
> - ആപ്പ്: സഹായം / കുറിച്ച് → പൂർണ്ണ മാനുവൽ (ബണ്ടിൽ ചെയ്ത HTML + സ്ക്രീൻഷോട്ടുകൾ)
>
> അന്തിമ ഉപയോക്താക്കളെ റോ `.md` URL-കളിൽ പോയിൻ്റ് ചെയ്യരുത് - ബ്രൗസറുകൾ പ്ലെയിൻ ടെക്‌സ്‌റ്റ് മാത്രം കാണിക്കുന്നു.

**നിങ്ങളുടെ** ക്ലൗഡ് അക്കൗണ്ടുകൾക്ക് കീഴിൽ ഓപ്‌ഷണൽ മൾട്ടി-ഡിവൈസ് സമന്വയവും ബാക്കപ്പും ഉള്ള ഇന്ധനം നിറയ്ക്കുന്നതിനും വാഹന ചെലവുകൾക്കുമായി ക്യാമറ-ആദ്യ ട്രാക്കിംഗ്.

ഇതാണ് ** പൂർണ്ണ മാനുവൽ** (സ്ക്രീൻഷോട്ടുകൾ + ഓരോ ഘട്ടവും). ഫോണിൽ, **മെനു → സഹായം** എന്നത് ആരംഭിക്കുന്നതിനുള്ള ഒരു ചെറിയ ഗൈഡാണ്.

**ഇവിടെ ഉൾപ്പെടുത്തിയിട്ടില്ല:** പഴയ ചിത്രങ്ങൾ, വിന്യാസ പരീക്ഷണം, പമ്പ് പരീക്ഷണം (ഡെവലപ്പർ / നൂതന ഉപകരണങ്ങൾ) എന്നിവ ഇറക്കുമതി ചെയ്യുക.

## <a id="what-you-need"></a>നിങ്ങൾക്ക് വേണ്ടത്

- Android ഫോൺ അല്ലെങ്കിൽ ടാബ്‌ലെറ്റ്.
- മികച്ച OCR-ന്: നിങ്ങളുടെ **ഡാഷ്‌ബോർഡ് ഓഡോമീറ്റർ**, ** പമ്പ് ടോട്ടലുകളുടെ വ്യക്തമായ കാഴ്ച** (അല്ലെങ്കിൽ കൈകൊണ്ട് നമ്പറുകൾ ടൈപ്പ് ചെയ്യുക).
- ഓപ്‌ഷണൽ: സ്‌പ്രെഡ്‌ഷീറ്റ് ഡാറ്റയ്‌ക്കും/അല്ലെങ്കിൽ ഫോട്ടോ ബാക്കപ്പിനുമായി **നിങ്ങൾ നിയന്ത്രിക്കുന്ന ** അക്കൗണ്ടുകൾ ([ബാക്കപ്പുകളും മൾട്ടി-ഡിവൈസ് സമന്വയവും](#backups-and-multi-device-sync) കാണുക).

## <a id="icons-at-a-glance"></a>ഐക്കണുകൾ ഒറ്റനോട്ടത്തിൽ

ഇവ പ്രധാന സ്ക്രീനുകളിൽ ദൃശ്യമാകും. അവരെ അറിയുന്നത് ധാരാളം വേട്ടയാടൽ ലാഭിക്കുന്നു.

| എവിടെ | ഐക്കൺ / നിയന്ത്രണം | അത് എന്ത് ചെയ്യുന്നു |
|-------|---------------|---------------|
| മുകളിലെ ബാർ | **☰ മെനു** (ഹാംബർഗർ) | നാവിഗേഷൻ ഡ്രോയർ തുറക്കുന്നു |
| മുകളിലെ ബാർ | **ⓘ** (പേജ് സഹായം) | **നിലവിലെ** പേജിനുള്ള ഹ്രസ്വ സഹായം (ലഭ്യമാകുമ്പോൾ മെനുവിന് അടുത്ത്) |
| മുകളിലെ ബാർ | **`?N`** (മഞ്ഞ) | ശേഷിക്കുന്ന ഇറക്കുമതി അവലോകന ചോദ്യങ്ങൾ — ഇറക്കുമതി അവലോകനം തുറക്കുന്നു |
| മുകളിലെ ബാർ | **!** (ചുവപ്പ്) | ഒരു സ്‌പ്രെഡ്‌ഷീറ്റോ ഫോട്ടോ ലക്ഷ്യസ്ഥാനമോ അടുത്തിടെ പരാജയപ്പെട്ടു — പരിഹരിക്കാൻ **സമന്വയിപ്പിക്കൽ** തുറക്കുക |
| മുകളിലെ ബാർ | **☰ + ←** | കുട്ടികളുടെ റിപ്പോർട്ടും ചെലവുകളുടെ ലിസ്റ്റും **മെനുവും തിരിച്ചും** ഒരുമിച്ച് കാണിക്കുന്നു; റിപ്പോർട്ടുകളുടെ കേന്ദ്രം മെനു മാത്രമാണ് |
| ക്രമീകരണങ്ങൾ / ഇന്ധന എഡിറ്റ് | **←** | പിന്നിലേക്ക് (ക്രമീകരണങ്ങൾ സ്‌പ്രെഡ്‌ഷീറ്റ്/ഫോട്ടോ, ഇന്ധനം എന്നിവയുടെ എഡിറ്റ് ബാക്ക്-ഫോക്കസ്ഡ് ആയി തുടരുക) |
| പൂരിപ്പിക്കുക | **വെളുത്ത വൃത്തം** (ഷട്ടർ) | OCR നായി ഓഡോമീറ്റർ അല്ലെങ്കിൽ പമ്പ് ഡിസ്പ്ലേ ക്യാപ്ചർ |
| പൂരിപ്പിക്കുക | **ഡിസ്ക് / സേവ്** | ഫിൽ-അപ്പ് സംരക്ഷിക്കുക (ഒരു വാഹനവും കുറഞ്ഞത് ഒരെണ്ണം ഓഡോ / വോളിയം / ചെലവ്) |
| പൂരിപ്പിക്കുക | **↕ അമ്പടയാളങ്ങൾ** (മോഡ് സ്വിച്ച്) | ടോഗിൾ ** ഓഡോമീറ്റർ മോഡ്** vs ** പമ്പ് (വില/വോളിയം) മോഡ്**. പച്ച ബോർഡർ സജീവ ഫീൽഡ് ഗ്രൂപ്പിനെ ഹൈലൈറ്റ് ചെയ്യുന്നു |

| പൂരിപ്പിക്കുക (പിടിച്ചതിന് ശേഷം) | പ്രധാന ബട്ടണിൽ **പുതുക്കുക** | പ്രിവ്യൂ ഉപേക്ഷിച്ച് ലൈവ് ക്യാമറയിലേക്ക് മടങ്ങുക |
| പൂരിപ്പിക്കുക (പ്രോസസ്സ് ചെയ്യുമ്പോൾ) | പ്രധാന ബട്ടണിൽ **X** | പുരോഗതിയിലുള്ള ക്യാപ്‌ചർ/OCR റദ്ദാക്കുക |
| ചെലവ് | **സംരക്ഷിക്കുക** | ചെലവ് ലാഭിക്കൂ |

| ചെലവ് | **ഗാലറി** | ലൈബ്രറിയിൽ നിന്ന് ഒരു രസീത് ചിത്രം തിരഞ്ഞെടുക്കുക |
| ചെലവ് | **വീണ്ടെടുക്കുക** | കറൻ്റ് രസീത് ഫോട്ടോ മായ്ച്ച് വീണ്ടും ഷൂട്ട് ചെയ്യുക |
| ചെലവ് / വാഹനങ്ങൾ നിയന്ത്രിക്കുക | **+ / -** FAB-കൾ | ഫോട്ടോ പ്രിവ്യൂ സൂം ചെയ്യുക |
| ലാൻഡ്‌മാർക്കുകൾ ഡയലോഗ് | **ഒസിആർ എഡിറ്റ് ചെയ്യുക** | എഞ്ചിനുകൾ നഷ്‌ടമായ വാചകം ശരിയാക്കുക അല്ലെങ്കിൽ ചേർക്കുക |

കോസ്റ്റ് ഫീൽഡുകളിലെ കറൻസി ചിഹ്നങ്ങളും വോളിയം ഫീൽഡുകളിൽ **G/L** ടാപ്പുചെയ്യാനാകും: കറൻസി മാറ്റാൻ ഒരു ചെറിയ മെനു തുറക്കുക അല്ലെങ്കിൽ ആ എൻട്രിക്ക് ലിറ്ററിന് എതിരെ ഗാലൻ.

![നാവിഗേഷൻ ഡ്രോയർ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/01-drawer.jpg)

**പ്രധാന ഡ്രോയർ:** പൂരിപ്പിക്കുക · യാത്ര ആരംഭിക്കുക · വാഹനങ്ങൾ നിയന്ത്രിക്കുക · പുതിയ ചെലവ് · ** റിപ്പോർട്ടുകൾ** · ക്രമീകരണങ്ങൾ · സമന്വയിപ്പിക്കൽ · സഹായം · കുറിച്ച്.

**പരീക്ഷണ ഡ്രോയർ** (ക്രമീകരണങ്ങൾ → പരീക്ഷണ സ്ക്രീനുകൾ കാണിക്കുക): വിന്യാസ പരീക്ഷണം · പമ്പ് പരീക്ഷണം · **പഴയ ചിത്രങ്ങൾ ഇറക്കുമതി ചെയ്യുക**.

**റിപ്പോർട്ട് ഹബ് വഴി (പ്രധാന ഡ്രോയർ അല്ല):** ചെലവുകളുടെ ലിസ്റ്റ് · ചരിത്രം പൂരിപ്പിക്കുക.

## <a id="first-time-setup-manage-vehicles"></a>ആദ്യത്തെ സജ്ജീകരണം: വാഹനങ്ങൾ നിയന്ത്രിക്കുക

OCR, **ഓട്ടോമാറ്റിക് വെഹിക്കിൾ പൊരുത്തപ്പെടുത്തൽ** നിങ്ങൾ ഓരോ വാഹനവും ഒരു ** റഫറൻസ് ഡാഷ്‌ബോർഡ് ഫോട്ടോ** ഉപയോഗിച്ച് രജിസ്റ്റർ ചെയ്‌ത് **ഡിസ്കവറി** റൺ ചെയ്‌ത് ഒരു പാഡിൽ സീഡിൽ നിന്ന് ഓഡോമീറ്റർ ക്രോപ്പ് സജ്ജീകരിച്ച് ആ ഡാഷിനായി ലാൻഡ്‌മാർക്കുകൾ സംരക്ഷിച്ചതിന് ശേഷം മികച്ച രീതിയിൽ പ്രവർത്തിക്കുന്നു.

### <a id="open-manage-vehicles"></a>ഓപ്പൺ മാനേജ് വെഹിക്കിൾസ്

### <a id="add-or-edit-a-vehicle"></a>ഒരു വാഹനം ചേർക്കുക അല്ലെങ്കിൽ എഡിറ്റ് ചെയ്യുക

1. **വാഹനം** ഡ്രോപ്പ്ഡൗൺ തുറക്കുക → ഒരു വാഹനം തിരഞ്ഞെടുക്കുക അല്ലെങ്കിൽ **പുതിയ വാഹനം ചേർക്കുക**.
2. വ്യക്തമായ ഒരു ** റഫറൻസ് ഡാഷ് ഫോട്ടോ** (പൂർണ്ണമായ ഇൻസ്ട്രുമെൻ്റ് ക്ലസ്റ്റർ, നല്ല വെളിച്ചം, ഫോൺ ഏകദേശം സ്ക്വയർ-ഓൺ) എടുക്കുക അല്ലെങ്കിൽ തിരഞ്ഞെടുക്കുക. **ഫോട്ടോ എടുക്കുക** അല്ലെങ്കിൽ **ഗാലറി** ഉപയോഗിക്കുക.
3. ടാപ്പ് **ഡിസ്കവറി പ്രവർത്തിപ്പിക്കുക** — പാഡിൽ കണ്ടെത്തൽ ഫോട്ടോയിൽ മഞ്ഞ **വിത്തുകൾ** സ്ഥാപിക്കുന്നു (ലാൻഡ്‌മാർക്കുകൾ മുമ്പത്തെ അതേ `"ML Kit"` JSON ഉപയോഗിക്കുന്നു).
4. **ഓഡോ തിരഞ്ഞെടുക്കുക** ടാപ്പ് ചെയ്യുക, അക്കങ്ങളിൽ വിത്ത് ടാപ്പ് ചെയ്യുക, ഹാൻഡിലുകൾ ക്രമീകരിക്കുക, തുടർന്ന് **സേവ്**.
5. **ഓഡോ എഡിറ്റ് ചെയ്യുക** ഇതിനകം ഉള്ള ഒരു ബോക്സ് ക്രമീകരിക്കുന്നു. ** ക്ലിയർ ഓഡോ** അത് നീക്കംചെയ്യുന്നു, തുടർന്ന് ബട്ടൺ ** ഓഡോ തിരഞ്ഞെടുക്കുക** എന്ന് വായിക്കുന്നു.
6. **ലാൻഡ്‌മാർക്കുകൾ കാണിക്കുക** ഉപയോഗിച്ച് അവലോകനം ചെയ്യുക. തെറ്റായ വായനകൾ പരിഹരിക്കാൻ **OCR എഡിറ്റുചെയ്യുക** ഉപയോഗിക്കുക അല്ലെങ്കിൽ നഷ്‌ടമായ വാചകം ** ചേർക്കുക** ഉപയോഗിക്കുക.
7. **വാഹനത്തിൻ്റെ പേര്** (ആവശ്യമാണ്), കൂടാതെ നിങ്ങൾക്ക് ഇഷ്ടമുള്ള രീതിയിൽ നിർമ്മിക്കുക/മോഡൽ/വർഷം/പ്ലേറ്റ് എന്നിവ പൂരിപ്പിക്കുക.
8. **വാഹനം സൃഷ്‌ടിക്കുക** അല്ലെങ്കിൽ **മാറ്റങ്ങൾ സംരക്ഷിക്കുക** ടാപ്പ് ചെയ്യുക (ഒരു പുതിയ വാഹനത്തിന് പേര് + റഫറൻസ് ഫോട്ടോ ആവശ്യമാണ്).

![പുതിയ വാഹന ഫോം ഫീൽഡുകൾ ചേർക്കുക](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/03b-manage-vehicles-new.jpg)

### <a id="landmarks-fix-what-discovery-missed"></a>ലാൻഡ്‌മാർക്കുകൾ: ഡിസ്‌കവറിക്ക് നഷ്‌ടമായത് പരിഹരിക്കുക

**ലാൻഡ്‌മാർക്കുകൾ കാണിക്കുക** എന്നതിന് ശേഷം, ലിസ്റ്റ് സ്ക്രോൾ ചെയ്ത് മൂല്യങ്ങൾ ശരിയാക്കുക. എഞ്ചിനുകൾക്ക് ചിലപ്പോൾ ചെറിയ അക്കങ്ങൾ നഷ്ടപ്പെടും (ഉദാഹരണത്തിന് ക്ലസ്റ്ററിൻ്റെ താഴെ വലതുവശത്തുള്ള ഒരു ക്ലോക്ക് **60**). അവ ചേർക്കുന്നതിനോ പരിഹരിക്കുന്നതിനോ **എഡിറ്റ് OCR** ​​ഉപയോഗിക്കുക, അതുവഴി വാഹന ഐഡൻ്റിറ്റി വിശ്വസനീയമായി നിലനിൽക്കും.

![ലാൻഡ്‌മാർക്കുകൾ ഡയലോഗ് — OCR അവലോകനം ചെയ്ത് എഡിറ്റ് ചെയ്യുക](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a>ഒരു തികഞ്ഞ ഫോട്ടോ ഇല്ലാതെ ടൈപ്പുചെയ്യുന്നു

ഒരു വാഹനം തിരഞ്ഞെടുത്ത് നിങ്ങൾക്ക് തുടർന്നും ആപ്പ് ഉപയോഗിക്കാനാകും, കൂടാതെ **ടൈപ്പ്** ഓഡോമീറ്റർ, വോളിയം, ഫിൽ എന്നിവയിലെ വില - OCR എല്ലാ ഫീൽഡുകൾക്കും ഓപ്‌ഷണലാണ്. നിങ്ങൾ ഇൻ-ആപ്പ് ഷൂട്ട് ചെയ്യരുതെന്ന് താൽപ്പര്യപ്പെടുമ്പോൾ റഫറൻസ് ഡാഷ് ഫോട്ടോയ്‌ക്കായി ഗാലറി ഇറക്കുമതി പ്രവർത്തിക്കുന്നു.

**നുറുങ്ങ്:** സ്‌പ്രെഡ്‌ഷീറ്റ് സമന്വയത്തിന് ശേഷം, വാഹന നിർവചനങ്ങൾ (വിളകൾ, ലാൻഡ്‌മാർക്കുകൾ) പ്രാദേശിക ഡാറ്റാബേസിൽ തത്സമയമാണ് - അവ ഉപയോഗിക്കുന്നതിന് നിങ്ങൾ വാഹനങ്ങൾ നിയന്ത്രിക്കുക വീണ്ടും തുറക്കേണ്ടതില്ല.

## <a id="backups-and-multi-device-sync"></a>ബാക്കപ്പുകളും മൾട്ടി-ഡിവൈസ് സമന്വയവും

ആപ്പ് നിർമ്മിച്ചിരിക്കുന്നതിനാൽ **നിരവധി ഫോണുകൾക്കോ ടാബ്‌ലെറ്റുകൾക്കോ ഒരേ ഫ്ലീറ്റ് ഡാറ്റ പങ്കിടാനാകും**, അതിനാൽ നിങ്ങൾക്ക് ഉപകരണത്തിൽ നിന്ന് ** ഡാറ്റയുടെയും ഫോട്ടോകളുടെയും ഒരു പകർപ്പ് സൂക്ഷിക്കാനാകും**. അത് **നിങ്ങൾ** **നിങ്ങളുടെ** അക്കൗണ്ടുകൾക്കോ ​​**നിങ്ങളുടെ** സ്വയം ഹോസ്റ്റ് ചെയ്‌ത സെർവറുകളുടെയോ കീഴിൽ കോൺഫിഗർ ചെയ്‌ത ലക്ഷ്യസ്ഥാനങ്ങൾ ഉപയോഗിച്ചാണ് ചെയ്യുന്നത് — മറ്റ് ആളുകൾക്ക് കാണാൻ കഴിയുന്ന ഒരു കമ്പനി നടത്തുന്ന “വാഹന ചെലവ് ക്ലൗഡ്” അല്ല.

### <a id="what-runs-where"></a>എന്ത് എവിടെയാണ് ഓടുന്നത്

| ദയ | എന്താണ് സംഭരിക്കുന്നത് | സാധാരണ ഉപയോഗം |
|------|---------------|------------|
| **സ്പ്രെഡ്ഷീറ്റ് / പട്ടിക സമന്വയം** | വാഹനങ്ങൾ, ഇന്ധനം നിറയ്ക്കൽ, ചെലവുകൾ (വരികളും ടാബുകളും) | മൾട്ടി-ഡിവൈസ് ലയനം + ഘടനാപരമായ ബാക്കപ്പ് |
| **ഫോട്ടോ ബാക്കപ്പ്** | ബൈനറി ചിത്രങ്ങൾ (ഡാഷ്/പമ്പ്/രസീത്/റഫറൻസ് ഫോട്ടോകൾ) | ഫോട്ടോ ബാക്കപ്പ് + നഷ്‌ടമായ ഫയലുകൾ പുനഃസ്ഥാപിക്കുക |

നിങ്ങൾക്ക് ഓരോ തരത്തിലുമുള്ള **ഒന്നിലധികം ലക്ഷ്യസ്ഥാനങ്ങൾ** കോൺഫിഗർ ചെയ്യാം (ഓരോ തരത്തിനും സോഫ്റ്റ് ക്യാപ്). മാനുവൽ **ഇപ്പോൾ സമന്വയിപ്പിക്കുക** കൂടാതെ **പശ്ചാത്തലം** പ്രവർത്തകർ പ്രവർത്തനക്ഷമമാക്കിയവ പ്രവർത്തിപ്പിക്കുന്നു.

### <a id="offline-first"></a>ഓഫ്ലൈൻ ആദ്യം

- പൂരിപ്പിക്കൽ, ചെലവ് അല്ലെങ്കിൽ രസീത് ചേർക്കുന്നതിന് ** നെറ്റ്‌വർക്ക് ആവശ്യമില്ല**. എല്ലാം സംരക്ഷിച്ചു **പ്രാദേശികമായി ആദ്യം**.
- നെറ്റ്‌വർക്ക് ലഭ്യമാകുമ്പോൾ, സമന്വയവും ഫോട്ടോ ബാക്കപ്പും **പശ്ചാത്തല ടാസ്‌ക്കുകളായി റൺ ചെയ്യുക** (നിങ്ങൾ സജ്ജമാക്കിയ ഷെഡ്യൂളിൽ, നിങ്ങൾ **ഇപ്പോൾ സമന്വയിപ്പിക്കുക** ടാപ്പുചെയ്യുമ്പോൾ). പരാജയങ്ങൾ ക്രമീകരണ വരികൾക്ക് കീഴിൽ ചുവന്ന വാചകമായും ആപ്പ് ടൈറ്റിൽ ബാറിൽ **!** ആയി കാണിക്കുന്നു.

### <a id="your-accounts-only"></a>നിങ്ങളുടെ അക്കൗണ്ടുകൾ മാത്രം

നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന ദാതാക്കളുടെ (Google, Microsoft, S3 കീകൾ, സ്വയം-ഹോസ്‌റ്റ് ചെയ്‌ത URL-കൾ മുതലായവ) സൈൻ-ഇൻ ചെയ്യലും ടോക്കണുകളും ഉപകരണത്തിൽ നിലനിൽക്കും. ലക്ഷ്യസ്ഥാനങ്ങൾ ** ഉപയോക്താവിൻ്റെ പൂർണ്ണ നിയന്ത്രണത്തിലാണ്** — നിങ്ങളുടെ Google അക്കൗണ്ട്, നിങ്ങളുടെ OneDrive, നിങ്ങളുടെ MinIO ബക്കറ്റ്, നിങ്ങളുടെ EtherCalc ഹോസ്റ്റ് മുതലായവ. പങ്കിട്ട ബാക്കെൻഡിലൂടെ മറ്റ് വാഹന ചെലവ് ഉപയോക്താക്കളുമായി ഒന്നും പങ്കിടില്ല.

### <a id="supported-targets--data-spreadsheet--tabular"></a>പിന്തുണയുള്ള ടാർഗെറ്റുകൾ — ഡാറ്റ (സ്‌പ്രെഡ്‌ഷീറ്റ് / പട്ടിക)

| ലക്ഷ്യം | കുറിപ്പുകൾ |
|---------|---------|

മാറ്റിവെച്ചത് / ഇതുവരെ തലയില്ലാത്തവരല്ല (മറ്റുള്ളവയ്ക്ക് കീഴിൽ ലിസ്റ്റുചെയ്തിട്ടുണ്ട് എന്നാൽ പൂർണ്ണമായി നടപ്പിലാക്കിയിട്ടില്ല): ഓഫീസ്, കൊളബോറ മാത്രം. [സ്വയം-ഹോസ്റ്റ് സൂചിക](reference/self-host/INDEX.md) ഇതും കാണുക.

CSV **കയറ്റുമതി/ഇറക്കുമതി** (ഒരേ ടാബ് ലേഔട്ടിൻ്റെ ZIP) തത്സമയ സമന്വയത്തിൽ നിന്ന് സ്വതന്ത്രമായ ഒരു പോർട്ടബിൾ ബാക്കപ്പായി ക്രമീകരണങ്ങളിൽ നിന്ന് ലഭ്യമാണ്.

### <a id="supported-targets--photos-image-backup"></a>പിന്തുണയുള്ള ടാർഗെറ്റുകൾ — ഫോട്ടോകൾ (ഇമേജ് ബാക്കപ്പ്)

**മെനു → സമന്വയിപ്പിക്കൽ → ഫോട്ടോ ബാക്കപ്പ്** എന്നതിന് കീഴിൽ കോൺഫിഗർ ചെയ്‌തു (ക്രമീകരണ സംഗ്രഹ വരികളിൽ നിന്നും):

| ലക്ഷ്യം | കുറിപ്പുകൾ |
|---------|---------|
| **Google ഡ്രൈവ്** | നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന ഫോൾഡർ (URL ബ്രൗസ് ചെയ്യുക അല്ലെങ്കിൽ ഒട്ടിക്കുക) |
| **വൺഡ്രൈവ്** | Microsoft അക്കൗണ്ട് + പാത്ത് പ്രിഫിക്സ് |
| **S3** | AWS, Wasabi, Cloudflare R2, MinIO, മറ്റ് S3-അനുയോജ്യമായ എൻഡ് പോയിൻ്റുകൾ |
| **മറ്റ്** | rclone പിന്തുണയുള്ള സംഭരണം (ഉദാ. WebDAV, SFTP, മറ്റ് ക്യൂറേറ്റഡ് റിമോട്ടുകൾ എന്നിവ ഇൻ-ആപ്പ് പിക്കറിൽ ലഭ്യമാണ്) |

സ്വയം-ഹോസ്‌റ്റ് ചെയ്‌ത ഫോട്ടോയ്‌ക്കും ടാബ്‌ലർ ടാർഗെറ്റുകൾക്കുമായി ചീറ്റ്‌ഷീറ്റുകൾ സജ്ജീകരിക്കുക: [സ്വയം-ഹോസ്റ്റ് സൂചിക](reference/self-host/INDEX.md).

### <a id="multi-device-behavior-short"></a>Multi-device സ്വഭാവം (ഹ്രസ്വ)

- **സമന്വയ ഐഡി** വഴി **അപ്‌ഡേറ്റ് ചെയ്‌ത** ടൈംസ്റ്റാമ്പുകളിൽ **അവസാനമായി എഴുതിയ വിജയങ്ങൾ** ഉപയോഗിച്ച് വരികൾ ലയിക്കുന്നു.
- ഇല്ലാതാക്കലുകൾ മൃദുവാണ്; മറ്റൊരു ഉപകരണത്തിൽ ഒരു പുതിയ എഡിറ്റ് ഒരു വരി പുനഃസ്ഥാപിക്കാൻ കഴിയും.
- രണ്ട് ഉപകരണങ്ങളിൽ ** ഒരേ ഫിൽ രണ്ടുതവണ** നൽകുന്നത് **രണ്ട് വരികൾ** സൃഷ്ടിക്കുന്നു - നിങ്ങൾ ശ്രദ്ധിക്കുമ്പോൾ അധികമായത് ഇല്ലാതാക്കുക.
- കൂടുതൽ വിശദാംശങ്ങൾ: [സമന്വയ പെരുമാറ്റ കുറിപ്പുകൾ](#sync-behavior-notes) കൂടാതെ [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md).

### <a id="sync-behavior-notes"></a> പെരുമാറ്റ കുറിപ്പുകൾ സമന്വയിപ്പിക്കുക

- ആപ്പ് അപ്‌ഗ്രേഡിന് ശേഷം നിങ്ങൾക്ക് **“അപ്‌ഗ്രേഡ് ചെയ്‌തതിന് ശേഷം ഡാറ്റാബേസ് അപ്‌ഡേറ്റ് ചെയ്യുന്നു…”** (പ്രാദേശിക സമന്വയ-ഐഡി ബാക്ക്ഫിൽ) ഹ്രസ്വമായി കണ്ടേക്കാം.
- ഒരു സമന്വയം തടസ്സപ്പെട്ടാൽ, അടുത്ത **വിജയകരമായ** സമന്വയം വീണ്ടും ലയിപ്പിക്കുകയും റിമോട്ട് ടാബുകൾ നന്നാക്കുകയും ചെയ്യുന്നു.
- പരാജയങ്ങൾ: ആപ്പ് ബാറിൽ സമന്വയിപ്പിക്കുന്ന കാർഡുകളിലെ ചുവന്ന സംഗ്രഹം + **!**.

## <a id="fill-up-fuel"></a>Fill (ഇന്ധനം)

നിങ്ങൾ ആപ്പ് തുറക്കുമ്പോൾ ഇത് **ഹോം സ്‌ക്രീൻ** ആണ്.

### <a id="vehicle-selection-usually-automatic"></a>വാഹന തിരഞ്ഞെടുപ്പ് (സാധാരണയായി ഓട്ടോമാറ്റിക്)

നിങ്ങൾ ആദ്യം വാഹനം തിരഞ്ഞെടുക്കേണ്ട **അല്ല**. വാഹനങ്ങൾ നിയന്ത്രിക്കുക എന്നതിൽ വാഹനങ്ങൾ **ലാൻഡ്‌മാർക്കുകൾ** സജ്ജീകരിച്ചിരിക്കുമ്പോൾ, നിങ്ങൾ ഓഡോമീറ്റർ ക്യാപ്‌ചർ ചെയ്‌തതിന് ശേഷം ഡാഷ് ഇമേജിൽ നിന്ന് **ഏത് വാഹനം എന്ന് സ്വയം കണ്ടെത്തുന്നു. ആവശ്യമെങ്കിൽ അസാധുവാക്കാൻ നിങ്ങൾക്ക് തുടർന്നും **വാഹനം** ഡ്രോപ്പ്ഡൗൺ തുറക്കാം.

### <a id="aim-at-the-odometer"></a>ഓഡോമീറ്ററിൽ ലക്ഷ്യമിടുക

ഓഡോമീറ്റർ മോഡിൽ തുടരുക, ക്ലസ്റ്റർ ഫ്രെയിം ചെയ്യുക. നിർദ്ദേശം: *ഓഡോമീറ്റർ ലക്ഷ്യമിടുക. ക്യാപ്‌ചർ ചെയ്യാൻ ഷട്ടറിൽ ടാപ്പ് ചെയ്യുക.*

![ഫിൽ — ഓഡോമീറ്ററിൽ ലൈവ് ക്യാമറ (പ്രിവ്യൂവിൽ ഡാഷ് ഇമേജ് ഉദാഹരണം)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a>ഓഡോമീറ്റർ ഷട്ടറിന് ശേഷം

OCR **Odo** പൂരിപ്പിക്കുകയും ലാൻഡ്‌മാർക്കുകളിൽ നിന്ന് വാഹനവുമായി പൊരുത്തപ്പെടാൻ ശ്രമിക്കുകയും ചെയ്യുന്നു (ആവശ്യമെങ്കിൽ രണ്ടും അവലോകനം ചെയ്യുക). പ്രധാന ബട്ടൺ വീണ്ടും ഷൂട്ട് ചെയ്യാൻ **വീണ്ടും ശ്രമിക്കൂ** ആയി മാറുന്നു. പ്രബോധനം വായനയെ സംഗ്രഹിക്കുന്നു.

![ഫിൽ — ഓഡോമീറ്റർ OCR ഫലം](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a>Pump mode (ചെലവും അളവും)

1. പമ്പ് മോഡിലേക്ക് മാറാൻ **↕** ടാപ്പ് ചെയ്യുക: *പമ്പ് ഡിസ്‌പ്ലേ ലക്ഷ്യമിടുക (വില/വോളിയം). ഷട്ടർ ടാപ്പ് ചെയ്യുക.*
2. പമ്പിൻ്റെ ആകെത്തുക ക്യാപ്‌ചർ ചെയ്യുക. ചെലവും വോളിയവും ഫീൽഡുകൾ പൂരിപ്പിക്കുക; അവ മാറ്റുകയാണെങ്കിൽ **↔** ഉപയോഗിക്കുക.
3. ആവശ്യമെങ്കിൽ കറൻസി അല്ലെങ്കിൽ **G/L** ടാപ്പ് ചെയ്യുക, തുടർന്ന് **സംരക്ഷിക്കുക** (ഡിസ്ക്). ശൂന്യമായ ഫീൽഡുകൾ **ഭാഗിക പൂരിപ്പിക്കൽ** (ഇപ്പോഴും അനുവദനീയമാണ്).

![പൂരിപ്പിക്കുക — പമ്പ് പ്രിവ്യൂ / ആകെത്തുക (ഉദാഹരണം പമ്പ് ചിത്രം പ്രിവ്യൂവിൽ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

അടുത്ത സ്റ്റോപ്പിനായി നിങ്ങൾ ഫിൽ തുടരുക (സംരക്ഷിച്ചതിന് ശേഷം ഫീൽഡുകൾ മായ്‌ക്കുക). പൂർണ്ണമായും ** ഓഫ്‌ലൈനായി** പ്രവർത്തിക്കുക; കോൺഫിഗർ ചെയ്യുമ്പോൾ പശ്ചാത്തലത്തിൽ പിന്നീട് സമന്വയം പ്രവർത്തിക്കുന്നു.

### <a id="manual-entry-no-camera--bad-ocr"></a>മാനുവൽ എൻട്രി (ക്യാമറ ഇല്ല / മോശം OCR)

1. **ഓഡോ**, **കോസ്റ്റ്**, അല്ലെങ്കിൽ **വോളിയം** ടാപ്പ് ചെയ്‌ത് മൂല്യങ്ങൾ ടൈപ്പ് ചെയ്യുക (പോർട്രെയ്‌റ്റ് സിസ്റ്റം കീബോർഡ് ഉപയോഗിക്കുന്നു; ലാൻഡ്‌സ്‌കേപ്പ് ഓൺ-സ്‌ക്രീൻ കീപാഡ് ഉപയോഗിക്കുന്നു).
2. ഓട്ടോ-ഡിറ്റക്റ്റ് പ്രവർത്തിച്ചില്ലെങ്കിൽ **വാഹനം** തിരഞ്ഞെടുക്കുക അല്ലെങ്കിൽ സ്ഥിരീകരിക്കുക.
3. മുകളിൽ പറഞ്ഞതുപോലെ സംരക്ഷിക്കുക.

### <a id="modes-and-borders"></a>മോഡുകളും ബോർഡറുകളും

- **പച്ച ബോർഡർ** വാഹനത്തിന് ചുറ്റും+ഓഡോ → ക്യാപ്ചറിംഗ്/എഡിറ്റിംഗ് ഓഡോമീറ്റർ.
- **പച്ച ബോർഡർ** ചെലവ്+വോളിയം → പമ്പ് മോഡ്.
- ഒരു വാഹനം തിരഞ്ഞെടുക്കുന്നത് വരെ **സംരക്ഷിക്കുക** പ്രവർത്തനരഹിതമായി തുടരുകയും ഒഡോ/കോസ്റ്റ്/വോളിയം എന്നിവയിലൊന്നെങ്കിലും ഡാറ്റ ഉണ്ടായിരിക്കുകയും OCR ഇപ്പോഴും പ്രവർത്തിക്കുന്നില്ല.

ഓൺ-സ്‌ക്രീൻ ടിപ്പ് (നിർദ്ദേശ ലൈനിന് താഴെ): *ഷട്ടർ = ക്യാപ്‌ചർ · ഡിസ്‌ക് = സേവ് · ↕ = ഓഡോ/പമ്പ് മോഡ് · ↔ = സ്വാപ്പ് കോസ്റ്റ്/വോളിയം.*

## <a id="expenses"></a>ചെലവുകൾ

### <a id="new-expense"></a>പുതിയ ചെലവ്

മെനു → **പുതിയ ചെലവ്**.

![പുതിയ ചെലവ് ഫോമും ക്യാമറ നിയന്ത്രണങ്ങളും (ശൂന്യമായിരിക്കുമ്പോൾ ക്യാമറ ബാൻഡിലെ ഡാഷ് ഇമേജ് ഉദാഹരണം)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r6-new-expense.jpg)

1. **സംരക്ഷിക്കുക** (ഡിസ്ക്), **ഷട്ടർ** (രസീത് ഫോട്ടോ), അല്ലെങ്കിൽ **ഗാലറി** (ചിത്രം തിരഞ്ഞെടുക്കുക).
2. **തീയതി**, **വാഹനം**, **വെണ്ടർ**, **വിവരണം**, **തുക** (കറൻസി ചിഹ്നം ടാപ്പുചെയ്യാവുന്നത്), **വിഭാഗം**, ഓപ്‌ഷണൽ **ഓഡോമീറ്റർ** എന്നിവ പൂരിപ്പിക്കുക.
3. മൾട്ടി-പേജ് രസീതുകൾ: UI പേജിംഗ് വാഗ്ദാനം ചെയ്യുന്നുവെങ്കിൽ അധിക പേജുകൾ ക്യാപ്‌ചർ ചെയ്യുക (പേജ് 0 ആണ് പ്രാഥമിക രസീത്).
4. സംഭരിക്കാൻ **സംരക്ഷിക്കുക** (പ്രാദേശികമായി ആദ്യം; ഫോട്ടോ ബാക്കപ്പും സ്‌പ്രെഡ്‌ഷീറ്റ് സമന്വയവും കോൺഫിഗർ ചെയ്യുമ്പോൾ പശ്ചാത്തലത്തിൽ സംഭവിക്കുന്നു).

### <a id="expense-list"></a>ചെലവ് ലിസ്റ്റ്

മെനു → **റിപ്പോർട്ടുകൾ** → **ചെലവ് ലിസ്റ്റ്** — മുൻകാല ഇന്ധനേതര ചെലവുകൾ ബ്രൗസ് ചെയ്യുക; എഡിറ്റുചെയ്യാൻ ഒരു ഇനം തുറക്കുക.

![ചെലവ് ലിസ്റ്റ്](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/05-expense-list.jpg)

### <a id="edit-expense"></a>ചെലവ് എഡിറ്റ് ചെയ്യുക

ലിസ്റ്റിൽ നിന്ന് ഒരു വരി തുറക്കുക. ശരിയായ വെണ്ടർ, തുക, വിഭാഗം, വാഹനം, വിവരണം. രസീത് ഫോട്ടോ ബാക്കപ്പിൽ മാത്രമാണെങ്കിൽ (വായിക്കാൻ കഴിയുന്ന പ്രാദേശിക ഫയലുകളൊന്നുമില്ല), കാണിക്കുമ്പോൾ **ആർക്കൈവിൽ നിന്ന് ചിത്രം എടുക്കുക** ഉപയോഗിക്കുക (കോൺഫിഗർ ചെയ്‌ത ഫോട്ടോ ലക്ഷ്യസ്ഥാനങ്ങളിൽ ഉടനീളം പ്രവർത്തിക്കുന്നു).

![ചെലവ് എഡിറ്റ് ചെയ്യുക](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/expense-edit.jpg)

## <a id="start-trip"></a>ട്രിപ്പ് ആരംഭിക്കുക

മെനു → **യാത്ര ആരംഭിക്കുക** (ഡ്രോയർ പൂരിപ്പിച്ച ശേഷം). ക്യാപ്‌ചർ ചെയ്യുക അല്ലെങ്കിൽ ഓഡോമീറ്റർ നൽകുക, ട്രിപ്പ് തരം തിരഞ്ഞെടുക്കുക, **ഡിസ്ക്** ഐക്കൺ ഉപയോഗിച്ച് സംരക്ഷിക്കുക. **സ്റ്റോപ്പ്** എന്നത് ഇപ്പോൾ കൈവശം വച്ചിരിക്കുന്ന GPS ലൊക്കേഷനിൽ സ്വകാര്യതയ്ക്കുള്ള ഒരു കുറുക്കുവഴിയാണ്. നിയന്ത്രണ ഓർമ്മപ്പെടുത്തലുകൾക്കായി **ⓘ** ഉപയോഗിക്കുക.

![യാത്ര ആരംഭിക്കുക](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/start-trip.jpg)

ട്രിപ്പ് സ്റ്റാർട്ടുകൾ **ട്രിപ്പ് തരം** (സാധാരണ ഫില്ലുകൾ അല്ല) ഉള്ള ഇന്ധന നിരകളായി സംഭരിക്കുന്നു. അവ ഇന്ധന ചരിത്രത്തിന് കീഴിലല്ല, **റിപ്പോർട്ടുകൾ → ട്രിപ്പ് മൈലുകൾ** എന്നതിന് കീഴിൽ ദൃശ്യമാകും.

## <a id="reports"></a>Reports

മെനു → **റിപ്പോർട്ടുകൾ** ഉൽപ്പന്ന ഹബ് തുറക്കുന്നു (എല്ലാ സമയ സംഗ്രഹം + കാറ്റലോഗ് കാർഡുകൾ). ഉൽപ്പന്ന റിപ്പോർട്ടുകളുടെ ഉപരിതലം ഇതാണ് - പ്രത്യേക "റിപ്പോർട്ടുകളും ചാർട്ടുകളും" ഡ്രോയർ ഇനങ്ങളില്ല.

![റിപ്പോർട്ട് ഹബ്](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/06-reports.jpg)

വാഹന മോഡിനായി ഒരു കാർഡ് തുറക്കുക (**എല്ലാം / ഓരോന്നും / സിംഗിൾ**), കാലയളവ് ഫിൽട്ടറുകൾ, ചാർട്ടുകൾ, പങ്കിടൽ (**TEXT / CSV / PDF**). റിപ്പോർട്ട് ചെയ്യപ്പെടുന്ന കുട്ടികളുടെ മുകളിലെ ബാർ: **☰ + ←** (കൂടാതെ **ⓘ** രജിസ്റ്റർ ചെയ്യുമ്പോൾ).

### <a id="time-based-reports"></a>സമയം അടിസ്ഥാനമാക്കിയുള്ള റിപ്പോർട്ടുകൾ

പ്രധാന ചാർട്ട് കാർഡ്. ഓപ്ഷണൽ മെട്രിക്സ് (mpg, G/mi പോലുള്ള വോളിയം/ദൂരം, $/G പോലുള്ള യൂണിറ്റ് വില, ചെലവ്/ദൂരം, പ്രതിമാസ $, ട്രിപ്പ് മൈലുകൾ, തരം അനുസരിച്ച് ട്രിപ്പ് %) **സ്മൂത്ത്** ബിന്നുകളും **സ്വതന്ത്ര Y സ്കെയിലുകളും** (സാമ്പത്തിക ഇടത്; പണവും ട്രിപ്പ് കുടുംബങ്ങളും വലതുവശത്ത്).

![സമയത്തെ അടിസ്ഥാനമാക്കിയുള്ള റിപ്പോർട്ടുകൾ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports.jpg)

![സമയത്തെ അടിസ്ഥാനമാക്കിയുള്ള റിപ്പോർട്ടുകൾ — സ്ക്രോൾ ചെയ്ത മെട്രിക്‌സ്](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports-scrolled.jpg)

സാമ്പത്തിക ഗണിതത്തിൻ്റെ വിശദാംശങ്ങൾ: [REPORTS_METRICS.md](reference/REPORTS_METRICS.md).

### <a id="fill-history-vs-fuel-history"></a>Fill history vs Fuel History

- **റിപ്പോർട്ടുകൾ → ചരിത്രം പൂരിപ്പിക്കുക** — റിപ്പോർട്ട് ഫിൽട്ടറുകൾക്കായുള്ള കാലാനുസൃതമായ പൂരിപ്പിക്കൽ (** പൂരിപ്പിക്കൽ മാത്രം**; യാത്രയൊന്നും ആരംഭിക്കുന്നില്ല).

![ചരിത്ര റിപ്പോർട്ട് പൂരിപ്പിക്കുക](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fill-history.jpg)

- **ഇന്ധന ചരിത്രം** (നിങ്ങളുടെ ബിൽഡിൻ്റെ നാവിഗേഷനിൽ ഉണ്ടെങ്കിൽ) — ഓരോ വാഹനത്തിനും ഫിൽ ഇൻവെൻ്ററിയും പൂരിപ്പിക്കുന്നു; എഡിറ്റ് ചെയ്യാൻ ഒരു വരിയിൽ ടാപ്പ് ചെയ്യുക.

### <a id="trip-miles"></a>ട്രിപ്പ് മൈലുകൾ

**റിപ്പോർട്ടുകൾ → ട്രിപ്പ് മൈലുകൾ** — മൈലുകൾ തരം, ചാർട്ടുകൾ, കാലക്രമത്തിൽ **യാത്ര ആരംഭം / സെഗ്മെൻ്റ് ലിസ്റ്റ്**. ആ വരിയിൽ **എഡിറ്റ് ഫിൽ** തുറക്കാൻ ഒരു യഥാർത്ഥ തുടക്കം ടാപ്പ് ചെയ്യുക.

![ട്രിപ്പ് മൈൽ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a>ഫിൽ എഡിറ്റ് ചെയ്യുക

ഫിൽ ഹിസ്റ്ററി, ഫ്യുവൽ ഹിസ്റ്ററി അല്ലെങ്കിൽ ട്രിപ്പ് മൈലുകൾ എന്നിവയിൽ നിന്ന് ഒരു ഫിൽ തുറക്കുക. ലേഔട്ട്: വാഹനവും ഓഡോമീറ്ററും, **ചെലവിന് മുമ്പുള്ള കറൻസി**, വോളിയം, നോട്ടുകൾ. വരി ഒരു യാത്ര ആരംഭിക്കുമ്പോൾ മാത്രമേ ട്രിപ്പ് തരം ദൃശ്യമാകൂ. ലൊക്കേഷന് ഒരു സംഗ്രഹവും **ലൊക്കേഷൻ വിശദാംശങ്ങളും** ഉണ്ട്. ക്ലൗഡ് ഐഡൻ്റിറ്റിയുള്ള പ്രാദേശിക ഫോട്ടോ നഷ്‌ടമായി: **ആർക്കൈവിൽ നിന്ന് ചിത്രം നേടുക**.

![ഫിൽ എഡിറ്റ് ചെയ്യുക - പ്രാദേശിക ഫോട്ടോ നഷ്‌ടപ്പെടുമ്പോൾ ആർക്കൈവിൽ നിന്ന് എടുക്കുക](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

മറ്റ് കാറ്റലോഗ് കാർഡുകളിൽ വിഭാഗം പ്രകാരമുള്ള ചെലവുകൾ, വാഹന സംഗ്രഹം, ചെലവുകളുടെ പട്ടിക എന്നിവ ഉൾപ്പെടുന്നു.

സജ്ജീകരിക്കുമ്പോൾ പണം ഓരോ വരിയുടെയും കറൻസി ഉപയോഗിക്കുന്നു. മിക്സഡ്-കറൻസി ടോട്ടലുകൾ **ഓരോ കറൻസി സബ്ടോട്ടലുകൾ കാണിക്കുന്നു** (സൈലൻ്റ് എഫ്എക്സ് പരിവർത്തനം ഇല്ല).

## <a id="syncing"></a>Syncing

മെനു → **സമന്വയിപ്പിക്കൽ** എന്നത് സ്‌പ്രെഡ്‌ഷീറ്റിൻ്റെയും ഫോട്ടോ ലക്ഷ്യസ്ഥാനങ്ങളുടെയും കേന്ദ്രമാണ് (ക്രമീകരണങ്ങൾക്ക് കീഴിൽ മാത്രമല്ല).

![സമന്വയ കേന്ദ്രം](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- ഹ്രസ്വ സ്റ്റാറ്റസുള്ള **സ്‌പ്രെഡ്‌ഷീറ്റ് സമന്വയത്തിനും **ഫോട്ടോ ബാക്കപ്പിനുമുള്ള** കാർഡുകൾ, അത്തരത്തിലുള്ളവയ്ക്ക് **സമന്വയം**, കൂടാതെ **›** ലക്ഷ്യസ്ഥാന ലിസ്റ്റിലേക്ക്.
- **ടെസ്‌റ്റ് കണക്ഷനായി ഒരു ലക്ഷ്യസ്ഥാനം തുറക്കുക** കൂടാതെ **ഇപ്പോൾ സമന്വയിപ്പിക്കുക (ഈ ലക്ഷ്യസ്ഥാനം)** / എല്ലാം ക്രമീകരിച്ചു.
- പരാജയം **വിശദാംശങ്ങൾ** ഇവിടെ ടൈറ്റിൽ ബാർ ലാൻഡിലെ ചുവപ്പ് **!**.
- ഘട്ടം ഘട്ടമായുള്ള Google ഷീറ്റുകളും ഡ്രൈവ് സജ്ജീകരണവും: [ബാക്കപ്പുകളും മൾട്ടി-ഡിവൈസ് സമന്വയവും](#backups-and-multi-device-sync).

## <a id="settings-local-preferences"></a>ക്രമീകരണങ്ങൾ (പ്രാദേശിക മുൻഗണനകൾ)

മെനു → **ക്രമീകരണങ്ങൾ**.

![ക്രമീകരണങ്ങൾ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07-settings.jpg)

![കൂടുതൽ ക്രമീകരണങ്ങൾ (സ്ക്രോൾ ചെയ്‌തത്)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07b-settings-more.jpg)

ലക്ഷ്യസ്ഥാനങ്ങൾക്കായി, **മെനു → സമന്വയിപ്പിക്കൽ** തിരഞ്ഞെടുക്കുക. സമാന ലിസ്‌റ്റുകൾ തുറക്കുന്ന സംഗ്രഹ വരികൾ ക്രമീകരണങ്ങൾ തുടർന്നും കാണിച്ചേക്കാം.

### <a id="local-preferences-common"></a>പ്രാദേശിക മുൻഗണനകൾ (പൊതുവായത്)

- **ഇന്ധന രസീത് ഫോട്ടോകൾ സംരക്ഷിക്കുക** / **ചെലവ് ഫോട്ടോകൾ പ്രാദേശികമായി ലാഭിക്കുക** — ഉപകരണത്തിൽ ചിത്രങ്ങൾ സൂക്ഷിക്കുക (ഫോട്ടോകളുടെ അനുമതി അഭ്യർത്ഥിച്ചേക്കാം).
- **ഷട്ടർ സൗണ്ട് പ്ലേ ചെയ്യുക**
- **കറൻസി** / **വോളിയം യൂണിറ്റ്** — ആപ്പ് ഡിഫോൾട്ടുകൾ (സിസ്റ്റം അല്ലെങ്കിൽ സ്പഷ്ടം). നിലവിലുള്ള ഇന്ധന ഡാറ്റ ഉപയോഗിച്ച് വോളിയം യൂണിറ്റ് മാറ്റുന്നത് പരിവർത്തന ഡയലോഗ് വാഗ്ദാനം ചെയ്തേക്കാം.
- **ഡാർക്ക് മോഡ്**
- **സജ്ജീകരണ നുറുങ്ങുകൾ** — ആദ്യം പ്രവർത്തിപ്പിക്കുന്ന വാഹനം / സമന്വയ ട്യൂട്ടോറിയലുകൾ വീണ്ടും തുറക്കുക.
- **ഡീബഗ് ഫിൽ** / ** പരീക്ഷണ സ്ക്രീനുകൾ കാണിക്കുക (dev)** — വിപുലമായത്; ദൈനംദിന ഉപയോഗത്തിനായി വിടുക. പരീക്ഷണ സ്ക്രീനുകൾ ഇവിടെ രേഖപ്പെടുത്തപ്പെട്ടിട്ടില്ല.

CSV **കയറ്റുമതി/ഇറക്കുമതി** (വാഹനങ്ങൾ / ചെലവുകൾ / ഇന്ധന ടാബുകളുടെ ZIP) നിലവിലെ ബിൽഡ് ഓഫർ ചെയ്യുമ്പോൾ ക്രമീകരണങ്ങളിൽ നിന്ന് ലഭ്യമാണ്.
