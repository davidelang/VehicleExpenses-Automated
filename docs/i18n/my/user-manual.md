> - ဝဘ်- [`docs/user-manual/index.html`](index.html) (`./scripts/render-user-manual.sh` ဖြင့် ပြန်ထုတ်သည်)
> - အက်ပ်- အကူအညီ / အကြောင်း → လက်စွဲအပြည့်အစုံ ( HTML + ဖန်သားပြင်ဓာတ်ပုံများ ထုပ်ပိုးထားသည်)
>
> အသုံးပြုသူများအား ကုန်ကြမ်း `.md` URL များထံ မညွှန်ပါနှင့် — ဘရောက်ဆာများသည် ရိုးရိုးစာသားကိုသာ ပြသသည်။

**သင်၏** cloud အကောင့်များအောက်တွင် ရွေးချယ်နိုင်သော စက်ပေါင်းများစွာကို ထပ်တူပြုခြင်းနှင့် အရန်သိမ်းဆည်းခြင်းတို့ဖြင့် လောင်စာဆီဖြည့်ခြင်းနှင့် ယာဉ်ကုန်ကျစရိတ်များအတွက် ကင်မရာ-ပထမခြေရာခံခြင်း။

ဒါက **လက်စွဲစာအုပ်အပြည့်အစုံ** (မျက်နှာပြင်ပုံများ + အဆင့်တိုင်း)။ ဖုန်းတွင်၊ **Menu → Help** သည် ပိုမိုတိုတောင်းသော စတင်ခြင်းလမ်းညွှန်တစ်ခုဖြစ်သည်။

**ဤနေရာတွင် အကျုံးမဝင်ပါ-** ပုံဟောင်းများ၊ ချိန်ညှိမှုစမ်းသပ်မှုနှင့် Pump စမ်းသပ်မှု (ဆော့ဖ်ဝဲရေးသားသူ/အဆင့်မြင့်ကိရိယာများ) တင်သွင်းပါ။

## <a id="what-you-need"></a> ဘာလိုလဲ။

- Android ဖုန်း သို့မဟုတ် တက်ဘလက်။
- အကောင်းဆုံး OCR အတွက်- သင်၏ **ဒက်ရှ်ဘုတ် odometer** နှင့် **pump စုစုပေါင်း** (သို့မဟုတ် နံပါတ်များကို လက်ဖြင့်ရိုက်ပါ)။
- ရွေးချယ်နိုင်သည်- စာရင်းဇယားဒေတာနှင့်/သို့မဟုတ် ဓာတ်ပုံအရန်ကူးရန်အတွက် **သင်ထိန်းချုပ်ထားသော အကောင့်များ** ([အရန်သိမ်းဆည်းမှုများနှင့် စက်ပေါင်းများစွာ ထပ်တူပြုခြင်းကို ကြည့်ပါ](#backups-and-multi-device-sync))။

## <a id="open-the-menu"></a> မီနူးကိုဖွင့်ပါ။

1. ဘယ်ဘက်အပေါ်ရှိ **☰** ကိုနှိပ်ပါ။
2. စာမျက်နှာတစ်ခုကို ရွေးချယ်ပါ။

![လမ်းပြအံဆွဲ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/01-drawer.jpg)

**ပင်မအံဆွဲ-** ဖြည့်စွက် · ခရီးစဉ်စတင်ခြင်း · ယာဉ်များကို စီမံခန့်ခွဲ · ကုန်ကျစရိတ်အသစ် · ** အစီရင်ခံစာများ** · ဆက်တင်များ · စင့်ခ်လုပ်ခြင်း · အကူအညီ · အကြောင်း။

**စမ်းသပ်မှု အံဆွဲ** (ဆက်တင်များ → စမ်းသပ်မှု မျက်နှာပြင်များကို ပြပါ)- ချိန်ညှိမှု စမ်းသပ်မှု · Pump စမ်းသပ်ခြင်း · ** ပုံဟောင်းများကို တင်သွင်းခြင်း**။

**အစီရင်ခံချက်အချက်အချာမှတဆင့် (ပင်မအံဆွဲမဟုတ်ပါ):** ကုန်ကျစရိတ်စာရင်း · မှတ်တမ်းကို ဖြည့်ပါ။

## <a id="first-time-setup-manage-vehicles"></a> ပထမအကြိမ် စနစ်ထည့်သွင်းခြင်း- ယာဉ်များကို စီမံပါ

OCR နှင့် **အော်တိုမက်တစ်ယာဉ် ကိုက်ညီမှု** သည် **အကိုးအကား ဒက်ရှ်ဘုတ်ဓာတ်ပုံ** ဖြင့် ယာဉ်တစ်ခုစီကို စာရင်းသွင်းပြီးနောက်၊ **Discovery** ကို ပြေးပါ၊ လှော်တက်အစေ့မှ အကာအထွာကို သတ်မှတ်ပြီး ထိုဒက်ရှ်အတွက် မှတ်တိုင်များကို သိမ်းဆည်းပါ။

### <a id="open-manage-vehicles"></a>ယာဉ်များကို စီမံခန့်ခွဲရန် ဖွင့်ပါ။

မီနူး → **ယာဉ်များကို စီမံပါ**။ ယာဉ်ကိုရွေးချယ်ပါ (သို့မဟုတ် **ယာဉ်အသစ်ထပ်ထည့်ပါ**)။

![ရည်ညွှန်း dash၊ သီးနှံများနှင့် ရှာဖွေတွေ့ရှိမှုဖြင့် ယာဉ်များကို စီမံခန့်ခွဲပါ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a> ယာဉ်ကို ထည့်ပါ သို့မဟုတ် တည်းဖြတ်ပါ။

1. **ယာဉ်**ကိုဖွင့်ပါ → ယာဉ်ကိုရွေးချယ်ပါ သို့မဟုတ် **ယာဉ်အသစ်ထည့်ပါ**။
2. ကြည်လင်ပြတ်သားသော **ကိုးကားချက် ဒက်ရှ်ဓာတ်ပုံ** (ကိရိယာအစုအဝေး၊ အလင်းရောင်ကောင်းစွာ၊ ဖုန်းကို အကြမ်းဖျင်းအားဖြင့် စတုရန်းတွင်) ရိုက်ယူပါ သို့မဟုတ် ရွေးပါ။ **ဓာတ်ပုံရိုက်ပါ** သို့မဟုတ် **ပြခန်း**ကို အသုံးပြုပါ။
3. **Run Discovery** ကိုနှိပ်ပါ — လှော်တက်ရှာဖွေခြင်းသည် ဓာတ်ပုံပေါ်တွင် **အစေ့များ** အဝါရောင်ကို နေရာပေးသည် (အထင်ကရနေရာများသည် ယခင်ကဲ့သို့ `"ML Kit"` JSON ကို အသုံးပြုသည်)။
4. ** Odo ကို ရွေးပါ ** ကို နှိပ်ပါ၊ ဂဏန်းများပေါ်ရှိ မျိုးစေ့ကို နှိပ်ပါ၊ လက်ကိုင်များကို ချိန်ညှိပါ၊ ထို့နောက် ** သိမ်းဆည်းပါ ** ။
5. **Edit Odo** ရှိနှင့်ပြီးသား ဘောက်စ်ကို ချိန်ညှိပါ။ **Clear Odo** သည် ၎င်းကိုဖယ်ရှားပြီး ခလုတ်ကိုနှိပ်၍ **Odo** ကိုရွေးချယ်ပါ ။
6. ** အထင်ကရများကို ပြပါ** ဖြင့် ပြန်လည်သုံးသပ်ပါ။ လွဲချော်နေသော စာသားများကို ပြင်ဆင်ရန် **Edit OCR** ​​ကို အသုံးပြုပါ သို့မဟုတ် လွတ်သွားသော စာသားကို **ထည့်ပါ**။
7. **ယာဉ်အမည်** (လိုအပ်သော) ဖြည့်စွက်ကာ စိတ်ကြိုက်ပုံစံ/မော်ဒယ်/နှစ်/ပန်းကန်ပြားကို စိတ်ကြိုက်ပြုလုပ်ပါ။
8. **ယာဉ်ဖန်တီးပါ** သို့မဟုတ် **ပြောင်းလဲမှုများကို သိမ်းဆည်းရန်** ကိုနှိပ်ပါ (ယာဉ်အသစ်အတွက် အမည် + ရည်ညွှန်းဓာတ်ပုံ လိုအပ်သည်)။

![ယာဉ်ပုံစံအကွက်အသစ်များထည့်ပါ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/03b-manage-vehicles-new.jpg)

### <a id="landmarks-fix-what-discovery-missed"></a> အထင်ကရနေရာများ- Discovery လွတ်သွားသည့်အရာကို ပြင်ဆင်ပါ

**အထင်ကရများကို ပြပြီးနောက်**၊ စာရင်းကို ရွှေ့ကာ တန်ဖိုးများကို ပြုပြင်ပါ။ အင်ဂျင်များသည် တစ်ခါတစ်ရံတွင် ဂဏန်းငယ်များလွဲချော်သည် (ဥပမာ အစုအဝေး၏အောက်ခြေညာဘက်ရှိ **60** နာရီတစ်လုံး)။ ယာဉ်အထောက်အထား စိတ်ချရစေရန်အတွက် ၎င်းတို့ကို ထည့်ရန် သို့မဟုတ် ပြင်ဆင်ရန် **တည်းဖြတ် OCR** ​​ကို အသုံးပြုပါ။

![Landmarks dialog — ပြန်လည်သုံးသပ်ပြီး OCR](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a> ပြီးပြည့်စုံသော ဓာတ်ပုံမပါဘဲ စာရိုက်ခြင်း။

ယာဉ်တစ်စီးကို ရွေးချယ်ခြင်းနှင့် **စာရိုက်ခြင်း** odometer၊ ထုထည်နှင့် ဖြည့်စွက်မှုတွင် ကုန်ကျစရိတ် — OCR သည် နယ်ပယ်တိုင်းအတွက် ရွေးချယ်နိုင်သဖြင့် အက်ပ်ကို သင်အသုံးပြုနိုင်သေးသည်။ အက်ပ်အတွင်း မရိုက်ကူးလိုသည့်အခါ ပြခန်းတင်သွင်းမှုသည် ရည်ညွှန်း dash ဓာတ်ပုံအတွက် အလုပ်လုပ်သည်။

**အကြံပြုချက်-** စာရင်းဇယားစင့်ခ်လုပ်ပြီးနောက်၊ ယာဉ်အဓိပ္ပာယ်ဖွင့်ဆိုချက်များ (ကောက်ပဲသီးနှံများ၊ အထင်ကရနေရာများ) သည် ဒေသတွင်းဒေတာဘေ့စ်တွင် နေထိုင်သည် — ၎င်းတို့ကိုအသုံးပြုရန်အတွက် ဖြည့်စွက်ရန်အတွက် စီမံကွပ်ကဲယာဉ်များကို သင်ပြန်လည်ဖွင့်ရန် မလိုအပ်ပါ။

## <a id="backups-and-multi-device-sync"></a> အရန်သိမ်းဆည်းမှုများနှင့် စက်ပစ္စည်းပေါင်းများစွာ စင့်ခ်လုပ်ခြင်း

အက်ပ်ကို တည်ဆောက်ထားသောကြောင့် **ဖုန်းများ သို့မဟုတ် တက်ဘလက်အများအပြားသည် တူညီသောရေယာဉ်ဒေတာကို မျှဝေနိုင်သည်**၊ ထို့ကြောင့် သင်သည် **သင်၏ဒေတာနှင့် ဓာတ်ပုံများကို မိတ္တူကူးယူထားနိုင်သည်**။ **သင့်** အကောင့်များ သို့မဟုတ် **သင်၏** ကိုယ်တိုင်လက်ခံဆောင်ရွက်ပေးထားသော ဆာဗာများအောက်တွင် သတ်မှတ်ထားသော ** သင်** ခရီးစဉ်များနှင့် လုပ်ဆောင်သည် — အခြားလူများမြင်နိုင်သည့် ကုမ္ပဏီမှလည်ပတ်သော “ယာဉ်စရိတ်များ cloud” မဟုတ်ပါ။

### <a id="what-runs-where"></a> ဘယ်ပြေးလဲ။

| ကြင်နာ | စတိုးဆိုင်များ | ပုံမှန်အသုံးပြုမှု |
|------|----------------|----------------|
| **Spreadsheet/tabular sync** | ယာဉ်များ၊ ဆီဖြည့်ခြင်း၊ ကုန်ကျစရိတ်များ (အတန်းများနှင့် တက်ဘ်များ) | စက်ပစ္စည်းပေါင်းစုံ ပေါင်းစည်းခြင်း + ဖွဲ့စည်းတည်ဆောက်ထားသော အရန်သိမ်းဆည်းခြင်း |
| **ဓာတ်ပုံအရန်** | ဒွိပုံများ (dash/pump/receipt/reference photos) | ဓာတ်ပုံ အရန်သိမ်း + ပျောက်ဆုံးနေသော ဖိုင်များ ပြန်လည်ရယူပါ |

အမျိုးအစားတစ်ခုစီ၏ **ဦးတည်ရာများစွာ**ကို သင်စီစဉ်သတ်မှတ်နိုင်သည် (အမျိုးအစားတစ်ခုလျှင် အပျော့စားထုပ်)။ လူကိုယ်တိုင် **ယခုစင့်ခ်လုပ်ခြင်း** နှင့် **နောက်ခံ** အလုပ်သမားများက ဖွင့်ထားသည့်အရာများကို လုပ်ဆောင်သည်။

### <a id="offline-first"></a> အော့ဖ်လိုင်းကို အရင်လုပ်ပါ။

- ဖြည့်သွင်းခြင်း၊ ကုန်ကျစရိတ် သို့မဟုတ် ပြေစာထည့်ရန် **ကွန်ရက်မလိုအပ်ပါ။ အရာအားလုံးကို **ပြည်တွင်း၌ ဦးစွာသိမ်းဆည်းသည်**။
- ကွန်ရက်ကို ရရှိနိုင်သောအခါ၊ စင့်ခ်လုပ်ပြီး ဓာတ်ပုံအရန်ကူးယူခြင်းကို ** နောက်ခံလုပ်ဆောင်စရာများ ** (သင်သတ်မှတ်ထားသည့်အချိန်ဇယားအတိုင်း နှင့် **ယခုစင့်ခ်လုပ်ခြင်း** ကိုနှိပ်သည့်အခါ)။ ပျက်ကွက်မှုများသည် ဆက်တင်အတန်းများအောက်ရှိ အနီရောင်စာသားနှင့် အက်ပ်ခေါင်းစဉ်ဘားရှိ **!** တစ်ခုဖြစ်သည်။

### <a id="your-accounts-only"></a> သင့်အကောင့်များသာ

အကောင့်ဝင်ပြီး တိုကင်များသည် သင်ရွေးချယ်သော ဝန်ဆောင်မှုပေးသူများအတွက် စက်ပစ္စည်းပေါ်တွင် ရှိနေသည် (Google၊ Microsoft၊ S3 သော့များ၊ ကိုယ်တိုင်လက်ခံထားသော URL များနှင့် အခြားအရာများ)။ သွားမည့်နေရာများသည် **အသုံးပြုသူ၏ အပြည့်အဝထိန်းချုပ်မှု** အောက်တွင် — — သင်၏ Google အကောင့်၊ သင်၏ OneDrive၊ သင်၏ MinIO ပုံး၊ သင်၏ EtherCalc host စသည်တို့ဖြစ်သည်။ မည်သည့်အရာကိုမျှ မျှဝေထားသော နောက်ခံဖိုင်မှတစ်ဆင့် အခြားယာဉ်အသုံးစရိတ်များကို သုံးစွဲသူများနှင့် မျှဝေမည်မဟုတ်ပါ။

### <a id="supported-targets--data-spreadsheet--tabular"></a> ပံ့ပိုးထားသောပစ်မှတ်များ — ဒေတာ (စာရင်းဇယား/ဇယားကွက်)

**Menu → Syncing → Spreadsheet စင့်ခ်လုပ်ခြင်း** (ဆက်တင်များ အကျဉ်းချုပ်အတန်းများမှလည်း ဆက်သွယ်နိုင်သည်) ပထမတန်းစား ရွေးစရာ ရွေးစရာများ-

| ပစ်မှတ် | မှတ်စုများ |
|--------|--------|
| **Google Sheets** | ဘုံပုံသေ; ယာဉ်၊ ကုန်ကျစရိတ်များနှင့် ယာဉ်တစ်စီးချင်းဆီအတွက် တက်ဘ်များ |
| **Excel** | ဂရပ်ဖစ်/OneDrive စတိုင် ပေါင်းစပ်ထားသော |
| **EtherCalc** | ကိုယ်တိုင်လက်ခံကျင်းပသည့် ပူးပေါင်းဆောင်ရွက်သည့် စာရင်းဇယားအခန်းများ |
| **အခြား →** လုပ်ဆောင်ချက် နောက်ခံများ | **Baserow**၊ **NocoDB**၊ **Airtable**၊ **PocketBase**၊ **Supabase**၊ **Firebase**၊ **Zoho Sheet** |

ရွှေ့ဆိုင်းထားသည် / ခေါင်းမထောင်ရသေး (အခြားအောက်တွင်ဖော်ပြထားသော်လည်း အပြည့်အဝအကောင်အထည်မဖော်သေးပါ): OnlyOffice၊ Collabora။ [ကိုယ်ပိုင်အိမ်ရှင်အညွှန်းကိန်း](reference/self-host/INDEX.md)ကိုလည်း ကြည့်ပါ။

CSV **ပို့ကုန်/တင်သွင်းခြင်း** (တူညီသောတက်ဘ်အပြင်အဆင်၏ ZIP) ကို တိုက်ရိုက်စင့်ခ်လုပ်ခြင်းမရှိဘဲ သယ်ဆောင်ရလွယ်ကူသော အရန်အဖြစ် ဆက်တင်များမှ ရရှိနိုင်ပါသည်။

### <a id="supported-targets--photos-image-backup"></a> ပံ့ပိုးထားသောပစ်မှတ်များ — ဓာတ်ပုံများ (ပုံအရန်ပုံ)

** မီနူး → စင့်ခ်လုပ်ခြင်း → ဓာတ်ပုံ အရန်ကူးခြင်း** (ဆက်တင်များ အနှစ်ချုပ်အတန်းများမှလည်း) အောက်တွင် စီစဉ်ထားသည်-

| ပစ်မှတ် | မှတ်စုများ |
|--------|--------|
| **Google Drive** | သင်ရွေးချယ်သောဖိုင်တွဲ (URL ကိုရှာဖွေပါ သို့မဟုတ် ကူးထည့်ပါ) |
| **OneDrive** | Microsoft အကောင့် + လမ်းကြောင်းရှေ့ဆက် |
| **S3** | AWS၊ Wasabi၊ Cloudflare R2၊ MinIO နှင့် အခြား S3-သဟဇာတရှိသော အဆုံးမှတ်များ |
| **အခြား** | rclone-ကျောထောက်နောက်ခံပြုထားသော သိုလှောင်မှု (ဥပမာ WebDAV၊ SFTP၊ နှင့် အခြားရွေးချယ်ထားသော အဝေးထိန်းကိရိယာများ) |

ကိုယ်တိုင်ထည့်သွင်းထားသော ဓာတ်ပုံနှင့် ဇယားပစ်မှတ်များအတွက် ကောက်ချက်စာရွက်များကို စနစ်ထည့်သွင်းပါ- [self-host index](reference/self-host/INDEX.md)။

### <a id="multi-device-behavior-short"></a> စက်ပစ္စည်းပေါင်းစုံ အပြုအမူ (အတိုချုပ်)

- **အပ်ဒိတ်လုပ်ထားသော** အချိန်တံဆိပ်ပေါ်တွင် **နောက်ဆုံးရေးသားခြင်း-အနိုင်ရ** ဖြင့် အတန်းများကို **Sync ID** ဖြင့် ပေါင်းစည်းပါ။
- ဖျက်မှုများသည် ပျော့ပျောင်းသည်။ အခြားစက်တွင် တည်းဖြတ်မှုအသစ်သည် အတန်းတစ်ခုကို ပြန်လည်ရယူနိုင်သည်။
- စက်နှစ်ခုတွင် **တူညီသောဖြည့်စွက်ချက်**ကို နှစ်ကြိမ်ထည့်ခြင်းဖြင့် **အတန်းနှစ်ခု** ကိုဖန်တီးပေးသည် — သင်သတိပြုမိသောအခါတွင် အပိုကိုဖျက်ပါ။
- နောက်ထပ်အသေးစိတ်- [ထပ်တူပြုမှုမှတ်စုများ](#sync-behavior-notes) နှင့် [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md)။

### <a id="sync-behavior-notes"></a> ထပ်တူပြုမှုမှတ်စုများ

- အက်ပ်အဆင့်မြှင့်ပြီးနောက် **“အဆင့်မြှင့်ပြီးနောက် ဒေတာဘေ့စ်ကို အပ်ဒိတ်လုပ်ခြင်း…”** (ဒေသတွင်း ထပ်တူပြုခြင်း-အိုင်ဒီ နောက်ခံဖြည့်စွက်မှု) ကို အကျဉ်းချုံးမြင်ရပေမည်။
- စင့်ခ်လုပ်ခြင်း ပြတ်တောက်သွားပါက၊ နောက်ထပ် **အောင်မြင်ပါပြီ** စင့်ခ်သည် ပြန်လည်ပေါင်းစည်းပြီး အဝေးထိန်းတက်ဘ်များကို ပြုပြင်ပေးပါသည်။
- ပျက်ကွက်မှုများ- အက်ပ်ဘားရှိ ကတ်များ ချိန်ကိုက်ခြင်းဆိုင်ရာ အနီရောင်အကျဉ်းချုပ် + **!**။

## <a id="fill-up-fuel"></a> ဆီဖြည့် (ဆီ)

၎င်းသည် သင်အက်ပ်ကိုဖွင့်သည့်အခါ **ပင်မစခရင်** ဖြစ်သည်။

### <a id="vehicle-selection-usually-automatic"></a> ယာဉ်ရွေးချယ်မှု (များသောအားဖြင့် အလိုအလျောက်)

သင် **မဟုတ်ပါ** ယာဉ်ကို ဦးစွာရွေးချယ်ရန် မလိုအပ်ပါ။ ယာဉ်များအား စီမံကွပ်ကဲမှုတွင် **အထင်ကရနေရာများ** ထားရှိသောအခါ၊ သင် odometer ကိုဖမ်းယူပြီးနောက် ဒိုင်ခွက်ပုံမှ မည်သည့်ယာဉ်ကို ရှာဖွေသည်ကို ** ဖြည့်စွက်ပါ။ လိုအပ်ပါက ထပ်ရေးရန် **ယာဉ်** dropdown ကို သင်ဖွင့်နိုင်ပါသေးသည်။

### <a id="aim-at-the-odometer"></a> အဝေးထိန်းမီတာကို ချိန်ပါ။

odometer မုဒ်တွင်နေ၍ အစုအဝေးကိုဘောင်သွင်းပါ။ ညွှန်ကြားချက်- * odometer ကို ချိန်ပါ။ ရိုက်ကူးရန် ရှပ်တာ ကို တို့ပါ။*

![Fill — odometer ပေါ်ရှိ တိုက်ရိုက်ကင်မရာကို ဖြည့်ပါ (အစမ်းကြည့်ရန် နမူနာ dash ပုံ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a> အဝေးထိန်းမီတာ ရှပ်တာပြီးနောက်၊

OCR သည် **Odo** ကိုဖြည့်ပြီး အထင်ကရနေရာများမှ ယာဉ်ကို ကိုက်ညီစေရန် ကြိုးစားသည် (လိုအပ်ပါက နှစ်ခုလုံးကို ပြန်လည်သုံးသပ်ပါ)။ ပြန်လည်ရိုက်ကူးရန် ပင်မခလုတ်သည် **Retry** ဖြစ်လာသည်။ ညွှန်ကြားချက်သည် စာဖတ်ခြင်းကို အကျဉ်းချုပ်ဖော်ပြသည်။

![ဖြည့်စွက် — odometer OCR ရလဒ်](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a> Pump မုဒ် (ကုန်ကျစရိတ်နှင့် ပမာဏ)

1. ပန့်မုဒ်သို့ပြောင်းရန် **↕** ကိုနှိပ်ပါ- *ပန့်ပုံပြသမှု (ကုန်ကျစရိတ်/ပမာဏ) ကို ဦးတည်ပါ။ ရှပ်တာကို တို့ပါ။*
2. စုပ်စက်စုစုပေါင်းများကို ဖမ်းယူပါ။ ကုန်ကျစရိတ်နှင့် အသံအတိုးအကျယ် အကွက်များ ဖြည့်စွက်ပါ။ ၎င်းတို့ကို လဲလှယ်ပါက **↔** ကို အသုံးပြုပါ။
3. လိုအပ်ပါက ငွေကြေး သို့မဟုတ် **G/L** ကိုနှိပ်ပါ၊ ထို့နောက် **Save** (disk)။ ကွက်လပ်များ ** တစ်စိတ်တစ်ပိုင်း ဖြည့်စွက်ခြင်း** (ခွင့်ပြုဆဲ)။

![ဖြည့်စွက် — ပန့်အစမ်းကြည့်ရှုခြင်း/စုစုပေါင်းများ (ဥပမာ ပန့်ပုံအစမ်းကြည့်ရှုမှုတွင်)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

သင်သည် နောက်ထပ်မှတ်တိုင်အတွက် Fill တွင် ဆက်ရှိနေသည် (သိမ်းဆည်းပြီးနောက် အကွက်များကို ရှင်းလင်း)။ **အော့ဖ်လိုင်း** အပြည့်ဖြင့် အလုပ်လုပ်ပါ။ စီစဉ်သတ်မှတ်လိုက်သောအခါ နောက်ခံတွင် စင့်ခ်လုပ်သည် ။

### <a id="manual-entry-no-camera--bad-ocr"></a> လူကိုယ်တိုင်ဝင်ရောက်ခြင်း (ကင်မရာမရှိ/မကောင်း OCR)

1. **Odo**၊ **ကုန်ကျစရိတ်** သို့မဟုတ် **အသံအတိုးအကျယ်** ကိုနှိပ်ပြီး တန်ဖိုးများကို ရိုက်ပါ (ပုံတူစနစ်ကီးဘုတ်ကို အသုံးပြုသည်၊ အခင်းအကျင်းသည် မျက်နှာပြင်ပေါ်ရှိ ကီးဘုတ်ကို အသုံးပြုသည်)။
2. အလိုအလျောက် သိရှိခြင်းမရှိပါက **ယာဉ်**ကို ရွေးပါ သို့မဟုတ် အတည်ပြုပါ။
3. အထက်ပါအတိုင်း သိမ်းဆည်းပါ။

### <a id="modes-and-borders"></a> မုဒ်များနှင့် နယ်နိမိတ်များ

- ** အစိမ်းရောင် နယ်နိမိတ်** သည် ယာဉ်ပတ်ပတ်လည် + odo → ဖမ်း/တည်းဖြတ် odometer ။
- **အစိမ်းရောင်ဘောင်** ကုန်ကျစရိတ်+ပမာဏ → ပန့်မုဒ်ဝန်းကျင်။
- **Save** သည် ယာဉ်တစ်စီးကို ရွေးချယ်ပြီးသည်အထိ အနည်းဆုံး odo/cost/volume တစ်ခုတွင် ဒေတာရှိပြီး OCR သည် ဆက်လက်လည်ပတ်နေမည်မဟုတ်ပါ။

စခရင်ပေါ်ရှိ အကြံပြုချက် (ညွှန်ကြားချက်စာကြောင်းအောက်)- *Shutter = ဖမ်းယူခြင်း · Disk = သိမ်းဆည်းခြင်း · ↕ = odo/pump မုဒ် · ↔ = လဲလှယ်စရိတ်/ပမာဏ။*

## <a id="expenses"></a> အသုံးစရိတ်များ

### <a id="new-expense"></a> ကုန်ကျစရိတ်အသစ်

မီနူး → **ကုန်ကျစရိတ်အသစ်**။

![ကုန်ကျစရိတ်ပုံစံအသစ်နှင့် ကင်မရာထိန်းချုပ်မှုများ (အလွတ်ဖြစ်နေသောအခါတွင် ကင်မရာဝိုင်းရှိ နမူနာ dash ပုံ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r6-new-expense.jpg)

1. **သိမ်းဆည်းရန်** (ဒစ်ခ်)၊ **ရှပ်တာ** (ပြေစာဓာတ်ပုံ) သို့မဟုတ် **ပြခန်း** (ပုံကို ရွေးပါ)။
2. **ရက်စွဲ**၊ **ယာဉ်**၊ **ရောင်းချသူ**၊ **ဖော်ပြချက်**၊ **ပမာဏ** (သုံးနိုင်သော ငွေကြေးသင်္ကေတ)၊ **အမျိုးအစား**၊ ရွေးချယ်နိုင်သော **Odometer**။
3. စာမျက်နှာပေါင်းများစွာ လက်ခံဖြတ်ပိုင်းများ- UI သည် စာမျက်နှာတင်ခြင်းကို ကမ်းလှမ်းပါက (စာမျက်နှာ 0 သည် အဓိကပြေစာဖြစ်သည်)။
4. **သိမ်းဆည်းရန်** ကို သိမ်းဆည်းရန် (စက်တွင်း ပထမ၊ ဓာတ်ပုံအရန်ကူးခြင်းနှင့် စာရင်းဇယားစင့်ခ်လုပ်ခြင်းကို နောက်ခံတွင် စီစဉ်သတ်မှတ်သည့်အခါ)။

### <a id="expense-list"></a> အသုံးစရိတ်စာရင်း

မီနူး → ** အစီရင်ခံစာများ ** → ** အသုံးစရိတ်များစာရင်း** — လောင်စာဆီမဟုတ်သော ကုန်ကျစရိတ်များကို ကြည့်ရှုပါ။ တည်းဖြတ်ရန် အကြောင်းအရာတစ်ခုကို ဖွင့်ပါ။

![ကုန်ကျစရိတ်စာရင်း](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/05-expense-list.jpg)

### <a id="edit-expense"></a> ကုန်ကျစရိတ်ကို တည်းဖြတ်ပါ။

စာရင်းမှ အတန်းတစ်ခုကို ဖွင့်ပါ။ မှန်ကန်သော ရောင်းချသူ၊ ပမာဏ၊ အမျိုးအစား၊ ယာဉ်နှင့် ဖော်ပြချက်။ အကယ်၍ ပြေစာသည် ဓာတ်ပုံအရန်ဖိုင်တွင်သာ ရှိနေပါက (ဖတ်ရှုနိုင်သော ဒေသန္တရ ဖိုင်မရှိပါ)၊ ပြထားသည့်အခါ **ဓာတ်ပုံကို မှတ်တမ်းဟောင်းမှ ရယူခြင်း** ကို အသုံးပြုပါ (ပြင်ဆင်ထားသော ဓာတ်ပုံနေရာများတွင် အလုပ်လုပ်သည်)။

![ကုန်ကျစရိတ်ပြင်ဆင်ရန်](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/expense-edit.jpg)

## <a id="start-trip"></a> ခရီးစဉ် စတင်လိုက်ပါ။

မီနူး → **ခရီးစဉ်စတင်ရန်** (အံဆွဲကိုဖြည့်ပြီးနောက်)။ odometer ကိုရိုက်ပါ သို့မဟုတ် ရိုက်ထည့်ပါ၊ ခရီးအမျိုးအစားကိုရွေးချယ်ပါ၊ **disk** အိုင်ကွန်ဖြင့် သိမ်းဆည်းပါ။ **Stop** သည် ယခုကျင်းပနေသော GPS တည်နေရာရှိ Personal အတွက် ဖြတ်လမ်းတစ်ခုဖြစ်သည်။ ထိန်းချုပ်သတိပေးချက်များအတွက် **ⓘ** ကိုသုံးပါ။

![ခရီးစတင်](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/start-trip.jpg)

ခရီးစဉ်စတင်ခြင်းကို **Trip Type** (သာမန်ဖြည့်သွင်းခြင်းမဟုတ်) ဖြင့် လောင်စာဆီတန်းများအဖြစ် သိမ်းဆည်းထားသည်။ ၎င်းတို့သည် လောင်စာဆီမှတ်တမ်းအောက်တွင်မဟုတ်ဘဲ **အစီရင်ခံစာများ → ခရီးမိုင်** အောက်တွင် ပေါ်လာသည်။

## <a id="reports"></a> အစီရင်ခံစာများ

မီနူး → **အစီရင်ခံစာများ** သည် ထုတ်ကုန်ဗဟိုချက် (အချိန်တိုင်း အကျဉ်းချုပ် + ကတ်တလောက်ကတ်များ) ကို ဖွင့်သည်။ ဤသည်မှာ တစ်ခုတည်းသော ထုတ်ကုန်အစီရင်ခံစာများဖြစ်သည် — သီးခြား "အစီရင်ခံစာများနှင့်ဇယားများ" အံဆွဲပါအကြောင်းအရာမရှိပါ။

![အစီရင်ခံချက်စင်တာ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/06-reports.jpg)

ယာဉ်မုဒ်အတွက် ကတ်တစ်ခုဖွင့်ပါ (**အားလုံး / တစ်ခုစီ / Single**)၊ ကာလအပိုင်းအခြားအလိုက် စစ်ထုတ်မှုများ၊ ဇယားများနှင့် မျှဝေပါ (**TEXT / CSV / PDF**)။ အစီရင်ခံစာကလေးများအတွက် ထိပ်တန်းဘား- **☰ + ←** (နှင့် **ⓘ** စာရင်းသွင်းသည့်အခါ)။

### <a id="time-based-reports"></a> အချိန်အခြေခံ အစီရင်ခံစာများ

ပင်မဇယားကတ်။ ရွေးချယ်နိုင်သော မက်ထရစ်များ (MPg၊ G/mi ကဲ့သို့သော အကွာအဝေး၊ $/G ကဲ့သို့သော ယူနစ်စျေးနှုန်း၊ ကုန်ကျစရိတ်/အကွာအဝေး၊ လစဉ် $၊ ခရီးမိုင်၊ ခရီးစဉ် % အမျိုးအစားအလိုက်) **Smooth** bins နှင့် **independent Y scales** (စီးပွားရေးဘယ်ဘက်၊ ငွေနှင့် ညာဘက်ရှိ မိသားစုခရီးစဉ်) တို့ပါရှိသော ရွေးချယ်နိုင်သော မက်ထရစ်များ။

![အချိန်အခြေခံ အစီရင်ခံစာများ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports.jpg)

![အချိန်အခြေခံအစီရင်ခံစာများ — လှိမ့်မက်ထရစ်များ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports-scrolled.jpg)

စီးပွားရေးသင်္ချာအသေးစိတ်- [REPORTS_METRICS.md](reference/REPORTS_METRICS.md)။

### <a id="fill-history-vs-fuel-history"></a> Fill history vs Fuel History

- ** အစီရင်ခံစာများ → မှတ်တမ်း ဖြည့်ခြင်း** — အစီရင်ခံစာ စစ်ထုတ်မှုများ အတွက် အချိန်နှင့် တပြေးညီ ဖြည့်စွက်မှုများ (** ဖြည့်ရန်သာ**၊ ခရီးစဉ် မစတင်ပါ)။

![မှတ်တမ်းဖြည့်တင်း](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fill-history.jpg)

- **လောင်စာဆီမှတ်တမ်း** (သင့်တည်ဆောက်မှု၏လမ်းညွှန်မှုတွင်ပါရှိလျှင်) — မော်တော်ယာဥ်တစ်ခုချင်းစီ ဖြည့်သွင်းထားသောစာရင်းကို ဖြည့်ရုံသာဖြစ်သည်။ တည်းဖြတ်ရန် အတန်းတစ်ခုကို နှိပ်ပါ။

### <a id="trip-miles"></a> ခရီးမိုင်

**အစီရင်ခံချက်များ → ခရီးမိုင်** — အမျိုးအစားအလိုက် မိုင်များ၊ ဇယားများနှင့် အချိန်နှင့်တစ်ပြေးညီ **ခရီးစဉ်အစ/အပိုင်းစာရင်း**။ ထိုအတန်းအတွက် **ဖြည့်စွက်တည်းဖြတ်ရန်** ကိုဖွင့်ရန် တကယ့်စတင်မှုကို နှိပ်ပါ။

![ခရီးမိုင်](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a> ဖြည့်စွက်ပြင်ဆင်ပါ။

ဖြည့်စွက်မှတ်တမ်း၊ လောင်စာဆီမှတ်တမ်း သို့မဟုတ် ခရီးမိုင်များမှ ဖြည့်စွက်ချက်ကို ဖွင့်ပါ။ အပြင်အဆင်- ယာဉ်နှင့် အဝေးထိန်းမီတာ၊ ကုန်ကျစရိတ်မတိုင်မီ **ငွေကြေး**၊ ထုထည်၊ မှတ်စုများ။ အတန်းသည် ခရီးစဉ်စတင်ချိန်တွင်သာ ခရီးစဉ်အမျိုးအစား ပေါ်လာသည်။ တည်နေရာအကျဉ်းချုပ်နှင့် **တည်နေရာအသေးစိတ်** ပါရှိသည်။ cloud အထောက်အထားပါရှိသော ဒေသန္တရဓာတ်ပုံ ပျောက်ဆုံးနေသည်- **မှတ်တမ်းမှ ဓာတ်ပုံကို ရယူပါ**။

![ဖြည့်စွက်တည်းဖြတ်ပါ — စက်တွင်းဓာတ်ပုံပျောက်ဆုံးသည့်အခါ မှတ်တမ်းမှရယူပါ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

အခြားကတ်တလောက်ကတ်များတွင် အမျိုးအစားအလိုက် ကုန်ကျစရိတ်များ၊ ယာဉ်အကျဉ်းချုပ်နှင့် ကုန်ကျစရိတ်စာရင်းတို့ ပါဝင်သည်။

ငွေသည် သတ်မှတ်သည့်အခါ အတန်းတစ်ခုစီ၏ ငွေကြေးကို အသုံးပြုသည်။ ရောနှောသောငွေကြေးစုစုပေါင်းသည် **ငွေကြေးတစ်ခုခြင်းစီခွဲများ** ကိုပြသသည် (အသံတိတ် FX ပြောင်းလဲခြင်းမရှိပါ)။

## <a id="syncing"></a> စင့်ခ်လုပ်ခြင်း။

မီနူး → **စင့်ခ်လုပ်ခြင်း** သည် စာရင်းဇယားနှင့် ဓာတ်ပုံနေရာများအတွက် အချက်အချာကျသည် (ဆက်တင်များအောက်တွင် မြှုပ်ထားရုံသာမက)။

![Syncing hub](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- **Spreadsheet စင့်ခ်လုပ်ခြင်း** နှင့် **ဓာတ်ပုံအရန်ကူးခြင်း** အတွက် ကတ်များသည် အတိုချုံးအခြေနေဖြင့်၊ ထိုအမျိုးအစားအတွက် **Sync** နှင့် **›**** သည် ဦးတည်ရာစာရင်းထဲသို့ ဝင်ပါ။
- **စမ်းသပ်ချိတ်ဆက်မှု** အတွက် ဦးတည်ရာတစ်ခုကို ဖွင့်ပြီး **ယခု (ဤဦးတည်ရာ)** / အားလုံး စီစဉ်သတ်မှတ်ထားသည်။
- ပျက်ကွက် **အသေးစိတ်** နှင့် အနီရောင် **!** ခေါင်းစဉ်ဘားတွင် ဤနေရာတွင်။
- အဆင့်ဆင့်သော Google Sheets နှင့် Drive စနစ်ထည့်သွင်းခြင်း- [အရန်သိမ်းဆည်းမှုများနှင့် စက်ပေါင်းများစွာ ထပ်တူပြုခြင်း](#backups-and-multi-device-sync)။

### <a id="local-preferences-common"></a> ဒေသဆိုင်ရာ ဦးစားပေးများ (ဘုံ)

- **လောင်စာဆီပြေစာဓာတ်ပုံများကို သိမ်းဆည်းပါ** / **ဒေသအလိုက် ကုန်ကျစရိတ် ဓာတ်ပုံများကို သိမ်းဆည်းပါ** — ရုပ်ပုံများကို စက်ပေါ်တွင် ထားရှိပါ (ဓာတ်ပုံများကို ခွင့်ပြုချက်တောင်းနိုင်သည်)။
- **Shutter အသံဖွင့်ရန်**
- **Currency** / **Volume Unit** — အက်ပ်၏ ပုံသေများ (စနစ် သို့မဟုတ် ပြတ်သားစွာ)။ လက်ရှိလောင်စာဆီဒေတာဖြင့် ထုထည်ယူနစ်ကို ပြောင်းလဲခြင်းသည် convert dialog ကို ပေးနိုင်ပါသည်။
- **အမှောင်မုဒ်**
- **တပ်ဆင်ခြင်းဆိုင်ရာ အကြံပြုချက်များ** — ပထမဆုံးပြေးဆွဲသည့် ယာဉ်/ထပ်တူကျသော သင်ခန်းစာများကို ပြန်လည်ဖွင့်ပါ။
- **Debug ဖြည့်စွက်ခြင်း** / **စမ်းသပ်မှု မျက်နှာပြင်များကို ပြပါ (dev)** — အဆင့်မြင့်၊ နေ့စဉ်အသုံးပြုမှုအတွက်ချန်ထားပါ။ စမ်းသပ်မှုစခရင်များကို ဤနေရာတွင် မှတ်တမ်းတင်မထားပါ။

CSV **တင်ပို့/တင်သွင်းခြင်း** (ယာဉ်/ကုန်ကျစရိတ်/လောင်စာဆီတက်ဘ်များ) ကို လက်ရှိတည်ဆောက်မှုမှ ကမ်းလှမ်းသည့်အခါ ဆက်တင်များမှ ရနိုင်ပါသည်။
