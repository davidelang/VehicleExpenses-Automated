## <a id="first-time-setup-manage-vehicles"></a> ການຕັ້ງຄ່າຄັ້ງທຳອິດ: ຈັດການພາຫະນະ

OCR ແລະ **ການຈັບຄູ່ລົດອັດຕະໂນມັດ** ເຮັດວຽກໄດ້ດີທີ່ສຸດຫຼັງຈາກທີ່ທ່ານລົງທະບຽນລົດແຕ່ລະຄັນດ້ວຍ **ຮູບ dashboard ອ້າງອີງ**, ແລ່ນ **Discovery**, ຕັ້ງເຄື່ອງວັດແທກໄລຍະໄກຈາກເມັດ paddle, ແລະບັນທຶກຈຸດສໍາຄັນສໍາລັບ dash ນັ້ນ.

### <a id="open-manage-vehicles"></a> ເປີດຄຸ້ມຄອງພາຫະນະ

ເມນູ → **ຈັດການພາຫະນະ**. ເລືອກພາຫະນະ (ຫຼື **ເພີ່ມລົດໃໝ່**).

### <a id="add-or-edit-a-vehicle"></a> ເພີ່ມ ຫຼື ແກ້ໄຂລົດ

1. ເປີດລາຍການເລື່ອນລົງ **ພາຫະນະ** → ເລືອກພາຫະນະ ຫຼື **ເພີ່ມລົດໃໝ່**.
2. ຖ່າຍຮູບ ຫຼືເລືອກຮູບທີ່ຊັດເຈນ **ຮູບ dash ອ້າງອີງ** (ກຸ່ມເຄື່ອງມືເຕັມ, ມີແສງດີ, ໂທລະສັບປະມານສີ່ຫຼ່ຽມເປີດ). ໃຊ້ **ຖ່າຍຮູບ** ຫຼື **ຄັງຮູບ**.
3. ແຕະ **Run Discovery** — ການກວດຫາ paddle ວາງ **ແກ່ນ** ສີເຫຼືອງໃສ່ໃນຮູບ (ຈຸດສຳຄັນໃຊ້ `"ML Kit"` JSON ຄືກັນ).
4. ແຕະ **ເລືອກ Odo**, ແຕະເມັດພືດໃສ່ຕົວເລກ, ປັບຕົວຈັບ, ຈາກນັ້ນ **ບັນທຶກ**.
5. **Edit Odo** ປັບກ່ອງທີ່ມີແລ້ວ. **Clear Odo ** ເອົາ​ມັນ​ອອກ​, ແລະ​ປຸ່ມ​ຫຼັງ​ຈາກ​ນັ້ນ​ອ່ານ **ເລືອກ Odo**​.
6. ທົບທວນກັບ **ສະແດງຈຸດສຳຄັນ**. ໃຊ້ **ແກ້ໄຂ OCR** ​​ເພື່ອແກ້ໄຂການອ່ານຜິດ ຫຼື **ເພີ່ມ** ຂໍ້ຄວາມທີ່ພາດໄປ.
7. ຕື່ມ **ຊື່ລົດ** (ຕ້ອງການ), ບວກກັບ make/model/year/plate ຕາມທີ່ທ່ານຕ້ອງການ.
8. ແຕະ **ສ້າງພາຫະນະ** ຫຼື **ບັນທຶກການປ່ຽນແປງ** (ຕ້ອງການຊື່ + ຮູບອ້າງອີງສຳລັບພາຫະນະໃໝ່).

![ເພີ່ມຊ່ອງໃສ່ແບບຟອມລົດໃໝ່](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/03b-manage-vehicles-new.jpg)

### <a id="landmarks-fix-what-discovery-missed"></a> ສະຖານທີ່ສຳຄັນ: ແກ້ໄຂສິ່ງທີ່ Discovery ພາດ

ຫຼັງຈາກ **ສະແດງຈຸດສຳຄັນ**, ເລື່ອນລາຍການ ແລະຄ່າທີ່ຖືກຕ້ອງ. ບາງຄັ້ງເຄື່ອງຈັກພາດຕົວເລກນ້ອຍໆ (ຕົວຢ່າງໂມງ **60** ຢູ່ເບື້ອງຂວາລຸ່ມຂອງກຸ່ມ). ໃຊ້ **ແກ້ໄຂ OCR** ​​ເພື່ອເພີ່ມ ຫຼືແກ້ໄຂພວກມັນ ເພື່ອໃຫ້ການລະບຸຕົວຕົນຂອງພາຫະນະມີຄວາມໜ້າເຊື່ອຖື.

![ກ່ອງຂໍ້ຄວາມ — ກວດເບິ່ງ ແລະແກ້ໄຂ OCR](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a> ພິມໂດຍບໍ່ມີຮູບທີ່ສົມບູນແບບ

ທ່ານ​ຍັງ​ສາ​ມາດ​ນໍາ​ໃຊ້ app ໄດ້​ໂດຍ​ການ​ເລືອກ​ຍານ​ພາ​ຫະ​ນະ​ແລະ **ການ​ພິມ ** odometer​, ປະ​ລິ​ມານ​, ແລະ​ຄ່າ​ໃຊ້​ຈ່າຍ​ໃນ​ການ​ຕື່ມ — OCR ເປັນ​ທາງ​ເລືອກ​ສໍາ​ລັບ​ທຸກ​ພາກ​ສະ​ຫນາມ​. ການນຳເຂົ້າແກເລີຣີໃຊ້ໄດ້ກັບຮູບ dash ອ້າງອີງເມື່ອທ່ານບໍ່ຕ້ອງການຖ່າຍໃນແອັບ.

**ເຄັດລັບ:** ຫຼັງຈາກການຊິງຄ໌ສະເປຣດຊີດ, ຄໍານິຍາມຂອງຍານພາຫະນະ (ການປູກພືດ, ສະຖານທີ່ສຳຄັນ) ຢູ່ໃນຖານຂໍ້ມູນທ້ອງຖິ່ນ — ທ່ານບໍ່ຈໍາເປັນຕ້ອງເປີດ Manage Vehicles ຄືນໃໝ່ເພື່ອໃຊ້ພວກມັນ.

## <a id="backups-and-multi-device-sync"></a> Backup ແລະ sync ຫຼາຍອຸປະກອນ

ແອັບ​ນີ້​ຖືກ​ສ້າງ​ຂຶ້ນ​ເພື່ອ​ໃຫ້ ** ໂທລະ​ສັບ​ຫຼື​ແທັບ​ເລັດ​ຈໍາ​ນວນ​ຫນຶ່ງ​ສາ​ມາດ​ແບ່ງ​ປັນ​ຂໍ້​ມູນ​ເຮືອ​ບິນ​ດຽວ​ກັນ **​, ແລະ​ດັ່ງ​ນັ້ນ​ທ່ານ​ສາ​ມາດ​ເກັບ ** ສໍາ​ເນົາ​ຂອງ​ຂໍ້​ມູນ​ແລະ​ຮູບ​ພາບ​ຂອງ​ທ່ານ​ອອກ​ຈາກ​ອຸ​ປະ​ກອນ **​. ອັນນັ້ນແມ່ນເຮັດກັບຈຸດໝາຍປາຍທາງ **ເຈົ້າ** ກຳນົດຄ່າພາຍໃຕ້ **ບັນຊີ** ຂອງທ່ານ ຫຼື **ເຊີບເວີ** ຂອງເຈົ້າເອງທີ່ໂຮສເອງ — ບໍ່ແມ່ນບໍລິສັດທີ່ດໍາເນີນການ “ຄລາວຄ່າໃຊ້ຈ່າຍພາຫະນະ” ທີ່ຄົນອື່ນສາມາດເຫັນໄດ້.

### <a id="what-runs-where"></a> ແລ່ນຢູ່ໃສ

| ປະເພດ | ມັນເກັບຮັກສາຫຍັງ | ການນໍາໃຊ້ທົ່ວໄປ |
|-----|----------------|----------------|
| **Spreadsheet / tabular sync** | ພາຫະນະ, ເຕີມນ້ຳມັນ, ຄ່າໃຊ້ຈ່າຍ (ແຖວ ແລະ ແຖບ) | ການລວມອຸປະກອນຫຼາຍ + ໂຄງສ້າງສໍາຮອງຂໍ້ມູນ |
| ** ການ​ສໍາ​ຮອງ​ຮູບ​ພາບ ** | ຮູບພາບຄູ່ (dash/pump/receipt/reference photos) | ການ​ສໍາ​ຮອງ​ຮູບ​ພາບ + ຟື້ນ​ຟູ​ໄຟລ​໌​ທີ່​ຂາດ​ຫາຍ |

​ທ່ານ​ສາ​ມາດ​ກໍາ​ນົດ​ຄ່າ **ຈຸດ​ຫມາຍ​ປາຍ​ທາງ​ຫຼາຍ ** ຂອງ​ແຕ່​ລະ​ປະ​ເພດ (ຝາ​ອ່ອນ​ຕໍ່​ປະ​ເພດ​)​. ຄູ່​ມື **ການ​ຊິງ​ຄ໌​ດຽວ​ນີ້** ແລະ **ພື້ນ​ຖານ** ຄົນ​ງານ​ແລ່ນ​ອັນ​ທີ່​ເປີດ​ໃຊ້​ງານ.

### <a id="offline-first"></a> ອອບໄລນ໌ກ່ອນ

- **ບໍ່​ຕ້ອງ​ການ​ເຄືອ​ຂ່າຍ** ເພື່ອ​ຕື່ມ​ການ​ຕື່ມ​ຂໍ້​ມູນ​, ຄ່າ​ໃຊ້​ຈ່າຍ​, ຫຼື​ໃບ​ຮັບ​ເງິນ​. ທຸກ​ສິ່ງ​ທຸກ​ຢ່າງ​ໄດ້​ຮັບ​ການ​ບັນ​ທຶກ​ໄວ້ **ໃນ​ທ້ອງ​ຖິ່ນ​ທໍາ​ອິດ **​.
- ເມື່ອ​ເຄືອ​ຂ່າຍ​ມີ​ໃຫ້​, ຊິງ​ຄ໌​ແລະ​ການ​ສໍາ​ຮອງ​ຮູບ​ພາບ​ດໍາ​ເນີນ​ການ​ເປັນ **ຫນ້າ​ທີ່​ໃນ​ເບື້ອງ​ຫຼັງ** (ຕາມ​ກໍາ​ນົດ​ເວ​ລາ​ທີ່​ທ່ານ​ກໍາ​ນົດ​ໄວ້​, ແລະ​ໃນ​ເວ​ລາ​ທີ່​ທ່ານ​ແຕະ **Sync ໃນ​ປັດ​ຈຸ​ບັນ **​)​. ຄວາມລົ້ມເຫຼວສະແດງເປັນຂໍ້ຄວາມສີແດງພາຍໃຕ້ແຖວການຕັ້ງຄ່າແລະ **!** ໃນແຖບຫົວຂໍ້ app.

### <a id="your-accounts-only"></a> ບັນຊີຂອງເຈົ້າເທົ່ານັ້ນ

ເຂົ້າສູ່ລະບົບ ແລະໂທເຄັນຢູ່ໃນອຸປະກອນສຳລັບຜູ້ໃຫ້ບໍລິການທີ່ທ່ານເລືອກ (ປຸ່ມ Google, Microsoft, S3, URL ທີ່ໂຮສເອງ, ແລະອື່ນໆ). ປາຍທາງແມ່ນຢູ່ພາຍໃຕ້ **ການຄວບຄຸມຂອງຜູ້ໃຊ້ຢ່າງເຕັມທີ່** — ບັນຊີ Google ຂອງທ່ານ, OneDrive ຂອງທ່ານ, ຖັງ MinIO ຂອງທ່ານ, ໂຮດ EtherCalc ຂອງທ່ານ, ແລະອື່ນໆ. ບໍ່ມີຫຍັງຖືກແບ່ງປັນກັບຜູ້ໃຊ້ຄ່າໃຊ້ຈ່າຍໃນຍານພາຫະນະອື່ນໆຜ່ານ backend ທີ່ໃຊ້ຮ່ວມກັນ.

### <a id="supported-targets--data-spreadsheet--tabular"></a> ເປົ້າໝາຍທີ່ຮອງຮັບ — ຂໍ້ມູນ (ຕາຕະລາງ/ຕາຕະລາງ)

ກຳນົດຄ່າພາຍໃຕ້ **ເມນູ → ການຊິງຄ໌ → ການຊິງຄ໌ສະເປຣດຊີດ** (ຍັງສາມາດເຂົ້າຫາໄດ້ຈາກແຖວສະຫຼຸບການຕັ້ງຄ່າ). ຕົວເລືອກຕົວເລືອກຊັ້ນໜຶ່ງ:

| ເປົ້າໝາຍ | ໝາຍເຫດ |
|--------|--------|
| **Google Sheets** | ຄ່າເລີ່ມຕົ້ນທົ່ວໄປ; ແຖບສໍາລັບຍານພາຫະນະ, ຄ່າໃຊ້ຈ່າຍ, ແລະນໍ້າມັນຕໍ່ຍານພາຫະນະ |
| **Excel** | Microsoft workbook ຜ່ານ Graph / OneDrive-style binding |
| **EtherCalc** | ຫ້ອງຕາຕະລາງການຮ່ວມມືທີ່ເປັນເຈົ້າພາບຂອງຕົນເອງ |
| **Other →** ປະຕິບັດ backends | **Baserow**, **NocoDB**, **Airtable**, **PocketBase**, **Supabase**, **Firebase**, **Zoho Sheet** |

ເລື່ອນເວລາ / ຍັງບໍ່ຫົວເທື່ອ (ລະບຸໄວ້ພາຍໃຕ້ການອື່ນໆ ແຕ່ບໍ່ໄດ້ປະຕິບັດຢ່າງເຕັມສ່ວນ): OnlyOffice, Collabora. ເບິ່ງ [ດັດຊະນີເຈົ້າພາບຕົນເອງ](reference/self-host/INDEX.md).

CSV **ການສົ່ງອອກ/ນໍາເຂົ້າ** (ZIP ຂອງຮູບແບບແຖບດຽວກັນ) ສາມາດໃຊ້ໄດ້ຈາກການຕັ້ງຄ່າເປັນການສໍາຮອງແບບເຄື່ອນທີ່, ບໍ່ຂຶ້ນກັບການຊິງຄ໌ສົດ.

### <a id="supported-targets--photos-image-backup"></a> ເປົ້າໝາຍທີ່ຮອງຮັບ — ຮູບພາບ (ສຳຮອງຮູບພາບ)

​ໄດ້​ຮັບ​ການ​ຕັ້ງ​ຄ່າ​ພາຍ​ໃຕ້ **ເມ​ນູ → ການ​ຊິງ​ຄ໌ → ການ​ສໍາ​ຮອງ​ຮູບ​ພາບ ** (ຍັງ​ຈາກ​ແຖວ​ສະ​ຫຼຸບ​ການ​ຕັ້ງ​ຄ່າ):

| ເປົ້າໝາຍ | ໝາຍເຫດ |
|--------|--------|
| **Google Drive** | ໂຟນເດີທີ່ທ່ານເລືອກ (ເບິ່ງ ຫຼືວາງ URL) |
| **OneDrive** | ບັນຊີ Microsoft + ຄຳນຳໜ້າເສັ້ນທາງ |
| **S3** | AWS, Wasabi, Cloudflare R2, MinIO, ແລະຈຸດສິ້ນສຸດອື່ນໆທີ່ເຂົ້າກັນໄດ້ກັບ S3 |
| **ອື່ນໆ** | ພື້ນທີ່ເກັບຂໍ້ມູນ rclone-backed (ເຊັ່ນ: WebDAV, SFTP, ແລະຣີໂໝດທີ່ຄັດສັນມາອື່ນໆທີ່ມີຢູ່ໃນຕົວເລືອກໃນແອັບ) |

ຕັ້ງຄ່າ cheatsheets ສໍາລັບຮູບພາບທີ່ເປັນເຈົ້າພາບ ແລະເປົ້າໝາຍຕາຕະລາງ: [self-host index](reference/self-host/INDEX.md).

### <a id="multi-device-behavior-short"></a> ພຶດຕິກໍາອຸປະກອນຫຼາຍອັນ (ສັ້ນ)

- ແຖວເຂົ້າກັນໂດຍ **Sync ID** ກັບ **write-write-wins** ໃນ **ອັບເດດ** timestamps.
- ລົບແມ່ນອ່ອນ; ການແກ້ໄຂທີ່ໃໝ່ກວ່າຢູ່ໃນອຸປະກອນອື່ນສາມາດຟື້ນຟູແຖວໄດ້.
- ການໃສ່ **ການຕື່ມຂໍ້ມູນດຽວກັນສອງຄັ້ງ** ຢູ່ໃນສອງອຸປະກອນຈະສ້າງ **ສອງແຖວ** — ລຶບສ່ວນເພີ່ມເຕີມເມື່ອທ່ານສັງເກດເຫັນ.
- ລາຍລະອຽດເພີ່ມເຕີມ: [ບັນທຶກພຶດຕິກໍາ](#sync-behavior-notes) ແລະ [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md).

### <a id="sync-behavior-notes"></a> Sync ບັນທຶກພຶດຕິກໍາ

- ຫຼັງ​ຈາກ​ການ​ຍົກ​ລະ​ດັບ app ທ່ານ​ສາ​ມາດ​ເບິ່ງ​ໂດຍ​ຫຍໍ້ **“ການ​ປັບ​ປຸງ​ຖານ​ຂໍ້​ມູນ​ຫຼັງ​ຈາກ​ການ​ຍົກ​ລະ​ດັບ…”** (local sync-id backfill​)​.
- ຖ້າການຊິງຄ໌ຖືກຂັດຈັງຫວະ, ການຊິງຄ໌ **ສຳເລັດ** ຕໍ່ໄປຈະຮວມ ແລະສ້ອມແປງແຖບທາງໄກ.
- ຄວາມລົ້ມເຫຼວ: ສະຫຼຸບສີແດງກ່ຽວກັບການຊິງຄ໌ບັດ + **!** ໃນແຖບ app.

## <a id="fill-up-fuel"></a> ເຕີມ (ນໍ້າມັນ)

ນີ້​ແມ່ນ **ໜ້າ​ຈໍ​ຫຼັກ** ເມື່ອ​ທ່ານ​ເປີດ​ແອັບ.

### <a id="vehicle-selection-usually-automatic"></a> ການຄັດເລືອກຍານພາຫະນະ (ປົກກະຕິອັດຕະໂນມັດ)

ເຈົ້າບໍ່ ** ບໍ່ ** ຕ້ອງເລືອກລົດກ່ອນ. ເມື່ອຍານພາຫະນະມີຈຸດຫມາຍ ** ຕັ້ງຢູ່ໃນການຄຸ້ມຄອງຍານພາຫະນະ, ຕື່ມ ** ອັດຕະໂນມັດກວດຫາຍານພາຫະນະ ** ຈາກຮູບ dash ຫຼັງຈາກທີ່ທ່ານຈັບ odometer ໄດ້. ເຈົ້າຍັງສາມາດເປີດລາຍການເລື່ອນລົງ **ພາຫະນະ** ເພື່ອ override ຖ້າຈຳເປັນ.

### <a id="aim-at-the-odometer"></a> ແນມໃສ່ເຄື່ອງວັດແທກລະດັບໄກ

ຢູ່ໃນໂໝດເຄື່ອງວັດແທກໄລຍະໄກ ແລະຈັດວາງກຸ່ມ. ຄໍາ​ແນະ​ນໍາ​: * ມຸ່ງ​ໄປ​ທີ່ odometer​. ແຕະຊັດເຕີເພື່ອຖ່າຍຮູບ.*

![ຕື່ມ — ກ້ອງສົດໃນເຄື່ອງວັດແທກລະດັບສຽງ (ຕົວຢ່າງຮູບ dash ໃນຕົວຢ່າງ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a> ຫຼັງປິດເຄື່ອງວັດໄກ

OCR ຕື່ມຂໍ້ມູນໃສ່ **Odo** ແລະພະຍາຍາມຈັບຄູ່ລົດຈາກຈຸດສຳຄັນຕ່າງໆ (ກວດເບິ່ງທັງສອງຖ້າຕ້ອງການ). ປຸ່ມຫຼັກຈະກາຍເປັນ **ລອງໃໝ່** ເພື່ອຍິງຄືນໃໝ່. ຄໍາແນະນໍາສະຫຼຸບການອ່ານ.

![ຕື່ມ — odometer OCR ຜົນ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a> ໂໝດປ້ຳ (ລາຄາ ແລະ ປະລິມານ)

1. ແຕະ **↕** ເພື່ອສະຫຼັບໄປໂໝດປັ໊ມ: *ແນມໃສ່ໜ້າຈໍປ້ຳ (ລາຄາ/ປະລິມານ). ແຕະ shutter.*
2. ຈັບຈຳນວນປ້ຳ. ຊ່ອງຂໍ້ມູນຄ່າໃຊ້ຈ່າຍແລະປະລິມານ; ໃຊ້ **↔** ຖ້າພວກມັນຖືກແລກປ່ຽນ.
3. ແຕະສະກຸນເງິນ ຫຼື **G/L** ຖ້າຕ້ອງການ, ຈາກນັ້ນ **ບັນທຶກ** (ແຜ່ນ). ຊ່ອງຫວ່າງເປົ່າເຮັດໃຫ້ **ການຕື່ມບາງສ່ວນ** (ຍັງອະນຸຍາດຢູ່).

![ຕື່ມ — ຕົວຢ່າງ pump preview / totals (ຕົວຢ່າງຮູບ pump in preview)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

ເຈົ້າຢູ່ Fill ເພື່ອຢຸດຕໍ່ໄປ (ຊ່ອງຂໍ້ມູນຈະແຈ້ງຫຼັງຈາກບັນທຶກ). ເຮັດວຽກຢ່າງເຕັມທີ່ **ອອຟໄລ**; sync ແລ່ນຕໍ່ມາໃນພື້ນຫຼັງເມື່ອຕັ້ງຄ່າ.

### <a id="manual-entry-no-camera--bad-ocr"></a> ຄູ່ມືເຂົ້າ (ບໍ່ມີກ້ອງຖ່າຍຮູບ / OCR ບໍ່ດີ)

1. ແຕະ **Odo**, **ຄ່າໃຊ້ຈ່າຍ**, ຫຼື **ປະລິມານ** ແລະຄ່າພິມ (ຮູບຄົນໃຊ້ແປ້ນພິມລະບົບ; ລວງນອນໃຊ້ປຸ່ມກົດເທິງໜ້າຈໍ).
2. ເລືອກ ຫຼືຢືນຢັນ **ຍານພາຫະນະ** ຖ້າກວດພົບອັດຕະໂນມັດບໍ່ໄດ້ແລ່ນ.
3. ບັນທຶກຕາມຂ້າງເທິງ.

### <a id="modes-and-borders"></a> ໂໝດ ແລະ ຂອບ

- **ຂອບສີຂຽວ** ຮອບລົດ+odo → ຈັບ/ແກ້ໄຂ odometer.
- **ຂອບສີຂຽວ** ປະມານລາຄາ+ປະລິມານ → ໂໝດສູບ.
- **Save** ຖືກປິດໄວ້ຈົນກວ່າຈະເລືອກຍານພາຫະນະ ແລະຢ່າງໜ້ອຍໜຶ່ງໃນ odo/cost/volume ມີຂໍ້ມູນ, ແລະ OCR ຍັງບໍ່ແລ່ນຢູ່.

ປາຍໜ້າຈໍ (ຢູ່ລຸ່ມເສັ້ນຄຳແນະນຳ): *Shutter = capture · Disk = save · ↕ = odo/pump mode · ↔ = swap cost/volume.*

## <a id="expenses"></a> ລາຍຈ່າຍ

### <a id="new-expense"></a> ລາຍຈ່າຍໃໝ່

ເມນູ → **ລາຍຈ່າຍໃໝ່**.

![ຮູບແບບຄ່າໃຊ້ຈ່າຍໃໝ່ ແລະການຄວບຄຸມກ້ອງຖ່າຍຮູບ (ຕົວຢ່າງຮູບ dash ໃນແຖບກ້ອງຖ່າຍຮູບເມື່ອຫວ່າງ)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r6-new-expense.jpg)

1. **ບັນທຶກ** (ແຜ່ນ), ** shutter** (ຮູບໃບຮັບເງິນ), ຫຼື **ຄັງຮູບ** (ເລືອກຮູບ).
2. ຕື່ມຂໍ້ມູນໃສ່ **ວັນທີ**, **ພາຫະນະ**, **ຜູ້ຂາຍ**, **ລາຍລະອຽດ**, **ຈຳນວນເງິນ** (ສັນຍາລັກສະກຸນເງິນສາມາດແຕະໄດ້), **ໝວດໝູ່**, ທາງເລືອກ **ເຄື່ອງວັດແທກຄວາມໄວ**.
3. ໃບຮັບເງິນຫຼາຍໜ້າ: ບັນທຶກໜ້າເພີ່ມເຕີມຖ້າ UI ສະເໜີໜ້າທີ່ໃຫ້ (ໜ້າ 0 ແມ່ນໃບຮັບເງິນຫຼັກ).
4. **ບັນທຶກ** ເພື່ອເກັບຮັກສາ (ທ້ອງຖິ່ນທຳອິດ; ການສຳຮອງຂໍ້ມູນຮູບພາບ ແລະ ການຊິງຄ໌ສະເປຣດຊີດຈະເກີດຂຶ້ນໃນພື້ນຫຼັງເມື່ອມີການກຳນົດຄ່າ).

### <a id="expense-list"></a> ລາຍການລາຍຈ່າຍ

ເມນູ → **ບົດລາຍງານ** → **ລາຍການຄ່າໃຊ້ຈ່າຍ** — ເບິ່ງຄ່າໃຊ້ຈ່າຍທີ່ບໍ່ແມ່ນນໍ້າມັນ; ເປີດລາຍການເພື່ອແກ້ໄຂ.

![ລາຍການຄ່າໃຊ້ຈ່າຍ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/05-expense-list.jpg)

### <a id="edit-expense"></a> ແກ້ໄຂຄ່າໃຊ້ຈ່າຍ

ເປີດແຖວຈາກລາຍຊື່. ຜູ້ຂາຍທີ່ຖືກຕ້ອງ, ຈໍານວນ, ປະເພດ, ຍານພາຫະນະ, ແລະຄໍາອະທິບາຍ. ຖ້າໃບຮັບເງິນພຽງແຕ່ຢູ່ໃນການສໍາຮອງຮູບ (ບໍ່ມີໄຟລ໌ທ້ອງຖິ່ນທີ່ສາມາດອ່ານໄດ້), ໃຫ້ໃຊ້ ** ດຶງຮູບພາບຈາກແຟ້ມຈັດເກັບ ** ເມື່ອສະແດງ (ໃຊ້ໄດ້ທົ່ວຈຸດຫມາຍປາຍທາງຮູບພາບທີ່ກໍານົດ).

![ແກ້ໄຂຄ່າໃຊ້ຈ່າຍ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/expense-edit.jpg)

## <a id="start-trip"></a> ເລີ່ມເດີນທາງ

ເມນູ → **ເລີ່ມຕົ້ນການເດີນທາງ** (ຫຼັງຈາກຕື່ມໃສ່ໃນລິ້ນຊັກ). ຈັບ​ຫຼື​ໃສ່ odometer​, ເລືອກ​ປະ​ເພດ​ການ​ເດີນ​ທາງ​, ຊ່ວຍ​ປະ​ຢັດ​ດ້ວຍ **disk ** icon​. **Stop** ເປັນ​ທາງ​ລັດ​ສໍາ​ລັບ​ສ່ວນ​ບຸກ​ຄົນ​ໃນ​ປັດ​ຈຸ​ບັນ​ຢູ່​ໃນ​ສະ​ຖານ​ທີ່ GPS ຖື​. ໃຊ້ **ⓘ** ເພື່ອຄວບຄຸມການແຈ້ງເຕືອນ.

![ເລີ່ມການເດີນທາງ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/start-trip.jpg)

ການ​ເລີ່ມ​ຕົ້ນ​ຂອງ​ການ​ເດີນ​ທາງ​ແມ່ນ​ເກັບ​ໄວ້​ເປັນ​ແຖວ​ເຊື້ອ​ໄຟ​ທີ່​ມີ **Trip Type** (ບໍ່​ແມ່ນ​ການ​ເຕີມ​ປົກ​ກະ​ຕິ​)​. ພວກມັນປາກົດຢູ່ພາຍໃຕ້ **ບົດລາຍງານ → ໄມລ໌ການເດີນທາງ**, ບໍ່ຢູ່ພາຍໃຕ້ປະຫວັດນໍ້າມັນເຊື້ອໄຟ.

## <a id="reports"></a> ລາຍງານ

ເມນູ → **ບົດລາຍງານ** ເປີດສູນຜະລິດຕະພັນ (ສະຫຼຸບຕະຫຼອດເວລາ + ບັດລາຍການ). ນີ້ແມ່ນບົດລາຍງານຜະລິດຕະພັນດຽວ - ບໍ່ມີລາຍການ "ບົດລາຍງານແລະຕາຕະລາງ" ແຍກຕ່າງຫາກ.

![ສູນລາຍງານ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/06-reports.jpg)

ເປີດບັດສຳລັບໂໝດພາຫະນະ (**ທັງໝົດ/ແຕ່ລະອັນ/ດຽວ**), ການກັ່ນຕອງໄລຍະເວລາ, ຕາຕະລາງ, ແລະແບ່ງປັນ (**TEXT / CSV / PDF**). ແຖບເທິງສຸດໃນລາຍງານເດັກນ້ອຍ: **☰ + ←** (ແລະ **ⓘ** ເມື່ອລົງທະບຽນ).

### <a id="time-based-reports"></a> ບົດລາຍງານຕາມເວລາ

ບັດຕາຕະລາງຫຼັກ. ຕົວວັດແທກທາງເລືອກ (mpg, ປະລິມານ/ໄລຍະທາງເຊັ່ນ: G/mi, ລາຄາຕໍ່ຫົວໜ່ວຍເຊັ່ນ $/G, ລາຄາ/ໄລຍະທາງ, ປະຈໍາເດືອນ $, ການເດີນທາງໄມລ໌, ການເດີນທາງ % ຕາມປະເພດ) ດ້ວຍຖັງຂີ້ເຫຍື້ອ **Smooth** ແລະ **ເຄື່ອງວັດແທກ Y ເອກະລາດ** (ເສດຖະກິດຊ້າຍ; ເງິນ ແລະຄອບຄົວເດີນທາງຢູ່ເບື້ອງຂວາ).

![ລາຍງານຕາມເວລາ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports.jpg)

![ການ​ລາຍ​ງານ​ຕາມ​ເວ​ລາ — metrics ເລື່ອນ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports-scrolled.jpg)

ລາຍລະອຽດຂອງຄະນິດສາດເສດຖະກິດ: [REPORTS_METRICS.md](reference/REPORTS_METRICS.md).

### <a id="fill-history-vs-fuel-history"></a> ເຕີມປະຫວັດສາດ vs ປະຫວັດນໍ້າມັນເຊື້ອໄຟ

- **ບົດລາຍງານ → ປະຫວັດການຕື່ມ** — ການຕື່ມຂໍ້ມູນຕາມລຳດັບສຳລັບຕົວກອງບົດລາຍງານ (**ຕື່ມຂໍ້ມູນເທົ່ານັ້ນ**; ບໍ່ມີການເດີນທາງເລີ່ມຕົ້ນ).

![ຕື່ມບົດລາຍງານປະຫວັດ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fill-history.jpg)

- **ປະຫວັດນໍ້າມັນເຊື້ອໄຟ** (ຖ້າມີຢູ່ໃນການນໍາທາງຂອງການກໍ່ສ້າງຂອງທ່ານ) — ສິນຄ້າຄົງຄັງເຕີມເຕັມຕໍ່ຍານພາຫະນະ, ຍັງຕື່ມພຽງແຕ່; ແຕະແຖວເພື່ອແກ້ໄຂ.

### <a id="trip-miles"></a> ໄລຍະທາງ

**ການ​ລາຍ​ງານ → ໄມ​ລ໌​ການ​ເດີນ​ທາງ** — ໄມ​ຕາມ​ປະ​ເພດ​, ຕາ​ຕະ​ລາງ​, ແລະ chronological ** ລາຍ​ການ​ເລີ່ມ​ຕົ້ນ / segment **​. ແຕະຈຸດເລີ່ມຕົ້ນທີ່ແທ້ຈິງເພື່ອເປີດ **ແກ້ໄຂຕື່ມ** ສໍາລັບແຖວນັ້ນ.

![ການເດີນທາງໄມລ໌](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a> ແກ້ໄຂຕື່ມ

ຈາກປະຫວັດການຕື່ມ, ປະຫວັດນໍ້າມັນເຊື້ອໄຟ, ຫຼືໄມລ໌ການເດີນທາງ, ເປີດການຕື່ມຂໍ້ມູນ. ຮູບ​ແບບ​: ຍານ​ພາ​ຫະ​ນະ​ແລະ odometer​, ** ສະ​ກຸນ​ເງິນ​ກ່ອນ​ຄ່າ​ໃຊ້​ຈ່າຍ **​, ປະ​ລິ​ມານ​ການ​, ຫມາຍ​ເຫດ​. ປະເພດການເດີນທາງຈະປາກົດເມື່ອແຖວເປັນການເດີນທາງເລີ່ມຕົ້ນເທົ່ານັ້ນ. ສະຖານທີ່ມີສະຫຼຸບບວກກັບ **ລາຍລະອຽດສະຖານທີ່**. ບໍ່ມີຮູບພາບທ້ອງຖິ່ນທີ່ມີເອກະລັກຄລາວ: **ເອົາຮູບຈາກແຟ້ມຈັດເກັບ**.

![ແກ້​ໄຂ​ຕື່ມ — ເອົາ​ຈາກ​ແຟ້ມ​ຈັດ​ເກັບ​ໃນ​ເວ​ລາ​ທີ່​ຮູບ​ພາບ​ທີ່​ຂາດ​ຫາຍ​ໄປ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg​)

​ບັດ​ລາຍ​ການ​ອື່ນໆ​ລວມ​ມີ​ລາຍ​ຈ່າຍ​ຕາມ​ປະ​ເພດ​, ສະ​ຫຼຸບ​ພາ​ຫະ​ນະ​, ແລະ​ບັນ​ຊີ​ລາຍ​ການ​ລາຍ​ຈ່າຍ​.

ເງິນໃຊ້ສະກຸນເງິນແຕ່ລະແຖວເມື່ອຕັ້ງ. ຈໍານວນລວມສະກຸນເງິນແບບປະສົມສະແດງ **ຜົນລວມຍ່ອຍຕໍ່ສະກຸນເງິນ** (ບໍ່ມີການແປງ FX ງຽບ).

## <a id="syncing"></a>ກຳລັງຊິງຄ໌

ເມ​ນູ → **ການ​ຊິງ​ຄ໌** ເປັນ​ສູນ​ກາງ​ສໍາ​ລັບ​ສະ​ເປ​ຣດ​ຊີດ​ແລະ​ຈຸດ​ຫມາຍ​ປາຍ​ທາງ​ຮູບ​ພາບ (ບໍ່​ພຽງ​ແຕ່​ຝັງ​ຢູ່​ໃນ​ການ​ຕັ້ງ​ຄ່າ​)​.

![ສູນການຊິງຄ໌](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- ບັດ​ສໍາ​ລັບ **Spreadsheet sync** ແລະ **ການ​ສໍາ​ຮອງ​ຮູບ​ພາບ** ທີ່​ມີ​ສະ​ຖາ​ນະ​ພາບ​ສັ້ນ, **Sync** ສໍາ​ລັບ​ການ​ປະ​ເພດ​ນັ້ນ, ແລະ **›** ເຂົ້າ​ໄປ​ໃນ​ບັນ​ຊີ​ລາຍ​ການ​ຈຸດ​ຫມາຍ​ປາຍ​ທາງ.
- ເປີດ​ຈຸດ​ຫມາຍ​ປາຍ​ທາງ​ສໍາ​ລັບ **ການ​ເຊື່ອມ​ຕໍ່​ການ​ທົດ​ສອບ** ແລະ **Sync ໃນ​ປັດ​ຈຸ​ບັນ (ຈຸດ​ຫມາຍ​ປາຍ​ທາງ​ນີ້​)** / ການ​ຕັ້ງ​ຄ່າ​ທັງ​ຫມົດ​.
- ຄວາມລົ້ມເຫຼວ **ລາຍລະອຽດ** ແລະສີແດງ**!** ຢູ່ໃນຫົວຂໍ້ທີ່ດິນ ທີ່ນີ້.
- ການຕັ້ງຄ່າ Google Sheets ແລະ Drive ແບບເທື່ອລະຂັ້ນຕອນ: [ການສຳຮອງຂໍ້ມູນ ແລະ ການຊິ້ງຂໍ້ມູນຫຼາຍອຸປະກອນ](#backups-and-multi-device-sync).

ເມນູ → **ການຕັ້ງຄ່າ**.

### <a id="local-preferences-common"></a> ຄວາມມັກທ້ອງຖິ່ນ (ທົ່ວໄປ)

- **ບັນທຶກຮູບໃບຮັບນໍ້າມັນເຊື້ອໄຟ** / **ບັນທຶກຄ່າໃຊ້ຈ່າຍໃນພື້ນທີ່** — ເກັບຮັກສາຮູບພາບໄວ້ໃນອຸປະກອນ (ອາດຈະຂໍອະນຸຍາດຮູບພາບ).
- **ຫຼິ້ນສຽງຊັດເຕີ**
- **ສະກຸນເງິນ** / ** ໜ່ວຍປະລິມານ** — ແອັບເປັນຄ່າເລີ່ມຕົ້ນ (ລະບົບ ຫຼື ຈະແຈ້ງ). ການປ່ຽນຫົວໜ່ວຍປະລິມານກັບຂໍ້ມູນນໍ້າມັນເຊື້ອໄຟທີ່ມີຢູ່ນັ້ນອາດຈະສະເໜີກ່ອງໂຕ້ຕອບການແປງ.
- **ໂໝດມືດ**
- **ເຄັດ​ລັບ​ການ​ຕັ້ງ​ຄ່າ** — ເປີດ​ຄືນ​ໃຫມ່​ການ​ສອນ​ຍານ​ພາ​ຫະ​ນະ / ການ​ຊິ້ງ​ຄັ້ງ​ທໍາ​ອິດ​.
- **Debug Fill** / **ສະແດງໜ້າຈໍທົດລອງ (dev)** — ຂັ້ນສູງ; ປະ​ໄວ້​ສໍາ​ລັບ​ການ​ນໍາ​ໃຊ້​ປະ​ຈໍາ​ວັນ​. ໜ້າຈໍການທົດລອງບໍ່ໄດ້ຖືກບັນທຶກຢູ່ທີ່ນີ້.

CSV **ການສົ່ງອອກ/ນໍາເຂົ້າ** (ZIP ຂອງຍານພາຫະນະ / ຄ່າໃຊ້ຈ່າຍ / ແຖບນໍ້າມັນເຊື້ອໄຟ) ສາມາດໃຊ້ໄດ້ຈາກການຕັ້ງຄ່າເມື່ອສະເຫນີໂດຍການກໍ່ສ້າງໃນປະຈຸບັນ.
