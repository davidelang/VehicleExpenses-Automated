## <a id="first-time-setup-manage-vehicles"></a> ติดตั้งครั้งแรก: จัดการยานพาหนะ

OCR และ **การจับคู่รถอัตโนมัติ** ทำงานได้ดีที่สุดหลังจากที่คุณลงทะเบียนรถแต่ละคันด้วย **ภาพถ่ายแดชบอร์ดอ้างอิง** วิ่ง **การค้นพบ** ตั้งค่าครอบตัดมาตรวัดระยะทางจากเมล็ดพาย และบันทึกจุดสังเกตสำหรับแผงหน้าปัดนั้น

### <a id="open-manage-vehicles"></a>เปิดจัดการยานพาหนะ

เมนู → **จัดการยานพาหนะ** เลือกยานพาหนะ (หรือ **เพิ่มยานพาหนะใหม่**)

![จัดการยานพาหนะด้วยเส้นประอ้างอิง พืชผล และการค้นพบ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r1-manage-vehicles-crops.jpg)

### <a id="add-or-edit-a-vehicle"></a>เพิ่มหรือแก้ไขยานพาหนะ

1. เปิดเมนูแบบเลื่อนลง **ยานพาหนะ** → เลือกยานพาหนะ หรือ **เพิ่มยานพาหนะใหม่**
2. จับภาพหรือเลือก **ภาพถ่ายแผงหน้าปัดอ้างอิง** ที่ชัดเจน (แผงหน้าปัดเต็ม มีแสงสว่างเพียงพอ โทรศัพท์วางค่อนข้างตรง) ใช้ **ถ่ายภาพ** หรือ **แกลเลอรี**
3. แตะ **เรียกใช้การค้นพบ** — การตรวจจับไม้พายทำให้ **เมล็ดพืช** สีเหลืองบนรูปภาพ (จุดสังเกตใช้ `"ML Kit"` JSON เหมือนเดิม)
4. แตะ **เลือก Odo** แตะเมล็ดบนตัวเลข ปรับแฮนเดิล จากนั้น **บันทึก**
5. **Edit Odo** ปรับกล่องที่มีอยู่แล้ว **Clear Odo** จะลบออก จากนั้นปุ่มจะอ่านว่า **เลือก Odo**
6. รีวิวด้วย **แสดงจุดสังเกต** ใช้ **แก้ไข OCR** ​​เพื่อแก้ไขการอ่านผิดหรือ **เพิ่ม** ข้อความที่พลาด
7. กรอก **ชื่อยานพาหนะ** (จำเป็น) พร้อมยี่ห้อ/รุ่น/ปี/ป้ายทะเบียน ตามที่คุณต้องการ
8. แตะ **สร้างยานพาหนะ** หรือ **บันทึกการเปลี่ยนแปลง** (ต้องมีชื่อ + ภาพถ่ายอ้างอิงสำหรับยานพาหนะใหม่)

![เพิ่มช่องแบบฟอร์มยานพาหนะใหม่](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/03b-manage-vehicles-new.jpg)

### <a id="landmarks-fix-what-discovery-missed"></a>จุดสังเกต: แก้ไขสิ่งที่ Discovery พลาดไป

หลังจาก **แสดงจุดสังเกต** ให้เลื่อนรายการและแก้ไขค่าให้ถูกต้อง บางครั้งเครื่องยนต์อาจพลาดตัวเลขเล็กๆ (เช่น นาฬิกา **60** ที่มุมขวาล่างของคลัสเตอร์) ใช้ **แก้ไข OCR** ​​เพื่อเพิ่มหรือแก้ไขเพื่อให้ข้อมูลประจำตัวของยานพาหนะมีความน่าเชื่อถือ

![กล่องโต้ตอบจุดสังเกต — ตรวจสอบและแก้ไข OCR](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r2-manage-vehicles-landmarks.jpg)

### <a id="typing-without-a-perfect-photo"></a>พิมพ์โดยไม่มีภาพที่สมบูรณ์แบบ

คุณยังคงสามารถใช้แอปได้โดยเลือกยานพาหนะและ **พิมพ์** มาตรวัดระยะทาง ปริมาณ และค่าใช้จ่ายในการเติม — OCR เป็นตัวเลือกสำหรับทุกฟิลด์ การนำเข้าแกลเลอรีใช้ได้กับรูปภาพประอ้างอิงเมื่อคุณไม่ต้องการถ่ายภาพในแอป

**เคล็ดลับ:** หลังจากการซิงค์สเปรดชีต คำจำกัดความของยานพาหนะ (พืชผล จุดสังเกต) จะอยู่ในฐานข้อมูลท้องถิ่น คุณไม่จำเป็นต้องเปิด Manage Vehicles for Fill อีกครั้งเพื่อใช้งาน

## <a id="backups-and-multi-device-sync"></a>สำรองข้อมูลและการซิงค์หลายอุปกรณ์

แอปนี้สร้างขึ้นเพื่อให้ **โทรศัพท์หรือแท็บเล็ตหลายเครื่องสามารถแชร์ข้อมูลกลุ่มยานพาหนะเดียวกัน** และเพื่อให้คุณสามารถเก็บ **สำเนาข้อมูลและรูปภาพของคุณไว้นอกอุปกรณ์** ซึ่งทำได้กับปลายทาง **คุณ** กำหนดค่าภายใต้บัญชี **ของคุณ** หรือ **ของคุณ** เซิร์ฟเวอร์ที่โฮสต์เอง — ไม่ใช่ “ระบบคลาวด์ค่าใช้จ่ายยานพาหนะ” ที่ดำเนินการโดยบริษัทที่บุคคลอื่นสามารถเห็นได้

### <a id="what-runs-where"></a>อะไรวิ่งไปไหน

| ชนิด | มันเก็บอะไร | การใช้งานทั่วไป |
|-|----------------|-------------|
| **สเปรดชีต / การซิงค์แบบตาราง** | ยานพาหนะ, การเติมน้ำมัน, ค่าใช้จ่าย (แถวและแท็บ) | การรวมอุปกรณ์หลายเครื่อง + การสำรองข้อมูลแบบมีโครงสร้าง |
| **สำรองรูปภาพ** | รูปภาพไบนารี (เส้นประ/ปั๊ม/ใบเสร็จรับเงิน/ภาพถ่ายอ้างอิง) | สำรองรูปภาพ + กู้คืนไฟล์ที่หายไป |

คุณสามารถกำหนดค่า **หลายปลายทาง** ของแต่ละประเภทได้ (soft cap ต่อประเภท) ผู้ปฏิบัติงาน **ซิงค์ทันที** และ **พื้นหลัง** ด้วยตนเองจะเรียกใช้งานที่เปิดใช้งาน

### <a id="offline-first"></a>ออฟไลน์ก่อน

- **ไม่ต้องใช้เครือข่าย** เพื่อเพิ่มการเติม ค่าใช้จ่าย หรือใบเสร็จรับเงิน ทุกอย่างจะถูกบันทึก **ในเครื่องก่อน**
- เมื่อเครือข่ายพร้อมใช้งาน การซิงค์และการสำรองข้อมูลรูปภาพจะทำงานเป็น **งานพื้นหลัง** (ตามกำหนดเวลาที่คุณตั้งไว้ และเมื่อคุณแตะ **ซิงค์ทันที**) ความล้มเหลวแสดงเป็นข้อความสีแดงใต้แถวการตั้งค่าและ **!** ในแถบชื่อแอป

### <a id="your-accounts-only"></a> บัญชีของคุณเท่านั้น

การลงชื่อเข้าใช้และโทเค็นจะยังคงอยู่ในอุปกรณ์สำหรับผู้ให้บริการที่คุณเลือก (Google, Microsoft, คีย์ S3, URL ที่โฮสต์ด้วยตนเอง และอื่นๆ) ปลายทางอยู่ภายใต้ **การควบคุมโดยสมบูรณ์ของผู้ใช้** — บัญชี Google ของคุณ, OneDrive ของคุณ, บัคเก็ต MiniIO ของคุณ, โฮสต์ EtherCalc ของคุณ ฯลฯ ไม่มีการแบ่งปันกับผู้ใช้ Vehicle Expenses รายอื่นผ่านแบ็กเอนด์ที่แชร์

### <a id="supported-targets--data-spreadsheet--tabular"></a>เป้าหมายที่สนับสนุน — ข้อมูล (สเปรดชีต / ตาราง)

กำหนดค่าภายใต้ **เมนู → การซิงค์ → การซิงค์สเปรดชีต** (สามารถเข้าถึงได้จากแถวสรุปการตั้งค่า) ตัวเลือกตัวเลือกชั้นหนึ่ง:

| เป้าหมาย | หมายเหตุ |
|--------|--------|
| **กูเกิลชีต** | ค่าเริ่มต้นทั่วไป แท็บสำหรับยานพาหนะ ค่าใช้จ่าย และน้ำมันเชื้อเพลิงต่อคัน |
| **เอ็กเซล** | สมุดงาน Microsoft ผ่านการผูกแบบกราฟ / OneDrive |
| **อีเธอร์แคลมป์** | ห้องสเปรดชีตการทำงานร่วมกันที่โฮสต์ด้วยตนเอง |
| **อื่นๆ →** แบ็กเอนด์ที่ใช้งาน | **Baserow**, **NocoDB**, **Airtable**, **PocketBase**, **Supabase**, **Firebase**, **Zoho Sheet** |

เลื่อนออกไป / ยังไม่ไม่มีหัว (แสดงอยู่ในรายการอื่น ๆ แต่ยังไม่ได้นำไปใช้อย่างสมบูรณ์): OnlyOffice, Collabora ดูเพิ่มเติมที่ [ดัชนีโฮสต์ตนเอง](reference/self-host/INDEX.md)

CSV **ส่งออก/นำเข้า** (ZIP ของรูปแบบแท็บเดียวกัน) พร้อมใช้งานจากการตั้งค่าเป็นข้อมูลสำรองแบบพกพา โดยไม่ขึ้นอยู่กับไลฟ์ซิงค์

### <a id="supported-targets--photos-image-backup"></a>เป้าหมายที่รองรับ — รูปภาพ (สำรองรูปภาพ)

กำหนดค่าภายใต้ **เมนู → การซิงค์ → การสำรองข้อมูลรูปภาพ** (รวมถึงจากแถวสรุปการตั้งค่าด้วย):

| เป้าหมาย | หมายเหตุ |
|--------|--------|
| **กูเกิ้ลไดรฟ์** | โฟลเดอร์ที่คุณเลือก (เรียกดูหรือวาง URL) |
| **วันไดรฟ์** | บัญชี Microsoft + คำนำหน้าเส้นทาง |
| **S3** | AWS, Wasabi, Cloudflare R2, MiniIO และตำแหน่งข้อมูลอื่นๆ ที่เข้ากันได้กับ S3 |
| **อื่นๆ** | พื้นที่เก็บข้อมูลที่สนับสนุน rclone (เช่น WebDAV, SFTP และรีโมตที่ได้รับการดูแลจัดการอื่น ๆ ที่มีอยู่ในเครื่องมือเลือกในแอป) |

ตั้งค่าเอกสารสรุปสำหรับรูปภาพที่โฮสต์เองและเป้าหมายแบบตาราง: [ดัชนีโฮสต์ด้วยตนเอง](reference/self-host/INDEX.md)

### <a id="multi-device-behavior-short"></a>พฤติกรรมหลายอุปกรณ์ (สั้น)

- แถวผสานโดย **Sync ID** พร้อมด้วย **last-write-wins** บน **Updated** timestamps
- การลบแบบนุ่มนวล การแก้ไขที่ใหม่กว่าบนอุปกรณ์อื่นสามารถกู้คืนแถวได้
- การป้อน **การเติมเดียวกันสองครั้ง** บนอุปกรณ์สองเครื่องจะสร้าง **สองแถว** — ลบส่วนเกินออกเมื่อคุณสังเกตเห็น
- รายละเอียดเพิ่มเติม: [บันทึกพฤติกรรมการซิงค์](#sync-behavior-notes) และ [SYNC_BEHAVIOR.md](reference/SYNC_BEHAVIOR.md)

- ความล้มเหลว: สรุปสีแดงเกี่ยวกับการซิงค์การ์ด + **!** ในแถบแอป

## <a id="fill-up-fuel"></a>เติม (น้ำมันเชื้อเพลิง)

นี่คือ **หน้าจอหลัก** เมื่อคุณเปิดแอป

### <a id="vehicle-selection-usually-automatic"></a>การเลือกยานพาหนะ (โดยปกติจะเป็นแบบอัตโนมัติ)

คุณ **ไม่** ต้องเลือกรถก่อน เมื่อยานพาหนะมี **จุดสังเกต** ตั้งค่าไว้ในจัดการยานพาหนะ ให้เติม **ตรวจจับอัตโนมัติว่ารถคันไหน** จากภาพแผงหน้าปัดหลังจากที่คุณบันทึกมาตรวัดระยะทาง คุณยังคงเปิดเมนูแบบเลื่อนลง **ยานพาหนะ** เพื่อแทนที่ได้หากจำเป็น

### <a id="aim-at-the-odometer"></a>เล็งไปที่มาตรวัดระยะทาง

อยู่ในโหมดมาตรวัดระยะทางและจัดเฟรมคลัสเตอร์ คำแนะนำ: *เล็งไปที่มาตรวัดระยะทาง แตะชัตเตอร์เพื่อถ่ายภาพ*

![เติม — กล้องถ่ายทอดสดบนมาตรวัดระยะทาง (ตัวอย่างภาพแผงหน้าปัดในหน้าตัวอย่าง)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r3-fill-odo-live.jpg)

### <a id="after-the-odometer-shutter"></a>หลังชัตเตอร์วัดระยะทาง

OCR เติม **Odo** และพยายามจับคู่รถจากจุดสังเกต (ตรวจสอบทั้งสองอย่างหากจำเป็น) ปุ่มหลักจะกลายเป็น **ลองอีกครั้ง** เพื่อถ่ายภาพใหม่ คำสั่งสรุปการอ่าน

![กรอก — ผล OCR มาตรวัดระยะทาง](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r4-fill-odo-result.jpg)

### <a id="pump-mode-cost-and-volume"></a>โหมดปั๊ม (ต้นทุนและปริมาณ)

1. แตะ **↕** เพื่อสลับไปที่โหมดปั๊ม: *เล็งไปที่การแสดงปั๊ม (ราคา/ปริมาณ) แตะชัตเตอร์*
2. จับยอดรวมปั๊ม กรอกฟิลด์ต้นทุนและปริมาณ ใช้ **↔** หากมีการสลับ
3. แตะสกุลเงินหรือ **G/L** หากจำเป็น จากนั้น **บันทึก** (ดิสก์) ช่องที่ว่างให้ **เติมบางส่วน** (ยังอนุญาตอยู่)

![กรอก — ดูตัวอย่างปั๊ม / ผลรวม (ตัวอย่างภาพปั๊มในหน้าตัวอย่าง)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/r5-fill-pump-result.jpg)

คุณจะอยู่ในสถานะเติมเพื่อไปยังจุดถัดไป (ช่องจะถูกล้างหลังจากบันทึก) ทำงานอย่างเต็มที่ **ออฟไลน์**; การซิงค์จะทำงานในภายหลังในพื้นหลังเมื่อกำหนดค่า

### <a id="manual-entry-no-camera--bad-ocr"></a> รายการด้วยตนเอง (ไม่มีกล้อง / OCR ไม่ดี)

1. แตะ **Odo**, **ต้นทุน** หรือ **ระดับเสียง** และค่าประเภท (แนวตั้งใช้แป้นพิมพ์ของระบบ แนวนอนใช้แป้นพิมพ์บนหน้าจอ)
2. เลือกหรือยืนยัน **ยานพาหนะ** หากไม่ได้ทำงานการตรวจจับอัตโนมัติ
3. บันทึกตามด้านบน.

### <a id="modes-and-borders"></a>โหมดและเส้นขอบ

- **ขอบสีเขียว** รอบรถ+โอโด → การจับภาพ/แก้ไขมาตรวัดระยะทาง
- **ขอบสีเขียว** บริเวณราคา+ปริมาณ → โหมดปั๊ม
- **บันทึก** จะยังคงปิดใช้งานอยู่จนกว่าจะเลือกรถและมีข้อมูล odo/ต้นทุน/ปริมาณอย่างน้อยหนึ่งรายการ และ OCR ยังคงทำงานอยู่

เคล็ดลับบนหน้าจอ (ใต้บรรทัดคำสั่ง): *Shutter = capture · Disk = save · ↕ = odo/pump mode · ↔ = swap cost/volume.*

## <a id="reports"></a>รายงาน

เมนู → **รายงาน** เปิดศูนย์กลางผลิตภัณฑ์ (สรุปตลอดเวลา + การ์ดแค็ตตาล็อก) นี่เป็นเพียงพื้นผิวรายงานผลิตภัณฑ์เท่านั้น ไม่มีรายการลิ้นชัก "รายงานและแผนภูมิ" แยกต่างหาก

![ศูนย์กลางรายงาน](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/06-reports.jpg)

เปิดการ์ดสำหรับโหมดยานพาหนะ (**ทั้งหมด / แต่ละ / เดี่ยว**) ตัวกรองช่วงเวลา แผนภูมิ และแชร์ (**ข้อความ / CSV / PDF**) แถบด้านบนของรายการรายงาน: **☰ + ←** (และ **ⓘ** เมื่อลงทะเบียน)

### <a id="time-based-reports"></a> รายงานตามเวลา

การ์ดกราฟหลัก ตัวชี้วัดที่เป็นตัวเลือก (mpg, ปริมาตร/ระยะทาง เช่น G/mi, ราคาต่อหน่วย เช่น $/G, ราคา/ระยะทาง, $ รายเดือน, ไมล์การเดินทาง, % การเดินทางตามประเภท) พร้อมช่อง **เรียบ** และ **สเกล Y อิสระ** (เหลือเศรษฐกิจ, กลุ่มเงินและครอบครัวทางด้านขวา)

![รายงานตามเวลา](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports.jpg)

![รายงานตามเวลา — เมตริกแบบเลื่อน](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/time-based-reports-scrolled.jpg)

รายละเอียดคณิตศาสตร์เศรษฐศาสตร์: [REPORTS_METRICS.md](reference/REPORTS_METRICS.md)

### <a id="fill-history-vs-fuel-history"></a>เติมประวัติเทียบกับประวัติเชื้อเพลิง

- **รายงาน → ประวัติการเติม** — การเติมตามลำดับเวลาสำหรับตัวกรองรายงาน (**การเติมเท่านั้น**; ไม่มีการเริ่มต้นการเดินทาง)

![กรอกรายงานประวัติ](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fill-history.jpg)

- **ประวัติเชื้อเพลิง** (หากมีอยู่ในการนำทางของรุ่นของคุณ) — เติมสินค้าคงคลังต่อคัน และเติมเท่านั้น แตะแถวเพื่อแก้ไข

### <a id="trip-miles"></a> ไมล์ทริป

**รายงาน → ไมล์การเดินทาง** — ไมล์ตามประเภท แผนภูมิ และลำดับ **การเริ่มต้นการเดินทาง/รายการส่วน** แตะจุดเริ่มต้นจริงเพื่อเปิด **แก้ไขการเติม** สำหรับแถวนั้น

![ไมล์การเดินทาง](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/trip-miles.jpg)

### <a id="edit-fill"></a>แก้ไขการเติม

จากประวัติการเติม ประวัติเชื้อเพลิง หรือไมล์การเดินทาง ให้เปิดการเติม เค้าโครง: ยานพาหนะและมาตรวัดระยะทาง, **สกุลเงินก่อนต้นทุน**, ปริมาณ, หมายเหตุ ประเภทการเดินทางจะปรากฏเฉพาะเมื่อแถวเป็นการเดินทางเริ่มต้นเท่านั้น ที่ตั้งมีสรุปบวก **รายละเอียดสถานที่** รูปภาพในเครื่องที่หายไปซึ่งมีข้อมูลระบุตัวตนบนคลาวด์: **ดึงรูปภาพจากที่เก็บถาวร**

![แก้ไขการเติม — ดึงข้อมูลจากไฟล์เก็บถาวรเมื่อรูปภาพในเครื่องหายไป](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/fuel-edit.jpg)

การ์ดแค็ตตาล็อกอื่นๆ ได้แก่ ค่าใช้จ่ายตามหมวดหมู่ สรุปยานพาหนะ และรายการค่าใช้จ่าย

เงินจะใช้สกุลเงินของแต่ละแถวเมื่อตั้งค่า ผลรวมของสกุลเงินผสมจะแสดง **ผลรวมย่อยต่อสกุลเงิน** (ไม่มีการแปลง FX โดยไม่แจ้ง)

## <a id="syncing"></a> กำลังซิงค์

เมนู → **การซิงค์** เป็นศูนย์กลางสำหรับสเปรดชีตและปลายทางรูปภาพ (ไม่เพียงแต่ฝังอยู่ใต้การตั้งค่าเท่านั้น)

![ฮับการซิงค์](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/syncing-hub.jpg)

- การ์ดสำหรับ **การซิงค์สเปรดชีต** และ **การสำรองข้อมูลรูปภาพ** พร้อมสถานะแบบสั้น **การซิงค์** สำหรับประเภทนั้น และ **›** ลงในรายการปลายทาง
- เปิดปลายทางสำหรับ **ทดสอบการเชื่อมต่อ** และ **ซิงค์ทันที (ปลายทางนี้)** / กำหนดค่าทั้งหมด
- ความล้มเหลว **รายละเอียด** และสีแดง **!** ในแถบชื่อเรื่องปรากฏที่นี่
- การตั้งค่า Google ชีตและไดรฟ์แบบทีละขั้นตอน: [การสำรองข้อมูลและการซิงค์หลายอุปกรณ์](#backups-and-multi-device-sync)

## <a id="settings-local-preferences"></a>การตั้งค่า (การตั้งค่าท้องถิ่น)

เมนู → **การตั้งค่า**

![การตั้งค่า](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07-settings.jpg)

![การตั้งค่าเพิ่มเติม (เลื่อน)](https://raw.githubusercontent.com/davidelang/VehicleExpenses-Automated/master/docs/user-manual/images/07b-settings-more.jpg)

สำหรับจุดหมายปลายทาง ให้เลือก **เมนู → กำลังซิงค์** การตั้งค่าอาจยังคงแสดงแถวสรุปที่เปิดรายการเดียวกัน

### <a id="local-preferences-common"></a> การตั้งค่าท้องถิ่น (ทั่วไป)

- **บันทึกรูปภาพใบเสร็จรับเงินน้ำมันเชื้อเพลิง** / **บันทึกรูปภาพค่าใช้จ่ายในเครื่อง** — เก็บรูปภาพไว้ในอุปกรณ์ (อาจขออนุญาตใช้รูปภาพ)
- **เล่นเสียงชัตเตอร์**
- **สกุลเงิน** / **หน่วยปริมาณ** — ค่าเริ่มต้นของแอป (ระบบหรือชัดเจน) การเปลี่ยนหน่วยปริมาตรด้วยข้อมูลเชื้อเพลิงที่มีอยู่อาจมีกล่องโต้ตอบการแปลง
- **โหมดมืด**
- **เคล็ดลับการตั้งค่า** — เปิดบทช่วยสอนเกี่ยวกับรถยนต์คันแรก / การซิงค์อีกครั้ง
- **เติมการแก้ไขข้อบกพร่อง** / **แสดงหน้าจอการทดสอบ (dev)** — ขั้นสูง; ทิ้งไว้เพื่อใช้ในชีวิตประจำวัน หน้าจอการทดลองไม่ได้บันทึกไว้ที่นี่

CSV **ส่งออก/นำเข้า** (รหัสไปรษณีย์ของยานพาหนะ / ค่าใช้จ่าย / แท็บเชื้อเพลิง) สามารถใช้งานได้จากการตั้งค่าเมื่อนำเสนอโดยรุ่นปัจจุบัน
