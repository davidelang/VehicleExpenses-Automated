# Photo (image) self-host targets

These are used from **Settings → Photo backup**.

- **S3 tile:** MinIO and S3-compatible (set Endpoint).  
- **Other → Self-hosted / protocols:** WebDAV, SFTP, FTP, SMB, Seafile.

All store **JPEG (and similar) binaries** under a path prefix. Use **Test connection** after setup.
