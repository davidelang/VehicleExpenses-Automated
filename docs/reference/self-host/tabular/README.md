# Tabular (spreadsheet) self-host targets

These support **concurrent multi-writer** row/field (or collab sheet) models — not CSV file mirrors.

| Cheatsheet | In-app place |
|------------|----------------|
| [ethercalc.md](ethercalc.md) | Spreadsheet → **EtherCalc** (top tier) |
| [baserow.md](baserow.md) | Other → Row databases → **Baserow** |
| [nocodb.md](nocodb.md) | Other → Row databases → **NocoDB** |
| [airtable.md](airtable.md) | Other → Row databases → **Airtable** |
| [firebase.md](firebase.md) | Other → App backends → **Firebase** |
| [zoho-sheet.md](zoho-sheet.md) | Other → Collaborative → **Zoho Sheet** |
| [onlyoffice.md](onlyoffice.md) | Other → Collaborative (deferred) |
| [collabora.md](collabora.md) | Other → Collaborative (deferred) |
| [pocketbase.md](pocketbase.md) | Other → App backends → **PocketBase** |
| [supabase-selfhost.md](supabase-selfhost.md) | Other → App backends → **Supabase** |

App sync maps logical tabs **Vehicles**, **Expenses**, **Fuel - {name}** via `TabularSchema` and per-destination table id map in `configJson`.
