# User Manual

## Getting Started
1. Sign in with Google
2. Create or connect a Sheet
3. Add expenses/fuel normally
4. Tap "Sync Now" for instant two-way sync

## Background Sync
Enable in Settings → choose WiFi/charging/frequency.

Full guide: https://github.com/davidelang/VehicleExpenses-Automated/blob/master/docs/user-manual.md
