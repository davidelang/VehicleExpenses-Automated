# Vehicle Expenses Automated - User Guide (Offline First)

## Quick Start

When you first open the app, a **default vehicle** called **"My Vehicle"** is automatically created. You can start adding data **immediately** without any setup.

### 1. Add a Fuel Fill (Most Common Action)

1. From the home screen, tap **Fuel**
2. Select your vehicle (defaults to "My Vehicle")
3. Enter:
   - Date (defaults to today)
   - Gallons
   - Price per gallon
   - Odometer reading
   - Fuel type and notes (optional)
4. Tap **Save**

Your fillup is saved locally instantly.

### 2. Add an Expense

1. Tap **Expenses**
2. Select your vehicle
3. Enter:
   - Date
   - Amount
   - Category (Fuel, Maintenance, Insurance, Parking, etc.)
   - Description
4. Tap **Save**

### 3. Add Additional Vehicles

1. Tap **Vehicles** in the main menu
2. Tap the + button
3. Enter Make, Model, Year, and optional nickname
4. Save

### 4. View Reports & Analysis

- Go to **Dashboard** for overview and summaries
- Per-vehicle history shows all fillups and expenses
- Basic cost analysis (cost per mile, total spent, etc.)

### 5. Google Sheets Sync (Optional - Backup & Multi-Device)

1. Go to **Settings & Sync**
2. Sign in with your Google account
3. Enter or create a Google Sheet ID
4. Enable sync
5. Configure background sync options (WiFi only, charging only, frequency)
6. Tap **Sync Now** for immediate sync

All data remains on your device until you enable sync. Sync is two-way and fully optional.
