# Vehicle Expenses Automated
Android app for tracking vehicle expenses and fuel with **optional two-way Google Sheets sync** using your device's Google account.

## Features
- Local Room database
- Full bidirectional Google Sheets sync
- Configurable background periodic sync (WiFi/charging/frequency)
- Clean Material 3 UI
- **Camera-First Workflow**: Automated data entry via Multi-Engine OCR (ML Kit, Paddle-Lite, Hybrid).
- **Automated Vehicle Identification**: Uses an advanced Veto-based logic with a 1-vs-3+ Rescue Algorithm to match vehicles to dashboard photos.
- **Robust Image Alignment**: Features ORB and Anchor-Triangulation alignment for precise spatial mapping.
