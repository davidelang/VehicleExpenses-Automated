# Antigravity overlay

Law is `AGENT_MANDATES.md`. `GEMINI.md` is the project card (the same text as `AGENTS.md`). This file is the Antigravity tool note.

This is a native Android app. Web-stack defaults do not apply.

Tool names:

- `run_shell_command` is the shell
- `write_to_file` writes a file
- `replace_file_content` or `multi_replace_file_content` edits
- `invoke_subagent` is a subagent, and planning does not spawn one

There is no native plan-mode switch. Planning still means sandbox plans only. After compact, re-read the law on the next turn.
